# 第一章 金融市场与资产管理

本章两节：**金融市场**（概念、构成要素、分类、功能与地位）、**资产管理**（概念、发展现状、前景）。

---

## 1.1 金融市场

### 1.1.a 【掌握】金融市场的概念 P2

**大纲原文**：掌握金融市场的概念

**先看"市场"**：市场是买方（需求方）和卖方（供给方）在一定规则和机制下，进行商品或服务交换的**场所或过程**。核心是**供求关系**，供求决定价格和数量；价格变动引导资源流动，实现资源有效配置。

**金融市场（教材定义）**：资金供给方和资金需求方**通过金融工具等进行交易融通资金的场所**，是货币资金借贷、有价证券的发行与交易、期货和衍生品交易、外汇与黄金的买卖等所形成的**交易机制及其关系的总和**。

定义抓两段： **"场所" + "机制及其关系的总和"**。考概念题时，凡只说"场所"而不含"机制/关系"的表述是不完整的。

**定义里点名了四类活动**（记忆：借贷、证券、期货衍生品、外汇黄金）：

1. 货币资金借贷
2. 有价证券的发行与交易
3. 期货和衍生品交易
4. 外汇与黄金的买卖

易错：金融市场交易的对象是**资金（使用权）**，不是商品本身。资金融通的本质是**资金使用权的让渡**，不是所有权转移。

---

### 1.1.a+ 教材补充：金融市场的五大构成要素 P3–P6

> 大纲没有单列这一条，但它是"概念"的展开，也是历年高频考点，务必背下来。

**五大必备要素**：主体、客体、交易价格、交易方式、交易中介。

口诀： **"主客价式中"**（主体、客体、价格、方式、中介）。

#### （1）金融市场主体 P3–P4

即金融市场的**参与者**，包含资金供给方和资金需求方。

**按参与身份划分**：境内投资者（政府、中央银行、金融机构、非金融企业、个人）+ 境外投资者。

| 主体 | 角色定位 |
|---|---|
| **金融机构** | 多重角色：资金供给者、需求者、中间人；既发行创造金融工具，也购买金融工具；既是中介人，也是投资者、货币政策传递者与承受者 |
| **政府** | 主要资金需求方（发行政府债券融资），有时也是供给方（如发起创业投资引导基金）；也是套期保值主体 |
| **非金融企业** | 主要资金需求方（筹措生产经营资金），也把闲置资金投向金融市场；还是期货衍生品市场上套期保值对冲风险的主体 |
| **中央银行**|**特殊地位**：兼具"参与主体"与"市场监管者"双重身份。作为"银行的银行"通过再贴现提供再贷款→资金供给方；通过公开市场业务调节货币供应量；作为监管者承担制定货币政策、防范化解金融风险、维护金融稳定的宏观审慎监管职责 |
| **个人** | 主要资金供给方（谋求资产保值增值），有时通过消费信贷成为需求方 |
| **境外投资者** | 资金供给方。可通过 QFII（合格境外机构投资者）投资境内证券市场；也可通过沪港通、深港通投资上交所、深交所的 A 股和 ETF |

**按参与动机划分**（表 1-1，六类）：

| 主体类型 | 参与动机 |
|---|---|
| 筹资者 | 发行股票、债券等筹集资金，用于扩张、项目融资、偿债等；是**资金需求者** |
| 投资者 | 购买并持有股票、债券、基金，期望股息、利息或资产增值；通常是**资金供给者**，卖出时转为需求者 |
| 投机者 | 基于对走势的预测买卖，赚取**短期价格波动** 收益；可能供给也可能需求 |
| 套期保值者 | 持有与现货头寸**相反、价值变动大体相当** 的期货合约，降低或消除价格波动风险 |
| 套利者 | 利用**同一产品不同市场的价差**、不同期货合约间价差、期现不合理价差，反向交易或建立多空头寸，获取**无风险或低风险** 利润 |
| 调控监管者 | 中央银行及其他金融监管部门，制定法规规则、宏观调控、监管市场活动，防范系统性风险 |

**投机者 vs 套利者**：投机者赌**价格方向**（承担风险）；套利者赚**价差**（无风险/低风险）。这是选择题常设的干扰项。

#### （2）金融市场客体 P5

即资金融通或买卖交易的**载体或对象**，除金融工具外，还包括金融资产和金融产品。三个概念要分清：

| 概念 | 定义要点 |
|---|---|
| **金融工具**| 股票、债券、证券投资基金、期货合约、标准化期权合约等**标准化、可交易**的具体对象；是金融市场交易的**基础单元** |
| **金融资产**| 个人或机构持有的、以金融工具或其组合形式存在的资产；代表持有者**未来收益与合法权益** |
| **金融产品**| 为满足特定客户需求设计的**综合金融服务或金融工具的组合**，可含一个或多个金融工具（如证券投资基金 = 多种股票债券组成的投资组合） |

递进关系：工具（单元）→ 资产（持有形态）→ 产品（客户导向的组合）。

#### （3）金融市场交易价格 P5

即资金融通所支付的**对价**。不同客体的定价方式不同——这张表必须记住：

| 场景 | 定价方式 |
|---|---|
| 借贷关系 | 主要是**利率**；不违反法律法规时由**交易双方协商确定** |
| 证券集中竞价 | 按当事人报价，**价格优先、时间优先** 原则撮合成交 |
| 开放式基金**募集期间**| 按**基金份额面值** 认购 |
| 基金**申购、赎回**|**"未知价"原则**，以申请当日**收市后** 计算的基金份额净值为基准 |
| 上市交易基金 | 采用**限价申报或市价申报** 方式进行份额竞价交易 |
| 人民币汇率 | 以中国外汇交易中心公布的**汇率中间价** 适当上下浮动计价 |

多数金融工具到期时的**实际交易价格并不确定**，受市场行情波动影响。

#### （4）金融市场交易方式 P5

按交易的组织方式分两类：

| 方式 | 特征 | 典型 |
|---|---|---|
| **场内交易**| 有**固定场所**、有制度、**集中** 交易 | 交易所交易 |
| **场外交易**| 交易所之外，金融机构、销售机构**柜台**上买卖双方**面议**、**分散** 交易 | 银行间债券市场、代办股份转让系统、债券柜台交易市场 |

**十家交易所**（国务院批准或同意设立）：上交所、深交所、北交所、上海期货交易所、郑州商品交易所、大连商品交易所、广州期货交易所、中国金融期货交易所、全国中小企业股份转让系统（新三板）、上海黄金交易所。

记忆分组：**证券 3**（上交所、深交所、北交所）+**商品期货 4**（上海期货、郑州商品、大连商品、广州期货）+**金融期货 1**（中国金融期货交易所）+**其他 2**（全国股转系统/新三板、上海黄金交易所）=**10 家**。

另按交易频率可分为高频/低频交易，也可分为日内、短线、长线交易。

#### （5）金融市场交易中介 P6

如银行、证券公司、基金公司、保险公司、期货公司等，在融通资金中**连接资金供需双方**，发挥**桥梁和媒介**作用，提供资金融通渠道和服务。出于安全与规范考虑，一般需取得**金融业务许可或进行备案**。

### 1.1.b 【掌握】金融市场的分类 P6–P10

**大纲原文**：掌握金融市场的分类

四个划分维度（表 1-2）：

| 划分标准 | 子市场 |
|---|---|
| 按**交易标的物** | 货币市场、资本市场、外汇市场、期货和衍生品市场、黄金市场 |
| 按**融资方式** | 直接融资市场、间接融资市场 |
| 按**交割期限** | 现货市场、期货和衍生品市场 |
| 按**地域范围** | 国内金融市场、国际金融市场 |

口诀： **"标、融、割、域"**。

#### （1）按交易标的物划分 P6–P7

| 子市场 | 期限/性质 | 构成 |
|---|---|---|
| **货币市场**| 融通**短期**资金（通常**不超过 1 年**）；解决短期资金周转和余额调剂 | 同业拆借市场、回购市场、票据市场、**大面额可转让存单市场** |
| **资本市场**|**中长期**资金（通常 1 年以上或**无固定期限**） | 广义 = 银行中长期存贷款市场 + 有价证券市场；<br>狭义 =**专指有价证券市场**（债券市场、股票市场等） |
| **外汇市场**| 各国中央银行、外汇银行、外汇经纪人及客户组成的外汇买卖、经营活动总和 | 外汇**批发**市场 + 银行同企业、个人间外汇买卖的**零售** 市场 |
| **期货和衍生品市场**| 以**期货合约或标准化期权合约**为标的的期货交易市场；以**互换、远期、非标准化期权** 及其组合为标的的衍生品交易市场 | — |
| **黄金市场** | 集中进行黄金买卖的交易中心或场所 | 黄金仍是国际储备资产之一，在国际支付中占一定地位，故仍视为金融市场的组成部分 |

高频陷阱：**资本市场"广义/狭义"之分**（狭义只含债券、股票等有价证券市场）；**货币市场"1 年"红线**。

**教材知识框：我国多层次资本市场体系** P7

- 2003 年 10 月，十六届三中全会《关于完善社会主义市场经济体制若干问题的决定》**首次提出**"建立多层次资本市场体系"。
- 2024 年 4 月，国务院《关于加强监管防范风险推动资本市场高质量发展的若干意见》（新"国九条"）：完善多层次资本市场体系，坚持**主板、科创板、创业板和北交所错位发展**，深化新三板改革，促进区域性股权市场规范发展；畅通"募投管退"循环；推动债券和 REITs 市场高质量发展。
- 时间线：1990.12.19 上交所开业、1991.7.3 深交所开业（主板）→ 2004.5.17 深交所设中小企业板（2021.4.6 与主板合并）→ 2009.10.23 创业板启动 → 2019.7.22 科创板开市（服务科技创新企业）→ 2013.1.16 全国股转系统（新三板）正式运营 → 2021.9.3 北交所成立（服务创新型中小企业，发挥转板上市功能）→ 2008 年以来各地设区域性股权市场，2017.1 国务院办公厅定位为**省域内中小微企业的私募股权市场**。

#### （2）按融资方式划分 P8

| 类型 | 定义 | 特点 |
|---|---|---|
| **直接融资市场**| 资金需求方以发行**股票或债券**等直接融资工具，从资金供给方融通资金 | 以**资本市场为主导**；资金供需双方**直接** 建立股权或债权债务关系 |
| **间接融资市场**| 资金需求方**通过银行等金融机构**融通资金（银行以储蓄存款取得资金，再以贷款提供给需求方） | 以**银行等金融机构为主导**；资金供需双方**没有直接法律关系**，无法提出权利主张 |

**教材知识框：全球金融市场体系两种类型** P8–P9

- **市场主导型**：以资本市场直接融资为主导，以股票和债券市场为核心，企业通过发行股票债券筹资——如**美国、英国**。
- **银行主导型**：以银行间接融资市场为主导，强调银行信贷作用，银行在资源配置中起核心作用——如**德国、法国**。
- **现阶段我国属于银行主导型**。2024 年 7 月，二十届三中全会《关于进一步全面深化改革推进中国式现代化的决定》指出：要"发展多元股权融资，加快多层次债券市场发展，**提高直接融资比重**"。

#### （3）按交割期限划分 P9

| 类型 | 要点 |
|---|---|
| **现货市场**| 成交后须在**若干个交易日内**交割，立即或短期内交割，**利率和汇率风险都很小** |
| **期货和衍生品市场**| 协议达成后**并不立刻交割**，约定**特定时间后**交割，**协议成立与标的交割相分离**；按协议成立时的协议价格交割，价格升降使交易者获利或受损，故只能依靠**对市场未来的判断** 交易 |

#### （4）按地域范围划分 P9–P10

| 类型 | 要点 |
|---|---|
| **国内金融市场**| 一国范围内的资金融通与交易，**不涉及** 货币资金跨境流动 |
| **国际金融市场**| 国际间的资金融通与交易，**涉及**货币资金**跨境流动**；由经营国际间货币业务的金融机构组成，内容包括跨境资金借贷、外汇买卖、证券买卖、资金交易等 |

### 1.1.c 【理解】金融市场的功能 P10

**大纲原文**：理解金融市场的功能

**六大主要功能**（表 1-3）：

| 功能 | 具体表现 |
|---|---|
| **资金融通**|**最基本的功能**。提供丰富金融工具，供给方按闲置期限、投资方式选品种，需求方通过支付利息（债务融资）或让渡收益权（股权融资）获得资金，完成交付；汇集社会分散资金投入社会再生产，服务实体经济 |
| **价格发现** | 交易价格由供需关系决定，为各种金融资产定价，反映内在价值、体现资金供需状况和未来预期判断；需求方可据此调整经营策略，供给方也可相应调整 |
| **资源配置**| 提高资金利用效率，使资金向**高效率、高效用**的地方流转；资金流转带动**资源和财富的再分配**；有效市场能实现有限资源合理配置 |
| **风险管理**| 供给方购买金融工具实现**转移或分散**风险；参与者通过金融衍生品等工具**对冲、缓释或管理** 风险，减少潜在经济损失 |
| **效率提升**| 通过**集中交易** 减少信息搜寻成本和交易成本，有利于金融资产快速买卖，提高资金流动性，提升市场效率 |
| **经济反映**| 繁荣程度、价格波动反映社会经济发展状况，被称为社会经济活动的 **"晴雨表"**，为宏观调控提供决策依据和载体平台 |

口诀： **"融通、发现、配置、风险、效率、反映"**（首字：融、发、配、风、效、反）。

必考：**资金融通是金融市场最基本的功能**。题目常把"资源配置"或"价格发现"设为干扰项。

### 1.1.d 【理解】金融市场的地位 P10–P12

**大纲原文**：理解金融市场的地位

教材从三个层面表述：

**1. 金融市场在现代市场经济体系中占据重要地位**
- 金融市场是现代市场经济体系中构成市场经济基础和市场经济循环体系的**三大主要市场之一**，是市场经济的**重要枢纽**，在市场机制中**扮演主导角色**。

| 三大主要市场 | 内涵 |
|---|---|
| **商品市场** | 实物商品（食品、服装、家电等）和服务（教育、医疗等）买卖的市场，消费者购买以满足各类需求 |
| **要素市场** | 生产要素（劳动力、资本、土地、数据等）交易的市场，为生产过程提供必要投入 |
| **金融市场** | 资金借贷和投融资的场所，同时为个人、企业和政府融资，为个人投资者和机构投资者提供投资渠道 |

**2. 金融市场是现代金融体系的重要组成部分**
- 金融市场和金融机构是现代金融体系的两大**运作载体**；通过金融机构在金融市场的活动，以各种金融工具连接资金供给者与需求者，实现货币资金有效配置。
- 常用金融调控政策（货币政策、利率政策、信贷政策等）都要**通过金融市场传导**到商品市场或要素市场，最终调节经济运行；金融市场的运行状况和效率**直接影响宏观经济政策的传导和效果**。
- 现代金融体系 = 金融市场 + 金融机构 + 金融调控 + 金融监管 + 金融基础设施 + 金融产品和服务的协同（成熟市场离不开有效的金融调控与监管；繁荣市场催生金融机构提供更多优质产品和服务；稳健市场依托安全高效的金融基础设施）。

**3. 金融市场是一个国家和地区经济实力的重要标志**
- 活跃发达的金融市场能吸引更多金融机构和资本流入，增强该地区**金融中心** 的地位和竞争力；金融中心通过聚集人才和资源推动产品服务创新，进一步促进市场繁荣。
- **国际金融中心**：聚集大量金融机构和金融服务产业的城市或地区，要求具备**金融市场齐全、服务业高度密集、对周边地区甚至全球具有辐射影响力** 等基本特征。

### 1.2.a 【掌握】资产管理的概念 P15–P16

**大纲原文**：掌握资产管理的概念

**教材定义**：资产管理是指**经依法批准或自律备案**的资产管理机构，接受投资者委托，担任**资产管理人**，按照与委托人事先约定的**投资策略、风险承担和收益分配方式**，对受托财产进行**投资和管理** 的服务。

定义四要素：**谁来做**（依法批准或自律备案的机构）、**做什么**（接受委托、担任管理人）、**按什么做**（事先约定的投资策略、风险承担、收益分配方式）、**做什么事**（对受托财产投资和管理）。

#### 三方关系：委托人、管理人、托管人

| 角色 | 身份 | 职责 |
|---|---|---|
| 投资者 | **委托人** | 将资产委托给资产管理人 |
| 资产管理人 | **受托人**| 承担**投资管理** 职责 |
| 资产托管人 | **受托人**| 承担**财产托管** 职责（按合同约定可设） |

- 委托人与受托人之间形成**信托关系**。
- 受托人"**受人之托、代人理财**"，应尽到"**诚实信用、勤勉尽责**"的信托责任，恪守**信义义务**。

关键区分：**管理人与托管人分别承担投资管理和财产托管的职责**，两者相互独立、相互制衡。考试常把"托管人负责投资决策"设为错误项。

#### 信义义务的两个构成

| 构成 | 要求 |
|---|---|
| **忠实义务**| 受托人应当**忠于委托人的利益和受托目的**，**不得与委托人利益发生冲突** |
| **谨慎勤勉义务**| 受托人应当具备**专业的投资管理和运作能力**，并为实现受托目的和**委托人利益最大化** 而努力 |

记：忠实 = 不冲突；勤勉 = 有能力 + 尽全力。

#### 资产管理的三大基本原则

| 原则 | 核心内容 |
|---|---|
| **风险收益匹配原则**| 要求风险与收益相匹配。管理人应坚持"**了解产品**""**了解客户**"的经营理念，向投资者发行销售与其**风险识别能力和风险承受能力相适应** 的产品。在受托人履行信义义务的前提下，投资者所获取的收益与其承担的风险相匹配 |
| **卖者尽责原则**| 侧重**对投资者的保护**，是"买者自负"的**前提**；基于投资者在资管业务中的**劣势地位**进行倾向性保护，有利于规范管理人销售行为。要求管理人在**产品设计、产品销售、投资管理和退出清算全链条**做到诚实守信、勤勉尽责，严格兑现法律承诺，坚持"**投资者利益至上**"，不得利用自身优势为自己或他人牟取不正当利益；发行销售时要实事求是，充分履行**风险告知义务**，做好信息披露 |
| **买者自负原则**| 侧重**投资者风险意识**的提升，通过投资者教育提升整体风险意识水平。投资者承担最终的收益和风险，**不得存在保本保收益等"刚性兑付"**。投资者若不承担市场波动风险，就不可能获取投资收益；应根据自身风险承受能力选择合适产品，自担风险并获取与所承担风险相匹配的收益 |

三者关系：**卖者尽责是买者自负的前提**；风险收益匹配是贯穿两者的内在要求。

高频陷阱：
- "卖者尽责"侧重保护投资者，"买者自负"侧重提升投资者风险意识——**不要记反**。
- 刚性兑付（保本保收益）被明确禁止，属于"买者自负"的反面。

#### 案例 1-1：风险等级匹配与销售适当性 P16

客户甲某投诉：申购 D 证券公司管理的 X 基金，称产品"承诺正收益概率 100%"却发生亏损。核查发现：

- 客户经理乙某的聊天与通话记录显示，X 基金实为"**固收+**"产品，宣传材料**完整披露了投资范围、风险等级**，其中"每季度获得正收益的概率为 100%"是对**过往历史业绩**的描述，且已作"**历史业绩不代表未来表现**"的风险提示。
- X 基金风险等级 **R3**，投资者甲某风险承受能力等级**C4**——**风险承受能力高于产品风险等级，属匹配**。

**评析**：投资者风险承受能力与基金风险等级匹配，客户经理作为管理人代表，**勤勉尽责地履行了销售适当性义务**，投资者应合理认识适当性规定，**自负产品盈亏**。

考点提炼：判断"卖者是否尽责"，看**是否做了风险测评匹配、是否充分揭示风险、是否把历史业绩说成未来承诺**。

### 1.2.b 【理解】中国资产管理行业发展现状 P16–P23

**大纲原文**：理解中国资产管理行业发展现状

#### （1）机构体系：什么是"大资管" P16–P17

我国资产管理机构主要包括**八类**：

1. 基金管理公司及其子公司
2. 证券公司及其子公司
3. 期货公司及其子公司
4. 私募基金管理人
5. 银行及其理财子公司
6. 保险公司与保险资产管理机构
7. 信托公司
8. 金融资产投资公司

上述所有资产管理机构构成我国资产管理机构的**主体体系**，俗称"**大资管**"。

**准入与备案的分工**（这张表容易考）：

| 机构/业务 | 审批或备案要求 |
|---|---|
| 基金、证券、保险等机构开展**公募基金**管理业务 | 须经**中国证监会批准**；公募基金产品须经中国证监会**产品注册及基金备案** |
| 证券期货经营机构开展**私募资产管理业务**| 资格须经**中国证监会批准**；设立私募资产管理计划须经**基金业协会备案** |
| 其他机构担任**私募基金管理人**| 须经**基金业协会登记**；募集完毕须经**基金业协会备案** |
| 银行及理财子公司、保险公司与保险资管机构、信托公司、金融资产投资公司 | 须经**国家金融监督管理总局** 批准设立，在批准的经营范围内开展业务 |

记：**公募看证监会，私募看协会（登记+备案），银行保险信托看金融监管总局**。

#### （2）业务链全景 P17–P18

我国资管行业已形成以**上游投资人 → 中游管理人 → 下游投资标的** 为主线的完整业务链：

- **上游（资金供给方）**：个人资金、机构资金（金融机构、非金融企业、养老委托资金、政府资金、外资/主权财富基金、社保基金、企业年金等养老资金、慈善基金等公益基金）
- **中游（管理人）**：券商及子公司、基金公司及子公司、私募管理人、期货公司及子公司、银行及理财子公司、保险及保险资管机构、信托公司、金融资产投资公司
- **产品载体**：公募类（公募基金、银行公募理财产品）；非公开类（集合/单一资产管理计划、私募证券投资基金、私募股权投资基金、创业投资基金、集合资金信托计划、银行私募理财产品、资产支持专项计划）
- **下游（投资标的）**：股票、债券、期货、衍生品、资产支持证券、公募基金、私募股权基金、房地产等
- **配套**：销售机构（管理人直销、银行、证券公司、独立销售机构）、资产托管人、清算交割机构（中国结算、中国证券金融公司）

#### （3）现状的七个特征

教材把现状归纳为七个"化"，这是 1.2.b 的骨架：

| # | 特征 | 一句话记忆 |
|---|---|---|
| 1 | 投资人结构**差异化** | 机构与个人的占比在各子行业差别很大 |
| 2 | 管理人性质**多样化** | 股东背景五花八门 |
| 3 | 业务发展**多元化** | 各类机构回归本源、聚焦主业 |
| 4 | 产品类型**标准化** | 按投资范围、募集方式统一分类 |
| 5 | 产品投资**规范化** | 标准化债权、非标、集中度都有硬约束 |
| 6 | 规模增长**趋势化** | 总规模稳步增长，结构在变 |
| 7 | 监管原则**明晰化** | 功能监管、穿透式监管等四条原则 |

口诀： **"人、管、业、品、投、规、监"**——投资人、管理人、业务、产品、投资、规模、监管。

##### 特征 1：投资人结构差异化 P18–P19

投资者分**机构投资者**和**个人投资者**。机构投资者包括金融机构（含其管理的产品）、非金融企业、养老金、政府、外资或主权财富基金，以及社保基金、企业年金、公益基金等。

截至 **2023 年末** 的持有人结构（数据要记牢，是典型考题）：

| 领域 | 个人投资者占比 | 机构投资者占比 |
|---|---|---|
| **公募基金**（资产净值） |**53.60%** | 46.40% |
| 证券期货经营机构私募资管计划（出资） | 8.61% | **91.39%** |
| 私募证券投资基金 | 44.97% | 55.03% |
| 私募股权投资基金 | 7.47% | **92.53%** |

- 公募基金持有人结构近年**较为平稳均衡**，个人略高于机构。
- **银行理财**投资者数量近些年显著上升：2023 年末个人投资者近**1.13 亿人**、占比**98.82%**；机构投资者 134.6 万家、占比 1.18%。

反差记忆：**公募基金个人占多数（53.60%）**，而**私募股权、私募资管计划机构占绝对多数（90%+）**，银行理财则是个人"一统天下"（98.82%）。

##### 特征 2：管理人性质多样化 P19–P20

截至 **2024 年 6 月**（不含港澳台）：

- **公募基金管理人 163 家**= 基金管理公司**148 家**+ 取得公募基金管理资格的资产管理机构**15 家**
- 按管理人**最大股东性质**划分：证券公司**66**、自然人**25**、信托公司**20**、银行**15**、外商独资公司**8**、保险公司**7**、私募基金管理人**3**、期货公司**2**、其他**18**
- 在基金业协会**登记并存续的私募基金管理人 20 768 家**：私募证券投资基金管理人**8 200 家**、私募股权与创业投资基金管理人**12 335 家**、其他类型**233 家**
- 信托公司 **70 家**、银行理财子公司**31 家**、保险资产管理公司**34 家**、金融资产投资公司**5 家**

分母记忆：公募 163（148+15）、私募 20 768（8 200 + 12 335 + 233）。

##### 特征 3：业务发展多元化 P20

各类机构**回归本源、聚焦主业**，夯实核心管理能力，以多元化策略满足不同风险偏好投资者需求。基金业协会从**机构类型**和**业务** 两个维度归纳行业外延（表 1-8）：

| 机构类型 | 资产管理业务 |
|---|---|
| 基金管理公司及其子公司 | 公募基金、集合资产管理计划、单一资产管理计划、各类养老金、资产支持专项计划 |
| 私募基金管理人 | 私募证券投资基金、私募股权投资基金、创业投资基金 |
| 信托公司 | 集合资金信托 |
| 证券公司及其子公司 | 公募基金、集合资产管理计划、单一资产管理计划、私募子公司私募基金、各类养老金、资产支持专项计划 |
| 期货公司及其子公司 | 集合资产管理计划、单一资产管理计划 |
| 保险公司、保险资产管理公司 | 公募基金、万能险、投连险、管理企业年金、养老保障及其他委托管理资产、资产支持专项计划 |
| 银行及其理财子公司 | 银行理财产品、私人银行业务 |

**注意**：**信托公司只有"集合资金信托"一类**；**期货公司及其子公司只有集合/单一资管计划两类**。这两行最容易设陷阱。

##### 特征 4：产品类型标准化 P21

按**投资范围**分：证券类资管产品、股权类资管产品。证券类再分四类（表 1-9，**80% 是硬门槛**）：

| 产品类别 | 投资范围 |
|---|---|
| **固定收益类**| 投资于存款、债券等**债权类资产**比例**不低于 80%** |
| **权益类**| 投资于股票、未上市企业股权等**权益类资产**比例**不低于 80%** |
| **商品及金融衍生品类**| 投资于商品及金融衍生品的比例**不低于 80%** |
| **混合类**| 投资于债权类、权益类、商品及金融衍生品类资产，且**任一资产的投资比例均未达到前三类标准** |

另按**募集方式**分：**公募产品**向不特定社会公众发行；**私募产品**面向**合格投资者**通过**非公开方式** 发行。

必考：资产管理机构发行产品时**应当明示产品类型**；四类的界线是**80%**，混合类是"都不够 80%"。

##### 特征 5：产品投资规范化 P21–P22

**公募 vs 私募的投资范围**：

| 类型 | 可投资范围 |
|---|---|
| **公募**资管产品 | 主要投资**标准化债权类资产**及**上市交易的股票**；除法律法规和监管部门另有规定外，**不得投资未上市企业股权**；可投资商品及金融衍生品，但须符合规定 |
| **私募**资管产品 | 投资范围**由合同约定**：可投债权类资产、上市或挂牌交易的股票、未上市企业股权（含债转股）和受（收）益权，以及符合法律法规规定的其他资产；须严格遵守**投资者适当性管理** 要求 |

**标准化债权类资产的五个条件**（须**同时** 符合）：

1. **等分化，可交易**
2. **信息披露充分**
3. **集中登记，独立托管**
4. **公允定价，流动性机制完善**
5. 在**银行间市场、证券交易所市场等经国务院同意设立的交易市场** 交易

口诀： **"等分、披露、登记、定价、市场"**。

**三条投资红线**：

1. 标准化债权以外的债权类资产均为**非标准化债权类资产**，投资须遵守金融监管部门的**限额管理、流动性管理** 等监管标准。
2. 管理人**不得**将资管产品资金**直接投资于商业银行信贷资产**。
3. 资管产品**不得**直接或间接投资法律法规和国家政策**禁止** 进行债权或股权投资的行业和领域。

**期限匹配的硬规定**：

- 投资**非标债权**的：非标资产的**终止日不得晚于**封闭式产品到期日或开放式产品的**最近一次开放日**。
- 投资**未上市企业股权及其受（收）益权**的：**应当为封闭式**资管产品，并明确退出安排；**退出日不得晚于** 封闭式产品到期日。
- 所投资产的**集中度** 需符合法律规定及合同约定。

##### 特征 6：规模增长趋势化 P22

截至 **2023 年底**，资产管理行业规模**118.7 万亿元**，前三名：

| 排名 | 类别 | 规模 |
|---|---|---|
| 1 | **银行理财产品**| 超过**27.65 万亿元** |
| 2 | **公募基金**| 约**27.60 万亿元** |
| 3 | **私募基金**| 约**20.32 万亿元** |

演变脉络：2018 年《关于规范金融机构资产管理业务的指导意见》（**资管新规**）发布后，**信托产品**和**证券期货经营机构私募资管计划**规模均有所下降；2021 年资管新规**过渡期结束**后**银行理财**规模也有所下降；**公募基金规模逐年增长**，对行业规模总体增长起了**主要作用**。

银行理财与公募基金只差 0.05 万亿，记"**银行理财第一、公募第二、私募第三**"即可。

##### 特征 7：监管原则明晰化 P23

法规体系自上而下： **《信托法》《证券法》《证券投资基金法》**+ 资管新规 + 国务院《私募投资基金监督管理条例》，由"**一行一局一会**"（中国人民银行、金融监管总局、中国证监会）按职责制定部门规章监管。

**四条监管原则**：

| 原则 | 要点 |
|---|---|
| **机构监管与功能监管相结合**| 按**产品类型**而不是机构类型实施功能监管，同一类型产品适用**同一监管标准**，减少监管真空和套利 |
| **实行穿透式监管**| 对多层嵌套产品，向上识别**最终投资者**，向下识别**底层资产**（**公募基金除外**） |
| **强化宏观审慎管理**| 建立宏观审慎政策框架，从**宏观、逆周期、跨市场** 角度加强监测、评估和调节 |
| **实现实时监管**| 对发行销售、投资、兑付各环节**全面动态监管**，建立**综合统计制度** |

口诀： **"功能、穿透、宏观、实时"**。穿透式监管的例外只有**公募基金**。

### 1.2.c 【了解】中国资产管理行业发展历程 P23–P27

**大纲原文**：了解中国资产管理行业发展历程

起步晚、发展快，从无到有、从小到大，历经**四个阶段**：

| 阶段 | 时间 | 关键词 |
|---|---|---|
| 1. **萌芽式起步** | 1992—1997 年 | 老基金、首部行政法规 |
| 2. **多层次探索** | 1998—2011 年 | 真正意义的基金诞生、一法六规 |
| 3. **创新和规范** | 2012—2021 年 | 大资管扩张、资管新规 |
| 4. **高质量发展** | 2022 年至今 | 费率改革、强监管 |

#### 阶段 1：萌芽式起步（1992—1997 年） P23

- **1992 年 11 月**，中国人民银行总行批准设立国内**第一只在交易所上市交易的投资基金**——**淄博乡镇企业投资基金**，1993 年上半年引发短暂的投资基金热潮。
- 1993 年下半年经济过热引发通胀，政府宏观调控，基金审批受限； **1994—1997 年基本处于停滞状态**。
- 1997 年以前设立的基金俗称"**老基金**"，共**75 只**，筹资规模**58 亿元**，投资方向主要是房地产、实业、股票、债券及金融衍生品。
- "老基金"**并非严格意义上的证券投资基金**，带有很大的自发性和探索性。
- **1997 年 11 月**，原国务院证券委员会颁布《**证券投资基金管理暂行办法**》，这是我国**首部规范公募基金的行政法规**：明确公募基金管理人准入标准，对发行公募基金实行**审批制度**，落实**托管机制**，建立**信息披露制度**。

两个"第一"别混：**第一只上市交易基金 = 淄博基金（1992）**；**首部规范公募基金的行政法规 = 《证券投资基金管理暂行办法》（1997）**。

#### 阶段 2：多层次探索（1998—2011 年） P24–P25

- **1998 年**，首批真正意义上的封闭式证券投资基金——"**基金金泰**"和"**基金开元**"经中国证监会批准发行成立，标志着**现代意义上的中国资产管理行业正式诞生**。
- **2000 年 10 月**，中国证监会发布《**开放式证券投资基金试点办法**》；**2001 年 9 月**，**华安创新** 开放式证券投资基金发行。
- **2001 年 4 月**，《**信托法**》颁布，推动私募基金发展，为以信托关系为基础的资管业务提供法律基础；借助**集合资金信托计划**，**阳光私募** 孕育而生。
- **2003 年 10 月**，《**证券投资基金法**》由全国人大常委会表决通过，**2004 年 6 月 1 日起施行**。证监会陆续发布配套法规，形成"**一法六规**"体系（规范管理人、运作、销售、信息披露、托管及高管任职）。2003 年的基金法**尚未规范私募基金，但为其预留了空间**。
- **2003 年 11 月**，证监会发布《证券公司客户资产管理业务试行办法》，将券商客户资管业务分为三类：为单一客户办**定向**、为多个客户办**集合**、为客户办**特定目的的专项** 资产管理业务。
- **2004 年**，银行理财全面铺开：光大银行上海分行发行第一只外币理财产品"**阳光理财 A 计划**"，随后发行第一只人民币理财产品"**阳光理财 B 计划**"，标志商业银行正式启动资管业务。
- **2005 年 9 月**，原中国银监会发布《商业银行个人理财业务管理暂行办法》，将理财计划分为**保证收益型**和**非保证收益型**，后者再分**保本浮动收益型**和**非保本浮动收益型**。
- 2003 年经原中国保监会批准，**首批保险资产管理公司**成立；**2006 年**首只保险资管产品"**华泰增值投资产品**"试点发行。
- **2007 年以前**以公募基金为主导；2008 年国际金融危机后权益类产品业绩下滑，公募规模下降，**2011 年仍在 2 万亿元左右徘徊**。2007 年后各子行业逐步增长，**银信、银证、银保、证保**等跨机构合作加强；截至**2011 年末商业银行理财产品余额达 4 万亿元**。

时间线记忆： **1998 金泰开元 → 2001 华安创新 → 2003 基金法 → 2004 阳光理财 → 2005 理财办法**。

#### 阶段 3：创新和规范（2012—2021 年） P25–P26

**创新扩张期：**

- **2012 年 10 月**，证监会发布《证券公司客户资产管理业务管理办法》《证券投资基金管理公司子公司管理暂行规定》：**放宽**专户资管（私募资管）业务门槛、**扩大**资管计划投资范围、允许基金公司**成立专门子公司**设立专项资管计划开展**非标** 业务。
- **2013 年 6 月**，修订后的《**证券投资基金法**》施行，**将私募基金纳入统一规范**。
- 银行、保险、信托等纷纷发行各类资管产品，形成"既相似又不同"的**混业局面**。

**乱象**：分业监管下出现**风险盲区**——各类资管计划、私募基金成为银行表内资产转向表外的**通道**，为资金池提供错配通道，资金流向同业及高风险非标；产品**层层嵌套**、场外配资**加杠杆**、承诺**刚性兑付**，风险积累在金融市场，**脱离了资产管理本源**。

**规范收紧期：**

- **2016 年 7 月**，证监会《证券期货经营机构私募资产管理业务运作管理暂行规定》：大幅**降低杠杆**、**禁止资金池**、**全面禁止通道业务**、不得**让渡管理责任**。
- **2018 年 4 月**，中国人民银行、原中国银保监会、证监会、国家外汇管理局联合发布《**关于规范金融机构资产管理业务的指导意见**》（资管新规），核心要求：

| 要点 | 具体规定 |
|---|---|
| 统一监管标准 | 明确内涵外延，按**产品类型**制定统一标准，同类业务统一规定，实行公平市场准入和监管，**最大程度消除监管套利空间** |
| **打破刚兑**| 明确资管产品实行**净值化管理**，**不得承诺保本保收益** |
| **禁止资金池** | 禁止资金池业务 |
| **消除多层嵌套**| 限制嵌套层级：产品可**再投资一层**资管产品，但所投产品**不得再投资公募基金以外** 的资管产品 |
| **统一杠杆水平**| 开放式公募产品总资产 ≤ 净资产**140%**；封闭式公募产品、私募产品总资产 ≤ 净资产**200%**；**分级私募产品**总资产 ≤ 净资产**140%**；计算单只产品总资产时按**穿透原则合并计算** |

- 过渡期：原设 **2 年**，后因疫情等因素**延长 1 年**，即实际**3 年** 过渡期。
- 资管新规后，证监会、银行保险监管部门陆续颁布配套规则。公募基金的一整套机制为其他资管业务**树立了标杆**：**卖者尽责、买者自负**的销售适当性管理、**强制托管**制度、**每日估值**的净值化管理、**充分的信息披露**、**公平交易**制度、**委托财产独立**。

杠杆三个数字必背：**开放式公募 140%，封闭式公募与私募 200%，分级私募 140%**。

#### 阶段 4：高质量发展（2022 年至今） P27–P28

| 时间 | 文件/事件 | 要点 |
|---|---|---|
| 2022.4 | 证监会《关于加快推进公募基金行业高质量发展的意见》 | 从**培育专业资管机构、强化专业能力、打造良好生态、提升监管转型效能** 四方面部署 |
| 2022.5 | 原中国银保监会《保险资金委托投资管理办法》等 | 明确委托投资适用主体和范围，压实委托人责任，强化受托人主动管理责任；拓宽保险资金可投金融产品范围（理财公司理财产品、单一资管计划、债转股投资计划等） |
| 2022.8 | 原中国银保监会《保险资产管理公司管理规定》《理财公司内部控制管理办法》 | 强化受托人主动管理责任，**取消外资持股比例上限**；要求理财公司建立全面、制衡、匹配、审慎的内控机制 |
| 2023.3 | 原中国银保监会信托业务三分类新规 | 分为**资产服务信托、资产管理信托、公益慈善信托**三大类**25 个**业务品种；明确信托公司资管业务为**私募** 业务 |
| 2023.5.18 | **金融监管总局挂牌成立**| 在原中国银保监会基础上组建，统一负责**除证券业之外**的金融业监管；形成"**一行一局一会**"新格局；机构监管改革强化"**机构监管、行为监管、功能监管、穿透式监管、持续监管**" |
| 2023.7 | 证监会《公募基金行业费率改革工作方案》 | 两年内 **15 项**举措，按"**管理费用—交易费用—销售费用**"路径分阶段推进费率改革 |
| 2023.7 | 国务院《**私募投资基金监督管理条例**》 | 我国**私募基金行业首部行政法规**，填补私募基金监管法律法规空缺 |
| 2023.10 | 首批 **5 家**保险资管机构获批**ABS 及 REITs** 业务 | 扩大到投资优质基础设施资产 |
| 2023.11 | 金融监管总局《商业银行资本管理办法》 | 构建**差异化资本监管体系**，全面修订风险加权资产计量规则，提升资本计量的风险敏感性 |
| 2023.11 | 中国银行业协会《理财产品过往业绩展示行为准则》 | 统一银行理财业绩展示标准 |
| 2025.5 | 证监会《推动公募基金高质量发展行动方案》 | **25 项**改革措施，推动行业从"**重规模**"向"**重回报**"转变 |

记"三个首部/首次"：**首部规范公募基金行政法规**（1997 暂行办法）、**首部私募基金行政法规**（2023 条例）、**首次提出多层次资本市场体系**（2003 十六届三中全会）。

### 1.2.d 【理解】中国资产管理行业发展前景 P28–P39

**大纲原文**：理解中国资产管理行业发展前景

教材从三个视角展望：**外部需求驱动**、**内部行业变革**、**国际视野**。

#### （一）外部需求驱动行业持续增长 P28–P34

##### 1. 资金供给端：居民财富管理与养老金融带来增量资金 P28–P31

**（1）居民理财需求持续扩大，资管与财富管理进一步结合**

- 2023 年全国居民人均可支配收入 **39 218 元**，比上年增长**6.3%**。
- 2023 年末全部金融机构本外币各项存款余额 **289.9 万亿元**，比年初增加 25.4 万亿元；其中境内住户存款余额**137.9 万亿元**，较上年末增长**13.8%**。
- 2022 年末个人可投资资产规模达 **278 万亿元**，预计 2024 年达**327 万亿元**。
- 配置结构：目前仍以**现金和存款**为主，其次为**不动产**；此外还有股票、公募基金、银行理财、保险、信托、私募基金、黄金等。
- 趋势：**高净值客户及新生代投资群崛起**，对创新型财富管理服务模式和理财产品接受度提高，对**多元资产及海外资产配置** 需求持续增加。

**（2）个人养老金市场是资管行业发展的"蓝海"**

我国养老保障体系"**三支柱**"：

| 支柱 | 内容 |
|---|---|
| 第一支柱 | **基本养老保险**（政府主导） |
| 第二支柱 | **企业年金和职业年金** |
| 第三支柱 | **个人养老金和商业养老保险** |

- 当前国内养老金主要来源仍以**第一支柱**为主；养老金是资管行业**中长期资金** 的主要来源。
- **2022 年 11 月**，人社部等五部门发布《**个人养老金实施办法**》，个人养老金制度正式启动：**个人账户制**，缴费**完全由参加人个人承担**，自主选择购买符合规定的**储蓄存款、理财产品、商业养老保险、公募基金**等金融产品，实行**完全积累**，享受**税收优惠**。
- 截至 **2023 年底**，超**5 000 万人**开立个人养老金账户；但实际储存资金人数不足**1/3**，人均储存仅**2 000 多元**（缴存上限每人每年**1.2 万元**），实际储存总额仅**200 多亿元**。
- 截至 **2024 年 6 月底**，共**649 只**个人养老金产品发行：权益类**209 只**、固定收益类**403 只**、货币型**37 只**。
- **2024 年 12 月**，五部门《关于全面实施个人养老金制度的通知》：将**特定养老储蓄、指数基金**纳入个人养老金产品目录；证监会随后将首批**85 只权益类指数基金**纳入，使个人养老金可投资公募基金达**284 只**。

记： **"三支柱"+"1.2 万缴存上限"+"5000 万人开户"**。

##### 2. 资金需求端："双碳"目标扩大资金需求 P31–P32

- **2020 年 9 月**承诺：二氧化碳排放力争**2030 年前**达峰，努力争取**2060 年前**实现碳中和（"**双碳**"目标），将使资管行业迎来**绿色投资** 发展机遇期。
- 绿色金融政策（表 1-10）关键节点：2016.8 七部委《关于构建绿色金融体系的指导意见》；2018.11 协会《绿色投资指引（试行）》；2021.4《绿色债券支持项目目录（2021 年版）》；2022.6《银行业保险业绿色金融指引》；2022.7《中国绿色债券原则》；2024.3 七部委《关于进一步强化金融支持绿色低碳发展的指导意见》；2024.4 三所《上市公司可持续发展报告指引》。
- 公募基金在**制度建设、绿色投资研究、评价和风险监控处置机制**等方面已初见成效；**私募股权投资基金**能参与被投企业治理、协助上下游产业链合作，在推动被投企业绿色发展的**深度和广度** 上优势突出。

##### 3. 资管产品端：REITs 带来新机遇 P32–P34

**REITs 定义**：依法向社会投资者**公开募集资金形成基金财产**，通过**基础设施资产支持证券等特殊目的载体**持有基础设施项目，由**基金管理人等主动管理运营**上述项目，并将产生的**绝大部分收益分配给投资者**的**标准化金融产品**。

- **特点**：**中等收益、中等风险**；**流动性高、收益稳定、安全性强**。
- **意义**：短期有利于广泛筹集项目资本金、降低债务风险，是**稳投资、补短板** 的有效政策工具；长期有利于完善储蓄转化投资机制、降低实体经济杠杆，推动基础设施投融资市场化、规范化发展。
- **产品结构**："**公募基金 + 资产支持证券**"，交易结构**三层**：公募基金、ABS、项目公司。
- **关键节点**：

| 时间 | 事件 |
|---|---|
| 2020.4 | 国家发展改革委、证监会《关于推进基础设施领域不动产投资信托基金（REITs）试点相关工作的通知》，**试点正式起步** |
| 2020.8 | 证监会《公开募集基础设施证券投资基金指引（试行）》，构成 REITs 监管框架体系**核心** |
| 2021.6.21 | **首批 9 个** REITs 试点项目挂牌上市 |
| 2024.7 | 国家发展改革委《关于全面推动基础设施领域 REITs 项目常态化发行的通知》，标志**常态化发行新阶段** |

- 截至 **2024 年 7 月**：发改委已推荐**67 个**项目（含扩募），其中**44 个**发行上市，共发售基金**1 285 亿元**，用于新增投资的净回收资金超**510 亿元**，可带动新项目总投资超**6 400 亿元**；上市项目累计向投资者**分红超 130 亿元**；2024 年上半年中证 REITs 全收益指数上涨**8.65%**。
- 底层资产已涵盖：能源、交通、园区、消费、生态环保、仓储物流、保障性租赁住房等基础设施。

易错：REITs"三个对"——对运营企业是**盘活存量资产**，对投资者是**长期优质资产投资工具**，对市场是**基础设施不动产的价格发现**。

### 1.2.d+ 教材补充一：资管、财富管理与投资顾问的关系 P30

三者都是金融机构为委托人财产管理提供的服务。

| 概念 | 要点 |
|---|---|
| **财富管理（广义）**| 金融机构等受客户委托，提供**财务规划、投资管理、投资咨询、保险**等系列服务，对客户的**资产、负债及流动性** 进行管理，满足不同阶段财务需求 |
| **财富管理（狭义）**| 即"**私人财富管理**"，为**高资产净值** 家庭或个人提供投资组合管理、税务规划、遗产规划、信托服务、离岸资产服务、不动产管理、融资、慈善安排等 |
| **投资顾问**| 金融机构接受客户委托，按约定向客户提供**投资建议** 并收取费用的服务；是基础性的资本市场中介服务 |

**资管与投顾的对比**（常考）：

| 维度 | 资产管理 | 投资顾问 |
|---|---|---|
| 中心 | 以**资产**为中心 | 以**客户** 为中心 |
| 特点 | 专业投资管理能力；强调客户风险收益偏好与产品风险等级**匹配**| 更注重**持续服务**，关注客户风险承受能力的**变化** |
| 立场 | — | 应防范利益冲突、规避有利益冲突的收费方式，属于**买方服务** |
| 行为 | — | 更有动力**抵制追涨杀跌**，考虑**降低客户交易成本**，追求长期盈利 |

- 二者**都是财富管理的服务内容**。
- 我国财富管理仍处**起步阶段**，机构更重视**销售环节**；趋势是**从卖方销售视角转向买方投顾**。目前买方投顾服务主要指**基金投资顾问服务**。

一句话区分：**资管管"钱"，投顾管"人"**。

### 1.2.d+ 教材补充二：全球资产管理行业发展简况 P39–P42

**起源三节点**：

1. **1868 年**英国"**海外及殖民地政府信托基金**"——最早通过公开方式发售的基金，一般被认为是**封闭式投资基金的起源**；认购者权益**仅限于分红和派息**。
2. **1879 年**英国《股份有限公司法》后，部分基金发展为**股份有限公司式**组织形式——**公司型基金的原型**。
3. **1924 年**美国波士顿"**马萨诸塞投资信托基金**"——**首只开放式公司型共同基金**（Mutual Fund）。

**监管格局**：

- **美国**：多数专业资管公司在 SEC 注册为**投资顾问公司**并受 SEC 监管；SEC 注册的投资公司包括**共同基金、ETF、封闭式基金、单位投资信托**。截至 2023 年底，美国注册投资公司管理净资产**33.9 万亿美元**，服务逾**1.2 亿**个人投资者。《**多德-弗兰克法案**》影响深远：**FSOC**与美联储主导防范系统性风险，**SEC 与 CFTC**推动透明度与风险/利益冲突管理，**CFPB** 保护消费者权益。
- **欧盟**：分**欧盟层面**与**各国层面**；欧盟三大监管制度为**可转让证券集合投资计划指令、欧洲金融工具市场指令、另类投资基金管理指令**；各国各有立法（如法国 1996 年《金融业务现代化法案》，德国《银行监管法》《投资公司法》《证券交易法》《安全托管法》）。

**全球现状（BCG《2024 年全球资产管理报告》）**：

- 2023 年全球资管规模增至近 **118.7 万亿美元**，较 2022 年（当年下降近 9%）**增长近 12%**；北美**16%**、亚太（不含日澳）**5%**。
- 隐忧：**收入仅增 0.2%，成本上升 4.3%，利润下降 8.1%**。
- **被动型产品**加速增长：2023 年吸引全球共同基金与 ETF 总净流入的**70%**（约**9 200 亿美元**），高于 2019—2022 年的 57%。
- 成本自 2010 年以来已上升约 **80%**，复合年均增长率**5%**；2006 年以来行业近**90%** 的营业收入增长来自**资产增值**。
- 趋势： **AI 技术**被视为提升价值链效率的新解法；除**ESG 投资**外，**数字资产和加密货币** 正成为重要组成部分。

## 本章小结

第一章两条主线：
