# 第三章 基金法律法规体系和监管体系

本章三节：**法律法规体系**（层级与适用范围、主要组成部分）、**基金监管**（概念目标原则、三家监管机构的职责与措施）、**行业自律**（两家协会 + 各类交易场所）。

> 从这一章开始正式进入"法规区"。学习方法要变：**先记框架层级，再记具体规则**，否则容易越背越乱。

---

## 3.1 法律法规体系

### 3.1.a 【掌握】基金行业法律法规体系的层级和适用范围 P76–P79

**大纲原文**：掌握基金行业法律法规体系的层级和适用范围

#### （1）什么是法律法规体系 P76

- **国家**的法律法规体系：国家法律法规的**整体结构和相互关系**，相互关联但各有侧重，共同构成完整系统。
- **行业**的法律法规体系：该行业所有法律法规形成的、在行业运行发展方面**有机联系又各有侧重**的整体，旨在**规范行业秩序、促进行业健康发展**。

我国基金行业已形成完整体系，可**纵向看层级**、**横向看适用范围**：

- **纵向**：国家法律 → 行政法规 → 部门规章和规范性文件 → 自律规则。**上位法为下位法提供制定基础和依据**——国家法律规定基金的法律关系、管理人和托管人的核心义务等基础性内容，**自律规则规定的多为具体操作细则**。
- **横向**：适用于不同类型的基金及基金业务的各个方面——既有公募专项、也有私募专项；既有投资运作相关、也有销售等业务相关。

#### （2）四个层级（效力从高到低） P76–P77

| 层级 | 制定主体 | 在基金体系中的地位与代表 |
|---|---|---|
| **1. 国家法律**|**全国人民代表大会及其常务委员会**|**效力层级最高**，是下位法制定基础。**《证券投资基金法》是基金行业一系列下位法律法规的总纲**；此外《信托法》《证券法》《公司法》《合伙企业法》《民法典》《刑法》《反洗钱法》等在投资运作、公司治理、反洗钱等方面起重要作用 |
| **2. 行政法规**|**国务院**| 2023 年颁布施行的《**私募投资基金监督管理条例**》在私募基金行业发挥非常重要的作用 |
| **3. 部门规章和规范性文件**|**国务院所属各部、委员会**（中国证监会、中国人民银行、国家外汇管理局等） | 效力低于法律、行政法规，但**数量相对较多**，是**基金管理人、基金托管人等机构及其从业人员具体行为规范的主要依据** |
| **4. 自律规则**|**行业协会、交易场所**| 是对自律管理对象、交易参与者**给予纪律处分或实施其他自律管理措施的依据**；由**中国证券投资基金业协会、中国证券业协会及证券交易所等交易场所** 制定，在投资运作、人员管理、私募登记备案等方面作用重要 |

四层口诀：**法（人大）→ 规（国务院）→ 章（部委）→ 律（协会/交易所）**。

高频考点： **《证券投资基金法》是全国人大常委会制定**（不是国务院），**《私募投资基金监督管理条例》是国务院行政法规**（不是法律）。

#### （3）适用范围：横向覆盖三类产品 P77–P78

我国基金行业法律法规体系覆盖**公募基金、私募资产管理计划、私募基金**，但三者规范情况差别很大：

| 产品 | 规范特点 | 数量规模 |
|---|---|---|
| **公募基金**| 可向**不特定对象**募集、**事关中小投资者权益**，因此**规范相对最早、法律法规数量最多**| 2004 年基金法施行以来证监会制定修订大量规章；2012 年协会成立后制定大量自律规则。截至**2023 年底**，与公募基金直接相关的法律法规**超过一百部** |
| **私募资产管理计划**| 产生**晚于**公募基金，且**管理人经营管理、计划财产托管等与公募相同或相似**，因此**专项法规数量相对较少**，依托公募法规基础 | 自**2007 年**开始，特别是**2018 年**资管新规以来逐步完善。目前直接相关的法律法规凝练于**十余部** 部门规章、规范性文件和自律规则 |
| **私募基金**| 规范相对**较晚**；投资者均为高门槛投资者，但**数量日趋增多**，且管理人**并非证监会批准设立的机构**，故需更全面规范以保障投资者权益 |**2012 年修订的基金法**将其纳入规范对象。目前证监会制定**少量**部门规章和规范性文件，直接相关的规则**以协会自律规则为主** |

记三个关键词：公募"**最早、最多、超百部**"；私募资管计划"**较早但少、十余部**"；私募基金"**最晚、以自律规则为主**"。

| 基金从业人员管理 | 《证券基金经营机构董事、监事、高级管理人员及从业人员监督管理办法》 |

"一法六规"记六字：**管人、托管、募集、运作、披露、人员**。

### 3.1.b 【掌握】基金行业法律法规体系的主要组成部分 P79–P89

**大纲原文**：掌握基金行业法律法规体系的主要组成部分

#### （1）总体结构 P79

#### （2）国家法律 P80–P82

##### ① 《证券投资基金法》——行业基本法 P80

**2003 年 10 月**，全国人大常委会通过，是**中国基金行业里程碑式的事件**。五个方面的作用：

| # | 作用 | 要点 |
|---|---|---|
| 1 | **明确基金当事人的法律关系**| 以**信托关系**为基础，明确基金份额持有人作为**委托人与受益人**，基金管理人与基金托管人"**双受托人**"的法律地位。"双受托人"是**基金法律关系的核心**，二者各司其职又相互监督 |
| 2 | **确保基金财产安全、独立**| 遵循《信托法》的**信托财产独立原则**，明确基金财产相对于受托人财产的**独立性**；财产独立原则与**托管制度** 共同确保基金财产安全 |
| 3 | **使信义义务根植于基金行业**| 将**忠实**和**谨慎勤勉**原则上升到法律高度。忠实义务要求受托人**忠于基金份额持有人**，不得以基金财产牟取不正当利益或从事导致利益冲突的行为；谨慎勤勉义务要求受托人**发挥专业能力，为持有人利益最大化行事**。信义义务是管理人和托管人的**基本义务**，是其**其他主要法律义务的基础** |
| 4 | **明确基金份额持有人的权利及行使方式**| 规定基本权利内容及通过**基金份额持有人大会（及其日常机构）** 行使权利的形式，使权利"行之有据、行之有序" |
| 5 | **规定证监会职权、协会自律管理职责及法律责任**| 使证监会的监管、协会的自律管理**有据可依** |

- **2012 年修订**后，上述规定**均适用于公募基金和非公开募集基金**。
- 地位：《证券投资基金法》**统领下位法律法规**，是保护持有人权益、规范募集与投资运作及机构与从业人员行为的**基本法**。

"双受托人"是核心概念：**持有人 = 委托人 + 受益人；管理人、托管人 = 双受托人**。

##### ② 其他八部国家法律的分工 P80–P82

| 法律 | 立法目的 | 在基金领域的适用 |
|---|---|---|
| **《信托法》**| 调整信托关系、规范信托行为、保护信托当事人合法权益 | 基金基于**信托关系**构建当事人法律关系。**《证券投资基金法》未规定的**，凡涉及委托人（持有人）与受托人（管理人、托管人）的关系、委托人资格、受托人义务、信托（基金）费用等问题，**适用《信托法》** |
| **《证券法》**| 规范证券发行和交易行为、保护投资者合法权益 | 基金投资涉及的**证券发行、承销、交易**规则，以及**防控内幕交易、市场操纵**等要求，基金法未规定的**适用《证券法》** |
| **《公司法》**| 规范公司的组织和行为，保护公司、股东、职工和债权人合法权益 | 适用三处：**公募基金管理公司和公司型私募基金管理人的公司治理**；**基金参与上市公司治理**、行使股东权利履行股东义务；**公司型私募基金的运作** |
| **《合伙企业法》**| 规范合伙企业行为，保护合伙人、债权人合法权益 | 适用于**合伙型基金管理人**，以及**合伙型基金的设立、治理和管理** |
| **《民法典》**| 保护民事主体合法权益，调整民事关系 | 基金当事人之间的法律关系是**民事法律关系的一种**；基金合同的订立与履行、委托与担保等民事法律行为、民事责任等**适用《民法典》** |
| **《刑法》** | 惩罚犯罪，保护人民 | 严重违法行为可能触犯罪名（见下） |
| **《反洗钱法》**| 预防洗钱活动，遏制洗钱及相关犯罪 | 要求金融机构采取**预防、监控措施**，建立健全**反洗钱内部控制制度**，履行**客户尽职调查、客户身份资料和交易记录保存、大额交易和可疑交易报告、反洗钱特别预防措施** 等义务 |
| **《期货和衍生品法》**| — | 基金从事**期货和衍生品投资** 应当适用 |

**《刑法》可能涉及的罪名**（分两类记）：

| 环节 | 可能触犯的罪名 |
|---|---|
| **基金募集**中的违法行为 |**非法吸收公众存款罪、集资诈骗罪、行贿与受贿犯罪** 等 |
| **基金投资管理**中的违法行为 |**内幕交易罪、利用未公开信息交易罪、非国家工作人员受贿罪、背信运用受托财产罪** 等 |

记"两非两内一背信"：非吸、非法集资 + 内幕交易、利用未公开信息 + 背信运用受托财产。

#### （3）部门规章和规范性文件 P83–P86

自 2004 年以来，证监会制定修订多部规章和规范性文件，**十四项重点**（按教材编号）：

| # | 名称 | 规范什么 |
|---|---|---|
| ① | 《公开募集证券投资基金管理人监督管理办法》 | 公募**管理人准入、退出及其治理与管理** 的基本规范 |
| ② | 《基金管理公司子公司管理规定》 | 公募管理人**各类子公司设立、运作**的基本规范；确立对子公司的控制要求，**禁止母子公司同业竞争**、禁止子公司再下设机构、加强人员隔离、禁止股权激励错位；还制定私募资管业务子公司的**风险准备金制度和风险控制指标体系** |
| ③ | 《证券基金经营机构董事、监事、高级管理人员及从业人员监督管理办法》 | 公募管理人的**董监高及从业人员基本行为规范**；规定任职条件与行为准则，也规定行业从业人员**一般行为规范** |
| ④ | 《证券公司和证券投资基金管理公司合规管理办法》 | 公募管理人**合规管理**基本规范；建立合规管理体系，提出"**合规创造价值**"，规定合规环境、合规保障、职责、**督察长** 任职条件等 |
| ⑤ | 《证券投资基金托管业务管理办法》 | **基金托管人资格条件和托管业务** 基本规范；规定准入标准、业务规范与行为准则 |
| ⑥ | 《公开募集证券投资基金运作管理办法》 | 公募基金**募集注册、投资与运作**基本规范；规定注册条件、类别、**主要投资比例限制**、变更注册和持有人大会议事规则。配套《公开募集开放式证券投资基金流动性风险管理规定》是**重要补充** |
| ⑦ | 《公开募集证券投资基金销售机构监督管理办法》 | 公募**销售机构准入、销售行为准则**基本规范；销售私募基金也适用其业务规范、内控和风险管理规定；规范**租用第三方网络空间** 开展销售等 |
| ⑧ | 《证券期货投资者适当性管理办法》 | 保护销售过程中投资人权益；目标是"**将合适的基金卖给合适的人**"；要求建立**投资者分类制度、风险承受能力评价体系、基金产品风险等级评价体系**，加强对**普通投资者** 保护，避免风险等级错配 |
| ⑨ | 《公开募集证券投资基金信息披露管理办法》 | 公募**信息披露**基本规范；规定披露的**媒介、形式、基本内容、频率**及事务管理；要求披露**真实、准确、完整、简明和易得** |
| ⑩ | 《公开募集证券投资基金风险准备金监督管理暂行办法》 | **风险准备金制度**基本规范；要求管理人、托管人**每月从管理费、托管费收入中计提**；因违法违规、违反基金合同造成损失应赔偿的，**可优先使用风险准备金** 赔偿 |
| ⑪ | 《证券期货经营机构及其工作人员廉洁从业规定》 | 管理人及从业人员**廉洁从业准则**；严禁在投资管理、销售等各环节**输送和谋取不正当利益** |
| ⑫ | 《基金管理公司固有资金运用管理暂行规定》 | **固有资金运用**行为基本规范；规定运用范围、用途、**关联交易** 及信息披露 |
| ⑬ | 《关于规范金融机构资产管理业务的指导意见》 | **央行牵头**制定；统一同类资管产品监管标准、避免监管套利、防控金融风险，对统一基金行业与其他资管行业规则起**提纲挈领** 作用 |
| ⑭ | 《证券期货经营机构私募资产管理业务管理办法》 | 公募管理人及子公司、券商及子公司、期货公司及子公司等开展**私募资管业务** 的基本规范；配套《证券期货经营机构私募资产管理计划运作管理规定》 |

## 3.2 基金监管

### 3.2.a 【掌握】基金监管的概念、目标和原则 P90–P93

**大纲原文**：掌握基金监管的概念、目标和原则

#### （1）概念 P90

- **监管（行政监管）**：国家通过其**行政机构**对特定行业、领域或市场的行为进行**监督和管理**，以确保法律法规执行、维护市场秩序、保护公众利益、促进社会经济健康发展。
- **基金监管**：有**法定监管权**的行政机构依法对**基金市场、基金市场主体及其活动** 的监督和管理，主要包括三方面：

| 内容 | 举例 |
|---|---|
| **准入监管**| 基金经营机构的**设立及变更** |
| **市场行为监管**| 基金的**注册与备案**、基金的**投资** |
| **违法违规行为的处置措施** | — |

- **广义概念**：还包括**基金行业自律组织、基金经营机构内部监督部门、社会力量** 对基金市场的监督或管理。
- 本书为区分，对后三者分别称"**基金行业自律**""**基金经营机构内控**""**社会力量监督**"。

#### （2）三个目标 P90–P91

基金监管的目标体现为《证券投资基金法》的**立法宗旨**：

| 目标 | 要点 |
|---|---|
| **① 保护基金投资人的合法权益**| 是基金监管的**出发点和首要目标**。投资人是**出资人、基金资产的实际所有人和投资回报的受益人**；在销售、投资管理等活动中**多处于弱势地位**——不管理或保管基金财产、信息获取途径可能不足，权益容易受侵害。监管须通过监督管理机构，促使其**依法履行受托职责、依法披露信息**，使投资人免遭**误导、欺诈** 等违法违约行为损害 |
| **② 规范基金活动**| 是保护投资人权益目标的**必然要求**。侵害可能出现在各环节：销售环节可能面临**不符合适当性原则的推介**；投资管理环节可能因管理人**违反基金合同投资运作**而受损。监管须以规范**募集与投资、信息披露** 等为切入点和着力点 |
| **③ 促进基金行业和资本市场的健康发展**| 三层含义：**一是**以实现基金行业和**实体经济、资本市场共同发展**为目标（引导服务实体经济、促进融资便利化、降低实体经济成本、提高资源配置效率）；**二是**为行业发展**创造良好环境**（鼓励创新的同时创造公平竞争机制，避免无序竞争、恶性竞争）；**三是**着眼全局，以**防范资本市场系统性风险为底线**，确保风险可控 |

必背：**保护基金投资人合法权益是出发点和首要目标**。

#### （3）六条原则 P91–P93

| 原则 | 核心含义 |
|---|---|
| **① 依法监管**| 遵循**行政法治**原则，**于法有据**：机构设置及职权取得必须**有法律依据**；职权行使必须**严格遵照法律规定**，既不能超越授权滥用权力，也**不能怠于行使**法定职责；对违法行为制裁必须依据法律明确规定，**秉公执法、不偏不倚** |
| **② 保障基金投资人权益**| 不仅是监管的**首要目标**，也是监管的**首要原则**；立法、执法应始终秉持该理念，并将其作为**评价监管效果的首要标准** |
| **③ 加强监管和防范风险**| 强监管、严监管是保障行业健康发展的**核心和关键**。一方面引导行业发挥积极作用、提升国际地位；另一方面加大处罚力度、推动行业**回归本源、做优做强**。2024 年 4 月新"**国九条**"对基金行业的监管要求包括：推动证券基金经营机构高质量发展、树立正确经营理念、处理好**功能性和盈利性**关系；加强股东、业务**准入管理**，完善**高管任职条件与备案管理制度**；完善对**衍生品、融资融券**等重点业务监管；加强**投行能力和财富管理能力**建设；支持头部机构通过并购重组、组织创新提升核心竞争力，鼓励中小机构**差异化发展、特色化经营** |
| **④ 高效监管**| 促进基金行业**高效发展**，**不束缚行业活力**。一方面要求确立**科学合理的监管内容与模式**；另一方面要求有**明确的制裁手段**追究违法主体责任。有效的**监管协调、规范的监管程序、科学的监管技术、现代化的监管手段**也是重要保障。长期看，还应在**主体监管**基础上强化**功能监管、行为监管**，对同类产品和业务**统一监管**，完善**跨部门协作与信息共享** |
| **⑤ 审慎监管**| 也称"**结构性的早期干预和解决方案**"，是**金融业特有**的监管原则，旨在通过**偿付能力监管和风险防控制度体系**，维护投资人对金融市场的信心。2017 年全国金融工作会议就提出加强**宏观审慎管理制度**建设。具体要求监管机构在制定规范、实施行为时注重**资产状况和早期风险防控**，体现在对机构**内部治理结构、内部稽核监控制度、风险控制制度、资产流动性水平** 等方面的监管 |
| **⑥ 公开、公平、公正（"三公"）**|**公开**：确保市场具有充分透明度，实现**市场信息公开化**，且监管规则和处罚也应按**政务公开**原则公开；**公平**：市场主体平等，监管机构**依照相同标准**衡量同类监管对象的行为；**公正**：在公开、公平基础上**公正执法、一视同仁**，是**依法监管原则的具体化** |

六原则口诀：**依法、保权益、强监管、高效、审慎、三公**。

细节考点："审慎监管"= **结构性早期干预和解决方案**，是**金融业特有**；"公正"是"**依法监管的具体化**"。

### 3.2.b 【掌握】中国证监会对基金行业的监管职责与措施 P93–P96

**大纲原文**：掌握中国证监会对基金行业的监管职责与措施

#### （1）地位与内部分工 P93

- **依据**：《证券法》《证券投资基金法》《私募投资基金监督管理条例》等，**中国证监会是我国基金市场的行政监管部门**。
- **性质**：**国务院直属机构**，负责贯彻落实党中央关于金融工作的方针政策和决策部署，**统一监督管理全国证券期货市场**。
- **机关 vs 派出机构**：

| 层级 | 职责 |
|---|---|
| **证监会机关**| 制定、修改和完善证券期货市场**规章规则**，拟定市场发展规划，办理**重大审核事项**，指导协调**风险处置**，组织查处**重大违法违规案件**，指导、检查、督促和协调系统监管工作 |
| **派出机构**| 受证监会**垂直领导**，负责辖区内的一线监管工作 |

- **内设部门分工**：

| 部门 | 职责 |
|---|---|
| **证券基金机构监管司**| 拟订证券基金经营机构、证券投资咨询机构、**基金托管机构、基金服务机构、合格境外投资者**监管制度；依法对上述机构及其业务实施**准入管理**，对业务活动和人员从业行为实施监督管理，开展**风险监测和个案风险处置** |
| **市场监管二司**| 拟订并组织实施**私募基金、区域性股权市场**监管制度；承担**私募基金的监督检查**工作；承担**打击非法证券期货基金金融活动** 和清理整顿各类交易场所有关工作 |

#### （2）监管职责 P94

**公募基金行业七项职责**：

1. 制定有关证券投资基金活动监督管理的**规章、规则**，并行使**审批、核准或者注册权**；
2. 办理**基金备案**；
3. 对基金管理人、基金托管人及其他机构从事证券投资基金活动进行**监督管理**，对违法行为进行**查处并公告**；
4. 制定基金**从业人员的资格标准和行为准则**，并监督实施；
5. **监督检查基金信息的披露情况**；
6. **指导和监督中国证券投资基金业协会** 的活动；
7. 法律、行政法规规定的其他职责。

**私募基金行业四项职责**：

1. 制定有关私募基金业务活动监督管理的**规章、规则**；
2. 对私募基金管理人、托管人及其他机构从事私募基金业务活动进行**监督管理**，对违法行为进行**查处**；
3. 对**登记备案和自律管理活动**进行**指导、检查和监督**；
4. 法律、行政法规规定的其他职责。

- 此外，证监会根据私募管理人的**业务类型、管理资产规模、持续合规情况、风险控制情况、服务投资者能力**等实施**差异化监督管理**，并对**创业投资等股权投资、证券投资等不同类型**的私募基金实施**分类监督管理**。

区分：对**公募**是"制定规则 + 审批核准注册权 + 备案"；对**私募**是"制定规则 + 监督管理 + 指导登记备案与自律管理"（私募管理人登记和基金备案由**协会** 办理）。

#### （3）七项监管措施 P94–P95

基金市场违法行为具有**智商高、电子化、行为隐蔽、手段多样、涉案金额高、社会危害大** 等特点，故须强化执法权限。依据基金法、私募条例，证监会可采取：

1. 对管理人、托管人、服务机构进行**现场检查**，要求报送有关业务资料；
2. **进入**涉嫌违法行为发生场所**调查取证**；
3. **询问** 当事人和与被调查事件有关的单位和个人，要求作出说明；
4. **查阅、复制**与被调查事件有关的**财产权登记、通讯记录** 等资料；
5. **查阅、复制**证券交易记录、登记过户记录、财务会计资料及其他相关文件和资料；对可能被**转移、隐匿或者毁损**的文件和资料，可以**予以封存**；
6. **查询**资金账户、证券账户和银行账户；对有证据证明已经或可能**转移、隐匿违法资金、证券等涉案财产**，或**隐匿、伪造、毁损重要证据**的，经**证监会主要负责人批准**，可以**冻结或者查封**；
7. 在调查**操纵证券市场、内幕交易**等重大证券违法行为时，经**证监会主要负责人批准**，可以在法定期限内**限制被调查事件当事人的证券买卖**。

两个"经主要负责人批准"：**冻结/查封**和**限制证券买卖**。这两项是权限最重的措施。

#### （4）行政处罚 vs 行政监管措施 P95

| 类别 | 依据 | 性质 | 具体种类 |
|---|---|---|---|
| **行政处罚**| 《行政处罚法》和基金监管法律法规 | 对违法违规机构和个人依法采取**惩戒**的行为 |**警告、罚款、没收违法所得、暂停或者撤销基金从业资格** 等 |
| **行政监管措施**| 《证券期货市场监督管理措施实施办法（试行）》及基金监管法律法规 |**非行政处罚性**措施 |**责令改正、监管谈话、出具警示函、公开谴责、认定为不适当人选** 等 |

**针对不同对象的"专属"行政监管措施**（易混，务必分清）：

| 对象 | 可采取的主要行政监管措施 |
|---|---|
| **公募基金管理人**| ①**限制业务活动**，责令暂停部分或全部业务；②**限制分配红利**，限制向董监高支付报酬、提供福利；③限制**转让固有财产**或在固有财产上设定其他权利；④**责令更换**董监高或限制其权利；⑤**责令有关股东转让股权**或限制其行使股东权利；⑥责令**停业整顿、指定其他机构托管、接管、取消基金管理资格或者撤销**；⑦通知**出境管理机关**依法阻止直接负责的董监高和其他直接责任人员**出境**；⑧申请**司法机关**禁止上述人员**转移、转让或处分财产** |
| **私募基金管理人**| ①责令暂停部分或全部业务；②责令更换董监高、**执行事务合伙人或委派代表**，或限制其权利；③责令负有责任的股东转让股权、**负有责任的合伙人转让财产份额**；④责令聘请或指定**第三方机构对私募基金财产进行审计**，费用由管理人承担；⑤指定其他机构**接管**、通知登记备案机构**注销登记** |
| **基金托管人**| ①限制业务活动，**责令暂停办理新的基金托管业务**；②责令更换负有责任的**专门基金托管部门的高级管理人员** |

记忆抓手：公募有"**八项**"且最重（可停业整顿、撤销、限制出境）；私募突出"**合伙人/执行事务合伙人**"（因为多为合伙型）和"**审计、接管、注销登记**"；托管人只有"**两项**"。

#### 案例 3-1：利用未公开信息交易 P96

证监局突击检查辖区 14 家基金公司的基金经理执业行为，发现 A 公司甲某、B 公司乙某和丙某涉嫌**利用未公开信息买卖证券**：

- 甲某、乙某被**没收违法所得、罚款和市场禁入**；
- 丙某利用职务便利，当面或通过即时通信工具、电话传递信息，与他人共同操作其**亲属账户**，先于或同步于其管理的基金多次买卖相同个股，获利较大，被**移送司法机关追究刑事责任**，法院判处**有期徒刑 1 年，没收违法所得并处罚金 31 万元**。

**评析**：**2009 年 2 月 28 日**《**刑法修正案（七）**》增设"**利用未公开信息交易罪**"，将利用未公开信息交易纳入刑事制裁范围，加大了对基金从业人员**背信行为** 的打击力度。

### 3.2.c 【理解】中国人民银行、国家外汇管理局对基金行业的监管职责与措施 P96–P98

**大纲原文**：理解中国人民银行、国家外汇管理局对基金行业的监管职责与措施

#### （1）中国人民银行：反洗钱与反恐怖融资 P96–P97

依据《**反洗钱法**》，中国人民银行主要承担：

- **组织、协调** 全国的反洗钱工作；
- 负责反洗钱的**资金监测**；
- 制定或会同国务院有关金融管理部门制定**金融机构反洗钱管理规定**；
- **监督检查** 金融机构履行反洗钱义务的情况；
- 在职责范围内**调查可疑交易活动** 等。

**反洗钱监测分析机构**的职责：开展反洗钱**资金监测**，负责**接收、分析**大额交易和可疑交易报告，**移送**分析结果，并按规定向国务院反洗钱行政主管部门**报告** 工作情况。

- 金融机构的反洗钱与反恐怖融资工作适用《反洗钱法》《金融机构反洗钱和反恐怖融资监督管理办法》等，接受**中国人民银行** 监管。

#### 案例 3-2：未履行客户身份识别与可疑交易报告义务 P97

A 公募基金管理公司对部分投资人**未按规定履行客户身份识别义务**、**未按规定报送可疑交易报告**。2019 年，中国人民银行营业管理部依据《反洗钱法》：

- 因未履行客户身份识别义务，罚款 **145 万元**；
- 因未报送可疑交易报告，罚款 **45 万元**；
- **合计 190 万元**。

**评析**：反洗钱与反恐怖融资对维护经济安全和社会稳定、防范潜在金融风险和法律风险、维护金融安全、切断资助犯罪行为的资金来源、保护上游犯罪受害人财产权意义重大。金融机构应以**客户身份识别和尽职调查** 为基础，全面落实反洗钱义务。

#### （2）国家外汇管理局：涉外基金业务的外汇活动监管 P97–P98

监管主要体现在 **QDII**和**内地与香港基金互认** 两类业务。

**① 对 QDII 境外证券投资业务的外汇监管**

**QDII 业务定义**：符合法定条件的基金管理公司、证券公司等机构，经金融监管部门批准**在境内募集资金**，运用所募部分或全部资金（包括**公募基金或私募资产管理计划**）**以资产组合方式进行境外证券投资管理** 的业务。

**证监会与外汇局按各自职能分别监管**。外汇局的六项职责：

1. **审查批准**合格境内机构投资者的**经营外汇业务资格**；
2. **确定外汇额度**；
3. 接受 QDII 报送的**额度使用及资金汇出入** 情况；
4. 接受**产品托管人**报送的境外投资情况和**国际收支申报**；
5. 要求 QDII、托管人提供有关资料，必要时可**进行现场检查**；
6. QDII 运用基金、集合计划财产进行证券投资**发生重大违法违规行为**的，可依法采取**限制资金汇出（入）** 等措施并予以行政处罚。

**② 对内地与香港基金互认业务的外汇监管** P98

- **基金互认**：内地与香港之间达成**互相认可基金销售** 的机制。
- **北向互认基金**：依照**香港**法律在香港设立、运作和公开销售，并经**中国证监会批准在内地公开销售** 的单位信托、互惠基金或其他形式的集体投资计划。
- **南向互认基金**：依照**内地**法律在内地设立、运作，经履行**香港法律程序**，在香港公开销售的公募基金。

外汇局的四项职责：

1. **资金净汇入、净汇出的规模管理**；
2. 两地基金的**日常账户管理、资金汇入汇出管理**；
3. 接受跨境发行销售所涉及主体按规定进行的**国际收支申报、涉外收付款以及对外金融资产负债和交易统计申报**；
4. 其他**统计监测、信息报告**管理职责，以及对违法违规活动采取**执法措施**。

易错：**北向 = 香港的基金卖到内地**，**南向 = 内地的基金卖到香港**。方向是按"资金/产品流向内地还是香港"理解的，别记反。

#### 案例 3-3：转让或转卖 QDII 外汇额度 P98

A 公司是证券公司的私募资产管理子公司，违反 QDII 投资外汇管理规定，**向不具有 QDII 投资资质的公司提供投资额度**，累计**净汇出 1 628 万美元**，且向外汇局提交**不实证明材料**，严重干扰外汇市场秩序，情节严重。依据《外汇管理条例》，外汇局对 A 公司予以**警告并处罚款 775 万元人民币**。

**评析**：《合格境内机构投资者境外证券投资外汇管理规定》第六条规定"**合格投资者不得转让或转卖投资额度**"。A 公司获取额度后开展"**通道**"业务，实质性地**让渡了本公司取得的外汇额度**，构成"转让或转卖"行为。

## 3.3 行业自律

### 3.3.a 【掌握】中国证券投资基金业协会的性质、组成及其对基金行业的自律管理 P99–P101

**大纲原文**：掌握中国证券投资基金业协会的性质、组成及其对基金行业的自律管理

#### （1）概念与沿革 P99

- **行业自律**：某一行业内部通过**共同制定和遵守行业规范、标准和行为准则**，以维护行业良性发展和市场健康秩序的机制。
- **基金行业自律**：基金行业相关机构和从业人员，根据**行业协会、交易场所等自律组织** 的规范、标准和行为准则，共同维护基金市场秩序、促进行业健康发展的机制。
- 我国基金行业自律组织主要包括**中国证券投资基金业协会等行业协会**，以及**证券交易所等各类交易场所**。

**中国证券投资基金业协会的沿革**：

| 时间 | 事件 |
|---|---|
| **2001 年 8 月**| 中国证券业协会**基金公会** 成立 |
| **2002 年 12 月**| 中国证券业协会**证券投资基金业委员会** 成立（基金专业人士组成的议事机构，承接原基金公会职能，在证券业协会领导下开展工作） |
| **2007 年**| 中国证券业协会设立**基金公司会员部**，负责基金管理公司和基金托管银行**特别会员** 的自律管理 |
| **2012 年 6 月 6 日**|**中国证券投资基金业协会正式成立**，原证券业协会基金公司会员部的自律职责转入 |
| **2013 年**| 施行的《证券投资基金法》**专门增设"基金行业协会"一章**，详细规定其性质、组成及主要职责，为确定其地位、规范其职责权限提供**法律依据** |

记住"从证券业协会分出来"这条脉络： **2001 公会 → 2002 委员会 → 2007 会员部 → 2012 独立协会 → 2013 入法**。

#### （2）性质 P100

中国证券投资基金业协会是依据《**证券投资基金法**》和《**社会团体登记管理条例**》成立的**证券投资基金行业的自律性组织**，接受业务主管单位**中国证监会**和社团登记管理机关**民政部** 的业务指导和监督管理。

与证券业协会对比记：**基金业协会依据《证券投资基金法》**，**证券业协会依据《证券法》**；两者都受**证监会 + 民政部**双重指导监督，但证券业协会明确为**非营利性社会团体法人**。

#### （3）组成：四类会员 P100

| 会员类别 | 由谁构成 |
|---|---|
| **普通会员**|**公募基金管理人、基金托管人、符合协会规定条件的私募基金管理人** |
| **联席会员**|**基金服务机构** |
| **观察会员**|**不符合普通会员条件的其他私募基金管理人** |
| **特别会员**|**证券期货交易所、登记结算机构、指数公司、经副省级及以上人民政府民政部门登记的各类基金行业协会、境内外其他特定机构投资者** 等 |

- **同一机构从事多种与基金相关业务的**，应当以**普通会员、联席会员、观察会员、特别会员为次序**，依次选择对应会员类别申请入会。

**表 3-6 会员机构类型和入会基本条件**：

| 机构类型 | 入会基本条件 |
|---|---|
| **公募基金管理人** | 经核准从事公开募集基金业务的基金管理公司或其他金融机构 |
| **基金托管人** | 经核准取得证券投资基金托管资格的商业银行或其他金融机构 |
| **私募资产管理人** | 符合协会规定条件的从事私募资产管理业务的各类金融机构及其子公司 |
| **私募基金管理人** | 符合协会规定条件的从事非公开募集基金业务的基金管理人 |
| **基金服务机构** | 按规定注册、登记或备案的从事基金销售、销售支付、份额登记、估值、投资顾问、评价、信息技术系统服务等业务的机构 |
| **专业服务机构**| 为基金业务提供专业服务的**律师事务所和会计师事务所** 等 |
| **地方协会** | 经副省级及以上社会团体登记管理机关登记，接受国务院金融监督管理机构及其派出机构或地方政府金融监管部门业务指导监督的地方性社会团体 |
| **境外机构**| 经批准的**合格境外机构投资者** 和对基金行业有重要影响的境外机构 |

四类会员的记忆抓手：**普通（管钱的和托管钱的）→ 联席（服务的）→ 观察（不够格的私募）→ 特别（交易所、登记结算、境外等）**。

#### （4）八项职责 P100–P101

依据《证券投资基金法》，协会职责包括：

1. **教育和组织会员遵守**有关证券投资的法律、行政法规，**维护投资人合法权益**；
2. 依法**维护会员的合法权益**，反映会员的建议和要求；
3. **制定和实施行业自律规则**，监督、检查会员及其从业人员的执业行为，对违反自律规则和章程的**按规定给予纪律处分**；
4. 制定**行业执业标准和业务规范**，组织基金从业人员的**从业考试、资质管理和业务培训**；
5. **提供会员服务**，组织行业交流，推动行业创新，开展**行业宣传和投资人教育** 活动；
6. 对会员之间、会员与客户之间发生的**基金业务纠纷进行调解**；
7. 依法办理**非公开募集基金的登记、备案**；
8. 协会章程规定的其他职责。

- 协会通过**制定自律规则、开展自律检查**等方式，对管理人、托管人、销售机构、服务机构等行业机构及其从业人员实施自律管理；对违反法律法规的自律管理对象，可采取**自律管理和纪律处分措施**。

#### 案例 3-4：员工不当言论与未有效内控 P101

A 私募基金管理人的员工甲某、乙某通过**自媒体公众号**发表**贬低行业其他机构**的不当言论，并**向不特定对象宣传推介私募基金产品**，对行业声誉造成负面影响。A 公司**未能实施有效的内部控制**，未及时监督管控员工不当行为、未督促整改，构成**未履行谨慎勤勉义务** 的违规情形。

协会对 A 公司作出**公开谴责，并暂停受理私募基金产品备案 3 个月**的纪律处分；同步对涉事员工**公开谴责**，对 A 公司**法定代表人、合规风控负责人**进行**警告** 处分。

**评析**：违反《私募投资基金监督管理暂行办法》第四条（谨慎勤勉义务）、《私募投资基金管理人内部控制指引》（建立并实施有效内控、培养合规与风险意识）。协会依据基金法、暂行办法、协会章程、会员管理办法及**自律管理和纪律处分措施实施办法** 作出处分。

考点：**向不特定对象宣传推介私募基金**是典型违规；处罚形式包括**公开谴责、暂停备案、警告**。

### 3.3.b 【理解】中国证券业协会的性质、组成及其对基金行业的自律管理 P102–P103

**大纲原文**：理解中国证券业协会的性质、组成及其对基金行业的自律管理

#### （1）性质 P102

中国证券业协会是依据《**证券法**》和《**社会团体登记管理条例**》有关规定设立的**证券业自律性组织**，属于**非营利性社会团体法人**，接受业务主管单位**中国证监会**和社团登记管理机关**民政部** 的业务指导和监督管理。

#### （2）组成：三类会员 + 观察员 P102

| 会员类别 | 由谁构成 |
|---|---|
| **法定会员**|**证券公司** |
| **普通会员**| 证券投资咨询机构、证券资信评级机构、**证券公司私募投资基金子公司、证券公司另类投资子公司** 等可申请加入 |
| **特别会员**|**证券交易所、金融期货交易所、区域性股权市场运营机构** 等可申请加入 |
| **观察员**|**公募基金管理公司**根据相关规定可作为**网下机构投资者** 申请加入，成为观察员 |

关键差异：**在基金业协会，公募管理人是"普通会员"；在证券业协会，公募管理公司是"观察员"**。这是最容易设坑的一处对比。

#### （3）对基金行业的自律管理 P102–P103

- 依据《证券法》《中国证券业协会章程》《会员管理办法》，通过**制定自律规则、开展自律检查**实施自律管理；对违反证券法律法规的自律管理对象，可实施**自律管理措施和纪律处分**。作为会员的基金管理人等基金经营机构，**享有会员权利并履行会员义务**。
- **重点职责：对首次公开发行股票网下申购投资者的自律管理**。仅自《证券法》2019 年修订以来，协会就制定了《注册制下首次公开发行股票网下投资者管理规则》《首次公开发行证券网下投资者管理规则》等多部自律规则。
- **网下申购新股是证券投资基金的重要投资方式之一**，管理人运用基金财产参与 IPO 网下申购及其他协会有自律管理权的证券投资活动，应当适用上述规则并**接受协会自律管理**。

#### 案例 3-5：网下申购违规被列入限制名单 P103

A 公募基金管理公司管理的某私募资产管理计划在科创板"B 科技"等新股发行项目**网下申购、缴款**过程中存在违规（违反《注册制下首次公开发行股票网下投资者管理规则》第二十条），被列入**限制名单**。

另一案例：2019 年 12 月 9 日协会发布《首次公开发行股票配售对象黑名单公告（2019 年第 3 号）》，对在主板、中小企业板、创业板 2019 年 7 月至 8 月 **21 个 IPO 项目**网下申购中存在违反《首次公开发行股票承销业务规范》的**139 个股票配售对象**列入黑名单，其中包括若干公募基金和私募基金，被处以**未来半年或一年不得参与网下打新** 的自律管理措施。

**评析**：网下申购中的典型违规包括**弃购或部分弃购获配新股、违规顶格申购、获配后未按时足额缴付认购资金**等。这是协会对基金行业**较为典型和重要的自律管理手段之一**。

### 3.3.c 【理解】不同交易场所的性质及其对基金行业的自律管理 P103–P109

**大纲原文**：理解不同交易场所的性质及其对基金行业的自律管理

#### （1）证券交易所 P103–P105

**性质**：证券交易所是**为证券集中交易提供场所和设施，组织和监督证券交易，实行自律管理的法人**。

- 具有**监管者和被监管者的双重身份**：一方面作为**证券市场组织者**，提供集中交易场所、组织交易、实行自律管理，是**市场的管理者**，具有**法定的自律管理权限**；另一方面作为**特殊的市场主体**，也要**接受证券监管机构的监管**。

**十二项职责**（《证券交易所管理办法》）：

1. 提供证券交易的**场所、设施和服务**；
2. 制定和修改证券交易所的**业务规则**；
3. 依法**审核公开发行证券申请**；
4. **审核、安排证券上市交易**，决定证券终止上市和重新上市；
5. 提供**非公开发行证券转让服务**；
6. **组织和监督证券交易**；
7. 对**会员** 进行监管；
8. 对**证券上市交易公司及相关信息披露义务人** 进行监管；
9. 对**证券服务机构** 为证券上市、交易等提供服务的行为进行监管；
10. **管理和公布市场信息**；
11. 开展**投资者教育和保护**；
12. 法律、行政法规规定的以及**中国证监会许可、授权或者委托** 的其他职能。

**对基金行业的自律管理（两项）**：

| 方面 | 内容 |
|---|---|
| **① 对基金份额上市交易的自律管理**| 上交所、深交所都制定了《**证券投资基金上市规则**》及其他类型基金的业务指引，对在交易所挂牌上市的**封闭式基金、交易型开放式指数基金（ETF）、上市开放式基金（LOF）** 等基金的**上市条件和程序、信息披露要求** 作出具体规定。基金份额上市交易应遵守交易所业务规则，接受自律管理 |
| **② 对基金投资行为的自律管理**| 交易所设有**交易监控系统**，对基金在证券市场的投资运作行为以及投资者在场内买卖基金的合法合规性进行**日常监控**，重点监控涉嫌违法违规的交易行为、信息披露行为，并监控**基金财产买卖高风险股票**的行为等。发现交易行为**异常、涉嫌违法违规**的，可采取**电话提示、书面警告、约见谈话、公开谴责**等措施，并**同时向中国证监会报告** |

#### 案例 3-6：权益变动未及时披露 P104

A 公募基金管理公司旗下两只私募资产管理计划（"某某 1 号""某某 2 号"）合计持有 B 股份有限公司 **5% 以上**股份。2022 年 5 月 B 公司披露 A 的减持计划公告（合计减持不超过 6%）。至 2022 年 8 月 4 日合计减持 2%，但 A 公司在**所持股份每变动达到 1% 时未及时履行信息披露义务**，迟至 8 月 11 日才在减持进展公告中说明。**上交所认定违规，2024 年 5 月对 A 公司予以监管警示**。

**评析**：《证券法》第六十三条规定，投资者持有或与他人共同持有上市公司股份达到**5%** 之后，所持已发行**有表决权股份比例每增加或减少 1%**，应当在**该事实发生的次日通知该上市公司，并予公告**。

#### （2）其他交易场所 P105–P109

##### ① 中国银行间市场交易商协会 P105–P106

- **性质**：由市场参与者、中介机构及相关领域从业人员和专家学者**自愿组成**，包括**银行间债券市场、同业拆借市场、外汇市场、票据市场、黄金市场和衍生品市场**在内的**银行间市场的自律组织**；为**全国性的非营利性社会团体法人**，接受业务主管单位**中国人民银行**和社团登记管理机关**民政部** 的业务指导和监督管理。
- **基金进入银行间市场的依据**：
  - **1999 年**，中国人民银行《基金管理公司进入银行间同业市场管理规定》，允许**公募基金** 进入银行间债券市场交易；
  - **2015 年**，《中国人民银行金融市场司关于私募投资基金进入银行间债券市场有关事项的通知》，允许并规范**私募基金** 进入。
- 交易商协会针对银行间债券市场制定了《**银行间债券市场债券交易自律规则**》以及关于债券（含其他债务融资工具）**发行、信用评级、投资者准入** 及自律管理措施等方面的大量自律规则。
- **自律处分措施**：诫勉谈话、通报批评、警告、严重警告、公开谴责、责令改正、责令致歉、暂停相关业务、暂停会员权利、认定不适当人选、取消业务资格或取消会员资格等。

##### ② 期货交易所 P106

- **性质**：受**中国证监会集中统一监管**，为期货交易提供场所和设施，组织和监督期货交易，依据《**期货和衍生品法**》《**期货交易管理条例**》等设立，按照章程和业务规则**实行自律管理的法人**。
- **基金投资期货的依据**：股指期货、国债期货、商品期货等是基金的重要投资品种。公募基金参与期货交易适用《证券投资基金参与股指期货交易指引》《公开募集证券投资基金参与国债期货交易指引》《公开募集证券投资基金运作指引第 1 号——商品期货交易型开放式基金指引》等；**私募基金依据《证券投资基金法》同样可以进行期货投资**。
- **自律措施**：期货交易所可采取**暂停受理或办理相关业务、限制交易权限、取消会员资格** 等纪律处分或其他自律管理措施。

##### ③ 全国中小企业股份转让系统（新三板） P107

- **性质**：经**国务院批准**、依据《**证券法**》设立的**第三家全国性证券交易场所**。
- **运营机构**：全国中小企业股份转让系统有限责任公司（**全国股转公司**）；**全国股转公司、北京证券交易所实行一体管理**，受**中国证监会** 监督管理。
- **基金参与依据**：私募基金和私募资管计划可分别依据《私募投资基金监督管理暂行办法》《证券期货经营机构私募资产管理业务管理办法》等及合同约定参与全国股转系统的证券交易；同时，**全国股转系统挂牌股份转让退出也是私募股权投资基金的重要退出方式**。
- 管理人运用基金财产参与全国股转系统交易的，应接受**全国股转公司**的自律管理；股转公司发现违反法律法规及业务规则的，可依法采取**自律监管措施**并**报中国证监会备案**；依法应由证监会查处的，股转公司应向证监会**提出查处建议**。

##### ④ 区域性股权市场 P108–P109

- **性质**：主要服务于**所在省级行政区域内中小微企业**的**私募股权市场**，为非公开发行证券的**发行、转让** 提供场所和设施。
- **参与者**：符合条件的**合格投资者**，包括**私募股权投资基金等资产管理产品**，可参与并投资交易中小微企业非公开发行的**股票和可转债**。
- **监管分工**（《区域性股权市场监督管理试行办法》）：

| 主体 | 职责 |
|---|---|
| **省级人民政府**| 依法**监督管理**，负责**风险处置** |
| **省级政府指定的地方金融监管部门**| 承担**日常监督管理** 职责，依法查处违法违规行为，组织开展风险防范、处置 |
| **区域性股权市场运营机构**|**组织**市场活动，对市场参与者进行**自律管理** |

- 与全国股转系统相似，私募基金和私募资管计划可依约定参与区域性股权市场交易；区域性股权市场也为**私募股权投资基金提供了退出被投资企业的渠道**。

#### 案例 3-7～3-9：其他交易场所的典型自律处分 P105–P108

| 案例 | 违规事实 | 处分 |
|---|---|---|
| **3-7 交易商协会**| 2023 年交易商协会对**52 家机构**立案调查，作出自律处分**121 家（人）次**；查办"**自融**""**返费**"等非市场化发行案件**22 起**，涉及 10 家发行人、12 家中介机构 | 自律处分（含私募基金管理人、基金经理等） |

**法条依据**（案例 3-9 评析）：

- 《非上市公众公司收购管理办法》第十三条：投资者及其一致行动人拥有权益的股份达到公众公司已发行股份的 **10%** 后，其拥有权益的股份占该公司已发行股份的比例**每增加或减少 5%**，自该事实发生之日起**至披露后 2 日内，不得再行买卖** 该公众公司股票。
- 《证券法》第四十四条：上市公司、股票在国务院批准的其他全国性证券交易场所交易的公司，**持有 5% 以上股份的股东**，将其持有的该公司股票**在买入后 6 个月内卖出，或者在卖出后 6 个月内又买入**的，属于违法行为（**短线交易**）。

"自融"典型方式：发行人或其关联方**通过基金、资管产品投资其自身发行的债券或债务融资工具**，其后通过**债券回购融资继续用于滚动买入**自身或关联方发行的债券。"返费"：以"**账户监管费**"等名义，在债券发行完成后**补贴给投资者**。二者都干扰发行定价、破坏市场秩序。

## 本章小结

三条线：

- **法规体系**：纵向四层（法律→行政法规→部门规章→自律规则），横向覆盖三类产品与六类业务。"一法六规"是公募的骨架。
- **行政监管**：一个概念（准入+行为+处置）、三个目标（首要是保护投资人）、六条原则（依法、保权益、强监管、高效、审慎、三公）；**证监会**管主体与行为（含七项措施、处罚与监管措施之别），**央行**管反洗钱，**外汇局** 管 QDII 与基金互认。
- **行业自律**：**基金业协会**（依据基金法，四类会员，八项职责，办私募登记备案）、**证券业协会**（依据证券法，三类会员+观察员，管网下申购）、**交易场所**（交易所管上市与投资行为；交易商协会管银行间债券市场；期货交易所管期货；股转公司管新三板；地方管区域性股权市场）。

下一章进入**第四章 基金市场参与主体及其从业人员的法规要求**（4.1–4.6，23 个知识点，教材 P110–P171）——这是科目一**知识点最多、分值最重** 的一章。
