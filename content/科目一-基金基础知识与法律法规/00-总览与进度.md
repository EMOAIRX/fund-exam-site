# 科目一 · 总览与进度

> **科目一** ｜ 大纲依据：基金从业资格全国统一考试大纲（2026 年度修订）
> **教材**：基金基础知识与法律法规（2025 年版，中国财政经济出版社，399 页）

大纲共 **108 个知识点**，分 8 章。本站**严格按大纲顺序**推进，每条大纲知识点对应一个 `###` 小节，标题标注能力等级。

## 怎么用这份笔记

| 标记 | 含义 |
|---|---|
| 【掌握】 | 必须能**复述 + 辨析 + 应用**，考试重灾区，占比最高 |
| 【理解】 | 能用自己的话解释、能区分相近概念 |
| 【了解】 | 眼熟即可，多是背景、历史、名单类 |
| 📖 P12 | 该知识点在教材**印刷页码**第 12 页 |
| 💡 | 记忆锚点 / 口诀 |
| ⚠️ | 易错、易混点 |
| 🧩 教材补充 | 大纲未单列但教材有、真题常考的内容 |

> **页码说明**：教材 PDF 前 8 页是封面、版权、前言、目录，所以 **PDF 页码 = 印刷页码 + 8**。
