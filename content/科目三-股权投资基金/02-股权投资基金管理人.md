## 2.1 股权投资基金管理人概述

### 2.1.a 【了解】基金管理人的概念 P25

**大纲原文**：了解基金管理人的概念

> **股权投资基金管理人通常指具有专门的知识与经验，依据法律规定及基金合同约定，受托管理基金财产，致力于通过股权投资等方式实现基金财产增值，并努力为基金投资者获取收益的专业机构**。

> **基于国内外行业发展和立法实践，向合格投资者非公开募集资金、委托管理人进行管理、投向非公开交易的企业股权类资产是股权投资基金的主要特征**。

**股权投资基金管理人的五个特征（必背）**：

| # | 特征 |
|---|---|
| **（1）** | **向合格投资者非公开募集资金** |
| **（2）** | **与投资者存在受托关系，受托管理基金财产** |
| **（3）** | **利用受托的财产主要从事股权投资活动** |
| **（4）** | **为投资者之利益从事经营活动** |
| **（5）** | **通过受托管理行为获取合理报酬** |

> **因此，满足上述特征的机构一般应当被认定为股权投资基金管理人，纳入私募基金行业监管体系并按照相关监管要求开展经营活动**。

---

### 2.1.b 【掌握】基金管理人的基本经营要求 P25–P27

**大纲原文**：掌握基金管理人的基本经营要求

> **股权投资基金管理人是股权投资基金运作的关键主体**；**依据国内现行法律法规及自律规则，尽管股权投资基金管理人的设立不实行行政许可管理，但其应具备持续开展基金管理业务所需的从业人员、经营场所、资本金等运营基本设施和条件，并拥有健全的内部治理结构、完善的风控合规制度和利益冲突防范机制等**；**基金管理人在中国证券投资基金业协会完成登记之后方可开展资金募集、基金管理等业务活动**。

#### （一）管理人名称、经营范围和业务范围 P26

**名称与范围的强制性字样要求（必考）**：

| 项目 | 要求 |
|---|---|
| **名称中应标明** | **"私募基金""私募基金管理"或"创业投资"字样** |
| **经营范围中应标明** | **"私募投资基金管理""私募股权投资基金管理""创业投资基金管理"等体现行业特点的字样** |

**名称的三类禁止情形（必考）**：

| # | 禁止 |
|---|---|
| **1** | **未经批准，不得在名称中使用"金融控股""金融集团""中证"等字样** |
| **2** | **不得使用与国家重大发展战略、金融机构、知名私募基金管理人相同或者近似等可能误导投资者的字样** |
| **3** | **不得使用违背公序良俗或者造成不良社会影响的字样** |

**业务范围的专业化要求（核心考点）**：

> **从业务范围来看，股权投资基金管理人应体现专业化经营特征，聚焦投资管理主业，可围绕股权投资基金管理开展资金募集、投资管理、为被投资企业提供管理咨询等业务，但不得从事任何与股权投资基金相冲突或无关的业务**；**此外，股权投资基金管理人不能同时从事证券投资基金管理业务**。

#### （二）管理人组织形式 P26

> **在我国，股权投资基金管理人可采取公司制或合伙制**；**实践中，多数股权投资基金管理人采取公司组织形式，也有少量管理人采取有限合伙组织形式**。

#### （三）资本金（数字必背） P26

> **基金管理人的出资人应以合法自有资金出资，注册资本及实缴资本均应当符合相关规定，确保有足够的资本金保证机构有效运转**。

| 要求 | 内容 |
|---|---|
| **财务状况** | **应当财务状况良好** |
| **实缴资本门槛** | **实缴货币资本不低于 1 000 万元人民币或者等值可自由兑换货币**；**对专门管理创业投资基金的基金管理人另有规定的，从其规定** |
| **出资形式** | **资本金应当以货币出资，不得以实物、知识产权、土地使用权等非货币财产出资** |
| **境外出资人** | **应当以可自由兑换的货币出资** |

#### （四）基本管理制度 P27

> **基金管理人应制定并执行一系列基本管理制度**，**制度内容应涵盖**：

| # | 制度领域 |
|---|---|
| **1** | **基金募集** |
| **2** | **投资管理** |
| **3** | **关联交易与利益冲突管理** |
| **4** | **基金信息披露** |
| **5** | **财务管理** |
| **6** | **内部控制** |
| **7** | **档案管理** |

> **基金管理人应保持自身与所管理基金的独立性；管理人与所管理基金之间、管理人管理的不同基金之间，不得存在财产混同现象**。

#### （五）管理人登记 P27

> **股权投资基金管理人应当根据相关规定，向中国证券投资基金业协会申请管理人登记**；**管理人登记环节，应满足相关自律规则要求的条件**；**在完成管理人登记之前，不得开展基金募集、基金管理等业务**。

#### （六）基本经营要求速查表

| 维度 | 核心要求 |
|---|---|
| **名称** | **标明"私募基金""私募基金管理"或"创业投资"；禁用"金融控股""金融集团""中证"等** |
| **经营范围** | **标明"私募投资基金管理""私募股权投资基金管理""创业投资基金管理"等** |
| **业务范围** | **专业化经营，聚焦主业；不得与证券投资基金管理业务兼营** |
| **组织形式** | **公司制（多数）或合伙制（少量有限合伙）** |
| **资本金** | **实缴货币资本 ≥ 1 000 万元；仅货币出资** |
| **股权结构** | **清晰；禁止非自有资金出资、代持、循环出资、交叉持股** |
| **人员** | **法定代表人/高管/执行事务合伙人须有基金从业资格；除少数高管外须专职** |
| **制度** | **七类制度；保持独立性，禁止财产混同** |
| **登记** | **中基协登记后方可展业** |

### 2.1.c 【掌握】基金管理人股东、合伙人、实际控制人的合规要求 P26–P27

**大纲原文**：掌握基金管理人股东、合伙人、实际控制人的合规要求

> **基于组织类型差异，基金管理人的出资人包括公司的股东、合伙企业的合伙人**。

#### （一）出资人与股权结构的合规要求 P26–P27



**股权结构的四项要求（必考）**：

| # | 要求 |
|---|---|
| **1** | **股权结构应当清晰** |
| **2** | **不得以委托资金、债务资金等非自有资金出资** |
| **3** | **不得违规通过委托他人或者接受他人委托方式持有股权、财产份额（禁止代持）** |
| **4** | **不得存在循环出资、交叉持股、结构复杂等情形** |

> **基金管理人的实际控制人及主要出资人一般不应当是资产管理产品**。

> **此外，基金管理人的股东、合伙人以及股东、合伙人的控股股东、实际控制人，控股或者实际控制其他基金管理人的，应当符合中国证监会的规定**；**前述规定主要包括相关主体财务状况、治理结构、信用记录、潜在利益冲突、经验匹配等方面的要求**。


#### （二）股权结构的四项禁止性要求（必考）

| # | 要求 |
|---|---|
| **1** | **股权结构应当清晰** |
| **2** | **不得以委托资金、债务资金等非自有资金出资** |
| **3** | **不得违规通过委托他人或者接受他人委托方式持有股权、财产份额（禁止代持）** |
| **4** | **不得存在循环出资、交叉持股、结构复杂等情形** |

#### （三）实际控制人与主要出资人的限制

> **基金管理人的实际控制人及主要出资人一般不应当是资产管理产品**。

> **基金管理人的股东、合伙人以及股东、合伙人的控股股东、实际控制人，控股或者实际控制其他基金管理人的，应当符合中国证监会的规定**；**前述规定主要包括相关主体财务状况、治理结构、信用记录、潜在利益冲突、经验匹配等方面的要求**。

#### （四）股东与合伙人合规要求速查表

| 维度 | 合规要求 |
|---|---|
| **出资来源** | **合法自有资金；禁止委托资金、债务资金等非自有资金** |
| **股权结构** | **清晰；禁止代持、循环出资、交叉持股、结构复杂** |
| **实际控制人** | **一般不应当是资产管理产品** |
| **控股其他管理人** | **应符合中国证监会规定（财务状况、治理结构、信用记录、潜在利益冲突、经验匹配）** |

### 2.1.d 【掌握】基金管理人从业人员的合规要求 P27

**大纲原文**：掌握基金管理人从业人员的合规要求

> **为保障基金管理人持续胜任基金管理职责，从事股权投资基金管理业务相关工作人员应具备与岗位要求相适应的职业操守和专业胜任能力**。

#### （一）从业人员的合规要求 P27



| 要求 | 内容 |
|---|---|
| **基金从业资格** | **法定代表人、高级管理人员、执行事务合伙人或其委派代表应具备基金从业资格** |
| **专职要求** | **除少数高级管理人员外，管理人的从业人员应为专职人员** |
| **专业化管理** | **《私募条例》规定，基金管理人应当遵循专业化管理原则，聘用具有相应从业经历的高级管理人员负责投资管理、风险控制、合规等工作** |
| **负面清单** | **《私募条例》以"负面清单"形式列明了不得担任基金管理人的董事、监事、高级管理人员、执行事务合伙人或其委派代表的情形** |


#### （二）从业人员合规要求速查表

| 维度 | 要求 |
|---|---|
| **职业操守与专业能力** | **与岗位要求相适应** |
| **基金从业资格** | **法定代表人、高级管理人员、执行事务合伙人或其委派代表应具备基金从业资格** |
| **专职要求** | **除少数高级管理人员外，从业人员应为专职人员** |
| **专业化管理** | **聘用具有相应从业经历的高级管理人员负责投资管理、风险控制、合规等工作** |
| **负面清单** | **不得担任董事、监事、高级管理人员、执行事务合伙人或其委派代表的情形** |

### 2.1.e 【掌握】基金管理人的职责 P28–P29

**大纲原文**：掌握基金管理人的职责

#### （一）基金管理人在基金中的角色 P27–P28

> **随着行业的发展以及基金管理人群体的崛起，股权投资基金更多地被视为"投资载体"或"投资工具"，除非法律有特别要求，基金内部并不配备常设人员负责基金经营管理活动**；**对于基金和基金投资者而言，基金管理人作为基金的运营者承担受托人的角色，其首要责任是为投资者的最佳利益行事**。

> **基金管理人将提供运营基金所需要的服务，或者组织其他的服务提供方来提供相应的服务**；**前述服务通常包括两类**：

| # | 服务 | 内容 |
|---|---|---|
| **1** | **投资管理服务** | **投资管理是基金管理人可提供的核心服务内容，是基金管理人赖以生存的基本技能**；**包括潜在投资标的的获取、调查、分析与评估，投资组合的构建，以及对被投资企业的投后管理和退出等** |
| **2** | **基金运营服务** | **基金合法有效的存续有赖于基金管理人提供必要的运营管理**；**包括投资者事务、工商及税务相关事项、信息披露与报送、基金估值与核算、其他日常行政管理等** |

> **基金管理人可依法依规聘请符合条件的第三方服务机构提供部分基金运营服务**。

#### （二）我国基金管理人的八项法定职责（必背） P29

> **受限于基金所在地法律或监管规则不同，基金管理人职责或存在差异；就我国而言，依据《私募条例》，基金管理人应履行如下职责**：

| # | 职责 |
|---|---|
| **（1）** | **依法募集资金，办理基金备案** |
| **（2）** | **对所管理的不同基金财产分别管理、分别记账，进行投资** |
| **（3）** | **按照基金合同约定管理基金并进行投资，建立有效的风险控制制度** |
| **（4）** | **按照基金合同约定确定基金收益分配方案，向投资者分配收益** |
| **（5）** | **按照基金合同约定向投资者提供与基金管理业务活动相关的信息** |
| **（6）** | **保存基金财产管理业务活动的记录、账册、报表和其他有关资料** |
| **（7）** | **以基金管理人自己的名义，为基金财产利益行使诉讼权利或者实施其他法律行为** |
| **（8）** | **国务院证券监督管理机构规定和基金合同约定的其他职责** |

#### （三）管理人、普通合伙人与执行事务合伙人的区分（易考） P28

> **《私募条例》规定，在中华人民共和国境内以非公开方式募集资金，设立投资基金或者以进行投资活动为目的依法设立公司、合伙企业，由私募基金管理人或者普通合伙人管理，为投资者的利益所进行的投资活动，均视为私募投资基金业务活动受规制**；**以合伙企业形式设立的私募基金，资产由普通合伙人管理的，普通合伙人也适用《私募条例》关于私募基金管理人的规定**。

> **由于境外部分国家股权投资基金行业多采取有限合伙制，基金管理人经常会兼任合伙型基金的普通合伙人或执行事务合伙人，即使在不兼任情况下，两者通常也属主要管理团队出资设立的关联机构**——**因此国外立法及行业实践更强调普通合伙人作为基金运营者的核心作用，一定程度上淡化了基金管理人的作用，或者以普通合伙人指代基金管理人**。

> **实践中，业内经常将基金管理人与基金普通合伙人、执行事务合伙人混同使用，甚至以"GP 团队"指代基金管理人团队，但是在法律意义上，基金管理人、普通合伙人、执行事务合伙人存在严格区分**。

**我国合伙型基金的特别要求（必背）**：

> **合伙型基金主要依据《合伙企业法》规定设立，由基金管理人或其关联方作为普通合伙人负责执行合伙事务；根据《合伙企业法》规定，有限合伙企业中仅能由普通合伙人执行合伙事务**。

> **根据中国证券投资基金业协会发布的相关自律规则，基金管理人设立合伙型基金，应当担任执行事务合伙人，或者与执行事务合伙人存在控制关系或者受同一控股股东、实际控制人控制**。

> **从法律上，基金管理人、普通合伙人、执行事务合伙人既可以三者竞合，也可能出现基金管理人与普通合伙人、执行事务合伙人分离的情形**；**为防止基金管理人通道化，如果合伙型基金的基金管理人不担任执行事务合伙人，应与执行事务合伙人存在强关联关系**。

#### （四）八项职责速记

| 类别 | 职责要点 |
|---|---|
| **募集与备案** | **依法募集资金，办理基金备案** |
| **财产管理** | **分别管理、分别记账、进行投资；建立有效风险控制制度** |
| **收益与信息** | **确定收益分配方案并分配；提供与业务活动相关的信息** |
| **资料与诉讼** | **保存记录账册报表等资料；以自己的名义为基金财产利益行使诉讼权利或实施其他法律行为** |

## 2.2 股权投资基金管理人的信义义务

### 2.2.a 【了解】信义义务的概念 P29–P30

**大纲原文**：了解信义义务的概念

#### （一）信义关系 P29–P30

> **信义关系（Fiduciary Relationship）是委托人（受益人）与受托人建立在信任基础上形成的关系**；**信托是最为典型的信义关系**。

> **依据《中华人民共和国信托法》，信托是指委托人基于对受托人的信任，将其财产权委托给受托人，由受托人按委托人的意愿以自己的名义，为受益人的利益或者特定目的，进行管理或者处分的行为**。

**信义关系的四个特征（必背）**：

| # | 特征 |
|---|---|
| **（1）** | **受托人提供委托人需要且专业性较强的服务** |
| **（2）** | **受托人被托付财产或授予权力** |
| **（3）** | **存在受托人滥用权力或者服务未达预期的风险** |
| **（4）** | **市场机制无法保护委托人免于这种风险，或者交易成本太高导致保护机制无法建立** |

> **也有学者认为，只要受托人能够对涉及委托人重要利益的事务行使自由裁量权（信义权力），就可以认为委托人和受托人之间存在信义关系**。

> **一般认为，信义关系是信托关系的上位概念，委托人（受益人）与受托人之间信义关系的建立并不必然以双方信托关系的建立为前提**；**在经济领域，常见的信义关系还包括董事与公司、合伙人与合伙企业等**。

#### （二）信义义务 P30

> **在信义关系中，委托人（受益人）与受托人地位、信息与能力处于不对等、不平衡的状态，为了有效应对这个问题，受托人需要承担信义义务（Fiduciary Duty）**。

> **信义义务包括忠实义务（Duty of Loyalty）与勤勉义务（Duty of Care）**：

| 类型 | 定义 |
|---|---|
| **忠实义务** | **受托人应忠于受益人的利益，以受益人利益为先，不能将自身利益置于与受益人利益冲突的位置**；**忠实义务是信义义务的核心** |
| **勤勉义务（亦称注意义务、谨慎义务）** | **受托人为实现受益人利益最大化需具备专业能力并付出不懈努力** |

---

### 2.2.b 【了解】信义义务的重要性 P30–P31

**大纲原文**：了解信义义务的重要性

> **信义义务是股权投资基金领域不可或缺的法律原则，对于保护投资者利益、提升行业标准、促进资本形成和有效配置具有重要作用**。

#### （一）对管理人与投资者关系的作用 P30

> **信义义务为基金管理人与投资者之间建立了信任和责任的框架**。

| 作用 | 内容 |
|---|---|
| **强化信任与吸引资本** | **信义义务要求管理人将投资者的利益置于首位，避免利益冲突，确保所有投资决策都以最大化投资者回报为目标；这增强了投资者对基金管理人的信任，为基金吸引了更多的资本** |
| **提升决策质量与治理水平** | **信义义务通过规范管理人的行为，提高了投资决策的质量，促进了基金治理水平的提升，确保管理人采取适当的风险管理措施，保护投资者的资金安全** |

#### （二）对行业健康发展的作用 P30–P31

| 作用 | 内容 |
|---|---|
| **维护声誉、防止不当行为** | **有助于维护行业的声誉，防止不当行为** |
| **促进资本有效配置** | **促进了资本的有效配置，使资本能够流向最有潜力的投资机会** |
| **威慑作用** | **违反信义义务的管理人可能面临法律责任和声誉损失，这种威慑作用促使管理人更加谨慎行事，遵守行业规范** |
| **监管与评估标准** | **随着监管环境的日益严格，信义义务也成为监管机构和投资者评估基金管理人管理职责履行的重要标准** |

---

### 2.2.c 【掌握】基金管理人履行信义义务的核心要求 P31–P34

**大纲原文**：掌握基金管理人履行信义义务的核心要求

#### （一）信义义务的理论基础 P31

> **在股权投资基金领域，基金投资者将资金委托给基金管理人进行投资管理，由于基金管理对专业性要求较高，需要授予基金管理人较大的对于基金财产的管理权，包括投资决策、投资标的处置等；又由于基金投资者与基金管理人之间存在信息不对称和利益不必然一致，加上各国一般对股权投资基金管理人实行有限的适度监管，单纯依靠市场机制通常无法对基金投资者利益进行充分有效的保护**；**基金投资者与基金管理人之间的关系是典型的信义关系，基金管理人应当承担信义义务**。

> **我国的法律制度对于基金管理人的信义义务也有明确要求：《私募条例》规定，基金管理人管理、运用基金财产，应当遵守法律、行政法规规定，恪尽职守，履行诚实守信、谨慎勤勉的义务**。

#### （二）基金管理人的忠实义务（四个方面，必背） P31–P32

> **在股权投资基金行业，基金管理人的忠实义务主要围绕利益冲突管理展开，基金管理人有义务妥善管理与基金投资者的利益冲突**。

##### ① 关联交易与投资机会分配 P31

| 场景 | 要求 |
|---|---|
| **关联交易** | **基金管理人应明确界定基金关联交易的范围，明确处理关联交易的原则、规则和程序，并将相关事项在基金合同中进行约定，避免利用关联交易进行利益输送，从而损害投资者利益** |
| **投资机会分配** | **可能产生利益冲突的情形主要包括：基金与管理人自有资金投资之间、基金与管理人所管理的其他基金之间、基金不同投资者之间可能存在投资机会分配的情形**；**基金管理人应明确不同情况下投资机会分配的原则，避免形成对不同投资者的不公平对待** |

> **此外，基金管理人不应借助基金管理获取额外的不当利益**——**例如，基金管理人不应向基金的被投资企业收取咨询费、交易费等费用和报酬；如果管理人确实提供了相关服务，按照市场原则也确实应当收取一定费用时，除非管理人事先与基金投资者就此类收费的分配达成一致，否则这些收费原则上应归入基金收益**。

##### ② 基金费用与收益分配 P32

| 方面 | 要求 |
|---|---|
| **基金费用** | **一方面，管理人应本着维护投资者利益的原则，尽可能节约基金费用；另一方面，按照忠实义务的原则要求，管理人收取基金管理费应做到公平合理，杜绝基金管理人以赚取管理费为管理基金的首要目的** |
| **收益分配原则** | **要秉持投资者利益为先、激励有效和激励适度的原则** |
| **门槛收益安排** | **在投资者利益为先原则指导下，通常会设计门槛收益安排——在投资者收回投资本金之后，由投资者优先获得某一事先约定的门槛收益** |
| **业绩报酬安排** | **在激励有效和激励适度原则指导下，通常会设计业绩报酬安排，激励基金管理人努力实现基金利益最大化；同时，也需要对业绩报酬的比例进行适当限制，防止基金管理人将多数或全部超额收益占为己有** |
| **公平对待** | **在基金收益分配时，还要做到公平对待投资者，避免不同投资者被区别对待** |

##### ③ 基金运营和信息披露 P32

> **在基金财务核算与估值、财务审计、托管与服务外包等基金运营环节，管理人需要秉持诚信与透明原则，本着投资者利益优先的原则处理相关问题**；**同时，在外部服务机构特别是具有一定外部监督角色的机构选聘中，应由基金投资者为主进行决策或者按照投资者认可的决策机制进行决策**。

> **在基金运作过程中，基金管理人应当及时向投资者披露与投资者利益相关的所有重要信息，包括基金管理人的信息和基金的信息**。

##### ④ 合规义务 P32

> **为了维护投资者利益，基金管理人有义务遵循与基金管理相关的所有法律法规、监管要求及自律规则**：

| 方面 | 要求 |
|---|---|
| **机构层面** | **应建立合规管理和内部控制体系，防止违法违规行为发生** |
| **人员层面** | **基金管理人及其实际控制人、股东、董事、相关从业人员有义务约束自身行为，不得有任何欺诈行为** |

##### 案例 2-1：设立"资金池"，向关联方进行利益输送 P32–P33

> **Y 公司是一家注册在北京的基金管理公司，2014 年在中国证券投资基金业协会登记为私募基金管理人，且备案了 1 只产品，但其实际投资运作了 27 只产品**；**其处于存续期的产品规模大，涉及投资者众多，产品兑付压力大，个别产品已出现兑付风险**。

**违规事实**：

| # | 事实 |
|---|---|
| **1** | **发行 M1、M2……Mn 等多只私募产品，设立了 A1、A2……An 等多个有限合伙企业；合同约定 M1 由 A1 作为资金募集及运作主体，但实际由 A2 代理** |
| **2** | **合同约定 M2 投向信托产品劣后级，但实际投资中为规避监管将资金汇入某个人账户并以其名义投资于信托产品** |
| **3** | **合伙企业之间与管理人账户之间存在多笔资金往来；M3 产品成立后，资金转入合同未约定的其他单位账户** |
| **4** | **Y 公司将部分基金财产与公司固有财产及他人财产混同、涉嫌挪用基金财产** |

> **违反《私募投资基金监督管理暂行办法》第二十三条关于"不得侵占、挪用基金资产"的规定，北京证监局对 Y 公司进行了处理**。

**案例简评（"资金池"的三种形式，必考）**：

| # | 形式 |
|---|---|
| **1** | **通过发行多期产品，产品均投向同一项目，为满足不同运作阶段的资金需求，常常需要"借新还旧"** |
| **2** | **通过超额募集资金，将部分资金投资于约定项目，其余资金用于偿还到期产品的约定收益** |
| **3** | **公司将募集资金投入亏损项目，弥补损失** |

> **基金管理人通过复杂的关联交易进行利益输送**——**Y 公司与 B 公司之间关系较为复杂，涉嫌"关联交易非关联化"**。

##### 案例 2-2：挪用基金资产 P33–P34

> **某私募股权基金管理人在管的私募基金 A 向其实际管理的、应备案未备案的合伙企业 B 出资 3 000 万元作为投资款，拟由合伙企业 B 投资未上市企业股权**；**合伙企业 B 接收投资款后，同日即将该笔资金分别出借给管理人和某融资租赁公司**；**借款期间，融资租赁公司定期向合伙企业 B 支付利息，但利息收入均被转至管理人账户**；**管理人未向中基协提供足以证明向私募基金 A 的投资者充分披露上述款项实际使用情况的证据**；**截至自律检查期间，上述借款尚未归还**。

> **中基协认为，管理人的该等行为违反了《私募投资基金监督管理暂行办法》第二十三条第四项关于私募基金管理人不得侵占、挪用基金财产的相关规定**；**纪律处分：取消管理人的会员资格，撤销其管理人登记**。

#### （三）基金管理人的勤勉义务（专业 + 审慎） P34

> **勤勉义务要求基金管理人在行使投资决策和基金资产处置的自由裁量权过程中，应综合考虑基金目的、风险、期望收益等多个因素，秉持专业、审慎原则作出最符合基金投资者利益的决策**。

##### ① 专业 P34

> **在勤勉义务履行过程中，专业人士标准是最为重要的内容之一**；**专业人士标准，是指受托人应当具有与其受托目的和领域相适应的专业技能和专门知识，并使用这些专业技能和专门知识为受益人利益服务**。

> **股权投资基金管理人作为受托人，有义务按照基金运营目的和约定投资领域，配备专业的投资管理团队，从而为其勤勉义务的履行奠定专业基础**。

##### ② 审慎 P34

> **勤勉义务强调基金管理人应当为实现基金运营目的、维护投资者利益而不懈努力和发挥其专业能力**；**如果说团队专业性强调的是"能力"，那么"努力"就意味着基金管理人需要把这种"能力"付诸实践**：

| 方面 | 内容 |
|---|---|
| **努力寻找机会** | **在投资管理中努力寻找价值增值的机会** |
| **恪守注意义务** | **审慎进行投资风险管理** |

> **这就要求股权投资基金管理人建立专业化、市场化、规范化的投资管理体系，并确立制度化的内部激励和约束机制，以确保团队的专业性得到充分发挥并持续优化**。

#### （四）信义义务速查表

| 维度 | 核心要求 |
|---|---|
| **忠实义务（核心）** | **① 关联交易与投资机会分配；② 基金费用与收益分配（门槛收益 + 业绩报酬 + 公平对待）；③ 基金运营与信息披露；④ 合规义务** |
| **勤勉义务** | **专业（专业人士标准）+ 审慎（努力 + 恪守注意义务）** |
| **法规依据** | **《私募条例》：恪尽职守，履行诚实守信、谨慎勤勉的义务** |

## 2.3 股权投资基金管理人的专业要求

### 2.3.a 【了解】基金管理人的专业要求 P35–P37

**大纲原文**：了解基金管理人的专业要求

> **不同的基金运作方式（如作为母基金或作为直接投资基金）、不同的投资方式（如创业投资或并购投资）、不同的投资产业领域（如生物医疗或电子信息）、不同的投资阶段（如早期企业投资或临上市企业投资），对基金管理人团队专业性的要求有很大的区别**；**总体而言，基于股权投资的共性特征，作为股权投资基金管理人，其投资管理团队一般应当在以下几个领域具备一定的专业水平**。

#### （一）行业 P35

> **专业团队应当对基金投资领域所覆盖的行业（包括行业趋势、市场动态、竞争格局等）具有较为深入的理解，能够识别行业内的增长机会和潜在风险**。

> **由于股权投资的标的是非公开交易的企业股权，多数时候是未上市企业股权，因此，其投资风险相对较高；为有效应对投资风险，"不熟不做"是常见的投资原则，即基金管理人应避免对不了解、不熟悉的行业进行投资**。

> **因此，基金管理人的投资团队中，通常需要配备具有相应行业从业经验的投资管理人员；同一个投资团队通常只专注于投资某一个行业或者少数相关行业；基金管理人对目标行业的研究能力和水平在相当程度上影响着投资的结果**。

#### （二）企业管理 P35

> **科学有效的企业管理（包括战略规划、组织结构设计、运营管理等）是企业经营成功的关键要素之一**；**在股权投资中，被投资企业的团队有可能缺乏专业企业管理的能力**：

| 场景 | 说明 |
|---|---|
| **创业投资** | **许多初创科技企业的创始团队成员往往是技术背景而非管理背景；创业投资基金对此类企业进行投资后，投后增值服务的重要内容之一就是帮助被投资企业提升其企业管理的能力** |
| **并购投资** | **有时目标公司管理水平低下，导致价值被低估并成为并购基金的投资对象；在这种情况下，投后的重整将以提升被投资企业管理水平为重点** |

#### （三）法律 P35–P36

> **基金管理人在募资、运营和投资的各个环节中均需要运用法律专业知识和技能，以确保募资活动的合法性、运营过程的合规性以及投资决策的审慎性**：

| 环节 | 法律要求 |
|---|---|
| **募资阶段** | **对投资者进行适当性审查，确保募资流程的合规** |
| **运营阶段** | **构建严密的风险管理和内部控制体系，保障基金运作的规范性** |
| **投资阶段** | **进行详尽的法律尽职调查，评估并控制潜在风险** |

> **同时，管理人应持续关注并适应法律法规的最新变化，确保基金的持续合规性**；**以股权投资中的回购条款为例，投资协议中关于回购义务人、触发条件、定价机制等具体内容的约定，为确保相关条款具有法律效力，基金管理人需结合《公司法》对股权回购的限制性规定审慎设计履行主体及程序**。

##### 案例 2-3：产投基金与 S 科技、J 测试的股权回购纠纷 P36

> **2020 年 6 月，Z 投资管理有限公司与 S 科技有限公司、J 测试技术有限公司签订投资协议，Z 公司以货币形式向 J 测试投资人民币 2 000 万元，并取得 J 测试 20% 的股权**；**2021 年 8 月，Z 公司、某产投基金、J 测试、S 科技共同签订股权转让协议，约定 Z 公司将投资协议中其享有的全部权利义务转让于产投基金**。

**回购条款要点**：**J 测试及 S 科技保证投资款项专门用于公司生产经营；项目于 2020 年底前建设完成，年销售收入不低于 4 000 万元，年综合税收不低于 300 万元；如违背前述约定，产投基金有权要求 J 测试及 S 科技履行对标的股权的回购义务；回购价格 = 2 000 万元 + 利息**。

> **判决结果：J 测试并未完成约定的年综合税收数额，且向 S 科技提供了 232 万元借款**；**一审法院认为产投基金有权要求履行回购义务，但根据《公司法（2018 年修正）》第 142 条规定，未经减资等情形公司不得收购本公司的股份，故 J 测试不能履行回购义务，应由 S 科技承回购义务，并由 J 测试配合办理股权转让相关手续**；**二审法院维持一审判决**。

#### （四）财务分析 P36–P37

> **基金管理人需要对目标公司的历史财务状况、未来财务预期进行分析，对目标公司资本预算、现金流量、营收与利润情况进行研判，并结合其他因素对目标公司进行估值**。

> **由于股权投资是非公开交易，目标公司多数时候是非上市公司，业务及财务数据及信息的真实性、及时性和可靠性相对上市公司较差，从而对基金管理人的财务分析专业能力提出了更高的要求**。

**两类基金的估值侧重（必考）**：

| 基金类型 | 估值侧重 |
|---|---|
| **创业投资基金** | **通常更侧重评估目标公司未来的增长机会** |
| **并购基金** | **通常更侧重评估目标公司当前的价值** |

> **因此，一般来说，创业投资面临更大的估值不确定性**。

#### （五）资本市场 P37

> **投资的目的在于获取价值增值，而实现投资收益则需要依靠项目退出；经验表明，依靠公开资本市场退出通常是实现较高投资收益的途径**。

> **因此，基金管理人团队需要掌握国内外主要资本市场的专业知识，包括各资本市场定位、估值水平、交易量、流动性、监管环境等，以及上市或挂牌的标准、流程、所需时长、成本费用**。

> **需要指出的是，实践中，基金管理人可以选择把部分业务环节的工作（如法律和财务尽职调查）委托给外部机构完成，但即便如此，管理人自身的团队依然需要具备相关领域的专业知识，以确保能够有效监督外部机构的工作，并在必要时进行专业的判断和决策**。

#### （六）五个专业领域速查表

| # | 领域 | 关键要点 |
|---|---|---|
| **1** | **行业** | **行业趋势、市场动态、竞争格局；"不熟不做"；一个团队通常专注一个或少数相关行业** |
| **2** | **企业管理** | **战略规划、组织结构设计、运营管理；创投补创始团队管理短板，并购重整提升管理水平** |
| **3** | **法律** | **募资（适当性审查）、运营（风控内控）、投资（法律尽调）；持续关注法规变化** |
| **4** | **财务分析** | **历史与预期财务、资本预算、现金流量、营收利润、估值；创投看未来、并购看当前** |
| **5** | **资本市场** | **定位、估值水平、交易量、流动性、监管环境；上市/挂牌标准、流程、时长、成本** |

### 2.3.b 【了解】基金管理人专业化的制度保障 P37–P38

**大纲原文**：了解基金管理人专业化的制度保障

> **股权投资基金管理人专业化的制度保障主要通过法律法规和自律规则以及管理人内部制度两个维度来实现**。

#### （一）法律法规和自律规则 P37

> **法律法规和自律规则均明确要求基金管理人遵循专业化运营原则**：

| 要求 | 内容 |
|---|---|
| **职业道德** | **从业人员应当恪守职业道德和行为规范，具备从事基金业务所需的专业能力** |
| **专业胜任能力** | **管理人的高级管理人员和员工应具备与其职位相匹配的专业胜任能力和相关工作经验** |
| **资格与培训** | **同时持有相应的从业资格证书，定期参加合规和专业能力培训** |

#### （二）管理人内部制度 P37–P38

> **基金管理人应依据法律法规和自律规则的要求，建立一套全面的风险管理和内部控制体系**；**该体系需涵盖资金募集、投资决策、运作管理、信息披露等关键环节，并制定相应的详细业务流程与操作规范**；**同时，管理人应加强对员工的合规和专业能力培训，以提高员工的专业能力和风险意识**。

> **在所有要素中，尤为重要的是建立一个有效的投资管理体系、考核评价与激励约束机制**。

##### ① 投资管理体系 P38

> **基金管理人需要建立起覆盖项目投资全流程的投资管理体系，包括行业研究与项目开发、项目筛选、尽职调查、投资决策、投后管理、项目退出等环节**。

> **完整的投资管理与投资决策流程以及完善的内部控制体系，对于保证基金管理人专业审慎具有重要的价值**；**例如，从内部控制角度来看，保持风险控制团队与投资团队的相对独立性至关重要，对项目风险的评估不应当完全由投资团队完成；否则，即使投资团队具有较高的专业水平，也可能因为利益关系导致其不能作出对基金投资者利益最佳的行为**。

##### ② 考核评价与激励约束机制 P38

> **对基金管理团队实施有效的考核评价和激励约束机制，有利于激发团队的积极性，促使团队把专业能力更好地发挥出来**。

**考核评价的三项特点（必考）**：

| # | 特点 | 内容 |
|---|---|---|
| **第一** | **考核重点是投资组合整体表现** | **股权投资基金的项目投资更多地表现为投资组合；由于股权投资市场风险相对较高，单个项目的投资损失并不必然表示投资管理能力或努力的不足，因此，在单个项目层面应当建立起某种"容错"机制，考核评价的重点应当是投资组合即基金的整体表现，而非单个项目的业绩表现** |
| **第二** | **侧重长期投资收益考核** | **股权投资是长期投资，股权投资基金是"耐心资本"，基金投资收益的实现通常需要经历一段时间；因此，在投资收益考核中，应侧重对基金长期投资收益的考核** |
| **第三** | **与各阶段工作重点相适应** | **在基金募集设立期，主要工作是完成基金的募集与交割；在基金投资期，主要工作是高质量完成对外投资；在基金退出期，主要侧重于项目投后管理与退出、基金收益分配、基金清算等；不同阶段的考核评价，应当与各阶段的基金管理工作重点相适应** |

**激励约束的五种方式（必背）**：

> **对股权投资基金管理团队的激励和约束，主要通过团队持股、团队跟投、绩效奖励、业绩报酬分享、损失分担等方式实现**。

> **理论分析和行业实践均表明，科学有效的考核评价与激励约束机制对于提升股权投资基金管理团队的能力发挥具有显著的正向作用**。

## 2.4 股权投资基金管理人的内部治理

### 2.4.a 【了解】基金管理人内部治理的概念 P39

**大纲原文**：了解基金管理人内部治理的概念

> **基于基金治理视角，基金管理人必须保证适当地控制并实施内部合规架构，负责监督其合同义务的履行以及遵守适用于基金管理活动的规则**；**显然，基金治理实践要求注重基金管理人自身的治理问题，基金管理人存在与基金类似的内部治理问题**。

> **依据相关规定，国内股权投资基金管理人由依法设立的公司或者合伙企业担任**。

> **无论采取公司或合伙企业组织形式，基金管理人股东（合伙人）、经营者都会存在基于代理关系固有的利益冲突，基金管理人内部治理关注的核心命题是代理问题**。

#### （一）公司型与合伙型管理人的内部治理 P39

> **就公司型基金管理人而言，其内部治理是通过一系列的决策机制、激励机制和监督机制等制度安排，旨在规范股东、董事会和经理层之间的权利义务关系，以形成科学的自我约束机制和相互制衡机制，以保证企业的决策和运行效率**。

> **合伙型基金管理人内部治理同样适用前述界定，只是规范的利益主体不同**。

> **不区分组织形式，基金管理人内部治理是法律所确认的一种正式制度安排，实质是一种委托代理契约**。

#### （二）内部治理的目标（核心考点） P39

> **就基金管理人而言，其治理机制不限于以治理结构为基础的内部治理，利益相关者通过一系列的内部、外部机制来实施共同治理，涉及各利益主体权利、义务和责任的划分以及其相互制衡关系的整体制度安排**。

> **基金管理人内部治理的目标不仅是基金管理人所有者（股东）利益最大化，而且要保证其决策的科学性，从而保障利益相关者的利益最大化**。

#### （三）概念要点速查表

| 维度 | 内容 |
|---|---|
| **组织形式** | **依法设立的公司或者合伙企业** |
| **核心命题** | **代理问题（股东/合伙人与经营者基于代理关系固有的利益冲突）** |
| **实质** | **法律所确认的一种正式制度安排，实质是一种委托代理契约** |
| **公司型治理内容** | **决策机制、激励机制、监督机制；规范股东、董事会和经理层之间的权利义务关系** |
| **目标** | **不仅是股东利益最大化，还要保证决策的科学性，从而保障利益相关者的利益最大化** |

### 2.4.b 【了解】基金管理人内部治理的原则 P40

**大纲原文**：了解基金管理人内部治理的原则

> **不同组织类型基金管理人有着自身的特点和规律，这就要求所采取的治理方式、搭建的治理结构、构建的治理机制等应符合组织自身的治理逻辑和规律**。

> **基金管理人作为股权投资基金的重要当事人，应遵循股权投资基金的一般治理原则；同时，结合其自身特性，进一步对基金管理人内部治理的原则要求进行说明**。

**表 2-1 基金管理人内部治理的原则要求及说明（七项，必背）**：

| # | 原则要求 | 说明 |
|---|---|---|
| **1** | **设置适合的治理结构** | **① 治理结构要权责清晰，可促进管理人市场化运作并提高效率；② 受限于监管规则，管理人可根据自身情况设置差异化的治理结构** |
| **2** | **促进权利的行使和保护** | **治理框架应促进利益相关者权利的保护和行使**；**例如，行业协会关注管理人主要自然人股东不担任高级管理人员的理由、此时如何参与管理人经营管理以及是否会影响管理层的稳定性** |
| **3** | **董事会（如有）责任** | **① 要求董事会对公司的战略指导和对经营管理层的有效监督；② 要求董事会对公司和股东的责任和忠诚** |
| **4** | **风险管理和内部控制** | **要求建立必要的风险管理和内部控制安排，以确保其治理目标的实现**；**例如，行业协会要求管理人须设立合规风控负责人岗位，并将其视为高级管理人员以强化其责任和权力** |
| **5** | **公平对待** | **① 公平对待管理人所有股东；② 合伙型管理人，GP 执行合伙事务，尤其强调公平对待所有 LP** |
| **6** | **鼓励利益相关者参与** | **① 鼓励自身践行 ESG 投资；② 监管和自律引导**；**例如，行业协会在管理人申请登记环节引入法律意见书，以及关注管理层未持股情况下的稳定性** |
| **7** | **信息披露及透明化** | **要求对利益相关者保持充分的透明度；该原则已在监管及自律规则（甚至管理人内部法律文件）中得到充分重视** |

### 2.4.c 【掌握】基金管理人内部治理结构的分类、设置、常见形式 P40–P43

**大纲原文**：掌握基金管理人内部治理结构的分类、设置、常见形式

#### （一）组织形式与内部治理结构 P40

> **依据我国现行立法，基金管理人仅可采用公司型、合伙型两种法律组织形式，其他组织形式的机构以及自然人均不能受托作为基金管理人直接从事基金管理的活动**。

> **与之对应，基金管理人因具体法律组织形式的不同而分别受到《公司法》《合伙企业法》及《民法典》等法律的规制**。

> **尽管基金管理人组织形式的选择受法律体系的完备性、税收筹划、出资人数量、管理的便捷性等因素影响，但不同的内部治理结构是影响基金管理人组织形式选择的重要因素**。

> **内部治理结构是研究基金管理人内部治理问题的基础；良好的内部治理结构可解决相关利益方利益分配问题，对基金管理人能否高效运转、是否具有竞争力起到决定性的作用**。

#### （二）公司型基金管理人的内部治理结构 P41

> **公司型基金管理人可区分为有限责任公司、股份有限公司两种组织形式**。

> **在公司传统的"三会一层"法定治理结构中，决策权、经营管理权、监督权分属于股东会、董事会、监事会**：

| 机构 | 职权 |
|---|---|
| **股东会** | **决策权** |
| **董事会** | **经营管理权** |
| **监事会** | **监督权** |
| **经理层** | **"三会一层"中的"一层"，负责具体经营管理** |

> **基金管理人可视需要设置其他内部机构，还可以通过公司章程设置其他约定职责，并赋予相应的权利**。

#### （三）合伙型基金管理人的内部治理结构 P41

> **不同于公司成熟的内部治理结构，《合伙企业法》并未明确内部组织结构如何设置，而是充分尊重商事主体之间的契约自由，允许创设类似公司的内部治理机构**。

> **合伙型基金管理人可借鉴公司治理成熟经验，依据法律规定和自身情况设置合适的内部治理结构**；**例如，可设置有限合伙人委员会或顾问委员会审查内部利益冲突事项，可设置风险管理委员会负责内部合规和风控事项**。

#### （四）基金管理人常见组织架构 P41–P43

> **基金管理人组织架构是其内部治理结构的直接体现**。

> **2016 年 2 月，中国证券投资基金业协会颁布《私募投资基金管理人内部控制指引》，要求基金管理人组织结构应当体现职责明确、相互制约的原则，建立必要的防火墙制度和业务隔离制度，各部门有合理及明确的授权分工，操作相互独立**。

> **对于基金管理人来说，实践中还应注意相关部门之间的衔接配合，使相关制度具有可操作性**；**一般情况下，规模以上的基金管理人的组织架构至少包括如下部门**：

##### ① 投资部 P41–P42

> **较小规模的管理人通常只设置投资部，负责项目筛选、投资建议报告及投后跟踪管理等职能，并会将产业或行业研究工作纳入其中；而具备一定规模的管理人，可能会设置单独的研究部门**。

**投资部的十项主要职责（重点掌握前六项）**：

| # | 职责 |
|---|---|
| **（1）** | **开展行业研究，制定投资策略** |
| **（2）** | **根据发展规划和经营目标编制基金投资规划，落实具体的项目投资和退出计划** |
| **（3）** | **对拟投资项目进行尽职调查和可行性论证，编写立项报告、尽职调查报告、投资建议书等文件** |
| **（4）** | **负责项目的全流程管理，对拟投资项目按照投资决策流程，向立项委员会及投资决策委员会（投委会）提交材料并进行汇报** |
| **（5）** | **组织对已通过审批项目的交易执行，执行投委会决议，落实投资审批决策意见** |
| **（6）** | **对被投资企业开展投后管理及增值服务，定期提交被投资企业财务报表、投后管理情况报告，根据需要向被投资企业派出董事、监事等人选** |
| **（7）** | **发现风险后，及时向风控合规部门提交重大问题报告等** |
| **（8）** | **对拟退出项目，向投委会提交项目退出建议，按照批准的退出方案办理项目的退出手续** |
| **（9）** | **拟定项目管理的各项制度，经审批后执行** |
| **（10）** | **其他授权职能** |

##### ② 风险控制与合规部（风控部） P42

> **风控岗是管理人必设岗位**；**具备一定规模的管理人通常会设置风险控制与合规部**。

**风控部的九项主要职责**：

| # | 职责 |
|---|---|
| **（1）** | **根据法律法规、自律规则和业务规划拟定合规、风险控制与内部控制相关的制度和办法** |
| **（2）** | **审核经营过程中的各类法律文件，包括管理人和基金需要对外签署的各类法律文件** |
| **（3）** | **全面参与并监督基金募集，确保基金募集工作符合法律法规以及中国证监会、中国证券投资基金业协会等行业监管及自律管理机构的规范要求** |
| **（4）** | **全面参与项目投资、投后管理及投资退出等过程，配合开展全面尽职调查，提示风险，出具相关报告或意见，为基金投资决策提供专业意见，并对制度流程落实情况进行全流程监督** |
| **（5）** | **负责与行业监管及自律管理机构的沟通，根据监管及自律管理要求报送各项经营数据和报表** |
| **（6）** | **审核基金信息披露的相关文件** |
| **（7）** | **外部律师、法律顾问的遴选、沟通工作** |
| **（8）** | **管理人内控机制建设及内控有效性规范工作** |
| **（9）** | **其他授权职能** |

##### ③ 投资者关系部 P43

> **随着股权投资基金行业的发展以及信息披露要求的规范，管理人越来越重视与基金投资者的互动，并会设置专人或部门维护与基金投资者的关系**。

**投资者关系部的七项主要职责**：

| # | 职责 |
|---|---|
| **（1）** | **根据管理人发展规划和经营目标编制基金设立与募集规划，负责执行基金产品的发起、募集、设立；跟踪行业政策和发展趋势，制定管理人业务和产品发展规划** |
| **（2）** | **统筹管理人公共关系资源，负责政府、金融机构、企业集团等核心客户的服务** |
| **（3）** | **负责对潜在合格投资者的推介路演和反向尽职调查工作，并募集资金** |
| **（4）** | **负责组织年度基金投资者会议** |
| **（5）** | **负责基金产品的投资者关系管理工作，制定并持续完善投资者分类管理标准和日常工作规则** |
| **（6）** | **负责管理人品牌宣传工作** |
| **（7）** | **其他授权职能** |

##### ④ 运营管理部 P43

> **基金管理人通常会设置后台支持部门，即运营管理部，主要职责包括行政事务管理、人力资源管理等职责**。

##### ⑤ 财务审计部 P43

> **财务审计部的主要职责包括公司财务预决算规划、财务报告、记账、出纳、报税、资金管理、外部审计沟通等，以及基金产品对外投资的资金管理、财务核算等工作**。

##### ⑥ 集团化管理人的精细化分工 P43

| 分类 | 内容 |
|---|---|
| **前台投资** | **根据管理基金产品类型（企业股权、并购基金、夹层基金、基建基金、美元基金等）区分工作单元（或部门），同时将行业研究、融资、业务拓展、投后增值服务等与投资直接相关的工作单元一并纳入管理** |
| **中、后台运营及管理** | **区分为风险控制、合规、IT 运营、综合管理、公共关系管理、投资者关系管理、行政支持等工作单元** |

> **从内部治理要求而言，并无最优的组织架构，需结合管理人自身情况设置，核心是通过合理的机制设计和安排达到内部治理目标**。

#### （五）治理结构速查表

| 维度 | 内容 |
|---|---|
| **组织形式** | **仅公司型、合伙型两种（受《公司法》《合伙企业法》《民法典》规制）** |
| **公司型** | **"三会一层"：股东会（决策权）、董事会（经营管理权）、监事会（监督权）、经理层** |
| **合伙型** | **《合伙企业法》未明确设置，充分尊重契约自由；可设 LP 委员会/顾问委员会、风险管理委员会** |
| **常见五部门** | **投资部、风控部（必设风控岗）、投资者关系部、运营管理部、财务审计部** |
| **内控指引** | **《私募投资基金管理人内部控制指引》（2016 年 2 月）：职责明确、相互制约、防火墙、业务隔离、授权分工、操作独立** |

### 2.4.d 【了解】基金管理人内部治理的决策机制、激励机制和监督机制 P44–P45

**大纲原文**：了解基金管理人内部治理的决策机制、激励机制和监督机制

> **基金管理人的内部治理要求有适合的治理结构，且结构各单元（或机构）权责清晰、相互制衡**；**但治理的目的不是为制衡而制衡，还要关注如何使基金管理人最有效地运行，如何保证各方参与人的利益得到维护满足**。

> **良好的治理要求围绕内部治理结构建立一系列制度安排，规范相关主体的权利义务关系，形成科学的自我约束和相互制衡机制，保证企业的决策和运行效率；这些制度安排就是内部治理机制，主要包括决策机制、激励机制和监督机制等；这三个机制的设计和安排，是基金管理人内部治理机制的核心**。

#### （一）决策机制 P44–P45

> **决策机制主要解决基金管理人权力如何在内部科学、合理分配的问题**。

##### ① 决策权 P44

**公司型基金管理人的决策权配置**：

| 机构 | 地位与职权 |
|---|---|
| **股东会** | **权力机构，依据相关法律及公司章程规定进行决策** |
| **董事会（或执行董事）** | **依据相关法律及公司章程规定行使职权；董事会决策权是公司决策机制的核心** |
| **经理** | **对董事会负责，根据公司章程的规定或者董事会的授权行使职权** |

**董事会十项职权（必背）**：

| # | 职权 |
|---|---|
| **（1）** | **召集股东会会议并向股东会报告工作** |
| **（2）** | **执行股东会的决议** |
| **（3）** | **决定公司的经营计划和投资方案** |
| **（4）** | **制订公司的利润分配方案和弥补亏损方案** |
| **（5）** | **制订公司增加或者减少注册资本以及发行公司债券的方案** |
| **（6）** | **制订公司合并、分立、解散或者变更公司形式的方案** |
| **（7）** | **决定公司内部管理机构的设置** |
| **（8）** | **决定聘任或者解聘公司经理及其报酬事项，并根据经理的提名决定聘任或者解聘公司副经理、财务负责人及其报酬事项** |
| **（9）** | **制定公司的基本管理制度** |
| **（10）** | **公司章程规定或者股东会授予的其他职权** |

**合伙型基金管理人的决策权配置**：

> **基金管理人的普通合伙人通常会作为其执行事务合伙人，对外代表合伙企业，执行合伙事务**；**按照合伙协议的约定或者经全体合伙人决定，可以委托一个或者数个普通合伙人对外代表合伙企业，执行合伙事务**；**不执行合伙事务的合伙人有权监督执行事务合伙人执行合伙事务的情况**。

##### ② 决策方式 P44–P45

| 主体 | 表决方式 |
|---|---|
| **公司股东会** | **除法律要求外，可以按照股权比例或约定的方式行使表决权** |
| **公司董事会** | **通常会采取每人一票的方式进行投票表决** |
| **合伙型管理人** | **可按照合伙协议约定的表决办法办理**；**除非法律另有要求，合伙协议未约定或者约定不明确的，实行合伙人一人一票并经全体合伙人过半数通过的表决办法** |

##### ③ 决策程序 P45

> **基金管理人内部决策是一个从分歧、磋商、妥协到形成统一认识的过程**；**决策程序一般可以分为决策准备、决策方案的产生、决策方案的讨论和最终决定（形成决议）四个相互衔接的阶段**。

> **决策机制要求对决策权进行合理分配，同时要求决策应按照法定及约定程序实施；决策程序合规是所有层面决策有序进行的前提和先决条件**。

#### （二）激励机制 P45

> **就基金管理人而言，激励机制主要解决的是降低代理成本与激励代理人问题，是关于基金管理人所有者（股东或合伙人）与经营者（管理团队）如何分享经营成果的一种契约安排**。

**两类激励方式（必背）**：

| 层面 | 内容 |
|---|---|
| **精神层面** | **主要体现在管理人基于共同发展愿景为团队成员成长提供内部发展晋升机会及个人声誉认可** |
| **物质层面** | **① 建立股权及长效激励机制，鼓励团队成员与管理人共同成长**——**部分基金管理人通过设置期权激励或"虚拟股权"等方式，使团队成员分享源于管理人的股权收益**；**② 建立科学合理的业绩分成机制**——**团队成员业绩与其在基金管理环节的职责相匹配，合理依据其在基金"募投管退"过程中的个人贡献度参与分成** |

> **激励机制旨在使基金管理人内部团队成员获取其所付出的努力与承担的风险相对应的利益，同时也使其承担相应的风险和约束**；**其终极目标就是最大限度地挖掘管理人团队成员的潜力和效能，实现基金管理人股东（或合伙人）与团队成员"双赢"的利益格局**。

#### （三）监督机制 P45

> **监督机制是指基金管理人经营的经营结果、经营行为或决策所进行的一系列客观及时地审核、监察与督导的行动**；**内部权力的分立与制衡原理是设计和安排内部监督机制的一般原理**。

**公司型基金管理人的监督机制（必考）**：

| 层次 | 监督内容 |
|---|---|
| **总体** | **包括股东会和董事会对经理层的监督和制约，也包括它们之间权力的相互制衡与监督** |
| **股东对董事、经理层的四项监督** | **（1）选举和罢免董事、监事；（2）对玩忽职守、未勤勉尽职的董事提起诉讼；（3）对公司经营活动及账目的知情权；（4）通过监事会对董事会和经理层进行监督** |
| **董事会层面的监督** | **一般是通过行使聘任或者解雇经理层人员、拟订内部规章制度、定期考核等方式实现对经理层的有效监督** |

#### （四）三大治理机制速查表

| 机制 | 解决的问题 | 核心内容 |
|---|---|---|
| **决策机制** | **权力如何在内部科学、合理分配** | **股东会/董事会/经理层（公司型）或 GP 执行合伙事务（合伙型）；股东会按股权比例、董事会每人一票、合伙一人一票过半数；决策四阶段；决策程序合规是前提** |
| **激励机制** | **降低代理成本与激励代理人** | **精神（晋升机会、声誉认可）+ 物质（股权及长效激励如期权/虚拟股权、业绩分成机制）；终极目标"双赢"** |
| **监督机制** | **审核、监察与督导经营结果、行为或决策** | **内部权力的分立与制衡原理；股东四项监督 + 董事会层面监督** |

#### 二、易错点清单

1. **基金管理人设立不实行行政许可，但须在中基协登记后方可展业**；
2. **名称中须有"私募基金""私募基金管理"或"创业投资"；禁用"金融控股""金融集团""中证"**；
3. **股权投资基金管理人不能同时从事证券投资基金管理业务**；
4. **实缴资本仅限货币出资，禁止实物、知识产权、土地使用权**；
5. **实际控制人及主要出资人一般不应当是资产管理产品**；
6. **除少数高级管理人员外，从业人员应为专职人员**；
7. **基金与管理人之间、不同基金之间不得存在财产混同**；
8. **信义关系是信托关系的上位概念（反之不成立）**；
9. **忠实义务是信义义务的核心，不是勤勉义务**；
10. **勤勉义务=专业（专业人士标准）+ 审慎（努力+注意义务）**；
11. **管理人不得向被投资企业收取咨询费、交易费；除非事先与投资者就分配达成一致，否则应归入基金收益**；
12. **创业投资侧重未来增长机会，并购基金侧重当前价值；创业投资估值不确定性更大**；
13. **即使委托外部机构做尽调，管理人自身团队仍须具备专业知识**；
14. **考核评价须建立"容错"机制，重组合整体而非单项目**；
15. **基金管理人内部治理核心命题是代理问题**；
16. **内部治理实质是一种委托代理契约**；
17. **治理目标不仅是股东利益最大化，还要保证决策科学性、保障利益相关者利益最大化**；
18. **基金管理人仅可采用公司型、合伙型两种组织形式**；
19. **风控岗是管理人必设岗位（合规风控负责人视为高级管理人员）**；
20. **合伙型一人一票过半数通过（协议未约定时），不是按出资比例**；
21. **并无最优的组织架构，核心是通过合理的机制设计达到内部治理目标**。
