## 4.1 募集与设立概述

### 4.1.a 【理解】股权投资基金的募集与设立 P77–P79

**大纲原文**：理解股权投资基金的募集与设立

#### （一）募集的概念 P77

> **股权投资基金的募集，是指股权投资基金管理人或者受其委托的基金销售机构向投资者募集资金，用于设立股权投资基金的行为**。

> **募集行为包含推介私募基金，发售基金份额（权益），办理基金份额（权益）认/申购（认缴）、赎回（退出）等活动**。

> **对于股权投资基金，资金的募集是开展基金投资业务的必要前提**；**只有募集到充裕、稳定的资金，才能确保基金的顺利设立和平稳运行**；**资金的募集也是开展基金投资业务的起点，募集到的资金将由基金管理人负责管理，并投向特定投资对象，进而承担风险、产生收益，最终按照约定进行收益分配**。

#### （二）募集方式 P77

##### ① 自行募集与委托募集（按募集机构分）

| 方式 | 含义 |
|---|---|
| **自行募集**|**由基金管理人自行寻找投资者并按照法律法规和自律规则的规定完成募集工作** |
| **委托募集**|**基金管理人委托有资格的基金销售机构代为募集资金** |

> **无论采取自行募集还是委托募集方式，基金管理人均应设置有效机制，切实保障募集结算资金安全，确保股权投资基金仅向合格投资者募集，防止变相进行公开募集**。

> **基金管理人委托基金销售机构募集的，被委托机构应当获得中国证监会基金销售业务资格且成为中国证券投资基金业协会会员**；**基金管理人应制定募集机构遴选制度，与被委托机构签署基金销售协议**；**委托基金销售机构募集股权投资基金的，基金管理人不得因委托募集而免除其依法应承担的责任**。

##### ② 公开募集与非公开募集（按募集对象分）

> **公开募集是指通过公开渠道向非特定对象推介基金产品；非公开募集则是指通过设置特定对象确定程序的渠道进行非公开推介基金产品的行为**。

**我国非公开募集的两个必备条件（必背）**：

> **目前，我国不允许进行股权投资基金的公开募集**；**按照现行法律法规，股权投资基金只能以非公开方式募集，即必须同时满足两个条件**：

| # | 条件 |
|---|---|
| **一**|**向符合合格投资者标准的特定对象募集** |
| **二**|**单只基金的投资者人数不得超过法律规定的上限** |

> **视基金选择的组织形式不同，投资者人数上限应分别符合《证券投资基金法》《公司法》《合伙企业法》等适用法律的规定**。

#### （三）设立的概念 P77

> **股权投资基金必须具备特定的组织形式；我国现行的股权投资基金组织形式包括公司型、合伙型和契约型**。

> **选择组织形式时需考虑多种因素，主要包括法律依据、监管要求、基金架构设计、投资业务开展与基金运营的需求以及税负等**。

**设立程序的差异（必考）**：

| 组织形式 | 设立程序 |
|---|---|
| **公司型、合伙型**|**通常需在市场监督管理部门完成名称预先核准、申请设立登记和领取营业执照的流程** |
| **契约型**|**由于契约型基金不具备工商实体，因此无须办理企业注册登记** |

> **按照现行法律法规，股权投资基金设立后，应向中国证券投资基金业协会提交相应的基金备案**。

#### （四）募集与设立的区别和联系 P77–P78

**区别（必考）**：

| 环节 | 主导与关注点 |
|---|---|
| **基金的募集**|**基金管理人主导的募集资金的过程，主要关注募集方式、募集对象以及募集过程的合规性等问题** |
| **基金的设立**|**依法设立股权投资基金主体的过程，主要考量基金的组织形式、基金架构相关主体以及登记备案等事项** |

**程序上的联系**：

> **从程序上看，在基金募集阶段，基金投资者和基金管理人通过沟通谈判就基金成立达成一致意见，包括基金组织形式的选择、基金的核心要素和条款等；随后，进入合同签署、工商设立、基金备案等设立环节**；**基金于基金合同约定的条件成就后成立**。

> **实务中，常见的基金成立日是指基金合同签署且基金主体完成工商设立后，由基金管理人宣布的成立日期**；**有些基金合同会约定，基金管理人应在基金首期实缴出资全部到达托管账户后，宣布基金成立**。

> **通常情况下，基金设立标志着基金募集工作已全部完成或阶段性完成**；**基金进入设立程序后，投资者签署基金合同，并按照基金合同中关于出资的条款向基金缴付出资；在完成中基协备案后，股权投资基金即进入投资业务周期**。

> **后续募集条款**：**在符合适用法律法规要求的前提下，结合基金的商业需求，部分基金会在合同中约定后续募集条款，以便于在基金设立后的约定时限内继续进行基金募集**——**后续募集主要是考虑到股权投资基金募集周期可能较长，为了适时启动投资、扩大基金规模等而进行的安排**。

#### （五）股权投资基金募集的特征（三个，必背） P78–P79

> **作为一类资产配置产品，股权投资基金具有其独特的产品属性和价值；相应地，募集过程呈现出一系列显著的特征**。

| # | 特征 | 内涵 |
|---|---|---|
| **第一**|**募集活动通常需要较长的时间周期**|**这一点在首次募集基金的基金管理人中尤为显著**；**鉴于募集活动是基金业务周期的起点和业务开展的先决条件，基金管理人需要对募集活动进行系统筹划，并合理安排募集流程**；**募资环境会受到多重因素叠加影响，诸如投资者数量和构成、退出市场发展状况以及宏观经济发展情况等** |
| **第二**|**募集是基金投资者和基金管理人之间的双向选择**|**管理人之间因发展阶段、管理规模、专注行业领域、投资策略以及历史投资业绩等不同展现差异性和多样性，形成市场竞争**；**投资者群体也表现出多样化特征，部分投资者主要关注资本增值，部分旨在实现特定功能或战略目标**；**不同的制约因素可能影响投资者决策，包括资金流动性、个体风险承受能力以及适用的监管要求；投资者的投资频率、规模和集中度等同样呈现个性化差异** |
| **第三**|**募集阶段需要进行频繁和深入的互动**|**在启动任何一只基金的募集时，基金管理人需要提出所募集基金的架构、规模、存续期限、投资策略、基金费用、收益分配、决策机制等核心要素**；**而基金投资者需要与基金管理人进行充分的洽谈和协商，建立保障双方利益一致的机制，直至其认可基金的核心要素，并且信任基金的核心团队成员能够通过拟定的计划与安排实现基金投资目标** |

> **综上所述，股权投资基金的募集过程具有其独特性，需要基金管理人与投资者之间的密切合作与共同努力；通过双向选择和深入互动，实现基金管理人与投资者之间的匹配，并为基金的未来运作奠定坚实基础**。

## 4.2 募集对象

> **股权投资基金的募集对象，即股权投资基金的投资者，作为基金的出资人，按其所持有的基金份额享受收益并承担相应的风险**。

### 4.2.a 【了解】国外股权投资基金投资者的主要类型 P79–P80

**大纲原文**：了解国外股权投资基金投资者的主要类型

> **目前，国外股权投资基金的募集对象主要包括养老基金、母基金、大学基金会、大型企业、金融机构、高净值个人或家族办公室等**。

> **国外股权投资基金的投资者群体呈现专业化与多样化特征；各类投资者基于资金规模、风险偏好、投资目标等差异，形成了各具特色的参与模式**。

#### （一）六类国外投资者（必背） P79–P80

| # | 类型 | 特征 |
|---|---|---|
| **1**|**养老基金**|**包括公司养老基金和公共养老基金，是资本市场中稳定的机构投资者**；**能够提供长期资金来源，并基于投资风险和期望收益的平衡，将一定比例的资金配置到股权投资基金中**；**在美国和欧洲市场，养老基金因其庞大的规模，成为股权投资基金的主要资本供给者** |
| **2**|**母基金**|**作为股权投资行业专业化细分的产物，母基金专注于投资于其他股权投资基金**；**在投资标的（即股权投资基金）的筛选、风险管理和投后管理等方面展现出较高的专业化水平，是国外股权投资基金的重要机构投资者** |
| **3**|**大学基金会**|**是国外股权投资基金稳定的机构投资者，其资金主要来源于社会捐赠**；**作为非营利基金会，大学基金会为了维持学校的运营而设立，流动性需求较低，适合进行长期投资** |
| **4**|**大型企业**|**资金实力雄厚的大型企业通常通过两种方式参与股权投资**：**① 以自有资金投资，设立投资业务子公司开展股权投资或并购活动，通常聚焦于本企业主营业务相关或产业链上下游的企业；② 作为财务投资者，投资股权投资基金，以实现资本增值** |
| **5**|**金融机构**|**在西方国家，参与股权投资基金的金融机构主要包括商业银行、投资银行和保险公司**；**参与方式有两种：① 作为财务投资者投资于股权投资基金；② 作为基金管理人发起设立股权投资基金** |
| **6**|**高净值个人或家族办公室**|**在进行资产配置时，通常也会考虑将一定比例的可投资资金配置到股权投资基金这一资产类别当中**；**一般作为基金投资者而不是基金管理人参与到股权投资基金中** |

#### （二）六类投资者速查表

| 类型 | 核心特点 |
|---|---|
| **养老基金**|**规模庞大、长期资金；美欧市场主要资本供给者** |
| **母基金**|**专业化细分产物；筛选、风控、投后专业化水平高** |
| **大学基金会**|**社会捐赠；非营利；流动性需求低，适合长期投资** |
| **大型企业**|**自有资金设投资子公司（聚焦主业/产业链）+ 作为财务投资者** |
| **金融机构**|**商业银行、投资银行、保险公司；财务投资者 + 管理人** |
| **高净值个人/家族办公室**|**一般只做投资者，不做管理人** |

### 4.2.b 【理解】中国股权投资基金投资者的主要类型 P80–P83

**大纲原文**：理解中国股权投资基金投资者的主要类型

> **中国股权投资基金的募集对象则涵盖：母基金、政府投资基金、社会保障基金、企业年金、金融机构、产业资本、个人投资者以及境外投资者等**。

> **随着中国资本市场的日益成熟和资产管理行业的快速发展，股权投资基金已经成为资产管理领域的关键组成部分**；**资本市场的多层次发展和全面注册制的实施，不仅为股权投资基金提供了更为高效的退出机制，提升了资本的流动性和使用效率，也吸引了不同类型的投资者；不同类型投资者的投资偏好不仅反映了其对于多元化资产配置的需求，也在不断推动股权投资基金行业的创新和进步**。

#### （一）母基金 P81

| 维度 | 内容 |
|---|---|
| **核心策略**|**将募集到的资金投向多个不同的股权投资基金** |
| **新趋势**|**近年来，母基金在项目直投和跟投方面的趋势不断增强，提升了其在项目选择和资源配置中的影响力及市场竞争力**；**面对行业普遍的退出压力，母基金也在积极探索投资基金二手份额等投资策略，以提高资本的流动性和退出效率** |
| **价值**|**通过多元化的投资方式，实现了投资组合的多样性和分散性，降低了投资的整体风险，不仅帮助其投资者获得稳定收益，也为市场提供长期、专业的资金来源**；**注重投资的灵活性和多样性，力求在风险可控的前提下，实现资本的有效配置和增值** |

#### （二）政府投资基金 P81

| 维度 | 内容 |
|---|---|
| **定位**|**由政府设立并按市场化方式运作的基金，其以投资于股权投资基金为主要策略，形成了一种特殊的母基金** |
| **设立目的**|**通过股权投资的方式，引导社会资本投向战略性新兴产业，支持科技创新，推动经济转型升级**；**地方政府投资基金的设立，是地方政府财政收入模式由传统的依赖于土地财政向更加多元化的财政收入模式转变的一部分** |
| **地位**|**随着国家和地方各级政府积极推动，政府投资基金的数量和规模显著增长，已经成为我国股权投资基金领域最主要的出资来源之一** |
| **风险偏好**|**高度重视资金的安全性，通过严格的风险控制机制来保障投资的稳健性和收益性**；**注重投资的退出机制和资金的流动性，以期能够在适当时机顺利退出，提高资本的循环利用效率** |
| **政策导向**|**重视社会效益和政策导向，基于其设立目的和投资策略，通常要求所投资的股权投资基金在特定产业领域（如国家战略性新兴产业）或特定投资阶段（如早期创业企业）的项目上投入一定规模或比例的资金** |

#### （三）社会保障基金和企业年金 P81–P82

> **全国社会保障基金是中国最大的养老基金**；**根据财政部、人力资源和社会保障部的授权，全国社会保障基金可以将总资产的一定比例投资于股权投资基金**。

> **目前，社会保障基金投资于股权投资基金的总金额并不高、占总体可投资比例亦较低；随着股权投资基金行业的进一步发展和相关政策的逐步放宽，未来社会保障基金在该领域的投资金额有望实现大幅增长**。

> **目前，在我国养老保障体系中，企业年金等长期资金制度体系仍处于完善中阶段，覆盖资金规模有限，且在可投资范围上受到政策约束，尚未成为股权投资基金的稳定资金来源**。

**核心关注点（必考）**：

> **社会保障基金和企业年金在投资股权投资基金时，核心关注点包括资金的安全性和收益性，偏好投资于符合国家宏观政策和产业政策的项目，注重投资的社会责任和政策导向**；**此外，它们亦强调在投资周期结束时能够顺利退出，实现资金的有效回收和再投资，以确保资金的流动性和再投资能力**。

#### （四）金融机构 P82–P83

**我国金融机构投资者类型（必背）**：

> **在我国，保险公司、商业银行、金融资产投资公司、证券公司、基金子公司等金融机构是股权投资基金市场中的重要投资者**。

##### ① 资管行业背景 P82

> **随着 2018 年 4 月《关于规范金融机构资产管理业务的指导意见》的正式发布，2018—2019 年关于银行、证券公司、信托公司等金融机构的监管政策密集落地，银行理财子公司、券商资管、信托等各类资管机构的配套规定陆续推出，资管行业呈现出"去通道、去杠杆、打破刚性兑付、净值化"的发展特征**。

> **在此背景下，相较于其他资管产品，股权投资基金行业凭借其主动管理的特性，更好地适应了新的监管环境和市场需求；包括证券期货经营机构发行的资产管理计划、信托计划、保险资产管理计划等在内的各类资管计划，亦成为我国股权投资基金投资者结构中的重要组成部分**。

##### ② 保险资金 P82

> **保险资金具有较长的投资期限，天然适合于股权投资基金的投资**；**自 2010 年我国允许保险资金进入股权投资市场以来，从各保险公司的保险资金运用情况来看，保险资金仍以债券、银行存款和其他金融产品为主，配置权益资产（含股票与股权）的比例远低于政策规定的可投上限**。

> **近年来，国家金融监督管理总局（原中国银保监会）逐步放宽了保险资金投资于股权投资基金的政策限制，促进了保险资金通过投资股权投资基金支持实体经济，特别是中小企业和科技企业的股权融资**。

##### ③ 金融资产投资公司（AIC，时间线必背） P82

| 时间 | 事件 |
|---|---|
| **2018 年 6 月**|**原银保监会发布《金融资产投资公司管理办法（试行）》，允许中国工商银行、中国农业银行、中国银行、中国建设银行、交通银行下属金融资产投资公司作为商业银行债转股的平台，以债转股为目的开展企业股权投资** |
| **2020 年 2 月至 3 月**|**原银保监会陆续批准 5 家金融资产管理公司通过附属机构在上海开展不以债转股为目的的股权投资业务** |
| **2024 年 9 月**|**国家金融监管总局将金融资产管理公司股权投资试点扩大至北京等 18 个城市** |
| **2025 年 3 月**|**国家金融监管总局进一步将金融资产投资公司股权投资范围扩大至试点城市所在省份，支持符合条件的其他商业银行发起设立金融资产投资公司，并支持保险资金参与金融资产投资公司股权投资试点** |

##### ④ 金融机构的投资偏好 P82–P83

> **金融机构在投资股权投资基金时，追求长期稳定的投资回报，并注重投资的安全性与收益性，偏好投资于具有明确退出机制和高流动性的项目**。

> **以保险资金为例**：**一方面，保险公司对外配置资产需考虑偿付能力充足率的监管要求；另一方面，保险资金重视投资的收益性和回报，特别是在投后管理阶段，更关注项目的退出进度和已分配倍数（DPI）**。

#### （五）产业资本 P83

> **产业资本是我国股权投资基金的重要资金来源**；**近年来，随着政策的日益完善和市场的发展，各类企业投资者对股权投资基金的兴趣持续上升，并逐步形成了各具特色的参与模式**。

**活跃度增加的原因（两个角度，必考）**：

| 角度 | 原因 |
|---|---|
| **产业资本角度**|**随着全球经济环境的变化和国内经济结构的调整，企业需要通过股权投资来获取新的增长点和创新资源，实现产业升级和转型**；**同时，通过股权投资可以实现产业链的纵向和横向整合，提升企业在市场中的竞争力和影响力** |
| **基金管理人角度**|**产业资本在募资和退出方面具有显著优势，其雄厚的资金实力和品牌效应有助于吸引更多的投资者参与，而多元化的退出渠道和产业链整合退出策略则提升了投资的灵活性和成功率** |

> **产业资本在投资股权投资基金时，不仅追求长期稳定的投资回报和注重投资的安全性与收益性，而且相较于其他类型的投资者，其特别强调通过股权投资实现战略协同和产业链整合**；**偏好投资于能够带来业务协同效应、风险可控、回报可期，并且具有明确退出机制和高流动性的项目**。

#### （六）个人投资者 P83

> **在当前中国经济发展和资本市场成熟度不断提升的背景下，高净值个人投资者对股权投资基金的兴趣日益增长；这些投资者通常具备较多的可投资资产，并致力于实现财富的长期积累与增长**。

> **作为资本市场中的关键参与者，个人投资者通过积极的投资行为，不仅推动了股权投资市场的繁荣发展，而且对资本形成、创新支持和创业投资等方面产生了显著的促进作用**。

> **在投资偏好方面，高净值个人投资者特别重视长期稳定的投资回报和资金的安全性与收益性；他们倾向于选择能够提供持续现金流和较低波动性的投资项目，同时通过多元化投资组合来分散风险，以确保资产的保值增值**。

#### （七）境外投资者 P83

> **境外投资者主要通过合格境外有限合伙人（Qualified Foreign Limited Partner，QFLP）试点渠道投资于中国境内的股权投资基金**。

> **QFLP 政策通过逐步放宽的投资者条件、相对便利的结汇操作和简化的行政审批程序，使得境外投资者能够更便捷地参与境内股权投资市场；境外投资者能够将外汇资金兑换为人民币，进而直接投资于中国境内**。

#### （八）七类中国投资者速查表

| # | 类型 | 核心特点 |
|---|---|---|
| **1**|**母基金**|**投多只基金；直投跟投增强；探索二手份额** |
| **2**|**政府投资基金**|**特殊母基金；我国最主要出资来源之一；安全 + 政策导向 + 比例要求** |
| **3**|**社会保障基金和企业年金**|**全国社保基金是中国最大养老基金；企业年金尚未成为稳定资金来源；核心关注安全性、收益性、退出** |
| **4**|**金融机构**|**保险公司、商业银行、AIC、证券公司、基金子公司等；新规后"去通道、去杠杆、打破刚兑、净值化"；保险资金关注 DPI** |
| **5**|**产业资本**|**特别强调战略协同和产业链整合** |
| **6**|**个人投资者**|**高净值个人；重视长期稳定回报与安全性** |
| **7**|**境外投资者**|**主要通过 QFLP 试点渠道** |

### 4.2.c 【了解】建立合格投资者及投资者适当性制度的必要性 P84–P85

**大纲原文**：了解建立合格投资者及投资者适当性制度的必要性

#### （一）两个制度的概念 P84–P85

> **合格投资者制度**：**在我国，结合相关法律法规要求，合格投资者制度是指要求基金管理人或基金销售机构（统称为募集机构）只能向法律法规认可的、符合一定标准的合格投资者募集资金的制度**。

> **投资者适当性制度**：**是指经营机构在向投资者销售证券、基金、期货及其他衍生产品或提供证券期货服务时，全面了解投资者情况，深入调查分析产品或者服务信息，科学有效评估，充分揭示风险，基于投资者的不同风险承受能力以及产品或者服务的不同风险等级等因素，提出明确的适当性匹配意见，将适当的产品或者服务销售给适合的投资者的制度**。

#### （二）必要性（核心逻辑，必背） P85

> **合格投资者制度的建立，源于股权投资基金的基本特征**：

| 环节 | 内容 |
|---|---|
| **委托受托关系**|**基金投资者和基金管理人之间属于委托受托关系，基金管理人负责进行基金的投资决策，但投资资金主要由基金投资者提供** |
| **信息不对称**|**管理人居于信息优势地位，掌握着关于基金投资项目质量、投资风险、投资业绩等关系到投资者利益的信息；而基金投资者通常处于信息劣势地位** |
| **"败德"行为风险**|**在存在信息不对称的情况下，基金管理人有可能会利用其信息优势从事一些对自己有利而对基金投资者不利的"败德"行为，从而损害基金投资者利益** |
| **非公开募集的特殊性**|**特别是当股权投资基金以非公开方式募集时，无法通过公开披露信息机制约束基金管理人，"败德"行为可能发生得更多** |
| **结论**|**因此，不少国家规定，股权投资基金只能向合格投资者募集** |

> **不同于一般的投资者，合格投资者往往资本更为雄厚、风险识别与承受能力更强、专业知识更为丰富，对基金管理人及其发起设立的基金具有较强的筛选、判断及监督能力；在此基础上，辅以基金信息披露制度，才能较好地保护基金投资者**。

#### （三）我国的两层安排 P85

> **在我国，投资者适当性制度中存在普通投资者和专业投资者的划分**；**专业投资者除了满足普通投资者的条件外还需具备更丰富的投资经验和专业知识，对基金合规运行可以进一步提高监督要求**。

> **同时，投资者适当性制度相关要求有助于更好地平衡投资者对相关基金产品的风险预期**；**合格投资者制度与投资者适当性制度共同发挥作用，可以促进基金管理人和投资者之间建立更加健康和透明的合作关系，这对于促进股权投资基金行业稳定发展和保护投资者权益具有重要意义**。

#### （四）必要性论证速查表

| 层次 | 逻辑 |
|---|---|
| **第一层：信息不对称**|**管理人信息优势 + 投资者信息劣势** |
| **第二层：败德风险**|**管理人可能利用信息优势损害投资者利益** |
| **第三层：非公开募集放大风险**|**无法通过公开披露机制约束管理人** |
| **结论**|**只能向合格投资者募集 + 辅以信息披露制度** |

### 4.2.d 【掌握】合格投资者的标准 P85–P86

**大纲原文**：掌握合格投资者的标准

#### （一）合格投资者制度的起源与发展 P85

> **合格投资者制度起源于美国**；**经历了 1929—1933 年的经济"大萧条"后，美国对证券行业的监管体系进行了重构，并出台了一系列法律**；**这些法律要求基金管理人和基金必须向美国证券交易委员会申请注册；符合条件的非公开发行的股权投资基金可以豁免注册，其中的一个条件是必须向合格投资者募集**。

**现行合格投资者标准的四个特点（必背）**：

| # | 特点 |
|---|---|
| **第一**|**原则性地要求投资者具备一定的风险识别和承担能力** |
| **第二**|**要求投资者认购/申购的基金份额达到某一最低标准** |
| **第三**|**根据投资者的资产规模或收入水平来评估其风险承担能力** |
| **第四**|**某些持有特定金融牌照（例如商业银行）或其他大型专业投资机构（例如养老基金）及其高级管理人员被认定为当然的合格投资者** |

#### （二）我国合格投资者认定标准（核心数字，必背） P86

> **我国的合格投资者认定标准与国际上主要国家的标准基本一致**。

##### ① 《私募条例》的定义 P86

> **根据《私募条例》，合格投资者是指达到规定的资产规模或者收入水平，并且具备相应的风险识别能力和风险承担能力，其认购金额不低于规定限额的单位和个人**。

##### ② 《私募管理办法》的具体标准（必考） P86

> **中国证监会在《私募投资基金监督管理暂行办法》（《私募管理办法》）中进一步明确，私募基金的合格投资者是指具备相应风险识别能力和风险承担能力，投资于单只私募基金的金额不低于 100 万元且符合下列相关标准的单位和个人**：

| # | 标准 |
|---|---|
| **（1）**|**净资产不低于 1 000 万元的单位** |
| **（2）**|**金融资产不低于 300 万元或者最近三年个人年均收入不低于 50 万元的个人** |

##### ③ 四类当然合格投资者（必背） P86

> **在一般合格投资者界定的基础上，《私募管理办法》将以下四类投资者视为当然合格投资者**：

| # | 当然合格投资者 |
|---|---|
| **一**|**社会保障基金、企业年金等养老基金，慈善基金等社会公益基金** |
| **二**|**依法设立并在中国证券投资基金业协会备案的投资计划** |
| **三**|**投资于所管理私募基金的私募基金管理人及其从业人员** |
| **四**|**中国证监会规定的其他投资者** |

> **后续，中国证监会在《关于加强私募投资基金监管的若干规定》中进一步补充规定：国务院金融监督管理部门监管的机构依法发行的资产管理产品、合格境外机构投资者、人民币合格境外机构投资者视为《私募管理办法》规定的当然合格投资者，不再穿透核查最终投资者**。

##### ④ 穿透核查要求（必考） P86

> **结合实践中基金投资者的不同形态和投资路径，《私募管理办法》及中基协自律规则进一步强调了穿透核查合格投资者的要求，即**：

> **以合伙企业、契约等非法人形式，通过汇集多数投资者的资金直接或者间接投资于私募基金的，私募基金管理人、基金销售机构应当穿透核查每一层的投资者是否为合格投资者，并合并计算投资者人数**；**但是当然合格投资者可不再穿透核查投资者是否为合格投资者和合并计算投资者人数**。

#### （三）合格投资者标准数字速查表

| 指标 | 门槛 |
|---|---|
| **单只私募基金投资金额**|**不低于 100 万元** |
| **单位净资产**|**不低于 1 000 万元** |
| **个人金融资产**|**不低于 300 万元** |
| **个人最近三年年均收入**|**不低于 50 万元** |
| **当然合格投资者**|**四类 + 资管产品、QFII、RQFII（不穿透核查）** |

### 4.2.e 【掌握】投资者适当性的要求 P86–P88

**大纲原文**：掌握投资者适当性的要求

#### （一）三个规范性文件 P86

| 时间 | 文件 | 内容 |
|---|---|---|
| **2016 年 12 月**|**中国证监会《证券期货投资者适当性管理办法》**|**对投资者的基本分类作出统一安排，旨在将适当的产品销售给适合的投资者** |
| **2016 年**|**中基协《私募投资基金募集行为管理办法》**|**对推介私募基金、发售基金份额（权益）、办理认/申购（认缴）、赎回（退出）等活动过程中应遵守的要求进行了规范，其中就包括募集机构应遵守投资者适当性管理要求** |
| **2017 年**|**《基金募集机构投资者适当性管理实施指引（试行）》**|**进一步细化了募集机构在投资者适当性管理方面的具体要求** |

#### （二）募集六项程序（必背顺序） P86

> **股权投资基金募集应当履行下列程序**：

| # | 程序 |
|---|---|
| **（1）**|**特定对象确定** |
| **（2）**|**投资者适当性匹配** |
| **（3）**|**基金风险揭示** |
| **（4）**|**合格投资者确认** |
| **（5）**|**投资冷静期** |
| **（6）**|**回访确认** |

#### （三）适当性管理制度至少包括的六项内容 P87

> **基金募集机构建立适当性管理制度，至少应包括**：

| # | 内容 |
|---|---|
| **（1）**|**对基金管理人进行审慎调查的方式和方法** |
| **（2）**|**对基金产品或者服务的风险等级进行设置、对基金产品或者服务进行风险评价的方式或方法** |
| **（3）**|**对投资者进行分类的方法和程序、投资者转化的方法和程序** |
| **（4）**|**对普通投资者风险承受能力进行调查和评价的方式和方法** |
| **（5）**|**对基金产品或者服务和投资者进行匹配的方法** |
| **（6）**|**投资者适当性管理的保障措施和风控制度** |

#### （四）六项禁止行为（必背） P87

> **就投资者适当性核查结果的适用性，基金募集机构向投资者销售基金产品或者服务时，禁止出现以下行为**：

| # | 禁止行为 |
|---|---|
| **（1）**|**向不符合准入要求的投资者销售基金产品或者服务** |
| **（2）**|**向投资者就不确定的事项提供确定性的判断，或者告知投资者有可能使其误认为具有确定性的判断** |
| **（3）**|**向普通投资者主动推介风险等级高于其风险承受能力的基金产品或者服务** |
| **（4）**|**向普通投资者主动推介不符合其投资目标的基金产品或者服务** |
| **（5）**|**向风险承受能力最低类别的普通投资者销售风险等级高于其风险承受能力的基金产品或者服务** |
| **（6）**|**其他违背适当性要求，损害投资者合法权益的行为** |

#### （五）投资者分类 P87–P88

> **募集机构应编制投资者信息表及风险测评问卷，对投资者进行信息采集和风险测评，并初步判断其是否满足合格投资者的条件**；**对于不符合合格投资者要求的投资者，终止对其风险匹配和产品推介**；**根据投资经验等情况，进一步区分专业投资者和普通投资者**。

**专业投资者的五类情形（必考）**：

| # | 类型 | 条件 |
|---|---|---|
| **（1）**|**金融机构**|**经有关金融监管部门批准设立的金融机构，包括证券公司、期货公司、基金管理公司及其子公司、商业银行、保险公司、信托公司、财务公司等；经行业协会备案或者登记的证券公司子公司、期货公司子公司、私募基金管理人** |
| **（2）**|**上述机构发行的理财产品**|**包括但不限于证券公司资产管理产品、基金管理公司及其子公司产品、期货公司资产管理产品、银行理财产品、保险产品、信托产品、经行业协会备案的私募基金** |
| **（3）**|**养老基金、社会公益基金、QFII、RQFII**|**社会保障基金、企业年金等养老基金，慈善基金等社会公益基金，合格境外机构投资者（QFII）、人民币合格境外机构投资者（RQFII）** |
| **（4）**|**法人或其他组织**|**① 最近 1 年末净资产不低于 2 000 万元；② 最近 1 年末金融资产不低于 1 000 万元；③ 具有 2 年以上证券、基金、期货、黄金、外汇等投资经历** |
| **（5）**|**自然人**|**① 金融资产不低于 500 万元，或者最近 3 年个人年均收入不低于 50 万元；② 具有 2 年以上证券、基金、期货、黄金、外汇等投资经历，或者具有 2 年以上金融产品设计、投资、风险管理及相关工作经历，或者属于前述第（1）项规定的专业投资者的高级管理人员、获得职业资格认证的从事金融相关业务的注册会计师和律师** |

**普通投资者的分类（必考）**：

> **除专业投资者外，对于其他满足合格投资者标准的投资者，募集机构应认定其为普通投资者，并结合风险测评结果，按照其风险承受能力将普通投资者由低到高至少划分为 C1（含风险承受能力最低类别）、C2、C3、C4、C5 五种类型**；**募集机构可自主决定是否对专业投资者进行细化分类**。

> **在满足一定条件的情况下，普通投资者可申请转化为专业投资者，专业投资者可申请转化为普通投资者**。

#### （六）产品风险等级划分（表 4-1，必背） P88

> **募集机构应对其基金产品按照风险由低到高顺序，至少划分为 R1、R2、R3、R4、R5 五个等级**；**产品风险等级可根据产品结构、过往业绩、历史净值波动性、产品流动性、估值政策、杠杆因素等综合判断**。

| 风险等级 | 产品参考因素 |
|---|---|
| **R1**|**产品结构简单，过往业绩及净值的历史波动率低，投资标的流动性很好、不含衍生品，估值政策清晰，杠杆不超监管部门规定的标准** |
| **R2**|**产品结构简单，过往业绩及净值的历史波动率较低，投资标的流动性好、投资衍生品以套期保值目的，估值政策清晰，杠杆不超监管部门规定的标准** |
| **R3**|**产品结构较简单，过往业绩及净值的历史波动率较高，投资标的流动性较好、投资衍生品以对冲为目的，估值政策清晰，杠杆不超监管部门规定的标准** |
| **R4**|**产品结构较复杂，过往业绩及净值的历史波动率高，投资标的流动性较差，估值政策较清晰，1 倍（不含）以上至 3 倍（不含）以下杠杆** |
| **R5**|**产品结构复杂，过往业绩及净值的历史波动率很高，投资标的流动性差，估值政策不清晰，3 倍（含）以上杠杆** |

#### （七）投资者与产品风险匹配（必背） P88

**专业投资者的匹配**：

> **对于专业投资者而言，如募集机构未对专业投资者进行类别细分的，募集机构可向专业投资者匹配任何风险等级的基金产品；如募集机构选择对专业投资者进行类别细分的，应向其匹配相应风险等级的基金产品**。

**普通投资者的匹配（五条，必考）**：

| 投资者类型 | 可购买产品 |
|---|---|
| **C1 型（含最低风险承受能力类别）**|**可以购买 R1 级基金产品** |
| **C2 型**|**可以购买 R2 级及以下风险等级的基金产品** |
| **C3 型**|**可以购买 R3 级及以下风险等级的基金产品** |
| **C4 型**|**可以购买 R4 级及以下风险等级的基金产品** |
| **C5 型**|**可以购买所有风险等级的基金产品** |

### 4.2.f 【理解】专业投资者和普通投资者的区别 P85、P87–P88

**大纲原文**：理解专业投资者和普通投资者的区别

**五个维度的区别（必背）**：

| 维度 | 专业投资者 | 普通投资者 |
|---|---|---|
| **准入条件**|**除满足普通投资者的条件外，还需具备更丰富的投资经验和专业知识**（五类情形之一） |**满足合格投资者标准但不符合专业投资者条件的投资者** |
| **分类方式**|**募集机构可自主决定是否对专业投资者进行细化分类**|**必须由低到高至少划分为 C1（含最低类别）、C2、C3、C4、C5 五类** |
| **产品匹配**|**未细分时可匹配任何风险等级产品；已细分时匹配相应风险等级产品**|**严格按 C-R 匹配原则（C1→R1；C2→R2 及以下；C3→R3 及以下；C4→R4 及以下；C5→所有）** |
| **保护程度**|**相对宽松**|**更强保护**：**禁止主动推介风险等级高于其风险承受能力的产品；禁止向风险承受能力最低类别投资者销售高于其风险承受能力的产品** |
| **转化机制**|**在满足一定条件的情况下，专业投资者可申请转化为普通投资者**|**在满足一定条件的情况下，普通投资者可申请转化为专业投资者** |

> **制度目的：专业投资者对基金合规运行可以进一步提高监督要求；投资者适当性制度相关要求有助于更好地平衡投资者对相关基金产品的风险预期**。

## 4.3 募集与设立流程

### 4.3.a 【掌握】基金募集的流程 P89–P96

**大纲原文**：掌握基金募集的流程

> **股权投资基金募集需要经历一定的时间周期，其具体时长受多重因素的综合影响，包括投资者类型、基金架构复杂性、监管规则变化及宏观经济发展状况等因素**。

> **实务中，股权投资基金的募集流程通常划分为募集筹备、基金路演、投资者确认和基金合同签署四个阶段**。

| 阶段 | 主要工作 |
|---|---|
| **募集筹备**|**开发及会晤潜在投资者；准备募集推介资料；制订募资计划；准备合规事项** |
| **基金路演**|**分发募集推介材料；准备基金核心条款相关文件；进行定向路演活动** |
| **投资者确认**|**展开（反向）尽职调查、提供（反向）尽职调查资料；基金投资谈判** |
| **基金合同签署**|**签署基金合同和附属文件；启动基金设立和备案** |

#### （一）募集筹备 P89–P90

**业务工作重点（四项，必背）**：

##### ① 潜在投资者的开发和初步会晤 P89–P90

> **潜在投资者的开发是基金管理人的一项持续工作重点**；**对于任何一只即将开始募集的股权投资基金，管理人需要结合基金的目标募集规模、架构、投资领域、策略及相关监管规则，有针对性地筛选和匹配合适的潜在投资者，并了解他们的投资意向、投资能力和主要诉求**。

> **充分细致的募集筹备，尤其是对潜在投资者的深入了解及储备，可以有效提高基金路演和投资者确认阶段的效率**；**此外，一些股权投资基金会在筹备阶段锁定基石投资者的投资意向，并锚定基金的关键条款，为基金的成功募集奠定基础**。

##### ② 募集资料准备（四类） P90

| # | 资料 | 内容 |
|---|---|---|
| **①**|**募集推介材料**|**募集说明书等是基金管理人撰写的用以阐述自身优势和投资计划、旨在招募和吸引潜在投资者参与基金投资的文件** |
| **②**|**反向尽职调查资料**|**由于募集推介资料可能不足以满足投资者作出投资决策的全部信息需求，经验丰富的投资者（尤其是机构类专业投资者）可能会要求更加系统、更有针对性的信息；此类由投资者对基金管理人进行的调查被称为反向尽职调查**——**内容通常涵盖管理人的投资决策流程、内部治理结构（包括关联交易和利益冲突的处理机制等）、合规运营情况，核心团队成员的配置、背景、合作历史、激励与约束机制及稳定性，储备项目的情况等** |
| **③**|**基金核心条款清单**|**基金管理人通常会准备一份基金核心条款清单，详细描述重要潜在投资者特别关注的基金条款，作为双方后续商务谈判的基础；经验丰富的投资者也可能主动提供反映其投资偏好的条款清单** |
| **④**|**其他资料**|**例如基金估值政策文件、基金定期报告模板等** |

##### ③ 募资计划制订 P90

> **为了确保募集工作的有序进行，基金管理人在募集筹备阶段需要制订详细的募资计划，包括对募集规模、募集方式、内部组织架构、人员配置以及时间安排等关键事项的规划**。

##### ④ 合规事项准备 P90

> **基金管理人需要根据法律法规和自律规则，准备和定期更新一系列内部制度和业务规范；通过有效的内控措施，确保这些制度和规范得到有效执行，以保障募集流程的合规性**；**此外，基金管理人还需准备完整的合规文件，以满足募集流程中的各项合规要求**。

##### 合规重点事项（两项） P91

**① 募集方式与募集主体合规（必背）**：

> **在中基协办理私募基金管理人登记的机构可以自行募集其设立的股权投资基金；在中国证监会注册取得基金销售业务资格并已成为中基协成员的机构可以受基金管理人的委托募集股权投资基金；任何其他机构和个人不得从事股权投资基金的募集活动**。

> **从事股权投资基金募集业务的人员应当具有基金从业资格，应当遵守法律、行政法规和中基协的自律规则，恪守职业道德和行为规范，应当参加后续执业培训**。

> **基金管理人委托基金销售机构募集基金的，应当以书面形式签订基金销售协议，并将协议中关于基金管理人与基金销售机构权利义务划分以及其他涉及投资者利益的部分作为基金合同的附件；基金销售协议与基金合同附件关于基金销售的内容不一致的，以基金合同附件为准**。

> **双向审慎调查**：**基金销售机构选择销售基金产品或者服务，要对基金管理人进行审慎调查并进行评价，了解其诚信状况、经营管理能力、投资管理能力、产品设计能力和内部控制情况**；**基金管理人在选择基金销售机构时，要对基金销售机构进行审慎调查，了解其内部控制情况、信息管理平台建设、账户管理制度、销售人员能力和持续营销能力**。

> **基金募集机构应建立对销售人员的考核、监督问责、培训等机制，规范销售人员履行投资者适当性工作职责时的行为，不得实施鼓励销售人员向投资者销售不适当基金产品或者服务的考核、激励机制或措施**。

**② 募集材料规范（必背）**：

> **基金推介材料应由基金管理人制作并使用；基金管理人应当对基金推介材料内容的真实性、完整性、准确性负责**；**除基金管理人委托募集的基金销售机构可以使用推介材料向特定对象宣传推介外，其他任何机构或个人不得使用、更改、变相使用基金推介材料**。

> **募集机构应当采取合理方式向投资者披露基金信息，揭示投资风险，确保推介材料中的相关内容清晰、醒目；基金推介材料内容应与基金合同主要内容一致，不得有任何虚假记载、误导性陈述或者重大遗漏；如存在不一致之处，应当向投资者提供特别说明**。

**募集推介材料应披露的信息（必考）**：

> **基金的管理人以及管理团队、投资范围、投资策略、投资架构、基金架构、托管情况、相关费用、收益分配原则、基金退出等重要信息，投资风险、运营风险、流动性风险等风险情况，并披露关键人士（如有）或者投委会成员（如有）、单一拟投项目或者首个拟投项目组合（如有）的主营业务、交易对手方（如有）、基金投资款用途、退出方式等**。

##### 表 4-2 募集说明书的常见内容（必背框架） P93

> **募集说明书是基金募集过程中最常见的推介资料，其主要目的是向潜在投资者推介基金并介绍基金管理人；其通常包括基金方案、基金管理人、风险揭示等几个主要部分**：

| 部分 | 内容 |
|---|---|
| **基金方案 — 基本情况**|**基金的拟定名称、类型、注册地、目标募集规模和最低出资额（如有）等** |
| **基金方案 — 核心要素**|**基金存续期限（含延长机制）、投资范围、投资策略、投资架构及投资限制、储备项目、主要费用和费率、收益分配和亏损承担方式、托管安排、募集期限安排〔包括首轮交割和后续交割安排等（如有）〕、投资者重要权利（特别是入伙、转让、退出等权利）、信息披露机制、基金退出方式等** |
| **基金方案 — 基金架构**|**通常通过直观易懂的图示方式说明基金及相关主体的法律架构，特别是在基金涉及联接投资载体、平行投资载体等特殊架构安排时** |
| **基金方案 — 投资决策机制**|**说明基金投资决策机构的组成及运行机制** |
| **基金方案 — 合规与风控**|**介绍基金投资管理及投后管理、合规运营、风险控制等方面的保障制度与措施** |
| **基金管理人 — 企业基本情况**|**包括管理人在市场监督管理部门的登记信息，以及在中基协登记的基本情况** |
| **基金管理人 — 核心团队情况**|**主要介绍核心团队成员的投资管理经验、团队协作情况等** |
| **基金管理人 — 组织架构与人员**|**介绍管理人的组织架构及人员基本情况** |
| **基金管理人 — 历史业绩**|**介绍管理人或核心团队成员的历史投资业绩、项目运作情况** |
| **基金管理人 — 合规运作情况**|**说明管理人最近三年的诚信情况** |
| **风险揭示**|**向投资者披露投资股权投资基金的风险，包括但不限于投资风险、运营风险、流动性风险等** |

#### （二）基金路演 P93–P95

##### ① 业务工作重点 P93–P94

> **在基金筹备阶段，基金管理人通常已经储备了一定数量的投资意向相对明确的投资者；为了进一步推介基金，基金管理人可能会组织一系列线上或线下的定向路演活动**；**在路演活动中，基金管理人会向潜在投资者提供和阐述募集推介资料，并在必要时向重要的潜在投资者提供基金条款清单，为下一阶段的商务谈判奠定基础**。

> **对于股权投资基金而言，投资者关系管理是指基金管理人通过充分沟通和信息披露，向特定基金投资者（包括潜在投资者）展示基金的经营状况和发展前景的过程**；**基金募集阶段在投资者关系管理中占据关键地位，在此期间，基金管理人与投资者之间的互动尤为频繁，基金管理人需特别注重与投资者之间的专业、有效沟通，以建立稳固的投资者关系**。

> **从募集阶段开始，良好的投资者关系对基金管理人至关重要，它有助于缩短募集周期、降低募资成本，并获得长期资金支持**；**此外，良好的投资者关系有助于建立合理有效的基金治理体系，保障基金的顺畅运作**。

##### ② 合规重点事项（两项） P94

**① 特定对象确定与推介渠道合规（九项禁止渠道，必背）**：

> **募集机构应当向特定对象宣传推介股权投资基金；未经特定对象确定程序，不得向任何人宣传推介股权投资基金**。

> **在向投资者推介股权投资基金之前，募集机构应当采取问卷调查等方式履行特定对象确定程序，对投资者风险识别能力和风险承担能力进行评估，投资者应当以书面形式承诺其符合合格投资者标准**。

**禁止的九类推介渠道**：

| # | 禁止渠道 |
|---|---|
| **①**|**公开出版资料** |
| **②**|**面向社会公众的宣传单、布告、手册、信函、传真** |
| **③**|**海报、户外广告** |
| **④**|**电视、电影、电台及其他音像等公共传播媒体** |
| **⑤**|**公共、门户网站链接广告、博客等** |
| **⑥**|**未设置特定对象确定程序的募集机构官方网站、微信朋友圈等互联网媒介** |
| **⑦**|**未设置特定对象确定程序的讲座、报告会、分析会** |
| **⑧**|**未设置特定对象确定程序的电话、短信和电子邮件等通信媒介** |
| **⑨**|**法律、行政法规、中国证监会规定和中基协自律规则禁止的其他行为** |

**② 募集禁止性行为（十项，必背）**：

| # | 禁止行为 |
|---|---|
| **①**|**向合格投资者之外的单位、个人募集资金或者为投资者提供多人拼凑、资金借贷等满足合格投资者要求的便利** |
| **②**|**通过公众传播媒体、讲座报告会等方式，布告、传单、短信、即时通讯工具、博客和电子邮件等载体，向不特定对象宣传推介**（但通过设置特定对象确定程序的官网、客户端等互联网媒介向合格投资者宣传推介的情形除外） |
| **③**|**口头、书面或者通过短信、即时通讯工具等方式直接或者间接向投资者承诺保本保收益**（包括投资本金不受损失、固定比例损失或者承诺最低收益等情形） |
| **④**|**夸大、片面宣传基金**（包括使用安全、保本、零风险、收益有保障、高收益、本金无忧等可能导致投资者不能准确认识基金风险的表述，或者宣传预期收益率、目标收益率、基准收益率等类似表述） |
| **⑤**|**向投资者宣传的基金投向与基金合同约定投向不符** |
| **⑥**|**宣传推介材料有虚假记载、误导性陈述或者重大遗漏** |
| **⑦**|**以登记备案、金融机构托管、政府出资等名义为增信手段进行误导性宣传推介** |
| **⑧**|**委托不具有基金销售业务资格的单位或者个人从事资金募集活动** |
| **⑨**|**以从事资金募集活动为目的设立或者变相设立分支机构** |
| **⑩**|**法律、行政法规和中国证监会禁止的其他情形** |

> **基金管理人的出资人、实际控制人、关联方不得从事基金募集宣传推介，不得从事或者变相从事前述禁止性行为**。

#### （三）投资者确认 P95–P96

##### ① 业务工作重点 P95

> **对于股权投资基金，募集工作进展到这一阶段，基金潜在投资者的范围进一步缩小，基石投资者等重要投资者将被逐步锁定，此时，投资者也可开启反向尽职调查工作**。

> **股权投资基金对投资者来说属于期限较长、流动性较弱、估值难度较大的资产类别，因此，投资者有天然动力去主动、系统、深入地了解基金管理人，特别是业绩、团队、投资流程等，这些将成为反向尽职调查的重点**。

> **在基金管理人与投资者互相了解、深度互动的基础上，通过进一步的合格投资者认定、投资者适当性匹配等流程，管理人可逐步确认特定的基金投资者**；**在这个阶段，基金管理人可能会向有明确投资意向的潜在投资者提供基金合同，与其洽谈并初步确定基金合同条款**。

##### ② 合规重点事项：风险揭示 P95–P96

> **基金管理人应当向投资者披露股权投资基金的投资风险、运营风险、流动性风险等风险情况**。

**须特别提示的八种情形（必背）**：

> **有下列情形之一的，基金管理人应当通过风险揭示书向投资者进行特别提示**：

| # | 特别提示情形 |
|---|---|
| **①**|**基金财产不进行托管** |
| **②**|**基金管理人与基金销售机构存在关联关系** |
| **③**|**基金投资涉及关联交易** |
| **④**|**基金通过特殊目的载体投向投资标的** |
| **⑤**|**基金财产在境外进行投资** |
| **⑥**|**基金存在分级安排或者其他复杂结构，或者涉及重大无先例事项** |
| **⑦**|**基金管理人的控股股东、实际控制人、普通合伙人发生变更，尚未在中基协完成变更手续** |
| **⑧**|**其他重大投资风险或者利益冲突风险** |

> **基金投向单一标的、未进行组合投资的，基金管理人应当特别提示风险，对投资标的的基本情况、投资架构、因未进行组合投资而可能受到的损失、纠纷解决机制等进行书面揭示，并由投资者签署确认**。

#### （四）基金合同签署 P96

##### ① 业务工作重点 P96

> **在基金投资者与基金管理人通过沟通和谈判就基金设立达成一致意见后，即可准备签署一系列基金文件**；**基金合同是股权投资基金的核心法律文件，通常由基金管理人和基金投资者等相关主体共同签署，具体的签署主体可能会因基金的组织形式而有所不同**。

> **对于普通合伙人与基金管理人分离的合伙型基金以及受托管理的公司型基金，通常会由基金及/或普通合伙人与基金管理人签署委托管理协议**；**其他相关文件，例如募集结算资金专用账户监督协议、托管协议（如有），通常由基金、基金管理人及/或相关主体与募集监督机构、托管人（如有）等签署**。

> **基金文件签署完毕后，基金管理人将启动基金设立和备案的相关程序；基金合同生效后，基金投资者将依据合同约定履行出资义务，基金将按照基金合同的约定进入投资期并开始投资运作**。

##### ② 合规重点事项：募集资金监督 P96

> **为保障基金募集阶段的投资者资金财产安全，股权投资基金的募集机构应当开立基金募集结算资金专用账户，用于统一归集基金募集结算资金、向投资者分配收益以及分配基金清算后的剩余基金财产等，确保资金原路返还**。

#### （五）募集四阶段速查表

| 阶段 | 业务重点 | 合规重点 |
|---|---|---|
| **募集筹备**|**潜在投资者开发与会晤；募集资料（推介材料／反向尽调资料／核心条款清单）；募资计划；合规准备**|**募集方式与主体合规（管理人自行募集或持牌销售机构委托募集）；募集材料规范（管理人制作并负责）** |
| **基金路演**|**定向路演；提供条款清单；投资者关系管理**|**特定对象确定（九类禁止渠道）；十项募集禁止性行为** |
| **投资者确认**|**反向尽职调查；锁定基石投资者；初步确定合同条款**|**风险揭示（八种特别提示情形；单一标的特别提示）** |
| **基金合同签署**|**签署基金合同与附属文件；启动设立与备案**|**募集结算资金专用账户、冷静期、回访确认** |

### 4.3.b 【掌握】基金募集资料的合规要求 P91–P92

**大纲原文**：掌握基金募集资料的合规要求

#### （一）制作主体与责任（必考） P91

> **基金推介材料应由基金管理人制作并使用；基金管理人应当对基金推介材料内容的真实性、完整性、准确性负责**。

> **除基金管理人委托募集的基金销售机构可以使用推介材料向特定对象宣传推介外，其他任何机构或个人不得使用、更改、变相使用基金推介材料**。

#### （二）内容一致性要求（必考） P91

> **募集机构应当采取合理方式向投资者披露基金信息，揭示投资风险，确保推介材料中的相关内容清晰、醒目**。

> **基金推介材料内容应与基金合同主要内容一致，不得有任何虚假记载、误导性陈述或者重大遗漏；如存在不一致之处，应当向投资者提供特别说明**。

#### （三）必须披露的信息（必背） P91

> **募集推介材料应向投资者披露包括但不限于如下信息**：

| 类别 | 内容 |
|---|---|
| **基金与管理人信息**|**基金的管理人以及管理团队** |
| **投资要素**|**投资范围、投资策略、投资架构、基金架构、托管情况、相关费用、收益分配原则、基金退出** |
| **风险情况**|**投资风险、运营风险、流动性风险等** |
| **关键人士/投委会**|**关键人士（如有）或者投委会成员（如有）** |
| **拟投项目信息**|**单一拟投项目或者首个拟投项目组合（如有）的主营业务、交易对手方（如有）、基金投资款用途、退出方式等** |

#### （四）募集说明书的内容框架（表 4-2） P93

> **募集说明书是基金募集过程中最常见的推介资料，其主要目的是向潜在投资者推介基金并介绍基金管理人；其通常包括基金方案、基金管理人、风险揭示等几个主要部分**。

| 部分 | 子项 | 内容 |
|---|---|---|
| **基金方案**|**基本情况**|**基金的拟定名称、类型、注册地、目标募集规模和最低出资额（如有）等** |
| | **核心要素**|**基金存续期限（含延长机制）、投资范围、投资策略、投资架构及投资限制、储备项目、主要费用和费率、收益分配和亏损承担方式、托管安排、募集期限安排、投资者重要权利、信息披露机制、基金退出方式等** |
| | **基金架构**|**通常通过直观易懂的图示方式说明基金及相关主体的法律架构** |
| | **投资决策机制**|**说明基金投资决策机构的组成及运行机制** |
| | **合规与风控**|**介绍基金投资管理及投后管理、合规运营、风险控制等方面的保障制度与措施** |
| **基金管理人**|**企业基本情况**|**市场监督管理部门登记信息 + 中基协登记基本情况** |
| | **核心团队情况**|**核心团队成员的投资管理经验、团队协作情况等** |
| | **组织架构与人员**|**管理人的组织架构及人员基本情况** |
| | **历史业绩**|**管理人或核心团队成员的历史投资业绩、项目运作情况** |
| | **合规运作情况**|**说明基金管理人最近三年的诚信情况** |
| **风险揭示**| — |**向投资者披露投资股权投资基金的风险，包括但不限于投资风险、运营风险、流动性风险等** |

#### （五）与募集资料相关的禁止行为 P94

> **以下行为均属违反募集资料合规要求**：

| # | 禁止行为 |
|---|---|
| **④**|**夸大、片面宣传基金，包括使用安全、保本、零风险、收益有保障、高收益、本金无忧等可能导致投资者不能准确认识基金风险的表述，或者向投资者宣传预期收益率、目标收益率、基准收益率等类似表述** |
| **⑤**|**向投资者宣传的基金投向与基金合同约定投向不符** |
| **⑥**|**宣传推介材料有虚假记载、误导性陈述或者重大遗漏，包括未真实、准确、完整披露基金交易结构、各方主要权利义务、收益分配、费用安排、关联交易、委托第三方机构以及基金管理人的出资人、实际控制人等情况** |
| **⑦**|**以登记备案、金融机构托管、政府出资等名义为增信手段进行误导性宣传推介** |

#### （六）募集资料合规要点速查表

| 维度 | 要求 |
|---|---|
| **制作主体**|**基金管理人** |
| **责任主体**|**基金管理人对真实性、完整性、准确性负责** |
| **使用主体**|**管理人 + 其委托的基金销售机构；其他任何机构或个人不得使用、更改、变相使用** |
| **内容要求**|**与基金合同主要内容一致；不得虚假记载、误导性陈述或重大遗漏；不一致须特别说明** |
| **披露要求**|**清晰、醒目；全面披露投资要素、风险、关键人士、拟投项目信息** |

### 4.3.c 【掌握】基金募集方式的合规要求 P91、P94

**大纲原文**：掌握基金募集方式的合规要求

#### （一）募集主体资格（必考） P91

> **在中国证券投资基金业协会办理私募基金管理人登记的机构可以自行募集其设立的股权投资基金**。

> **在中国证监会注册取得基金销售业务资格并已成为中国证券投资基金业协会会员的机构可以受基金管理人的委托募集股权投资基金**。

> **任何其他机构和个人不得从事股权投资基金的募集活动**。

> **从事股权投资基金募集业务的人员应当具有基金从业资格，应当遵守法律、行政法规和中国证券投资基金业协会的自律规则，恪守职业道德和行为规范，应当参加后续执业培训**。

#### （二）委托募集的特殊要求（必考） P91

| # | 要求 |
|---|---|
| **1**|**应当以书面形式签订基金销售协议** |
| **2**|**应将协议中关于基金管理人与基金销售机构权利义务划分以及其他涉及投资者利益的部分作为基金合同的附件** |
| **3**|**基金销售协议与基金合同附件关于基金销售的内容不一致的，以基金合同附件为准** |
| **4**|**基金管理人不得因委托募集而免除其依法应承担的责任** |

#### （三）双向审慎调查 P91

| 方向 | 调查内容 |
|---|---|
| **销售机构 → 管理人**|**了解基金管理人的诚信状况、经营管理能力、投资管理能力、产品设计能力和内部控制情况，并可将调查结果作为决定是否销售该管理人产品或者服务、是否向投资者推介该管理人的重要依据** |
| **管理人 → 销售机构**|**为确保适当性的贯彻实施，要对基金销售机构进行审慎调查，了解其内部控制情况、信息管理平台建设、账户管理制度、销售人员能力和持续营销能力，并可将调查结果作为选择基金销售机构的重要依据** |

> **基金募集机构应建立对销售人员的考核、监督问责、培训等机制，规范销售人员履行投资者适当性工作职责时的行为，不得实施鼓励销售人员向投资者销售不适当基金产品或者服务的考核、激励机制或措施**。

#### （四）禁止变相公开募集（九类渠道 + 十项行为） P94

**不得通过九类媒介渠道推介（详见 4.3.a）**：

| # | 禁止渠道 |
|---|---|
| **①–⑤**|**公开出版资料；宣传单、布告、手册、信函、传真；海报、户外广告；电视、电影、电台等公共传播媒体；公共、门户网站链接广告、博客等** |
| **⑥–⑧**|**未设置特定对象确定程序的官方网站、微信朋友圈等互联网媒介；未设置特定对象确定程序的讲座、报告会、分析会；未设置特定对象确定程序的电话、短信和电子邮件等通信媒介** |
| **⑨**|**法律、行政法规、中国证监会规定和中基协自律规则禁止的其他行为** |

**与募集方式直接相关的四项禁止行为**：

| # | 禁止行为 |
|---|---|
| **①**|**向合格投资者之外的单位、个人募集资金或者为投资者提供多人拼凑、资金借贷等满足合格投资者要求的便利** |
| **②**|**通过公众传播媒体等方式向不特定对象宣传推介**（但设置特定对象确定程序的官网、客户端等互联网媒介向合格投资者宣传推介的情形除外） |
| **⑧**|**委托不具有基金销售业务资格的单位或者个人从事资金募集活动** |
| **⑨**|**以从事资金募集活动为目的设立或者变相设立分支机构** |

> **基金管理人的出资人、实际控制人、关联方不得从事基金募集宣传推介，不得从事或者变相从事前述禁止性行为**。

#### （五）募集方式合规要点速查表

| 维度 | 合规要求 |
|---|---|
| **自行募集主体**|**已在中基协登记的私募基金管理人** |
| **委托募集主体**|**已取得中国证监会基金销售业务资格 + 已为中基协成员** |
| **人员要求**|**具有基金从业资格；恪守职业道德；参加后续执业培训** |
| **协议要求**|**书面基金销售协议 + 作为基金合同附件；不一致以合同附件为准** |
| **责任**|**管理人不得因委托募集而免责** |
| **募集对象**|**仅限合格投资者；禁止拼凑、借贷** |
| **推介渠道**|**须先履行特定对象确定程序；九类渠道禁止** |

### 4.3.d 【掌握】基金设立的主要要求 P97–P99

**大纲原文**：掌握基金设立的主要要求

> **股权投资基金的设立流程主要包括基金合同的签署、基金在市场监督管理部门的注册（如涉及）等程序，并须按法律法规及自律规则要求在中国证券投资基金业协会资产管理业务综合报送平台完成基金产品备案**。

#### （一）公司型基金的设立 P97–P98

##### ① 有限责任公司的设立条件（五项，必背） P97–P98

| # | 条件 |
|---|---|
| **（1）**|**由 1 个以上 50 个以下股东出资设立** |
| **（2）**|**注册资本为在公司登记机关登记的全体股东认缴的出资额；全体股东认缴的出资额由股东按照公司章程的规定自公司成立之日起五年内缴足** |
| **（3）**|**股东共同制定公司章程** |
| **（4）**|**有公司名称（名称应当符合法律法规及自律规则的有关要求），设立符合有限责任公司要求的组织机构** |
| **（5）**|**有公司住所** |

##### ② 股份有限公司的设立条件（六项，必背） P98

| # | 条件 |
|---|---|
| **（1）**|**应当有 1 人以上 200 人以下为发起人，其中应当有半数以上的发起人在中华人民共和国境内有住所** |
| **（2）**|**以发起设立方式设立的，发起人应当认足公司章程规定的公司设立时应发行的股份；以募集设立方式设立的，发起人认购的股份不得少于公司章程规定的公司设立时应发行股份总数的 35%（法律、行政法规另有规定的，从其规定）；发起人应当在公司成立前按照其认购的股份全额缴纳股款** |
| **（3）**|**股份发行、筹办事项符合法律规定** |
| **（4）**|**由发起人共同制定公司章程** |
| **（5）**|**有公司名称，设立符合股份有限公司要求的组织机构** |
| **（6）**|**有公司住所** |

> **公司型基金依据《公司法》设立；有限责任公司的股东以其认缴的出资额为限对公司承担责任；股份有限公司的股东以其认购的股份为限对公司承担责任**。

##### ③ 其他要求 P98

> **公司型基金的组织形式为公司，由市场监督管理部门进行登记管理**；**公司应依据《公司法》《市场主体登记管理条例》《市场主体登记管理条例实施细则》、各地市场监督管理部门的要求等申请登记**。

> **通常而言，公司设立登记需要向市场监督管理部门提交公司登记申请书、公司章程、股东资格/身份证明文件、法定代表人、董事、监事和高级管理人员的任职文件、住所（经营场所）合法使用文件等申请材料**。

#### （二）合伙型基金的设立 P98–P99

**设立有限合伙企业的五项条件（必背）**：

| # | 条件 |
|---|---|
| **（1）**|**有限合伙企业由 2 个以上 50 个以下合伙人设立，但是法律法规另有规定的除外；有限合伙企业至少应当有 1 个普通合伙人** |
| **（2）**|**有书面合伙协议** |
| **（3）**|**有限合伙企业名称中应当标明"有限合伙"字样，且应符合作为私募基金的要求** |
| **（4）**|**有符合适用法律规定的合伙人认缴或者实际缴付的出资** |
| **（5）**|**法律法规规定的其他条件** |

> **合伙型基金与公司型基金均由市场监督管理部门进行登记管理，因而设立步骤相同**；**合伙型基金应依据《合伙企业法》《市场主体登记管理条例》、各地市场监督管理部门的要求等申请登记**。

> **对于公司型和合伙型基金，除了遵循常规的登记设立程序外，还需注意不同地区可能对股权投资基金设立设置了特定的要求——包括但不限于需要获得当地金融监管部门的审批和复审等流程；如果基金涉及外资参与，还可能需要满足特定的资质或审批条件**。

#### （三）契约型基金的设立 P99

> **根据相关法律法规，契约型基金的设立无须在市场监督管理部门登记**；**基金的成立通过签订基金合同来实现，合同中将明确约定基金投资者、管理人和托管人的权利、义务和职责，确保委托财产的安全并保护各方的合法权益**。

> **通常情况下，基金自基金合同生效之日起或于合同约定的成立日期即被视为正式成立**。

#### （四）设立条件数字速查表

| 主体 | 人数 | 其他关键数字 |
|---|---|---|
| **有限责任公司**|**1 个以上 50 个以下股东**|**认缴出资自成立之日起 5 年内缴足** |
| **股份有限公司**|**1 人以上 200 人以下发起人**|**半数以上发起人境内有住所；募集设立时发起人认购 ≥ 35%，成立前全额缴纳股款** |
| **有限合伙企业**|**2 个以上 50 个以下合伙人**|**至少 1 个普通合伙人；名称标明"有限合伙"** |
| **契约型基金**| — |**无须市场监督管理部门登记** |

### 4.3.e 【理解】基金备案的基本要求 P99–P100

**大纲原文**：理解基金备案的基本要求

> **依据现行法律法规和自律规则的要求，基金管理人应在股权投资基金募集完毕后履行基金备案手续，基金管理人不得管理未备案基金**；**实务中，基金管理人应根据自律规则规定的资料清单，全面、真实、准确、规范地准备并提交基金备案申请材料**。

#### （一）备案方式 P99

> **基金备案需要通过中国证券投资基金业协会资产管理业务综合报送平台提交相关材料或信息**。

#### （二）备案时间（20 个工作日 × 2，必考） P100

| 主体 | 时限 |
|---|---|
| **基金管理人**|**应当自基金募集完毕之日起 20 个工作日内报送备案材料** |
| **中国证券投资基金业协会**|**自备案材料齐备之日起 20 个工作日内为基金办结备案手续，并通过官方网站对已办理备案的基金相关信息进行公示** |

#### （三）备案前提（核心考点） P100

> **基金备案以基金募集完毕为前提**。

> **"募集完毕"是指基金的已认缴投资者已签署基金合同，且首期实缴募集资金已进入托管账户等基金财产账户**。

> **单个投资者首期实缴出资除另有规定外，不得低于合格投资者的最低出资要求**。

#### （四）备案材料清单（必背） P100

> **股权投资基金备案时，基金管理人需按照相关规定的要求在资产管理业务综合报送平台上传**：

| # | 材料 |
|---|---|
| **1**|**募集说明书** |
| **2**|**基金合同** |
| **3**|**委托管理协议（如涉及）** |
| **4**|**基金销售协议（如涉及）** |
| **5**|**募集结算资金专用账户监督协议** |
| **6**|**托管协议（如有）或者保障基金财产安全的制度措施相关文件** |
| **7**|**投资者适当性管理的相关文件** |
| **8**|**产品结构图** |
| **9**|**实缴出资证明** |

#### （五）备案要求涵盖的方面 P100

> **相关法律法规和自律规则明确了股权投资基金的备案要求，这些要求涵盖资金募集方式、基金架构、合格投资者及适当性管理、投资者资金来源、管理人职责、基金合同、募集推介材料、基金投资范围、托管机制、实缴出资金额、存续期、关联交易等方面**。

#### （六）备案要点速查表

| 维度 | 要求 |
|---|---|
| **备案义务**|**募集完毕后必须备案；不得管理未备案基金** |
| **备案平台**|**中基协资产管理业务综合报送平台** |
| **报送时限**|**募集完毕之日起 20 个工作日内** |
| **办结时限**|**材料齐备之日起 20 个工作日内** |
| **备案前提**|**募集完毕 = 已认缴投资者签署合同 + 首期实缴资金进入托管账户等基金财产账户** |
| **首期实缴**|**单个投资者不低于合格投资者最低出资要求** |

### 4.3.f 【掌握】基金备案的合规要点 P100–P103

**大纲原文**：掌握基金备案的合规要点

#### （一）备案常见问题：四个典型案例（必背） P100–P102

##### 案例 4-2：员工持股计划拟备案为私募基金 P100–P101

> **基金管理人 A 提交上市公司员工持股计划 B 备案申请，B 作为上市公司员工持股计划载体，拟以非交易过户方式受让该上市公司股票**。

> **案例分析**：**员工持股计划一般是指公司根据员工意愿，通过合法方式使员工获得本公司股份并长期持有、股份权益按约定分配给员工的制度安排，其目的主要在于实现员工激励，建立和完善劳动者与所有者的利益共享机制**；**而私募基金是指以非公开方式向合格投资者募集资金设立的投资基金，其设立目的为"受人之托，代人理财"，即基金管理人受投资者委托进行投资管理，实现资产增值以获取相应管理费及报酬，投资者按基金份额和约定承担风险并获取收益**。

> **因此，两者存在明显差异，故员工持股计划不属于私募基金备案范围，中基协亦不予备案**。

##### 案例 4-3：管理人出让投资决策权成为"通道" P101

> **基金管理人 A 提交合伙型股权投资基金 B 备案申请，该基金设置双执行事务合伙人结构，分别为基金管理人 A 以及未登记机构 C**；**根据合伙协议职责划分，机构 C 负责委任投资决策委员会委员、制定投资决策委员会议事规则、筛选投资项目并进行投后管理；同时，机构 C 将收取部分基金管理费**。

> **案例分析（两层违法）**：

| # | 违法点 |
|---|---|
| **第一**|**根据《关于加强私募投资基金监管的若干规定》第三条，未经登记任何单位不得进行私募基金业务活动；《私募投资基金登记备案办法》第三十条规定，基金管理人应当按照诚实信用、勤勉尽责原则切实履行受托管理职责，不得将投资管理职责委托他人行使**——**机构 C 并未登记为基金管理人，不具备管理私募基金的资质，但根据基金合伙协议约定控制基金投资决策委员会、负责筛选投资项目、进行投后管理，实质上管理基金；原基金管理人 A 出让投资决策权，将应当履行的受托责任转让他人，成为非登记机构开展私募业务的"通道"** |
| **第二**|**基金管理费为基金管理人从基金中收取的固定费用，用于覆盖基金管理的日常开支和基金管理人的基础运营成本，为基金管理人项下的专属费用科目，其他执行事务合伙人不得以"基金管理费"名义收取相关费用** |

> **综上，中基协认为上述私募基金不符备案要求，已对其不予备案**。

##### 案例 4-4：投资者不具备实缴出资能力 P102

> **基金管理人 A 提交股权投资基金 B 备案申请，其投资者为 3 只集合资金信托计划，均为认缴上亿元规模、实缴仅 100 万元情形**；**经核实，3 只集合资金信托计划均于近期设立且未募集完毕，信托计划账户内仅实缴 100 万元资金，不具备后续实缴出资能力，拟待股权投资基金 B 备案通过后，继续对外分批募集**。

> **案例分析**：**基金投资者对基金的认缴金额应与其实际出资能力相匹配；投资者认缴金额与实缴金额差异较大的，关注其是否具备后续实缴出资能力**；**上述行为涉嫌"先备后募"，中基协已退回要求基金管理人进行整改，其投资者信托计划应募集完毕并具备实缴出资能力后再提交基金备案申请**。

#### （二）暂停备案的十种情形（必背） P102–P103

> **对于存在特定情形的股权投资基金管理人，中基协可能会暂停其基金备案**。

| # | 暂停备案情形 |
|---|---|
| **（1）**|**基金管理人及其控股股东、实际控制人、普通合伙人、主要出资人因涉嫌违法违规被公安、检察、监察机关立案调查，或者正在接受金融管理部门、自律组织的调查、检查，尚未结案** |
| **（2）**|**被列为严重失信人或者被纳入失信被执行人名单** |
| **（3）**|**基金管理人及其控股股东、实际控制人、普通合伙人、关联基金管理人出现可能危害市场秩序或者损害投资者利益的重大经营风险或者其他风险** |
| **（4）**|**因涉嫌违法违规、侵害投资者合法权益等多次受到投诉，未能向中基协和投资者作出合理说明** |
| **（5）**|**未按规定向中基协报送信息，或者报送的信息存在虚假记载、误导性陈述或者重大遗漏** |
| **（6）**|**登记备案信息发生变更，未按规定及时向中基协履行变更手续，存在未及时改正等严重情形** |
| **（7）**|**办理登记备案业务时的相关承诺事项未履行或者未完全履行** |
| **（8）**|**采取拒绝、阻碍中国证监会及其派出机构、中基协及其工作人员依法行使检查、调查职权等方式，不配合行政监管或者自律管理，情节严重** |
| **（9）**|**中国证监会及其派出机构要求暂停备案** |
| **（10）**|**中国证监会、中基协规定的其他情形** |

#### （三）不予办理备案的九种情形（必背） P103

> **有下列情形之一的，中基协不予办理基金备案**：

| # | 不予备案情形 |
|---|---|
| **（1）**|**从事或者变相从事信贷业务，或者直接投向信贷资产**（中国证监会、中基协另有规定的除外） |
| **（2）**|**通过委托贷款、信托贷款等方式从事经营性民间借贷活动** |
| **（3）**|**基金通过设置无条件刚性回购安排变相从事借贷活动，基金收益不与投资标的的经营业绩或者收益挂钩** |
| **（4）**|**投向保理资产、融资租赁资产、典当资产等与私募基金相冲突业务的资产、资产收（受）益权，以及投向从事上述业务的公司的股权** |
| **（5）**|**投向国家禁止或者限制投资的项目，不符合国家产业政策、环境保护政策、土地管理政策的项目** |
| **（6）**|**通过投资公司、合伙企业、资产管理产品等方式间接从事或者变相从事上述第（1）项至第（5）项规定的活动** |
| **（7）**|**不属于《私募投资基金登记备案办法》规定的私募基金，不以基金形式设立和运作的投资公司和合伙企业** |
| **（8）**|**以员工激励为目的设立的员工持股计划和基金管理人的员工跟投平台** |
| **（9）**|**中国证监会、中基协规定的其他情形** |

#### （四）不能备案的处理 P103

> **对于中基协不予备案的股权投资基金，基金管理人应当及时告知投资者，妥善处置相关财产，保护投资者的合法权益**。

> **在实务中，各相关方可能会在基金合同或认购文件中约定基金不能备案情况下的费用承担（如基金募集期间的费用承担方式）、资金返还（如是否返还实缴出资资金到账期间的利息）等事项**。

#### （五）暂停备案 vs 不予备案（对比记忆，必考）

| 维度 | 暂停备案 | 不予备案 |
|---|---|---|
| **对象**|**针对基金管理人**|**针对基金本身** |
| **性质**|**管理人存在特定情形 → 暂停其基金备案**|**基金存在不符合适用法律规定的情形 → 不予办理该基金备案** |
| **典型情形**|**被立案调查、被列失信名单、重大经营风险、多次投诉、未报送或虚假报送、未及时变更登记、承诺未履行、不配合检查、证监会要求暂停**|**从事或变相从事信贷业务、经营性民间借贷、无条件刚性回购、投向保理/融资租赁/典当等冲突业务、投向禁止限制项目、间接从事上述活动、非基金形式的投资公司和合伙企业、员工持股计划和员工跟投平台** |

## 4.4 股权投资基金合同

> **股权投资基金募集行为的完成，以基金投资者与基金管理人签署基金合同等文件为重要标志**；**基金合同是股权投资基金最核心的法律文件，完整约定了基金管理人、基金投资者、托管人（如有）的权利义务**。

> **根据基金类型的不同，基金合同的形式也有所区别**：

| 基金类型 | 合同形式 |
|---|---|
| **公司型基金**|**公司章程** |
| **合伙型基金**|**合伙协议** |
| **契约型基金**|**基金合同** |

> **基金合同的具体内容应当反映基金管理人与基金投资者之间商业谈判的结果**。

### 4.4.a 【了解】基金合同通用条款的主要内容 P104–P105

**大纲原文**：了解基金合同通用条款的主要内容

> **尽管股权投资基金在类型和组织形式上存在差异，但基金合同通常会包含以下通用条款**。

#### （一）基金名称、经营场所和经营范围 P104

> **在我国，除契约型股权投资基金外，基金名称、经营场所和经营范围是基金提交市场监督管理部门登记的必备信息**。

**名称的强制性字样要求（必考）**：

| 基金类型 | 名称要求 |
|---|---|
| **股权投资基金**|**名称应当标明"股权基金""股权投资"等字样** |
| **契约型股权投资基金**|**名称应当标明"私募股权基金"字样** |
| **创业投资基金**|**名称应当包含"创业投资基金"，或者在公司型、合伙型创业投资基金的经营范围中包含"从事创业投资活动"等以体现创业投资策略的字样** |

#### （二）期限 P104–P105

> **基金的期限分为在基金合同中约定的基金存续期限和在市场监督管理部门登记的经营期限**。

> **基金合同中约定的基金存续期限会根据基金的投资策略等因素合理设定，通常包括投资期、退出期、延长期**；**此外，基金合同还可以约定基金的投资期提前终止情形、退出期可以实施投资的例外情形等**。

**存续期的强制性要求（数字必背）**：

> **自律规则要求股权投资基金的存续期不得少于 5 年（另有规定除外），鼓励基金管理人设立存续期不少于 7 年的股权投资基金**。

**该要求的两方面意义（必考）**：

| # | 意义 |
|---|---|
| **一方面**|**反映了股权投资自投资决策至完成退出通常需要较长周期的特点** |
| **另一方面**|**旨在鼓励和促进长期资本的形成，并防范出现"名股实债"或"名基实贷"的现象** |

> **注意：基金在市场监督管理部门登记的经营期限并不当然反映基金真实的期限**；**实务中，基金延长存续期限是比较普遍的现象，为避免频繁变更市场监督管理部门登记的经营期限，一些基金会登记较长的经营期限，如 20 年、50 年等**。

#### （三）通用条款速查表

| # | 通用条款 | 核心要点 |
|---|---|---|
| **1**|**名称、经营场所和经营范围**|**股权基金/股权投资；契约型标"私募股权基金"；创投标"创业投资基金"或经营范围含"从事创业投资活动"** |
| **2**|**期限**|**存续期限 ≥ 5 年（鼓励 ≥ 7 年）；投资期 + 退出期 + 延长期；登记经营期限 ≠ 真实期限** |
| **3**|**投资者及其出资安排**|**总认缴规模、单一投资者认缴金额、缴付方式与时间、逾期违约责任** |
| **4**|**基金费用**|**区分基金承担费用与管理人自担费用** |

### 4.4.b 【理解】基金合同通用条款中的投资者及其出资安排 P105–P106

**大纲原文**：理解基金合同通用条款中的投资者及其出资安排

> **投资者及其出资安排条款通常包括基金总认缴规模、单一投资者认缴金额、出资缴付方式、缴付时间、逾期缴付的违约责任等内容**。

#### （一）出资方式 P105

> **出资义务是基金投资者最核心的义务**；**合伙型基金与公司型基金的投资者通常采取承诺资本制，即在签署基金合同时先认缴一定金额的出资，之后根据基金合同约定分期缴付出资，以提高资金的使用效率**。

> **根据相关自律管理规则，单个投资者首期实缴出资除另有规定外，不得低于合格投资者的最低出资要求**。

**三种常见出资安排（必背，对比记忆）**：

| 方式 | 含义 | 适用/优势 |
|---|---|---|
| **按项目提款**|**管理人根据项目实际用款需求逐笔发出缴款通知**|**有助于避免资金闲置，提升基金的内部收益率** |
| **分期出资**|**由投资者依据基金合同中规定的时间和比例缴付出资**|**相较于按项目提款，减少了出资频率，使投资者能够根据合同约定更明确地预期和筹划资金安排** |
| **一次性出资**|**一次性缴付全部认缴出资**|**通常适用于单一项目基金、小规模基金或投资周期较短的基金** |

**公平对待与差异化安排（必考）**：

> **实务中，股权投资基金的所有投资者通常适用相同的出资条件，但部分基金可能会针对个别投资者的实际情况实施不同的出资安排**；**例如，采用分期出资安排的基金可能会要求认缴金额较小的自然人投资者一次性缴付出资，以提高缴款的便利性和确定性**。

> **基金管理人对个别投资者适用不同的缴款条件时，应当考虑到公平对待所有投资者的监管要求，确保差异化的出资条件具有合理性并取得投资者的同意**。

> **此外，在设计出资条款时，应确保出资安排满足基金备案前初始实缴募集资金规模等法律法规和自律规则的要求**。

#### （二）逾期缴付出资 P106

> **逾期缴付出资的违约责任条款对于基金管理人敦促投资者履约、防范风险至关重要**；**出资违约会影响基金的投资计划和投资安排，甚至可能引发其他投资者的"连锁反应"**。

> **因此，基金合同中通常会设置违约金、强制转让等违约责任条款以约束投资者按期履行出资义务**。

#### （三）首次关闭和后续募集 P106

> **基金合同中通常会约定首次关闭和后续募集事宜，允许股权投资基金在完成一定金额募集后即可开展对外投资**；**基金在满足自律规则相关要求的前提下，可以进行后续募集**。

> **对于设定了后续募集机制的基金，基金合同中通常会明确约定后续募集期限、后续募集投资者的出资溢价计算方法和支付方式、出资溢价的分配方式等**。

#### （四）冷静期、回访及解除权 P106

> **根据自律规则的相关要求，基金合同通常也会在出资安排部分设置投资冷静期、回访及解除权的相关条款**。

#### （五）投资者及出资安排速查表

| 维度 | 核心要点 |
|---|---|
| **制度基础**|**承诺资本制（先认缴、后分期缴付）** |
| **首期实缴底线**|**单个投资者首期实缴出资不得低于合格投资者最低出资要求** |
| **三种方式**|**按项目提款（提升 IRR）、分期出资（便于筹划）、一次性出资（单一项目/小规模/短周期）** |
| **公平性**|**差异化条件须具合理性并取得投资者同意** |
| **违约救济**|**违约金、强制转让** |
| **配套条款**|**冷静期、回访、解除权；后续募集期限与出资溢价安排** |

### 4.4.c 【理解】基金合同通用条款中的基金费用 P106–P108

**大纲原文**：理解基金合同通用条款中的基金费用

> **基金合同通常会详细列举应由基金承担的费用，以区分于基金管理人以其收取的管理费自行承担的费用**。

#### （一）基金费用 P106

> **除支付给基金管理人的管理费以外，基金费用一般包含**：

| # | 费用项目 |
|---|---|
| **1**|**筹建费** |
| **2**|**募集专用账户募集监督费用** |
| **3**|**托管费** |
| **4**|**审计费** |
| **5**|**因项目投资及退出而发生的费用** |
| **6**|**会议费用** |
| **7**|**受偿人士费用（与免责保证条款相关）** |
| **8**|**解散清算相关费用** |
| **9**|**为基金利益提起的诉讼仲裁费用等** |

> **基金合同通常会对基金费用的范围进行明确约定**；**实务中，一些投资者可能会要求在基金合同或其他相关法律文件中设定基金费用总额或特定费用项目的最高金额或比例限制**。

##### 案例 4-5：合伙型基金的"合伙费用"（14 项） P106–P107

> **合伙企业应负担所有与合伙企业之设立、运营、终止、解散、清算等相关的费用（"合伙费用"），包括**：

| # | 合伙费用 |
|---|---|
| **（1）**|**开办费，包括为合伙企业的筹建设立而产生的前期代垫费用以及设立过程中的法律、财务、会计、税务、差旅、通讯、打印、备案登记和其他政府规费；开办费上限为 X 万元，超出部分由普通合伙人承担** |
| **（2）**|**合伙企业发生的与投资交易或现金管理相关的所有费用和支出，包括但不限于聘请的法律、审计、评估、中介及其他第三方费用** |
| **（3）**|**为投资而组建投资工具所发生的费用（如有）** |
| **（4）**|**管理费** |
| **（5）**|**合伙企业日常运营和管理的法律、会计和审计、税务、评估及其他第三方顾问费用** |
| **（6）**|**合伙企业之财务报表及报告费用，包括制作、印刷和发送成本** |
| **（7）**|**合伙人会议、投资决策委员会、顾问委员会会议费用以及与合伙企业运营有关的其他会议费用** |
| **（8）**|**政府部门对合伙企业、合伙企业的收益或资产、合伙企业交易和运作所收取的税费及其他费用** |
| **（9）**|**合伙企业为维持合法存续而发生的登记、备案、年检等工商、审计、税务相关的费用，注册/经营场所租赁和维护费等成本** |
| **（10）**|**向募集结算资金专用账户监督机构、托管机构支付的费用** |
| **（11）**|**由合伙企业发起或针对合伙企业的诉讼、仲裁或其他司法或行政程序的费用，与该等诉讼、仲裁或程序相关的律师费，以及行使由此产生的任何支出** |
| **（12）**|**合伙企业向受补偿方直接或间接支付的补偿及其他相关的税费、政府收费、罚金、赔偿金或和解金，或合伙企业应付的保险费** |
| **（13）**|**合伙企业清算、解散、注销相关的费用** |
| **（14）**|**其他未明确列出，但合伙企业发生的与合伙企业的业务和运营有关的费用** |

#### （二）管理费（核心考点） P107

> **管理费是基金管理人收取的固定报酬，是基金费用的主要部分，主要用于覆盖其管理和运营基金的成本和开支，例如员工薪酬、差旅、办公场所等**。

> **基金合同通常会明确约定管理费的计算基数、费率水平以及支付周期等**；**作为基金合同的关键商业条款之一，管理费的设定通常体现了基金管理人与基金投资者博弈的结果**。

##### 案例 4-6：典型的"2% + 双基数"管理费结构 P107–P108

> **管理费总额为全体有限合伙人按照本条应分摊的管理费的总额；自首次交割日起至合伙企业解散日，就每一有限合伙人，其应分摊的年度管理费按照如下方式计算**：

| 阶段 | 计算基数 | 费率 |
|---|---|---|
| **从首次交割日起至投资期终止之日**|**该合伙人认缴出资额**|**2%** |
| **此后**|**该合伙人按照投资成本分摊比例所分摊的合伙企业尚未退出的投资项目的投资成本**|**2%** |

> **上述年度管理费适用的认缴出资额以及尚未退出的投资项目的投资成本每年度进行核算，以截至相应年度的首个工作日核算的金额为准**。

**计算和支付原则（必考）**：

| 方面 | 内容 |
|---|---|
| **支付期限**|**（i）首个管理费支付期间为首次交割日起至首次交割日所在年度的最后一日的期间；（ii）最后一个管理费支付期间为合伙企业解散日所在的年度之首日至合伙企业解散日的期间；（iii）此外，合伙企业首次交割日后的每一个完整的年度为一个管理费支付期间；针对非完整年度的管理费支付期间，管理费应根据该期间包含的实际日数按比例折算** |
| **支付方式**|**管理费应当由合伙企业按照年度预付**；**除非执行事务合伙人另行决定，首次管理费支付日为首期缴款通知所载的付款到期日后 15 日内，此后的管理费支付日为每年度的第 1 个工作日，最后一次管理费的支付日为合伙企业解散日之前 15 日内** |

#### （三）基金费用速查表

| 维度 | 要点 |
|---|---|
| **费用归属划分**|**基金承担的费用（筹建费、监督费、托管费、审计费、投资退出费用、会议费、受偿费用、清算费、诉讼仲裁费）vs 管理人自担费用（以管理费覆盖）** |
| **管理费性质**|**固定报酬，覆盖管理人管理和运营基金的成本开支，是基金费用的主要部分** |
| **管理费要素**|**计算基数、费率水平、支付周期** |
| **典型结构**|**投资期内按认缴出资额 2%；投资期后按未退出项目投资成本 2%** |
| **费用上限**|**投资者可要求设定费用总额或特定项目最高金额/比例限制** |

### 4.4.d 【理解】基金合同通用条款中的投资事项 P108–P109

**大纲原文**：理解基金合同通用条款中的投资事项

> **投资事项相关的条款主要规定基金对外投资的相关事宜，包括投资领域、阶段、策略、方式以及投资限制等**。

#### （一）投资方向和投资限制 P108

> **投资限制通常涵盖**：

| # | 投资限制 |
|---|---|
| **1**|**集中度限制（例如，单一项目的投资额不得超过基金总认缴出资额的特定比例）** |
| **2**|**对基金举债和对外担保的限制** |
| **3**|**禁止承担无限责任的投资** |
| **4**|**禁止从事证券交易等** |

#### （二）投资工具（三类，必背） P108–P109

> **关于平行基金、联接基金及特殊目的载体的条款也是投资事项中的重要组成部分**；**这些投资实体的设立通常是为了满足募资或投资端基于商业或法律原因的需求，其设立具有其合理性**；**然而，其结构的复杂性增加了对底层资产和相关投资实体权益进行识别的难度，因此，对基金管理人在信息披露、审计等方面的要求更为严格**。

> **为了遵循信息透明原则和公平对待投资者原则，投资者与基金管理人应就这些条款进行深入商讨，并达成明确的约定**。

| 类型 | 定义与特征 |
|---|---|
| **平行基金（平行投资载体）**|**是相对于作为主要投资载体的股权投资基金（即主基金）而言的**；**一般来讲，平行基金与主基金由同一基金管理人管理，二者具有相同的基金期限、投资领域与范围、投资决策程序，二者通常按固定比例同时投向相同的标的或从投资标的退出，即平行基金与主基金"同进同退"** |
| **联接基金（投资载体）**|**与主基金由同一基金管理人管理；通常情况下，管理人不在联接基金层面收取管理费和业绩报酬；联接基金一般作为主基金的上层基金，其全部资金均投入主基金** |
| **特殊目的载体（SPV）**|**通常作为投资工具使用，即在特定情况下，股权投资基金先出资至特殊目的载体，再由特殊目的载体出资至实际的投资标的** |

#### （三）关键人士 P109

> **关键人士通常是指在基金的投资、运营及退出等关键环节发挥决定性作用的团队核心成员**。

> **关键人士条款的主要目的在于确保在基金管理团队核心成员因离职、健康问题或其他原因无法继续为基金服务时，能够依据预先设定的机制采取适当措施，以维护基金投资者利益**；**一些基金合同将关键人士条款纳入投资章节，也有一些基金将其设置在普通合伙人或其他相关章节中**。

**关键人士条款的三项内容（必背）**：

| # | 内容 |
|---|---|
| **1**|**关键人士的界定** |
| **2**|**关键人士条款的触发条件** |
| **3**|**关键人士事件发生后的安排**——**如基金暂停投资，基金管理人在约定期限内提出投资者认可的关键人士替代方案，否则基金进入退出期等** |

#### （四）投资事项速查表

| 维度 | 要点 |
|---|---|
| **投资方向**|**投资领域、阶段、策略、方式** |
| **四项投资限制**|**集中度限制、举债与对外担保限制、禁止承担无限责任投资、禁止证券交易** |
| **三类投资工具**|**平行基金（同进同退）、联接基金（全部资金投入主基金，不收费）、SPV（先投载体再投标的）** |
| **关键人士**|**界定 + 触发条件 + 事件后安排（暂停投资、替代方案、否则进入退出期）** |

### 4.4.e 【理解】基金合同通用条款中的基金内部组织机构 P111–P112

**大纲原文**：理解基金合同通用条款中的基金内部组织机构

> **基金合同通常涵盖基金治理的相关内容，包括但不限于基金内部治理机构设置、机构权利义务关系，以及决策机制、激励机制和约束机制等**。

#### （一）基金的组织机构 P111

> **基金合同中关于基金治理的表述因基金组织形式而异，且可能分布在基金合同的不同章节**。

| 基金类型 | 组织机构安排 |
|---|---|
| **委托管理型公司型基金**|**基金的日常运营活动由基金管理人负责，且关键的决策权通常掌握在基金管理人手中；投委会一般设于管理人内部，而公司自身的决策机构（例如董事会）则可能相对虚设或者主要承担对管理人履职的监督职能** |
| **自我管理型公司型基金**|**需要依靠自身的股东会、董事会和经营管理层来执行基金的投资决策及运营职能** |
| **合伙型基金和契约型基金**|**普遍采用委托管理模式，由基金管理人负责基金的投资决策和运营；基金投资者通过合伙人会议、咨询委员会或份额持有人大会等机制参与基金重大事项的决策** |

#### （二）投委会（核心决策机构） P111

> **通常情况下，基金独立设置投委会，作为基金核心决策机构，负责项目投资决策、重大投后管理事项以及退出决策**；**一些情况下，重要的基金投资者要求委派投委会观察员**。

> **投委会运行相关条款是股权投资基金治理的核心条款之一，通常包括投委会的组成、决策机制、职权范围等**。

#### （三）投资者会议 P111–P112

> **基金的合伙人会议（或股东会、份额持有人大会）条款通常涵盖会议通知、召集方式、参会方式、召开时间、决议内容和表决机制等事项**。

| 会议类型 | 召集安排 |
|---|---|
| **年度会议**|**依据基金合同约定的时间和频率召开** |
| **临时会议**|**由基金管理人根据需要召集，或由持有一定比例权益的投资者提议召开** |

> **此外，基金合同应包含"通知和送达"条款，并记录投资者的联系方式，确保投资者能够及时收到会议通知**。

#### （四）内部组织机构速查表

| 机构 | 定位 |
|---|---|
| **投委会**|**基金核心决策机构：项目投资决策、重大投后管理事项、退出决策；组成 + 决策机制 + 职权范围** |
| **合伙人会议/股东会/份额持有人大会**|**投资者参与重大事项决策的机制；年度会议 + 临时会议；通知送达条款** |
| **咨询委员会**|**审议关联交易、利益冲突等事项** |
| **基金管理人**|**委托管理型下掌握关键决策权；自我管理型下由股东会、董事会、经营管理层执行** |

### 4.4.f 【理解】不同组织形式下的基金合同 P113–P115

**大纲原文**：理解不同组织形式下的基金合同

#### （一）公司型基金合同 P114–P115

> **公司型基金合同的法律形式为公司章程，需要符合《公司法》《市场主体登记管理条例》等法律法规对公司章程的基本要求**；**此外，公司型基金的章程应包含中基协在基金合同指引中规定的所有必备条款**。

**章程法定记载事项（必考）**：

| 类型 | 应当载明的事项 |
|---|---|
| **有限责任公司**|**公司名称和住所；公司经营范围；公司注册资本；股东的姓名或者名称；股东的出资额、出资方式和出资日期；公司的机构及其产生办法、职权、议事规则；公司法定代表人的产生、变更办法；股东会认为需要规定的其他事项** |
| **股份有限公司**|**公司名称和住所；公司经营范围；公司设立方式；公司注册资本、已发行的股份数和设立时发行的股份数，面额股的每股金额；发行类别股的，每一类别股的股份数及其权利和义务；发起人的姓名或者名称、认购的股份数、出资方式；董事会的组成、职权和议事规则；公司法定代表人的产生、变更办法；监事会的组成、职权和议事规则；公司利润分配办法；公司的解散事由与清算办法；公司的通知和公告办法；股东会认为需要规定的其他事项** |

**公司型基金合同的五项特殊性（必背）**：

| # | 特殊性 |
|---|---|
| **1**|**《公司法》明确规定了公司的组织机构设置、内部治理机制，基金管理人、基金投资者各自的权利、义务、责任以及所对应的基金决策机制、治理安排等，需对照《公司法》规定进行匹配和明确**——**其中，基金投资者主要通过股东会行使其投资者权利；基金管理人既可能通过董事会或执行董事、经理等组织机构、高级管理人员设置安排对基金进行投资管理，也可基于基金与基金管理人自身的委托关系作为外部管理者对基金进行管理** |
| **2**|**基金投资者的认购、退出和转让基金份额对应《公司法》的增资、减资和股权/股份转让程序，需遵循《公司法》规定（特别是减资所需适用的程序要求及其他规定）；此外，公司型基金的组织形式变更、解散、清算等，也需注意体现《公司法》所明确规定内容** |
| **3**|**针对委托管理型的公司型基金，如基金管理人同时为公司股东（一般为公司小股东），需注意区分其作为公司股东可行使的股东权利与作为基金管理人的投资管理职责的相关约定** |
| **4**|**针对自我管理型的公司型基金，管理团队一般为公司的高级管理人员，因此，对于公司高级管理人员的选聘机制及其权、责、利应进行明确详细的约定，相关内容可能需要体现在公司章程、公司管理制度或有关人员的劳动合同中** |
| **5**|**作为公司股东，公司型基金投资者通过公司利润分配取得收益，因此，公司型基金合同的收益分配条款需结合《公司法》中利润分配相关规定进行设计** |

#### （二）合伙型基金合同 P115

> **在合伙型基金中，普通合伙人、有限合伙人及基金管理人通过合伙协议、委托管理协议等一系列协议，约定相关权利义务和职责，有效运作合伙型基金**。

**合伙型基金合同的核心要点（必背）**：

| # | 要点 |
|---|---|
| **1**|**法律形式为合伙协议，需符合《合伙企业法》《市场主体登记管理条例》等法律法规对合伙协议的基本要求** |
| **2**|**应包含中基协基金合同指引规定的所有必备条款** |
| **3**|**普通合伙人执行合伙事务，有限合伙人不执行合伙事务、不得对外代表有限合伙企业** |
| **4**|**GP 与基金管理人分离的，需签署委托管理协议** |
| **5**|**收益分配须符合"先本金、后门槛收益、再业绩报酬"的顺序，并约定回拨机制** |

#### （三）契约型基金合同 P115

> **契约型基金的基金合同是明确基金投资者、管理人、托管人三方权利义务的法律文件**。

**契约型基金合同的核心要点（必背）**：

| # | 要点 |
|---|---|
| **1**|**法律形式为基金合同（信托契约性质），不设实体、无须工商登记** |
| **2**|**应包含中基协基金合同指引规定的所有必备条款** |
| **3**|**须明确投资者、管理人、托管人三方权利义务** |
| **4**|**契约型基金原则上应当托管**（按合同约定设置能够切实履行安全保管基金财产职责的基金份额持有人大会日常机构等制度措施的除外） |
| **5**|**投资者通过份额持有人大会参与基金重大事项决策** |

#### （四）三种组织形式合同对比（必背）

| 维度 | 公司型 | 合伙型 | 契约型 |
|---|---|---|---|
| **合同形式**|**公司章程**|**合伙协议**|**基金合同** |
| **主要法律依据**|**《公司法》《市场主体登记管理条例》**|**《合伙企业法》《市场主体登记管理条例》**|**《信托法》《证券投资基金法》《私募条例》** |
| **必备条款**|**中基协基金合同指引所有必备条款**|**中基协基金合同指引所有必备条款**|**中基协基金合同指引所有必备条款** |
| **投资者权利行使机制**|**股东会**|**合伙人会议**|**份额持有人大会** |
| **份额变动程序**|**对应增资、减资、股权/股份转让**|**入伙、退伙、财产份额转让**|**申购、赎回、份额转让** |
| **托管要求**|**按约定**|**按约定**|**原则上应当托管（例外除外）** |

| **1 : 1 / 30% / 70%**|**分级基金优先级与劣后级比例上限 / 优先级收益或亏损比例下限 / 劣后级上限** |

#### 二、易错点清单

1. **我国不允许股权投资基金公开募集**；
2. **委托销售机构募集不免除管理人责任**；**不一致时以基金合同附件为准**；
3. **合格投资者门槛是"100 万元投资金额 + 1 000 万净资产/300 万金融资产或 50 万年均收入"**；
4. **当然合格投资者不再穿透核查、不合并计算人数**；**其他非法人形式须穿透核查每一层并合并计算人数**；
5. **普通投资者细分五类，专业投资者可自主决定是否细分**；
6. **C1 只能买 R1；C5 可以买所有等级**；
7. **募集程序顺序不能颠倒：适当性匹配在风险揭示之前**；
8. **未经特定对象确定程序，不得向任何人宣传推介**；
9. **私募基金推介材料只能由管理人制作，且只有管理人和其委托的销售机构可以使用**；
10. **不得宣传预期收益率、目标收益率、基准收益率**；
11. **不得以登记备案、金融机构托管、政府出资等名义增信**；
12. **管理人的出资人、实际控制人、关联方不得从事募集宣传推介**；
13. **基金财产不托管、涉及关联交易、通过 SPV 投资、境外投资等都须特别风险揭示**；
14. **募集结算资金在划入基金财产账户前仍属于投资者合法财产**；
15. **投资冷静期内募集机构不得主动联系投资者**；
16. **契约型基金无须市场监督管理部门登记；公司型和合伙型需要**；
17. **有限责任公司 1–50 人、股份有限公司发起人 1–200 人、有限合伙企业 2–50 人**；
18. **单个投资者首期实缴出资不得低于合格投资者最低出资要求**；
19. **基金管理费仅为基金管理人专属费用科目，其他执行事务合伙人不得收取**；
20. **员工持股计划和员工跟投平台不予备案**；
21. **"名股实债""名基实贷"是存续期下限政策要防范的现象**；
22. **基金登记的经营期限不当然反映真实期限**；
23. **契约型基金原则上应当托管**；
24. **回拨机制：投资者实际收益率低于门槛收益率时，管理人须返还已分得的业绩报酬**。
