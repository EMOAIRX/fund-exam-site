## 3.1 股权投资基金产品概述

### 3.1.a 【了解】基金产品的基本要素 P48–P49

**大纲原文**：了解基金产品的基本要素

> **基金产品基本要素是指构成基金产品核心内容的要素，包括产品的基本信息、投资范围、投资方式、组织形式等，这些要素决定了基金产品的性质、特点和风险收益特征**。

#### （一）基本信息 P48

> **基金产品应当具备自身的基本信息，包括：基金名称、成立日期、基金期限、管理人名称、托管人（如有）等**。

> **在我国，基金产品备案过程中还会申请产品编码；基金通过设立公司或合伙等实体作为运营载体的，还会有实体的统一社会信用代码、工商成立日期和营业期限**。

#### （二）投资范围 P49

> **基金产品应当明确投资范围；股权投资基金产品的投资范围应当为非公开交易的股权性质的投资或以获得股权为目的的投资，后者主要指可转换债等**。

> **从被投资企业发展阶段而言，可以约定主要投资于企业的初创期、成长期、成熟期或转型重组期**。

> **此外，基金产品也会在设立之初明确基金的投资方向，即投资侧重的行业领域，例如生物医药、高端制造、人工智能、新消费等**。

#### （三）组织形式 P49

> **基金产品的投资运作需要依托一定的组织形式**：

| 类型 | 含义 |
|---|---|
| **契约型基金**|**不新设实体而仅以合同约定的方式运作** |
| **公司型 / 合伙型基金**|**新设公司或合伙企业作为运作载体** |

> **不同的组织形式，会对基金的具体运作和管理产生不同的影响**。

#### （四）投资方式 P49

| 方式 | 含义 |
|---|---|
| **直接投资模式**|**直接投资项目于被投资企业** |
| **间接投资**|**通过投资于子基金，再由子基金投向被投资企业，从而间接投资于底层被投资企业** |
| **混合方式**|**一部分资金用于直接投资，另一部分资金投向子基金；相应的比例安排也是基金投资策略的重要组成部分** |

#### （五）四个基本要素速查表

| # | 要素 | 内容 |
|---|---|---|
| **1**|**基本信息**|**基金名称、成立日期、基金期限、管理人名称、托管人（如有）；备案产品编码；实体则另有统一社会信用代码、工商成立日期、营业期限** |
| **2**|**投资范围**|**非公开交易的股权性质投资或以获得股权为目的的投资（如可转换债）；可约定投资阶段与行业方向** |
| **3**|**组织形式**|**契约型、公司型、合伙型** |
| **4**|**投资方式**|**直接投资、通过子基金间接投资、两者结合** |

### 3.1.b 【理解】基金组织形式、投资阶段、投资方式分类 P49–P52

**大纲原文**：理解基金组织形式、投资阶段、投资方式分类

#### （一）组织形式分类 P49

> **基金的运作需要依托于特定的组织形式；基金产品的组织形式决定了基金当事人之间的法律关系，亦是处理基金与其他主体关系的基础**。

> **基金选择何种组织形式，通常基于实际业务需求与监管规则层面的要求来综合确定；金融监管机构和相关自律组织出于推进相关监管或自律工作的便利性，也会对基金的组织形式存在一定的要求**。

> **基金组织形式的选择范围取决于当地法律框架**；**例如《合伙企业法》于 2006 年修订时增加了关于有限合伙企业的规定，为基金产品采取有限合伙企业的组织形式提供了法律依据**；**此外，一些法域为股权投资基金产品设计了特别的组织形式，拓宽了基金组织形式选择的可能性**。

**三种组织形式（必背）**：

| 类型 | 载体 |
|---|---|
| **公司型基金**|**新设公司作为运营实体** |
| **合伙型基金**|**新设有限合伙作为运营实体** |
| **契约型基金**|**不新设实体而仅以合同约束当事人** |

#### （二）投资阶段分类（核心考点） P50

> **公司从创立到发展，再到可能存在的重组或出售，整个生命周期可以大致划分为初创期、成长期、成熟期以及可能存在的转型重组期**；**基于对底层标的所处发展阶段的偏好，股权投资基金也相应分为几类**。

##### ① 创业投资基金（广义）→ 狭义创业投资基金 + 成长型股权基金 P50

> **创业投资基金是指主要从事创业投资活动的基金**；**根据行业惯例，可以将这一广义上的创业投资基金概念进一步细分为狭义的创业投资基金和成长型股权基金**。

**狭义的创业投资基金（必考）**：

| 维度 | 内容 |
|---|---|
| **投资对象**|**主要投资于初创期和小型成长期企业** |
| **目的与退出**|**提供资本支持以帮助企业快速发展、成熟，并在过程中实现股权价值增值，最终通过首次公开发行股票（IPO）或并购等方式转让股权以实现投资回报** |
| **风险收益特征**|**初创企业的产品尚处于开发和探索阶段，商业模式和盈利能力还未得到验证，距离上市相对遥远，企业发展具有较强的不确定性，因此公司股权价值较低、发展潜力大；创业投资往往面临很大的不确定性和较长的投资周期，而一旦成功，投资回报也可能非常丰厚** |
| **行业地位**|**创业投资基金是最早出现的一类股权投资基金，对于支持中小企业、推动科技创新和新兴行业发展发挥着不可替代的作用，是国家长期战略布局的重要助力** |

**成长型股权基金（必考）**：

| 维度 | 内容 |
|---|---|
| **投资对象**|**主要投资于成长期企业；与狭义的创业投资基金主要投资于初创期企业不同，更关注那些已经具备一定规模并处于快速增长阶段的企业** |
| **作用**|**帮助它们进一步扩展业务和提升价值** |
| **规模特征**|**单项目投资规模通常更大，因为被投资企业的估值和资金需求都较高** |
| **风险收益**|**投资风险和预期回报均小于狭义的创业投资基金** |
| **上市前投资基金**|**在中国市场，企业往往以上市作为"成熟"的标志；有的成长型基金偏好投资于成长期即将结束、基本达到可上市状态的企业，被称为上市前投资基金**；**核准制背景下中国企业上市标准高，二级市场估值普遍高于一级市场，上市企业短时间跌破发行价的概率极低，基金投资上市前项目的风险低、收益大；但随着市场发展和注册制改革，类似套利空间已经缩小、风险变大，上市前投资基金的占比也在下滑** |

##### ② 并购基金 P50、P51

> **并购基金主要投资于成熟期和转型重组期的企业**。

> **与初创期和成长期企业不同，资本通常不是限制成熟期或转型重组期企业发展的主要因素；相反，处于发展瓶颈的成熟期企业和陷入经营困境的转型重组期企业，迫切需要通过深度管理重构、战略调整和产业整合等全面的改革和重整来重振旗鼓**；**因此，基金必须通过并购等方式取得目标企业的控制权，这是启动任何重整计划的前提条件**。

##### ③ 阶段划分的两点局限（易考） P51

> **尽管如此，按照上述方式划分的基金类型，并不具有清晰明确的界限**：

| # | 局限 |
|---|---|
| **第一**|**公司的发展是循序渐进的，从"初创期"到"成长期"并不存在某一公认的时点或判断标准，狭义的创业投资基金与成长型股权基金之间并不存在严格的界限** |
| **第二**|**从中国并购市场的发展情况来看，在我国的并购基金中，采用典型的杠杆收购模式取得大型公司控制权的传统意义上的并购基金并不多见；目前市场上许多并购基金存在作为财务投资人参与并购交易的情况，为主导方提供资金支持** |

#### （三）投资方式分类 P51

| 类型 | 含义 |
|---|---|
| **直投基金**|**将主要资金直接投资于底层标的的基金** |
| **股权投资母基金**|**将主要资金投资于其他股权投资基金产品的基金**；**其主要资金投向其他股权投资基金产品，而非直接投资于底层标的；这种投资策略扩大了投资组合的范围，从而有效分散了投资风险** |

#### （四）特殊主体分类 P51–P52

> **不同背景的发起或参与主体会导致基金产品在投资方式、投资策略、风险收益偏好和受监管程度上呈现较大差异；典型的特殊主体包括政府及金融机构**。

##### ① 政府投资基金 P51

> **政府投资基金是指由各级政府通过预算安排，以单独出资或与社会资本共同出资设立，采用股权投资等市场化方式，引导各类社会资本支持相关产业和领域发展及创新创业的投资基金**；**在投资方向上，政府投资基金的布局通常具有较强的政策属性，发挥着鼓励支持相关产业发展的功能**。

##### ② 金融机构基金 P51–P52

> **在中国，金融行业采取分业经营、分业监管原则**；**金融机构发起或参与投资股权投资基金产品时，除了针对股权投资基金的一般规定外，还可能需要遵守其所在行业的监管机关或自律组织的特殊要求**；**最具代表性的包括证券公司、保险公司和商业银行**。

| 机构类型 | 监管要求 |
|---|---|
| **证券公司**|**应遵守《关于规范金融机构资产管理业务的指导意见》《证券期货经营机构私募资产管理业务管理办法》《证券期货经营机构私募资产管理计划运作管理规定》《证券公司私募投资基金子公司管理规范》等**；**在自律管理中独立于其他股权投资基金报送和公示；在实体设立、嵌套层级、关联交易和信息披露等方面更为严格，更关注与证券公司其他业务的关系，以防范利益输送和同业竞争** |
| **保险资金**|**须遵守《关于规范金融机构资产管理业务的指导意见》《保险资金投资股权暂行办法》《保险资产管理产品管理暂行办法》等；基金如欲获得保险资金投资，需要满足更为严格的审查条件，并可能需要向保险业监管机构和自律组织履行额外的信息披露和报送义务** |
| **银行资金**|**根据《商业银行法》，商业银行不得向非银行金融机构和企业投资，但国家另有规定的除外**；**目前银行资金主要通过理财子公司和金融资产投资子公司两个渠道参与；应遵守《资管新规》《商业银行资本管理办法》《商业银行理财业务监督管理办法》《商业银行理财子公司管理办法》《金融资产投资公司管理办法（试行）》等**；**近年来商业银行也逐步探索将关联机构注册登记为基金管理人，直接发起设立股权投资基金产品** |

#### （五）分类维度速查表

| 维度 | 类别 |
|---|---|
| **按组织形式**|**公司型、合伙型、契约型** |
| **按投资阶段**|**创业投资基金（狭义创业投资基金 + 成长型股权基金）、并购基金** |
| **按投资方式**|**直投基金、股权投资母基金** |
| **按特殊主体**|**政府投资基金、金融机构基金（证券、保险、银行）** |

### 3.1.c 【了解】基金特殊主体分类和现行产品备案分类 P51–P53

**大纲原文**：了解基金特殊主体分类和现行产品备案分类

#### （一）现行产品备案分类（核心考点） P52

> **根据我国现行法规，中国证券投资基金业协会是私募投资基金的登记备案机构，私募基金管理人应当在产品募集完毕后办理基金备案手续**。

> **目前产品备案通过资产管理业务综合报送平台线上化报送，在基金类型的选项中，有四种选项可供股权投资基金选择**：

| # | 备案类型 |
|---|---|
| **1**|**私募股权投资基金** |
| **2**|**私募股权投资类 FOF** |
| **3**|**创业投资基金** |
| **4**|**创业投资类 FOF** |

##### ① 私募股权投资基金 P52

> **私募股权投资基金，指投资包括未上市企业和上市企业非公开发行和交易的普通股（含上市公司定向增发、大宗交易、协议转让等）、可转换为普通股的优先股和可转换债等的私募基金**。

**选择"私募股权投资基金"后还需选择进一步细分类别（五类，必背）**：

| # | 细分类别 | 定义 |
|---|---|---|
| **1**|**并购基金**|**主要对处于重建期企业的存量股权展开收购的私募股权投资基金** |
| **2**|**房地产基金**|**从事房地产项目投资的私募基金** |
| **3**|**基础设施基金**|**投资于基础设施项目的私募基金** |
| **4**|**上市公司定增基金**|**主要投资于上市公司定向增发的私募股权投资基金** |
| **5**|**其他类基金** | — |

##### ② 创业投资基金（投资限制必背） P53

> **创业投资基金，根据中国证券投资基金业协会的说明，指主要向处于创业各阶段的未上市成长性企业进行股权投资的基金**。

> **原则上，鼓励创业投资基金投资早期企业、中小企业和高新技术企业**。

**创业投资基金的八项投资禁止（必考）**：

> **除中国证监会和中国证券投资基金业协会另有规定外，创业投资基金不得直接或者间接投资于**：

| # | 禁止投资标的 |
|---|---|
| **1**|**不动产（含基础设施）** |
| **2**|**首发企业股票和存托凭证** |
| **3**|**上市公司可转换债券和可交换债券** |
| **4**|**公开募集基础设施证券投资基金份额** |
| **5**|**资产支持证券** |
| **6**|**上市公司股票** |

> **但所投资公司上市后基金所持股份的未转让及其配售部分除外**。

##### ③ FOF（基金中基金/母基金） P53

> **FOF（Fund of Funds），指基金中基金或母基金**：

| 类型 | 含义 |
|---|---|
| **私募股权类 FOF**|**主要投向股权类私募基金、信托计划、券商资管、基金专户等资产管理计划的私募基金** |
| **创业投资类 FOF**|**主要投向创投类私募基金、信托计划、券商资管、基金专户等资产管理计划的私募基金** |

#### （二）备案分类速查表

## 3.2 公司型基金、合伙型基金与契约型基金

> **对于股权投资基金而言，不同的组织形式决定了基金的不同运作特点**：**组织形式决定了基金投资者对基金的权利和义务，影响基金的决策程序和治理结构**；**同时，不同组织形式的不同税收，也高度影响基金投资者的收益**。

### 3.2.a 【理解】公司型基金的概念和特点 P53–P55

**大纲原文**：理解公司型基金的概念和特点

#### （一）公司型基金的概念 P53–P54

> **公司是以营利为目的的企业法人**；**法人，即"法律上拟制的人"，从而具有独立从事法律行为的主体资格**；**这种法律上的拟制体现在两个方面，一是法律权利，二是法律义务**。

> **我国法律规定，公司能够以自己的名义享受法律权利，也以自身财产独立承担法律义务；公司的财产在设立时来自股东，但在股东投资后，该部分财产即独立于股东**——**这意味着，一般情况下，股东不能随意取回财产，而公司资不抵债时也不能强制要求股东以其他财产为公司承担债务**；**股东仅以所投资的财产为限承担责任的制度，被称为"有限责任"**。

**公司型基金的核心定义（必考）**：

| 维度 | 内容 |
|---|---|
| **组织形式**|**采用公司的组织形式设立** |
| **法律依据**|**《公司法》** |
| **投资者地位**|**投资者是公司股东，依法享有股东权利，并以其投资额为限对公司债务承担有限责任** |
| **管理方式**|**可自行或委托专业基金管理人进行基金管理** |
| **公司类型**|**在我国公司的类型是法定的，包括有限责任公司和股份有限公司；二者在股东人数限制、股权转让、组织治理方面的法律规定有所不同** |

> **公司型基金的参与主体主要为投资者和基金管理人**；**投资者既是基金份额持有者又是公司股东，按照公司章程行使相应权利、承担相应义务和责任**；**从投资者权利角度看，投资者作为公司的股东，可通过股东会和董事会委任并监督基金管理人**。

#### （二）公司型基金的三个特点（必背） P54–P55

##### ① 组织形式成熟 P54

> **公司在很多国家比合伙企业、契约结构有着更悠久的历史和更为健全的法律环境，进而使得这些国家的公司有着更完整的组织结构和更规范的管理系统，可以有效降低运作风险**。

##### ② 法人资格能为投资者隔离风险 P54

> **公司是独立的企业法人，所有股东只承担有限责任；正常情况下，债权人不会因公司型基金资不抵债而穿透追究投资者的责任**。

##### ③ 灵活性有限 P54–P55

> **法律法规赋予公司股东有限责任，同时也对公司施加诸多强制性的限制与规定；而公司这一组织形式并非为基金量身定做，因此公司的部分规定可能并不契合基金的运作模式**。

**具体体现（两类，必考）**：

| 层面 | 限制 |
|---|---|
| **资本制度**|**法律制度对公司的期待以及一般公司的目标是持续经营，在法定资本制下，公司需要遵循资本确定、资本维持、资本不变的原则**；**具体来说，公司需要保持与其资产与业务规模相适应的资本规模，公司股东未经法定减资程序不得随意将其对公司的出资抽回，公司利润分配前通常需要提取一定比例的法定公积金等限制** |
| **内部治理**|**公司的股东会、董事（会）、监事（会）、经理等架构设置以及各自部分职权内容由法律直接规定，这对一般的公司稳定运作、平衡各方利益是不可或缺的，但对于一个基金而言可能有些复杂和冗余，从而导致效率变低** |

> **鉴于此，在我国，公司型基金并非股权投资基金的主流组织形式**。

#### （三）公司型基金速查表

| 维度 | 要点 |
|---|---|
| **法律依据**|**《公司法》** |
| **法人地位**|**独立企业法人** |
| **投资者责任**|**以投资额为限承担有限责任** |
| **投资者身份**|**公司股东（既是基金份额持有者又是股东）** |
| **三个特点**|**组织形式成熟、法人资格隔离风险、灵活性有限** |
| **主流地位**|**我国并非主流组织形式** |

### 3.2.b 【掌握】合伙型基金的概念和特点 P55–P56

**大纲原文**：掌握合伙型基金的概念和特点

#### （一）合伙型基金的概念 P55

> **合伙企业不具备法人地位，普通合伙人对合伙企业债务承担无限连带责任**。

> **2006 年《合伙企业法》修订通过，增加了有限合伙企业制度，规定不执行合伙事务的合伙人可以作为有限合伙企业的有限合伙人，仅以认缴出资额为限对合伙企业债务承担责任；这打消了财务投资者对合伙企业投资的一大顾虑，也为股权投资基金提供了一个组织形式上的解决方案**。

**合伙型基金的核心定义（必考）**：

| 维度 | 内容 |
|---|---|
| **组织形式**|**依据《合伙企业法》采用合伙企业的组织形式设立** |
| **投资者地位**|**投资者作为合伙人参与投资，依法享有合伙企业财产权，由基金管理人具体负责投资运作** |
| **法人地位**|**不具有独立的法人地位** |

**两种合伙企业类型（必考）**：

| 类型 | 是否适用 | 原因 |
|---|---|---|
| **普通合伙企业**|**几乎没有基金采用**|**所有合伙人对合伙企业债务承担无限责任，与股权投资基金投资者和管理人在权责划分上的诉求不够契合** |
| **有限合伙企业**|**我国股权投资基金的主流组织形式**|**有限合伙人不参与经营管理且承担有限责任，普通合伙人承担无限责任，这样的特征与股权投资基金中投资者与管理人的角色设置更为契合** |

**三类参与主体及责任（必考）**：

| 主体 | 责任与地位 |
|---|---|
| **有限合伙人（LP）**|**以其认缴的出资额为限对基金（合伙企业）债务承担责任** |
| **普通合伙人（GP）**|**对基金（合伙企业）债务承担无限连带责任；在有限合伙企业中，至少应有一个普通合伙人** |
| **执行事务合伙人**|**由于基金管理人需要履行主动管理职责，因此通常由基金管理人或其关联方担任负责执行合伙企业事务的普通合伙人** |

#### （二）合伙型基金的三个特点（必背） P56

##### ① 权责分明 P56

> **与公司型基金通常使用的同股同权同利设计不同，合伙型基金中有限合伙人与普通合伙人承担的责任不同，这也就决定了他们对有限合伙企业的权利也不相同**：

| 主体 | 义务 |
|---|---|
| **有限合伙人**|**承担有限责任，因此仅需按照有限合伙协议约定按期、足额缴纳认缴出资** |
| **普通合伙人**|**对合伙企业债务承担无限连带责任，执行事务合伙人主要负责基金投资等重大事项的管理与决策，对有限合伙企业的责任最主要的是尽职地执行基金事务** |

##### ② 灵活度高 P56

> **由于合伙企业有高度人合性，且普通合伙人承担无限连带责任，法律法规对于合伙企业内部治理的强制性规定相对较少，企业内部可以进行更为灵活的安排**；**仍用利润分配举例，有限合伙企业不具有独立法人地位，投资者可以按照合伙协议或者合伙人会议决议收回其对合伙企业的出资本金，一般无须债权人同意**。

##### ③ 避免双重纳税 P56

> **根据我国法律规定，合伙企业不是企业所得税的纳税主体，只在合伙人环节征缴所得税**；**如果基金的投资者为个人，其投资于公司型基金获得的投资收益需要承担企业所得税和个人所得税双重税负，而投资于合伙型基金则仅需缴纳个人所得税**；**一般而言，后者税负相对较轻**。

#### （三）实践中的惯常安排 P56

> **在中国的股权投资基金实践中，合伙型基金是股权投资基金的主流组织形式；在惯常的安排下，投资者通常作为有限合伙人，管理人或其关联方作为普通合伙人**。

#### （四）合伙型基金速查表

| 维度 | 要点 |
|---|---|
| **法律依据**|**《合伙企业法》（2006 年修订增加有限合伙制度）** |
| **法人地位**|**不具有独立法人地位** |
| **责任划分**|**LP 以认缴出资额为限承担有限责任；GP 承担无限连带责任** |
| **三个特点**|**权责分明、灵活度高、避免双重纳税** |
| **主流地位**|**我国股权投资基金的主流组织形式** |

### 3.2.c 【了解】契约型基金的概念和特点 P56–P58

**大纲原文**：了解契约型基金的概念和特点

#### （一）契约型基金的概念 P56–P57

> **契约型股权投资基金是指通过订立信托契约的形式设立的股权投资基金**；**契约型基金不设立单独的实体，也就当然不具有独立的法人地位**。

**三类参与主体（必考）**：

| 主体 | 职责 |
|---|---|
| **基金投资者**|**通过购买基金份额，享有基金投资收益** |
| **基金管理人**|**依据基金合同负责基金的经营和管理操作** |
| **基金托管人**|**负责保管基金资产，执行管理人的有关指令，办理基金名下的资金往来** |

#### （二）契约型基金的四个特点（必背） P57–P58

##### ① 财产独立 P57

> **契约型基金属于信托性质**；**根据《信托法》《证券投资基金法》《私募条例》，基金财产独立于基金管理人、基金托管人的固有财产**；**因此，基金财产即使由管理人或托管人占有并运作，但不会被用于清偿管理人或托管人自身的债务；相较于一般合同关系，契约型基金财产的安全性更高**。

##### ② 灵活度很高 P57

> **契约型基金本质上是通过合同确立的一种契约关系，因此，合同各方不需要依据商事组织法设立商事实体，而可通过基金合同对基金的组织运作进行约定，相较新设公司或合伙等实体，运作更加灵活**。

**人数限制的对比（数字必背）**：

| 组织形式 | 人数限制 |
|---|---|
| **有限合伙企业**|**合伙人数量不得超过 50 人** |
| **有限责任公司**|**股东数量不得超过 50 人** |
| **契约型基金**|**不受上述限制，但仍需满足非公开募集基金的投资者人数不得超过 200 人的要求** |

##### ③ 避免双重纳税 P57

> **契约型基金不是企业所得税的纳税主体，不需要缴纳所得税，只有基金投资者需要对取得的投资收益缴纳所得税，对于个人投资者来说，避免了双重纳税**。

##### ④ 商事登记存在障碍 P57–P58

> **在我国目前的企业股权登记系统中，由市场监管部门负责的非公众公司股权登记系统不接受契约型基金登记为被投资企业股东**；**因此，契约型基金如果投资于这类被投资企业，通常需要采取管理人代契约型基金进行工商确权等安排，从而可能会承担额外的股权代持等风险**。

> **此外，股权代持可能会导致股权结构不清晰、不稳定，因此在被投资企业首次公开发行证券时，契约型基金持股可能会受到重点关注**。

#### （三）契约型基金速查表

| 维度 | 要点 |
|---|---|
| **法律依据**|**《信托法》《证券投资基金法》** |
| **法人地位**|**不具有独立法人地位（不设立单独实体）** |
| **参与主体**|**投资者、管理人、托管人** |
| **四个特点**|**财产独立、灵活度很高、避免双重纳税、商事登记存在障碍** |
| **人数上限**|**非公开募集基金投资者 ≤ 200 人** |

## 3.3 创业投资基金与并购基金

### 3.3.a 【理解】创业投资、创业投资基金的概念和运作特点 P59–P62

**大纲原文**：理解创业投资、创业投资基金的概念和运作特点

#### （一）创业投资的概念 P59

> **创业投资，也称风险投资，是指向处于各个创业阶段的未上市成长性企业的股权投资**。

> **具体来说，创业投资是指向处于创建或重建过程中的未上市成长性创业企业进行股权投资，以期所投资创业企业发育成熟或相对成熟后，主要通过股权转让获取资本增值收益的投资方式**。

**创业投资的七个特点（必背，与并购投资对比记忆）**：

| # | 特点 |
|---|---|
| **第一**|**投资对象主要以初创期和成长期创业企业为主，重点是寻找未来具有较大增长潜力的企业，在目标公司发展相对早期投资进入** |
| **第二**|**通常采取增资方式进行投资（而非受让企业存量股权），所投资金直接进入被投资企业，从而可以直接用于支持被投资企业发展** |
| **第三**|**通常以股权形式进行投资，尽管可能有过桥贷款或可转换债的安排，但投资时的主要目的是取得被投资企业的股权** |
| **第四**|**通常采取参股投资，一般不谋求获得被投资企业的控股权或控制权** |
| **第五**|**一般不使用杠杆，通常以自有资金进行投资** |
| **第六**|**在投后管理阶段，在对被投资企业进行监督的同时，侧重对被投资企业提供增值服务，以期帮助被投资企业成长** |
| **第七**|**在退出阶段，主要通过股权转让方式获得被投资企业成长带来的增值收益** |

#### （二）主要的创业投资主体 P59–P60

> **创业投资可以采取组织化形式和非组织化形式**：

| 形式 | 内容 |
|---|---|
| **组织化创业投资**|**主要包括创业投资基金和企业创业投资** |
| **非组织化创业投资**|**主要是指天使投资** |

> **创业投资基金具有一定的外部性，因此多数国家对创业投资基金进行一定限度的行政监管**；**企业创业投资和天使投资不涉及对外募资，由投资者使用自有资金进行投资，不具有明显的外部性，因此通常不需要专门的行政监管**。

#### （三）创业投资基金 P60

> **创业投资基金是最为常见的创业投资主体**；**与非基金类的创业投资主体（企业创业投资及天使投资）相比，创业投资基金面向合格投资者募集资金，并委托专业的基金管理人进行投资管理，可投资资金规模与投资管理专业性均具有一定的优势**。

**《私募条例》对创业投资基金的界定要点（必背）**：

| # | 要点 |
|---|---|
| **1**|**通常情况下，投资范围仅限于未上市企业** |
| **2**|**在基金名称或经营范围中包含"创业投资"字样** |
| **3**|**在基金合同中体现创业投资策略** |
| **4**|**不得使用杠杆融资** |
| **5**|**基金最低存续期应达到一定标准** |

|---|---|

> **随着中国经济发展动力由制造业驱动转向由创新驱动，我国经济将进一步实现产业升级和产业创新**；**在这一过程中，创业投资基金也将扮演重要的角色，助推我国科技创新企业发展从模式创新走向技术创新和原始创新**。

#### （四）创业投资七个特点速查表

| # | 特点 | 关键表述 |

| **4**|**持股比例**|**参股，不谋求控股权或控制权** |
| **5**|**资金来源**|**一般不使用杠杆，以自有资金投资** |
| **6**|**投后管理**|**监督 + 侧重增值服务** |
| **7**|**退出方式**|**股权转让获得成长增值收益** |

### 3.3.b 【了解】创业投资基金的鼓励和优惠政策 P60–P61

**大纲原文**：了解创业投资基金的鼓励和优惠政策

> **从宏观角度看，创业投资与国家产业政策和发展方向息息相关，因此我国对创业投资基金实行差异化管理，并出台了一系列的政策支持**。

### 3.3.c 【理解】并购投资、并购基金的概念和运作特点 P62–P64

**大纲原文**：理解并购投资、并购基金的概念和运作特点

#### （一）并购投资的概念 P62

> **并购即兼并与收购**；**并购投资是指通过投资取得另一企业的全部或部分资产或股权，从而对另一企业的产权及其经营管理实施部分或完全控制的行为**。

**并购投资的七个特点（必背，与创业投资对比）**：

| # | 特点 |
|---|---|
| **第一**|**并购投资的对象更多是成熟期企业，重点是寻找价值被低估的企业** |
| **第二**|**以收购目标公司存量股权方式进行，所投资金由目标公司原股东获得，并不会直接进入被投资企业** |
| **第三**|**通常采取股权投资，但完成对被投资企业并购后，投资方可能会以股东借款形式向被投资企业提供债权资金支持** |
| **第四**|**通常谋求获得被投资企业的控股权** |
| **第五**|**在资金来源方面，通常会使用杠杆，包括银行贷款、垃圾债券和夹层资本等** |
| **第六**|**在投后管理阶段，以对被投资企业进行重整为重点，以期实现被投资企业的价值提升** |
| **第七**|**在退出阶段，主要通过股权转让方式获得被投资企业估值恢复或价值提升带来的增值收益** |

#### （二）创业投资与并购投资的七项对比（核心考点）

| 维度 | 创业投资 | 并购投资 |
|---|---|---|
| **投资对象**|**初创期、成长期企业，寻找增长潜力**|**成熟期企业，寻找价值被低估** |
| **投资方式**|**增资（资金进入被投企业）**|**受让存量股权（资金给原股东）** |
| **持股比例**|**参股，不谋求控制权**|**谋求控股权** |
| **杠杆**|**一般不使用杠杆，以自有资金**|**通常使用杠杆（银行贷款、垃圾债券、夹层资本）** |
| **投后管理**|**监督 + 增值服务**|**以重整为重点** |
| **退出收益来源**|**企业成长带来的增值**|**估值恢复或价值提升** |

#### （三）主要的并购投资主体 P62

> **市场上的并购投资主体主要包括企业并购投资人和并购基金**。

**战略投资与财务投资的区分（必考）**：

| 类型 | 定义 | 主体倾向 |
|---|---|---|
| **战略投资**|**买方基于战略目标，发挥其与卖方企业之间的协同效应而进行的投资**|**企业并购投资人通常会利用其掌握的资源与被投资企业进行协同，因此会进行更多的战略投资** |
| **财务投资**|**买方主要基于获取阶段性财务回报目的而进行的投资**|**并购基金通常主要基于获取财务回报的目的进行并购投资，因此所进行的主要是财务投资** |

#### （四）并购基金 P62–P64

> **并购基金是指主要对企业进行财务性并购投资的股权投资基金**；**并购基金擅长存量经济的赋能、改造与整合，关注传统制造和消费行业等存量经济领域的投资机会，并关注与新兴行业的产业整合，助力传统经济改造升级和新经济整合提效**。

##### ① 四种并购投资策略（必背） P63

> **不同策略的并购投资随着承担的风险以及所需要的能力不同，其捕捉的价值亦不同**：

| # | 策略 | 内容与关键能力 |
|---|---|---|
| **1**|**杠杆收购**|**在收购一家目标公司时，利用目标公司的资产及未来现金流作为抵押，获取并购贷款及发行并购债**；**主要收益源自财务杠杆，关键在于公司稳定的现金流以及同现有管理层的绑定** |
| **2**|**市场套利**|**购入上市公司、将其私有化后在其他交易所再上市，或者将收购公司的资产分拆并卖出，以在不同市场间进行套利交易**；**需要基金寻找市场的估值偏误，包括同一资产在不同市场的估值差异以及整体与部分资产的估值差异** |
| **3**|**赋能式投资**|**并购基金通过在财务、战略、业务等方面主动赋能帮助目标公司改善运营，提升公司价值**；**要求基金有很强的投后赋能能力，存在一定的管理与业务风险** |
| **4**|**困境投资**|**基金在破产重整过程中以低价获取公司控制权，助力公司正常运营，待公司运营与市场估值改善后择机卖出**；**需要基金通过专业的司法手段低价购买资产，并通过自身强大的投后管理修复现有业务与管理** |

##### ② 海外杠杆收购的典型融资结构（数字必背） P63

> **并购基金在海外主要是杠杆收购基金的形式**；**在基金产品设计方面，并购基金会更多地采用结构化产品，将投资者区分为优先投资者、夹层投资者和劣后投资者，不同投资者承担不同的风险，并获得不同的期望收益**。

**三层融资结构（必考）**：

| 层级 | 类型 | 占比 | 提供方 |
|---|---|---|---|
| **第一层**|**有担保的优先级债务**|**50%～60%**|**主要由银行提供** |
| **第二层**|**没有担保的高收益债（次级债务）及夹层融资工具**|**20%～30%**|**主要由机构投资者、债券投资者提供** |
| **第三层（底层资本）**|**收购方提供的资本金**|**20%～30%**|**收购方** |

> **通过运用杠杆，在投资收益率一定的情况下，原始权益资本的收益率通过乘数作用得以放大**；**由于并购交易融资金额较大，所以基本上由多家金融机构参与，提供不同层次的融资**。

##### ③ 我国杠杆收购基金发展受限的原因（必考） P63–P64

> **在中国，杠杆收购基金目前并不多见**：

| 方面 | 原因 |
|---|---|
| **并购贷款审慎**|**商业银行对发放并购贷款非常慎重**——**从法规角度而言，监管部门对并购贷款余额占银行的核心资本净额比例、并购贷款占并购资金比例，以及并购贷款期限等方面均有比较严格的限制；并购贷款业务复杂、风险高、对资金的监控困难，这些因素也导致商业银行在审批并购贷款时非常审慎；有数据显示，境内商业银行并购贷款余额占其全部贷款余额的比例极低** |
| **债券发行障碍**|**并购基金在中国境内发行或通过特殊目的载体（SPV）发行债券也存在一定障碍**——**境内对债券发行主体财务要求较高，向合格投资者公开发行公司债券应满足严格的可分配利润、资产负债结构和现金流量要求；而非公开发行目前虽没有净资产、利润等硬性限制，但在实践中并购基金或 SPV 也难以通过非公开发行债券募集资金** |
| **退出渠道受限**|**国外并购基金主要通过在并购市场出售项目以及被投资企业上市后二级市场减持退出**——**境内并购市场活跃度不足，一些企业创始人对并购的认知度和接受度不高，对出售公司控制权存在抵触，收购方的并购经验与操作能力也待提高；上市退出方面，若并购基金为拟上市公司第一大股东，可能因业务性质、刚性退出要求、杠杆和结构化安排等在实践中面临问题** |

#### （五）并购投资与并购基金速查表

| 维度 | 要点 |
|---|---|
| **并购投资**|**取得全部或部分资产或股权，实施部分或完全控制** |
| **七个特点**|**成熟期企业、受让存量股权、可提供股东借款、谋求控股、使用杠杆、投后重整、股权转让退出** |
| **两类主体**|**企业并购投资人（偏战略投资）、并购基金（偏财务投资）** |
| **四种策略**|**杠杆收购、市场套利、赋能式投资、困境投资** |
| **海外融资结构**|**优先级债务 50%–60%（银行）+ 高收益债与夹层 20%–30%（机构）+ 收购方资本金 20%–30%** |
| **我国受限原因**|**并购贷款审慎、债券发行障碍、退出渠道受限** |

## 3.4 股权投资母基金

### 3.4.a 【了解】股权投资母基金的概念 P64–P65

**大纲原文**：了解股权投资母基金的概念

> **股权投资母基金（简称母基金）出现于 20 世纪 70 年代**。

#### （一）发展历程（必考） P64

| 阶段 | 特征 |
|---|---|
| **发展之初**|**股权投资母基金管理人只是与单独的投资者签订委托投资协议，是具有固定投资期限且一对一的委托关系；同时，无论是募资金额还是基金数量都微不足道** |
| **20 世纪 90 年代初期以来**|**伴随着大量股权投资资本的涌现，母基金开始演变成为集合多个投资者资金的专业受托投资业务，且管理的资金规模逐渐增大** |

> **目前，股权投资母基金已经成为股权投资基金最主要的投资者之一；尤其是在中国，母基金在股权投资市场中占据重要地位，持续作为优质资金供给方支持实体经济和科技创新**。

### 3.4.b 【理解】股权投资母基金的业务 P65–P66

**大纲原文**：理解股权投资母基金的业务

> **股权投资母基金的投资策略可以概括为"投资子基金 + 投资二手基金份额 + 直接投资"策略，即"P+S+D"策略（Primary + Secondary + Direct）**。

#### （一）投资子基金（P，本源业务） P65

> **投资子基金是指母基金在股权投资基金募集时对基金进行投资，成为基金投资者**；**母基金发展初期主要从事子基金投资业务，这是母基金的本源业务**。

**母基金选择股权投资基金的七个考察方面（表 3-2，必背）**：

| # | 考察项目 | 具体内容 |
|---|---|---|
| **1**|**投资理念**|**投资阶段、投资单笔规模、投资行业、目标公司特点、投资方式、投资角色、持股比例、董事会席位** |
| **2**|**市场**|**股权投资基金市场环境、市场定位、竞争对手分析** |
| **3**|**管理团队**|**团队历史、团队组织结构、管理层、和谐度、工作量、团队变更、核心人员详细介绍、对团队主管的评价** |
| **4**|**既往基金业绩**|**业绩整体分析、按照阶段分析、按照行业分析、按照退出途径分析、损失案例分析、高回报案例分析、投资角色分析** |
| **5**|**投资流程**|**项目挖掘、尽职调查、投资决策** |
| **6**|**基金条款**|**期限、规模、管理人投资、管理费、业绩报酬** |
| **7**|**主观分析**|**独特性、需要关注的问题** |

#### （二）投资二手基金份额（S） P65–P66

> **投资二手基金份额是指母基金在股权投资基金募集设立完成后，对存续基金或其投资组合进行投资**。

**两种类型（必背）**：

| 类型 | 含义 |
|---|---|
| **第一种**|**购买存续基金份额及后续出资额** |
| **第二种**|**购买基金持有的投资组合的股权** |

**三个原因（必考）**：

| # | 原因 | 说明 |
|---|---|---|
| **第一**|**价格折扣**|**股权投资基金主要采取私募形式，缺乏流动性，因此，基金份额投资一般都有价格折扣，从而提高收益** |
| **第二**|**加速投资回收**|**母基金投资的是存续期的股权投资基金，缩短了投资等待期，从而能够更快地回收投资**；**例如，假设一只股权投资基金达到盈亏平衡点需要 7 年时间，实现收益需要 8～12 年时间，那么母基金购买存续 5 年的基金可以将盈亏平衡点缩短至 2 年，将实现收益的时间缩短至 3～7 年** |
| **第三**|**底层资产透明度高**|**在投资子基金的业务中，母基金进行投资时，子基金尚未进行投资，因此还不知道基金的资产组合，只是基于对子基金管理人的信任而投资；但在二手基金份额投资业务中，母基金投资的是存续基金，基金已经进行了投资，因此母基金能够得知底层资产组合** |

> **专注于进行二手基金份额投资业务的母基金，即为 S 基金**。

#### （三）直接投资（D） P66

> **直接投资是指母基金直接对非公开交易的企业股权进行投资**。

> **在实际操作中，母基金通常扮演跟投角色，和其所投资的股权投资基金联合投资，依托子基金管理人的资源和能力获取优质项目**。

> **在直接投资业务中，母基金能够在股权投资基金的投资项目中，挑选最具吸引力、与其现有投资组合最佳匹配的项目，因此，直接投资也自然成为母基金的一项业务类型**。

#### （四）"P+S+D"业务速查表

| 字母 | 业务 | 核心要点 |
|---|---|---|
| **P（Primary）**|**投资子基金**|**本源业务；七个考察方面（投资理念、市场、管理团队、既往业绩、投资流程、基金条款、主观分析）** |
| **S（Secondary）**|**投资二手基金份额**|**两种类型；三个原因（价格折扣、加速回收、透明度高）；专注者即 S 基金** |
| **D（Direct）**|**直接投资**|**通常扮演跟投角色，挑选与现有组合最匹配的项目** |

### 3.4.c 【了解】股权投资母基金的作用 P66–P67

**大纲原文**：了解股权投资母基金的作用

> **投资者通过投资母基金间接投资股权投资基金，主要有以下四个原因：分散风险、专业管理、投资机会、规模优势**。

#### （一）分散风险 P66–P67

> **母基金通常会将所募集的资金分散投资于多只股权投资基金，从而避免了单只股权投资基金投资中依赖于某一基金管理人的风险**。

> **通过分散投资于多只股权投资基金，母基金的投资得以实现多样性，如投资阶段、时间跨度、地域、行业、投资风格等，从而使投资者可以有效地实现风险分散**。

#### （二）专业管理 P67

> **对股权投资基金进行投资，是一项专业性非常强的工作**；**直接投资股权投资基金，即使投资者拥有基金投资某一方面的知识，也可能因为缺乏对其他方面的了解而丧失投资机会或导致投资失败**。

> **而母基金管理人通常拥有丰富的股权投资的知识、人脉和资源，在对股权投资基金进行投资时，母基金比其他投资者更有可能作出正确的投资决策**；**母基金为缺乏经验的投资者提供了投资股权投资基金的渠道**。

#### （三）投资机会 P67

> **大部分业绩出色的股权投资基金都会获超额认购，因此，一般投资者难以获得投资机会**。

> **而母基金作为股权投资基金的专业投资者，通常与股权投资基金有长期的良好关系，有机会投资于这些优秀的基金，从而使投资者通过投资于母基金而获得投资优秀基金的机会**。

#### （四）规模优势 P67

> **在对股权投资基金进行投资时，投资规模的大小常常是一个问题，投资者的资金常常太大或者太小以至于难以进行合适的投资；而母基金可以通过帮助投资者"缩小规模"或"扩大规模"来解决这一问题**：

| 方向 | 作用 |
|---|---|
| **"缩小规模"**|**母基金可以帮助大的投资者投资小规模的基金，从而节约成本和分散投资** |
| **"扩大规模"**|**母基金可以帮助小的投资者投资大规模的基金，从而达到大型基金的投资门槛** |

> **母基金通常拥有相当程度的规模，能够吸引、聘用并留住行业内最优秀的投资管理人才；中小投资者很少有足够的资源来建立类似规模及品质的投资团队**；**如考虑薪资、差旅及其他管理成本，投资母基金往往比自行聘请专门投资股权投资基金的团队更加经济有效**。

#### （五）四项作用速查表

| # | 作用 | 关键逻辑 |
|---|---|---|
| **1**|**分散风险**|**分散投资于多只基金，避免依赖单一管理人；实现阶段、时间、地域、行业、风格多样化** |
| **2**|**专业管理**|**母基金管理人具备知识、人脉和资源，更可能作出正确决策；为缺乏经验者提供渠道** |
| **3**|**投资机会**|**业绩出色基金常获超额认购，母基金凭长期良好关系获得投资机会** |
| **4**|**规模优势**|**"缩小规模"或"扩大规模"；吸引留住优秀人才；成本更经济有效** |

### 3.4.d 【理解】股权投资母基金的投资风险、收益与成本 P67–P68

**大纲原文**：理解股权投资母基金的投资风险、收益与成本

#### （一）风险 P67–P68

> **股权投资母基金通过分散投资降低了风险**。

> **研究表明，投资于单只股权投资基金的风险较高，极高内部收益率和极低内部收益率出现的可能性较大**；**而投资于母基金的风险小于投资于单只股权投资基金，且在很大程度上降低了极高内部收益率和极低内部收益率出现的可能性**。

#### （二）收益 P68

> **股权投资母基金能够在分散风险的同时，取得与风险相匹配的收益**。

#### （三）成本（核心考点） P68

> **股权投资母基金管理人要向母基金投资者收取管理费和业绩报酬，因此，相比直接投资股权投资基金，投资者通过母基金间接投资股权投资基金需额外承担成本**。

> **投资者投资母基金时，应考虑投资母基金相对于直接投资股权投资基金的超额收益和成本**。

#### （四）风险、收益、成本三者关系速查表

| 维度 | 结论 |
|---|---|
| **风险**|**小于单只基金；降低极高/极低 IRR 出现的可能性** |
| **收益**|**与风险相匹配** |
| **成本**|**存在"双重收费"（母基金管理费 + 业绩报酬），额外承担成本** |
| **投资决策**|**权衡超额收益与额外成本** |

### 3.4.e 【理解】S 基金的概念、价值及优势、交易模式 P68–P69

**大纲原文**：理解 S 基金的概念、价值及优势、交易模式

#### （一）S 基金的概念 P68

> **股权投资二级市场指股权投资基金份额及基金投资标的企业股权资产的转让市场**；**股权投资二级市场中的卖方为转让基金份额或底层资产的基金投资者及管理人**。

> **股权二级市场基金（S 基金）是指通过收购基金份额、出资承诺、投资标的或投资组合的方式，主要投资于股权投资二级市场的基金**。

> **S 基金收购基金份额或出资承诺后会形成基金的嵌套结构，因此，大部分 S 基金以母基金形式存在**。

> **市场上，多数母基金主要投资于新设子基金，也会有部分母基金采用收购已设子基金份额、承接已设子基金认缴出资承诺等策略进行投资，此类通常称为母基金中的 S 策略**。

#### （二）S 基金的价值及优势（四项，必背） P68–P69

> **S 基金在股权投资二级市场上收购现有基金份额或底层资产，相对于普通股权投资基金，其独特的投资方式对卖方基金和买方基金投资者均有显著价值**。

##### ① 降低投资收益的不确定性 P68–P69

> **股权投资基金通常投资于具有成长空间的企业，在获取潜在增长红利的同时也承担收益不确定的风险；特别是在企业初创阶段进行投资的创业投资基金，其投资收益的不确定因素更强**。

> **S 基金通常在标的股权投资基金中后期进入，此时基金底层项目情况相比早期更加稳定清晰，基金收益可见度更高，可以有效降低 S 基金投资者面临的不确定性**。

##### ② 更快获得投资回报 P69

> **股权投资基金生命周期较长，多数基金存续期限为 5～10 年，少数基金可达十余年**；**在生命周期前几年内，基金通常由于费用支出及成本估值因素呈现亏损状态，现金流出也远大于现金流入**。

> **S 基金进入时点通常为标的股权投资基金中后期，此时基金底层项目趋于成熟，现金开始回流；S 基金能够避开标的股权投资基金大幅支出的投资阶段，即规避所谓"J 曲线效应"，更快获得投资回报**；**以投资成熟期基金份额为主的 S 基金，最早从投资元年就可以产生回报**。

##### ③ 相对较高的内部收益率（IRR） P69

> **从风险收益角度看，S 基金能够获得相对较高的内部收益率（Internal Rate of Return，IRR）和已分配倍数（Distributed to Paid-In Capital，DPI）**。

| 机制 | 说明 |
|---|---|
| **估值折扣**|**S 基金通过受让基金份额，通常可以获得一定的估值折扣，可以相对容易地以合适的估值持有底层项目中的优势资产，从而产生账面浮盈，提高投资收益** |
| **注重质量与成长性**|**S 基金也注重底层项目质量与成长性，使得投资者可以分享底层项目资产增值收益** |
| **平衡年限、平滑现金流**|**通过投资已设立股权投资基金份额，可以平衡基金投资组合的年限，从而在基金存续期内获得相对平滑的现金流，更符合对现金流要求较高、偏好稳健回报的大型机构投资者** |

##### ④ 更高效地构建投资组合 P69

> **S 基金可以通过股权投资二级市场方便地在不同主题、不同地域、不同年份的基金之间进行布局选择和重点投资**；**持有的底层资产往往横跨数年，底层资产的分散程度高，风险分散效果更好，具有一定抗周期作用**。

#### （三）S 基金的交易模式（两大类，必背） P69

> **S 基金交易模式可以按交易内容分为基金份额交易和底层资产交易两大类**。

| 模式 | 内容 |
|---|---|
| **基金份额交易**|**是最常见、最传统的 S 基金交易模式**——**S 基金受让股权投资基金中一个或多个投资者的出资份额，相当于 S 基金代替股权投资基金原有投资者成为新投资者，同时股权投资基金管理人保持不变**；**此类交易通常在 S 基金与目标基金的投资者之间完成，但前期 S 基金对目标基金的尽职调查、交易过程中手续履行等环节一般也需要目标基金管理人的配合** |
| **底层资产交易**|**S 基金受让股权投资基金的一个或多个被投资项目**；**在此类交易中，目标基金管理人发挥更为积极的作用，在许多情况下，底层资产交易就是由目标基金管理人发起并主导完成的** |

#### （四）S 基金速查表

| 维度 | 要点 |
|---|---|
| **定义**|**通过收购基金份额、出资承诺、投资标的或投资组合，主要投资于股权投资二级市场** |
| **存在形式**|**大部分以母基金形式存在** |
| **四项优势**|**降低不确定性、更快获得回报（规避 J 曲线效应）、相对较高的 IRR 与 DPI、更高效构建投资组合** |
| **两类交易模式**|**基金份额交易（最常见、管理人不变）、底层资产交易（管理人发起并主导）** |

## 3.5 政府投资基金

### 3.5.a 【理解】政府投资基金的概念 P70–P71

**大纲原文**：理解政府投资基金的概念

#### （一）政府投资基金的含义 P70

> **依据《关于促进政府投资基金高质量发展的指导意见》，政府投资基金是各级政府通过预算安排，单独出资或与社会资本共同出资设立，采用股权投资等市场化方式，引导各类社会资本支持相关产业和领域发展及创新创业的投资基金**。

**政府出资的方式（必考）**：

| 方面 | 内容 |
|---|---|
| **出资方式**|**主要包括通过预算直接出资、安排资金并委托国有企业出资等方式** |
| **注资国企方式**|**政府采取注资国有企业方式设立基金，明确相关资金专项用于对基金出资的，原则上按照政府出资有关要求管理** |
| **出资人职责**|**财政部门通常根据本级政府授权或合同章程规定行使政府出资人职责** |

> **政府投资基金遵循"政府引导、市场运作、科学决策、防范风险"的基本原则**。

#### （二）政府投资基金的特点 P70–P71

##### ① 按投资标的分类（必背） P70

| 类型 | 投资重点 |
|---|---|
| **产业投资类基金**|**主要围绕特定目标产业开展投资活动，重点投资产业链关键环节和延链补链强链项目，推动提升产业链供应链韧性和安全水平** |
| **创业投资类基金**|**主要围绕发展新质生产力开展投资活动，着力投早、投小、投长期、投硬科技** |

##### ② 按投资方式分类 P70

| 类型 | 架构 |
|---|---|
| **产业投资类政府投资基金**|**可采取母子基金架构或直投基金架构** |
| **创业投资类基金**|**多采用母子基金架构** |

> **母子基金架构即政府投资基金作为母基金投向子基金进而投资于项目企业的股权；直投基金架构即政府投资基金直接投资于项目企业的股权**。

##### ③ 政策属性强 P71

> **不同于单纯追求经济收益的市场化基金，政府投资基金通常具有较强的政策属性**；**政府投资基金的投向，不仅仅基于为基金获取经济回报的目标，也反映着政府对相关产业发展给予的支持和鼓励，体现着政策导向**。

##### ④ 管理原则：三者有机统一 P71

> **从管理原则看，政府投资基金要实现政府引导、市场化运作和专业化管理的有机统一**：

| 原则 | 内涵 |
|---|---|
| **"政府引导"**|**主要体现为政府部门要通过基金布局、投向规划和指导等方式，引导基金及社会资本投向有助于实现政策目标的领域**；**但政府部门不得以行政手段干预基金日常管理事务和具体项目投资决策** |
| **"市场化运作与专业化管理"**|**主要体现为在项目尽调、投资决策、投后管理、风险控制、投资退出等环节，充分尊重基金行业规律，充分发挥基金管理人的专业能力** |

##### ⑤ 运作规则更严格 P71

> **从运作规则来看，政府投资基金除遵守适用于股权投资基金运作管理的法律法规及自律规则之外，通常还需遵守政府部门制定的政府投资基金相关管理规则**；**各级政府部門在设立和运作政府投资基金时，通常会制定相应的管理办法，以规范基金的运作，并更有效地实现风险防控与绩效考核**。

> **这使得政府投资基金的运作通常会面临更严格的规则约束，特别是在政府投资基金作为母基金投向子基金时，需要特别注意避免政府投资基金的内部管理规定与其签署的子基金相关法律文件出现冲突的问题**。

### 3.5.b 【了解】政府投资基金的目标 P71–P72

**大纲原文**：了解政府投资基金的目标

> **政府投资基金的三大目标：提高财政资金使用效率、支持重点领域和重点产业发展、支持创新创业**。

#### （一）提高财政资金使用效率 P71

> **政府投资基金是财政投资方式的重大创新**；**政府将财政资金进行有效整合后，通过集中出资并向社会募集资金，以少量财政资金撬动更多的社会资本投入，从而达到引导、助力产业投资和产业转型升级的作用**；**有利于缓解由于财政资金实力不足难以更大规模投入、市场融资效率不高、社会资金无法投向部分重点领域以及间接融资风险过高等矛盾**。

**三种机制（必考）**：

| # | 机制 |
|---|---|
| **1**|**"拨改投"**——**近年来政府投资基金主要强调对财政资金投入的创新，将部分原来政府无偿资助的财政专项资金通过"拨改投"转变为以基金的方式出资使用** |
| **2**|**利益共享、风险共担**——**政府投资基金按市场化方式运作，与社会资本利益共享、风险共担，提高了财政资金的总体效率和效益** |
| **3**|**资金循环使用**——**政府投资基金通过股权投资的退出实现资金回收，使得财政资金得以循环使用，进一步放大了财政资金的杠杆作用和引导效果** |

#### （二）支持重点领域和重点产业发展 P71–P72

> **基于政府与市场关系的一般逻辑，从投向来看，政府应当主要投资于单纯依靠市场机制配置资源存在不足的领域**；**支持重点领域和重点产业发展，是政府投资基金天然的功能定位，发展政府投资基金，是引导和带动社会资本投资的重要举措**。

**两项落实机制（必考）**：

| # | 机制 | 内容 |
|---|---|---|
| **1**|**比例要求**|**在政府投资基金管理办法或相关协议中明确要求基金必须有一定比例投向目标产业，以此来落实国家产业政策，扶持重大关键技术产业化，实现优化升级产业结构和支持国家战略实施的目标** |
| **2**|**负面清单管理**|**对政府投资基金的投资方向实行负面清单管理，确保资金脱虚向实，投向重点领域和薄弱环节** |

#### （三）支持创新创业 P72

> **政府投资基金通过支持投早、投小、投长期、投硬科技，有助于改善初创科技企业融资环境，激发企业创新活力，推动加快实现高水平科技自立自强，提升自主创新能力和关键核心技术攻关能力，解决重点关键领域"卡脖子"难题**。

#### （四）三大目标速查表

| # | 目标 | 关键机制 |
|---|---|---|
| **1**|**提高财政资金使用效率**|**"拨改投"、利益共享风险共担、资金循环使用** |
| **2**|**支持重点领域和重点产业发展**|**一定比例投向目标产业、投资方向负面清单管理** |
| **3**|**支持创新创业**|**投早、投小、投长期、投硬科技** |

### 3.5.c 【理解】政府投资基金的运作原则与方式 P72–P74

**大纲原文**：理解政府投资基金的运作原则与方式

#### （一）四项运作原则（必背） P72–P73

##### ① 政府引导 P72

> **政府投资基金有别于纯粹市场化运作的基金，有其天然使命和功能定位**；**其部分或者全部出资来自政府，并纳入预算管理，由财政部门根据本级政府授权，按照法律规定和基金合同等约定履行投资者职责**。

> **政府投资基金通过引导产业资本、保险资金、社保资金等机构投资者资金以及民间资本、国外资本等社会资金聚集，进入国家支持和鼓励的重点领域，发挥了引导社会资金集聚、形成资本供给效应的重要作用**。

| 维度 | 内容 |
|---|---|
| **投资领域**|**主要聚焦重大战略、重点领域和市场不能充分发挥作用的薄弱环节，吸引带动更多社会资本，支持现代化产业体系建设，加快培育发展新质生产力** |
| **运行目标**|**坚持政策目标导向和商业可持续原则的有机统一**——**一方面撬动社会资本支持重点产业发展、支持创新创业，另一方面实现财政资金的高效利用和保值增值** |

##### ② 市场运作 P72–P73

> **从基金运作原理来看，政府投资基金虽然有政府财政出资参与，但仍应当遵循股权投资基金运作的一般规律，应尊重市场经济规律和基金管理流程，从募集、设立、投资、管理、退出等各主要环节，充分发挥市场配置资源的决策性作用**；**设立市场化基金运作实体，明确投资者、管理人和托管人等各方权责，强调"利益共享、风险共担"，信守契约精神**。

> **从政府投资基金运作实践来看，委托专业基金管理人进行市场化运作是政府投资基金目前主流的管理方式**；**政府部门不干预基金的日常经营管理和投资决策，各投资者按照"利益共享、风险共担"的原则约定收益分配和亏损负担方式**。

##### ③ 科学决策 P73

> **政府投资基金运行中的科学决策既包括通过科学的程序筛选基金管理人，也包括基金管理人在投资具体项目或企业上的决策，还包括基金退出时机的决策**。

> **选择优秀的基金管理人是科学决策最重要的一环**；**原则上，基金管理人应采取市场化方式通过竞争性遴选程序产生，基金管理人应具备与基金运作相适应的投资能力和管理能力，具有股权投资或相关基金管理经验，具有符合要求的投资管理业绩**。

##### ④ 防范风险 P73

> **政府投资基金应建立健全科学的基金治理结构**；**政府部门可通过监督投向、跟踪投资进度、委派观察员等方式，母基金通过对子基金投向、运作、财务等情况的监督，促进基金合规运作**。

> **此外，与一般股权投资基金一样，政府投资基金亦通过加强基金财务管理、托管、关联交易与利益冲突管理、信息披露与报告等环节的管理，有效控制基金风险**。

#### （二）运作方式 P73–P74

> **从投资方式来看，母基金是政府投资基金的主要形式之一**；**政府投资基金先作为投资者投向子基金，再由子基金直接投资重点领域的企业**；**这一方式有利于分散投资风险、撬动社会资本，同时借助专业管理人的力量提升政府投资基金市场化运作水平**。

> **近年来，部分政府投资基金引入直投基金模式，直接投资于企业的股权**；**直投模式对项目投资的参与度和把控力更强，能够更精准地扶持特定产业和企业，同时也对基金的项目获取和研判能力提出了更高要求**。

> **在近年新设立政府投资基金中，"母基金 + 直投"模式增多，反映出政府越来越强调对基金运作的深度参与，并以更积极的姿态介入当地产业和企业培育中**。

**投资行业与发展趋势**：

| 方面 | 内容 |
|---|---|
| **投资行业**|**主要聚焦政府重点支持的产业领域，如支持战略性新兴产业发展、鼓励传统行业转型升级等；近年来关注领域随着地方产业政策的逐步完善更加垂直细分，比如围绕重点产业链主题设立基金** |
| **创新探索**|**部分地区重点支持项目阶段逐渐前移，并出现更多鼓励"投早投小"的举措；越来越多地区注重各级引导基金协同联动，通过形成基金矩阵，发挥合力推动产业集聚** |

#### （三）运作原则与方式速查表

| 维度 | 内容 |
|---|---|
| **政府引导**|**出资来自政府并纳入预算管理；引导各类社会资金；聚焦重大战略与薄弱环节；政策目标导向与商业可持续相统一** |
| **市场运作**|**遵循基金运作一般规律；委托专业基金管理人为主流；政府部门不干预日常经营与投资决策；利益共享、风险共担** |
| **科学决策**|**筛选管理人、项目决策、退出时机；选择优秀管理人是科学决策最重要的一环；竞争性遴选** |
| **防范风险**|**科学的治理结构；监督投向、跟踪进度、委派观察员；母基金监督子基金** |
| **运作方式**|**母基金为主 + 直投模式；近年"母基金 + 直投"增多** |

### 3.5.d 【了解】政府投资基金的绩效管理 P74

**大纲原文**：了解政府投资基金的绩效管理

#### （一）绩效管理的定义 P74

> **政府投资基金的绩效管理，是指在政府投资基金成立前设定绩效目标和绩效指标，在运作过程中定期进行绩效监控，分阶段实施绩效评价，有效应用绩效评价结果，以此促进政府投资基金科学、规范运行，实现基金政策目标**。

> **政府投资基金绩效管理工作贯穿于基金募集、投资、管理、退出等基金运作的全过程**；**相应地，绩效管理的内容也涵盖绩效目标与绩效指标设定、绩效监控、绩效评价及评价结果应用等方面**。

#### （二）绩效目标的四个政策维度 P74

> **政府投资基金的政策目标通常包括引导社会资本投资、引导重点产业发展、支持创新创业、促进地方经济发展等几类**，**因此基金的政策效果相关的绩效目标在制定时也通常从这几个角度出发**。

> **除此之外，为了保证评价的全面性，基金的绩效目标还应该包括投资效益和管理效能两类，分别从财务回报情况、管理人运作合规和效率情况对基金进行评价**。

#### （三）绩效评价与结果运用 P74

> **政府投资基金的绩效评价是指政府部门预先设定基金绩效目标，运用综合的评估指标体系和科学的评估方法，依据规范的程序对基金运行进行过程性监督和监测，对财政预算资金的绩效进行评价，并运用评价结果改进绩效**。

> **结果运用是绩效评价的重要环节，其基本原则是按照"奖优罚劣"的原则发挥绩效评价对基金运作管理的"指挥棒"作用**：

| 评价结果 | 措施 |
|---|---|
| **较好**|**可采取通报表扬、优先后续支持、政府出资让利等方式进行激励** |
| **较差**|**可以综合采取调减管理费、调减超额收益分配等措施进行约束** |

#### （四）绩效管理速查表

| 维度 | 内容 |
|---|---|
| **四个环节**|**绩效目标与指标设定 → 绩效监控 → 绩效评价 → 评价结果应用** |
| **覆盖范围**|**贯穿募集、投资、管理、退出全过程** |
| **政策目标四类**|**引导社会资本投资、引导重点产业发展、支持创新创业、促进地方经济发展** |
| **补充两类目标**|**投资效益、管理效能** |
| **结果运用原则**|**"奖优罚劣"（好的：通报表扬、优先支持、政府让利；差的：调减管理费、调减超额收益分配）** |

#### 二、易错点清单

1. **公司型基金在我国并非主流组织形式；合伙型才是主流**；
2. **契约型基金不能登记为被投资企业股东，需管理人代持，IPO 时受重点关注**；
3. **契约型基金人数上限是 200 人（非公开募集），不是 50 人**；
4. **只有公司型基金需要提取法定公积金**；
5. **公司型是企业所得税纳税主体，合伙型和契约型不是**；
6. **创业投资是增资（钱进企业），并购投资是受让存量股权（钱给原股东）**；
7. **创业投资不谋求控股、不使用杠杆；并购投资谋求控股、通常使用杠杆**；
8. **创业投资与并购投资的投后管理重点不同：增值服务 vs 重整**；
9. **企业并购投资人偏战略投资，并购基金偏财务投资**；
10. **创业投资基金不得使用杠杆融资，且最低存续期须达到一定标准**；
11. **创业投资基金八项投资禁止中，不动产（含基础设施）也在禁止之列**；
12. **"反向挂钩"：投资期限越长，减持限制越宽松**；
13. **母基金本源业务是投资子基金，不是直接投资**；
14. **母基金存在双重收费，需额外承担成本**；
15. **S 基金交易中最常见的是基金份额交易，管理人不变**；
16. **底层资产交易中，目标基金管理人往往发起并主导**；
17. **政府投资基金四大基本原则是"政府引导、市场运作、科学决策、防范风险"**；
18. **政府部门不得以行政手段干预基金日常管理事务和具体项目投资决策**；
19. **选择优秀的基金管理人是科学决策最重要的一环**；
20. **绩效管理结果运用原则是"奖优罚劣"**。
