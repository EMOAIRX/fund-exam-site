## 15.1 基金资产的估值

### 15.1.a 【掌握】基金资产估值的概念和应用、法律依据、重要性及需要考虑的因素 P541–P544

**大纲原文**：掌握基金资产估值的概念和应用、法律依据、重要性和需要考虑的因素

#### （一）估值的三个核心概念（必背公式） P541

> **基金资产估值，是指通过对基金所拥有的全部资产及全部负债按一定的原则和方法进行估算，进而确定基金资产公允价值的过程**。

| 概念 | 定义 |
|---|---|
| **基金资产总值**|**基金全部资产的价值总和** |
| **基金资产净值**|**从基金资产中扣除基金所有负债即是基金资产净值** |
| **基金份额净值**|**基金资产净值除以基金当前的总份额** |

$$\text{基金资产净值}=\text{基金资产总值}-\text{基金负债总值}$$

$$\text{基金份额净值}=\frac{\text{基金资产净值}}{\text{基金总份额}}$$

> **基金份额净值是计算投资者申购基金份额、赎回资金金额的基础，也是评价基金投资业绩的基础指标之一**。

##### 案例 15-1：基金份额净值计算（必考） P542

> **某基金总资产为 50 亿元，基金总负债为 20 亿元，发行在外的基金份数为 30 亿份**。

$$\text{基金份额净值}=\frac{50-20}{30}=1\ (\text{元})$$

##### 案例 15-2：含多只股票与应付款项的份额净值（必考） P542

> **某只基金持有的三只股票数量分别为 10 万股、50 万股和 100 万股，每股收盘价分别为 30 元、20 元和 10 元，银行存款为 1 000 万元，对托管人或管理人应付未付的报酬为 500 万元，应付税费为 500 万元，本基金无其他资产与负债，已发行在外的基金份额为 2 000 万份**。

$$\text{基金份额净值}=\frac{(10\times30+50\times20+100\times10+1\,000)-500-500}{2\,000}=1.15\ (\text{元})$$

**分子拆解**：**股票市值 3 000 万（300+1 000+1 000）＋银行存款 1 000 万 − 应付报酬 500 万 − 应付税费 500 万 = 3 000 万元；3 000 ÷ 2 000 = 1.15 元**。

#### （二）法律依据（五部规章，必背） P542–P543

> **基金估值主体在现有基金法律体系中是完备的，无论是《证券投资基金法》还是中国证监会关于基金合同的格式要求、基金估值业务规定等都明确规定，基金管理人是基金估值的第一责任主体**。

| 法律/规章 | 核心规定 |
|---|---|
| **《证券投资基金法》**|**基金管理公司应履行计算并公告基金资产净值的责任，确定基金份额申购、赎回价格；托管人应履行复核、审查基金管理公司计算的基金资产净值和基金份额申购、赎回价格的责任** |
| **《证券投资基金信息披露内容与格式第 6 号〈基金合同的内容与格式〉》**|**基金合同应列明基金资产估值事项，包括估值日、估值方法、估值对象、估值程序、估值错误的处理、暂停估值的情形、基金净值的确认和特殊情况的处理** |
| **《公开募集证券投资基金运作管理办法》**|**开放式基金份额的申购、赎回价格，依据申购、赎回日基金份额净值加、减有关费用计算；开放式基金份额净值应于每个开放日闭市后，按照基金资产净值除以当日基金份额的余额数量计算；基金合同和招募说明书中应当载明基金份额净值的具体计算方法** |
| **《中国证监会关于证券投资基金估值业务的指导意见》**|**基金管理人应制定基金估值和份额净值计价的业务管理制度，明确基金估值的程序和技术；建立估值委员会，健全估值决策体系；使用可靠的估值业务系统；确保估值人员熟悉各类投资品种的估值原则及具体估值程序；完善相关风险监测、控制和报告机制** |
| **《资产管理产品相关会计处理规定》**|**资产管理产品应当加强金融资产的估值管理，确保所采用的估值技术和输入值的适当性以及估值结果的可靠性，不得随意变更同一金融资产的估值技术** |

#### （三）估值的重要性 P543

> **基金份额净值是基金申购份额、赎回金额计算的基础，直接关系到基金投资者的利益；因此，基金份额净值必须是公允的**。

> **广义上讲，每份基金都与基金的各项资产及各项负债按一定的比例一一对应**——**投资者申购一份基金所付出的金额应该相当于在市场上按当前价格购买对应资产的金额加相关费用，而赎回的投资者从基金中获取的金额也应是基金在市场上按当前价格出售相应资产所能获得的金额减相关费用**；**这就是在估值过程中一般均采用资产最新价格的原因**；**否则，申购或赎回的价格错误将会对基金资产价值产生影响**。

#### （四）估值需考虑的三个因素（核心考点） P543–P544

##### ① 估值频率（披露时限必背） P543

> **基金一般都按照固定的时间间隔对基金资产进行估值，通常监管法规会规定一个最低的估值频率**；**对开放式基金来说，估值的时间通常与开放申购、赎回的时间一致**。

| 基金类型 | 估值频率 | 披露要求 |
|---|---|---|
| **开放式基金**|**每个交易日估值**|**不晚于次日披露基金份额净值和基金份额累计净值** |
| **封闭式基金**|**每个交易日也都进行估值**|**至少每周披露一次基金份额净值和基金份额累计净值** |
| **共同要求**| — |**都需在不晚于半年度和年度最后一日的次日，披露半年度和年度最后一日的基金份额净值和基金份额累计净值** |

> **值得注意的是，基础设施基金由于其产品特征的特殊性，不适用常规基金信息披露事项，上述信息可不予披露**。

> **海外的基金多数也是每个交易日估值，但也有一部分基金是每周估值一次，有的甚至每半个月、每月估值一次**；**基金估值的频率是由基金的组织形式、投资对象的特点等因素决定的，并在相关的发行法律文件中明确列示**。

##### ② 交易价格及其公允性 P543

| 情形 | 估值处理 |
|---|---|
| **基金只投资于交易活跃的证券**|**市场交易价格是可接受的，也是可信的，直接采用市场交易价格就可以对基金资产估值** |
| **基金投资于交易不活跃的证券**|**基金持有的证券要么没有交易价格，要么交易价格不可信，此时对基金资产进行估值时就要非常慎重，其中证券资产的流动性是非常关键的考虑因素** |

> **如果证券的公允价值是由基金管理人通过估值技术获得的，基金托管人应对管理人所采用的估值技术的科学性、合理性、合法性等方面进行复核**。

##### ③ 估值方法的一致性及公开性（0.25% 红线，必考） P544

**一致性**：

> **估值方法的一致性是指基金在进行资产估值时均应采取同样的估值方法，遵守同样的估值规则，基金管理人对投资品种进行估值时应保持程序和技术的一致性**；**同一基金管理人对管理的不同基金持有的具有相同特征的同一投资品种的估值原则、程序及技术应当一致**。

> **为确保估值程序和技术的持续适用性，基金管理人应建立定期复核和审阅机制，以确保相关估值程序和技术不存在重大缺陷**；**当改变估值技术导致基金资产净值的变化在 0.25% 以上的，基金管理人应就所采用的相关估值技术、假设及输入值的适当性等咨询会计师事务所的专业意见**。

**公开性**：

> **估值方法的公开性是指基金管理人应履行与基金估值相关的披露义务**：

| 披露场景 | 要求 |
|---|---|
| **半年度和年度报告**|**应当披露估值程序、估值技术及重大变化、假设、输入值、对基金资产净值及当期损益的影响等对基金估值有重大影响的信息** |
| **改变估值技术时**|**应本着最大限度保护基金份额持有人的原则及时进行临时公告** |
| **会计师事务所审计**|**应对报告期间基金的估值技术及其重大变化，特别是对估值的适当性，采用外部信息进行估值的客观性和可靠性程度，以及相关披露的充分性和及时性等发表意见** |

### 15.1.b 【掌握】基金资产估值的责任主体、估值程序和基本原则 P544–P546

**大纲原文**：掌握基金资产估值的责任主体、估值程序和基本原则

#### （一）估值责任人（必背） P544

> **我国基金资产估值的责任人是基金管理人，基金托管人对基金管理人的估值结果负有复核责任**。

**管理人的六项工作要求** P544：

| # | 要求 |
|---|---|
| **1**|**制定基金估值和份额净值计价的业务管理制度，明确基金估值的程序和技术** |
| **2**|**建立估值委员会，健全估值决策体系** |
| **3**|**使用可靠的估值业务系统** |
| **4**|**确保估值人员熟悉各类投资品种的估值原则及具体估值程序** |
| **5**|**完善相关风险监测、控制和报告机制** |
| **6**|**建立定期复核和审阅机制，以确保相关程序和技术不存在重大缺陷** |

**信用风险与流动性缺失时的特别要求（易考）**：

> **基金管理人应审慎开展基金估值，切实履行主体责任，当基金组合资产出现信用风险和流动性缺失时，基金管理人不能简单依赖第三方估值基准服务机构提供的数据，应当召开估值委员会会议讨论公允价值或预期信用损失计量结果，在基金份额净值中及时、合理体现相关影响**。

**托管人的复核责任** P544：

> **托管人在复核、审查基金资产净值和基金份额申购、赎回价格之前，应认真审阅基金管理公司采用的估值原则及技术，避免因估值结果不公允导致投资者的合法权益受到损害**；**当对估值原则及技术有异议时，托管人有义务要求基金管理人作出合理解释，通过积极商讨达成一致意见**。

**中基协的估值指引（重要免责条款，必考）** P544–P545：

> **为提高估值的合理性和可靠性，中国证券投资基金业协会建立了基金估值工作机制，在充分征求行业意见并向中国证监会报备后，对没有活跃市场或在活跃市场不存在相同特征的资产或负债报价的投资品种提出估值指引，并定期对其出台的估值指引进行评估和修订**。

> **基金管理人和托管人在进行基金估值、计算基金份额净值及相关复核工作时，可参考中国证券投资基金业协会的估值指引，但是并不能免除相关责任；即使基金管理人选择基金服务机构进行估值，也不能免除管理人的相关责任**。

#### （二）估值程序（三步，必背） P545

| 步骤 | 内容 |
|---|---|
| **（1）**|**基金份额净值是按照每个开放日闭市后，基金资产净值除以当日基金份额的余额数量计算** |
| **（2）**|**基金日常估值由基金管理人进行**；**基金管理人每个交易日对基金资产估值后，将基金份额净值结果发给基金托管人** |
| **（3）**|**基金托管人按基金合同规定的估值方法、时间、程序对基金管理人的计算结果进行复核，复核无误后签章返回给基金管理人，由基金管理人对外公布，并由基金注册登记机构根据确认的基金份额净值计算申购、赎回数额**；**月末、年中和年末估值复核与基金会计账目的核对同时进行** |

**流程记忆**：**管理人估值 → 发送托管人 → 托管人复核签章返回 → 管理人对外公布 → 注册登记机构计算申赎数额**。

#### （三）估值的基本原则（三条，核心） P545

> **基金管理人在确定相关金融资产和金融负债的公允价值时，应根据企业会计准则的规定，采用在当前情况下适用并且有足够可利用数据和其他信息支持的估值技术**。

##### 原则 1：存在活跃市场且能获取相同资产或负债报价 P545

| 情形 | 处理 |
|---|---|
| **估值日有报价**|**除会计准则规定的例外情况外，应将该报价不加调整地应用于该资产或负债的公允价值计量** |
| **估值日无报价且最近交易后未发生影响公允价值计量的重大事件**|**应采用最近交易日的报价确定公允价值** |
| **有充足证据表明估值日或最近交易日的报价不能真实反映公允价值**|**应对报价进行调整，确定公允价值** |

**三条特殊规则（易考）**：

| # | 规则 |
|---|---|
| **1**|**与上述投资品种相同，但具有不同特征的，应以相同资产或负债的公允价值为基础，并在估值技术中考虑不同特征因素的影响** |
| **2**|**特征是指对资产出售或使用的限制等，如果该限制是针对资产持有者的，那么在估值技术中不应将该限制作为特征考虑** |
| **3**|**基金管理人不应考虑因其大量持有相关资产或负债所产生的溢价或折价** |

##### 原则 2：不存在活跃市场 P545

> **对不存在活跃市场的投资品种，应采用在当前情况下适用并且有足够可利用数据和其他信息支持的估值技术确定公允价值**；**采用估值技术确定公允价值时，应优先使用可观察输入值，只有在无法取得相关资产或负债可观察输入值或取得不切实可行的情况下，才可以使用不可观察输入值**。

##### 原则 3：重大变化的 0.25% 调整门槛 P545

> **如经济环境发生重大变化或证券发行人发生影响证券价格的重大事件，使潜在估值调整对前一估值日的基金资产净值的影响在 0.25% 以上的，应对估值进行调整并确定公允价值**。

#### （四）估值原则速查表

| 情形 | 处理方式 |
|---|---|
| **活跃市场、估值日有报价**|**报价不加调整直接使用** |
| **活跃市场、估值日无报价、无重大事件**|**用最近交易日报价** |
| **活跃市场、有证据表明报价不真实**|**调整报价确定公允价值** |
| **相同资产但特征不同**|**以相同资产公允价值为基础＋考虑特征因素** |
| **限制针对持有者**|**不作为特征考虑** |
| **管理人大量持有**|**不考虑溢价或折价** |
| **不存在活跃市场**|**用估值技术，优先可观察输入值** |
| **经济环境或发行人重大变化**|**影响前一估值日净值 ≥0.25% 则须调整估值** |

### 15.1.c 【理解】不同投资品种的估值方法、计价错误的处理与责任承担、暂停估值的情形及侧袋机制 P546–P550

**大纲原文**：理解不同投资品种的估值方法，计价错误的处理、责任承担、基金暂停估值的情形，以及侧袋机制

#### （一）九类投资品种的估值方法（核心考点） P546–P549

##### ① 交易所发行未上市品种 P546

| 情形 | 估值方法 |
|---|---|
| **首次公开发行未上市的股票**|**采用估值技术确定公允价值** |
| **送股、转增股、配股和公开增发新股等发行未上市股票**|**按交易所上市的同一股票的市价估值；该日无交易的，以最近一日的市价（收盘价）估值** |

##### ② 交易所上市交易的非流通受限品种 P546

> **交易所上市的有价证券（包括股票等），以其估值日在证券交易所挂牌的市价（收盘价）估值**；**估值日无交易的，且最近交易日后经济环境未发生重大变化或证券发行机构未发生影响证券价格的重大事件的，以最近交易日的市价（收盘价）估值**；**如最近交易日后经济环境发生了重大变化或证券发行机构发生影响证券价格的重大事件的，可参考类似投资品种的现行市价及重大变化因素，调整最近交易市价，确定公允价格**。

> **对于因重大特殊事项而长期停牌股票的估值，需要按估值基本原则判断是否采用估值技术**，**估值技术包括指数收益法、可比公司法、市场价格模型法和估值模型法等**，供管理人对基金估值时参考。

##### 案例 15-3：停牌股票的估值调整 P547

> **2017 年 7 月 8 日，A 基金、B 基金和 C 基金分别在其官网公告，调整旗下基金持有的 X 股票的估值**；**A 基金和 B 基金将 X 股票的估值调整为 22.37 元，C 基金调整为 22.05 元**；**2017 年 7 月 10 日，D 基金公告将 X 股票的估值下调至 20.13 元，较其停牌前股价下调四个跌停板**。

> **X 股票自 2017 年 4 月 4 日起停牌**——**各家基金管理人对 X 股票的估值反映的是对该公司股价变动的预期；估值难以简单参考市场和行业指数的变化来判断，因而各家基金公司给出的估值技术调整结果不尽相同**。

##### ③ 交易所上市交易的流通受限品种（公式必考） P546–P547

> **在发行时明确一定期限限售期的股票，包括但不限于非公开发行的股票、首次公开发行股票时公司股东公开发售的股份、通过大宗交易取得的带限售期的股票等，参考流通受限股票的估值指引进行估值**。

$$\text{FV}=\text{S}\times\left(1-\text{LoMD}\right)$$

| 符号 | 含义 |
|---|---|
| **FV**|**估值日该流通受限股票的价值** |
| **S**|**估值日在证券交易所上市交易的同一股票的公允价值** |
| **LoMD**|**该流通受限股票剩余限售期对应的流动性折扣** |

$$\text{LoMD}=\frac{P}{S}$$

> **P 为估值日看跌期权的价值**；**证券投资基金持有的流通受限股票在估值日按平均价格亚式期权模型（AAP 模型）确定估值日看跌期权的价值**。

##### ④ 固定收益品种（2022 年 12 月新标准） P547

> **2022 年 12 月中国证券投资基金业协会发布《关于固定收益品种的估值处理标准》，对国内各大交易所和全国银行间债券市场交易的固定收益品种估值进行了统一规范，明确基金在对各类固定收益品种进行估值、减值计量时，可依据第三方估值基准服务机构提供的数据**。

| 品种 | 估值方法 |
|---|---|
| **已上市或已挂牌转让的不含权固定收益品种**|**以第三方估值机构提供的相应品种当日的估值全价进行估值** |
| **已上市或已挂牌转让的含权固定收益品种**|**以第三方估值机构提供的相应品种当日的唯一估值全价或推荐估值全价进行估值** |
| **含投资人回售权的品种**|**行使回售权的，在回售登记日至实际收款日期间建议选取唯一估值全价或推荐估值全价，同时应充分考虑发行人的信用风险变化对公允价值的影响**；**回售登记期截止日（含当日）后未行使回售权的按照长待偿期所对应的价格进行估值** |
| **可转换债券等有活跃市场的含转股权债券**|**实行全价交易的，选取估值当日收盘价作为估值全价**；**实行净价交易的，估值当日收盘价加计每百元税前应计利息作为估值全价，每百元税前应计利息保留至小数点后 8 位** |
| **未上市或未挂牌转让且不存在活跃市场**|**应采用在当前情况下适用并且有足够可利用数据和其他信息支持的估值技术确定公允价值** |

##### ⑤ 基金中基金（FOF）投资的证券投资基金（易考分类） P548

| 所投基金类型 | 估值方法 |
|---|---|
| **境内非货币市场基金**|**按所投资基金估值日的份额净值估值** |
| **境内货币市场基金**|**按所投资基金前一估值日后至估值日期间（含节假日）的万份收益计提估值日基金收益** |
| **ETF**|**按所投资 ETF 估值日的收盘价估值** |
| **ETF 联接基金投资的 ETF**|**按所投资 ETF 估值日的份额净值估值** |
| **境内上市开放式基金（LOF）**|**按所投资基金估值日的份额净值估值** |
| **境内上市定期开放式基金、封闭式基金**|**按所投资基金估值日的收盘价估值** |
| **境内上市交易型货币市场基金**|**如披露份额净值，按份额净值估值；如披露万份（百份）收益，按前一估值日后至估值日期间（含节假日）的万份（百份）收益计提估值日基金收益** |

**三种特殊情况处理** P548：

| # | 原则 |
|---|---|
| **①**|**以份额净值估值的，若所投资基金与 FOF 估值频率一致但未公布估值日份额净值，按其最近公布的份额净值为基础估值** |
| **②**|**以收盘价估值的，若估值日无交易且最近交易日后市场环境未发生重大变化，按最近交易日收盘价估值；如发生重大变化，可使用最新份额净值为基础或参考类似投资品种现行市价及重大变化因素调整最近交易市价** |
| **③**|**如果所投资基金前一估值日至估值日期间发生分红除权、折算或拆分，应根据份额净值或收盘价、单位份额分红金额、折算或拆分比例、持仓份额等因素合理确定公允价值** |

##### ⑥ 期货合约 P548

> **期货合约，以期货合约当日结算价进行估值**；**估值当日无结算价的，且最近交易日后经济环境未发生重大变化的，采用最近交易日结算价估值**。

##### ⑦ 期权合约 P548

> **期权合约，以期权合约当日结算价进行估值**；**估值当日无结算价的，且最近交易日后经济环境未发生重大变化的，采用最近交易日结算价估值**。

**期货与期权估值方法完全相同：当日结算价 → 无结算价则用最近交易日结算价**。

##### ⑧ 信用衍生品 P548

| 类型 | 估值方法 |
|---|---|
| **交易所或银行间市场交易的凭证类**|**存在活跃市场：以活跃市场上未经调整的报价作为计量日公允价值**；**活跃市场报价未能代表计量日公允价值：应对市场报价进行调整**；**不存在市场活动或市场活动很少：应采用估值技术确定公允价值** |
| **非上市交易的合约类**（**且估值基准服务机构未提供估值价格**） |**建议采用估值技术确定其公允价值** |

##### ⑨ 贵金属投资品种（上海黄金交易所） P549

| 品种 | 估值方法 |
|---|---|
| **现货交易品种**|**按估值日在上海黄金交易所挂盘的收盘价估值**；**无交易且无重大变化则以最近交易日收盘价估值** |
| **集中定价合约**|**按估值日上海黄金交易所午盘基准价估值**；**无交易且无重大变化则以最近交易日的午盘基准价估值** |
| **现货延期交易品种**|**以其估值日在上海黄金交易所挂牌的结算价估值**；**无结算价且无重大变化则采用最近交易日结算价估值** |

#### （二）计价错误的处理及责任承担（0.25% / 0.5% 双红线，必背） P549

> **基金管理公司应制定估值及份额净值计价错误的识别及应急方案**；**当估值或资产净值计价错误实际发生时，基金管理人应立即纠正，及时采取合理措施防止损失进一步扩大**。

**两个报告门槛（必考）**：

| 错误幅度 | 处理要求 |
|---|---|
| **达到或超过基金份额净值的 0.25%**|**基金管理人应及时向中国证监会报告** |
| **达到或超过基金份额净值的 0.5%**|**基金管理人应及时编制临时报告书，并登载在指定报刊和指定网站上** |

**责任承担（易考）**：

> **基金管理公司和托管人在进行基金估值、计算或复核基金份额净值的过程中，未能遵循相关法律法规规定或基金合同约定，给基金财产或基金份额持有人造成损害的，应分别对各自行为依法承担赔偿责任**；**因共同行为给基金财产或基金份额持有人造成损害的，应承担连带赔偿责任**。

#### （三）暂停估值的四种情形（必背） P549

> **当基金有以下情形时，应当暂停估值**：

| # | 情形 |
|---|---|
| **（1）**|**基金投资所涉及的证券交易市场遇法定节假日或因其他原因暂停营业时** |
| **（2）**|**因不可抗力或其他情形致使基金管理人、基金托管人无法准确评估基金资产价值时** |
| **（3）**|**当前一估值日基金资产净值 50% 以上的资产出现无可参考的活跃市场价格且采用估值技术仍导致公允价值存在重大不确定性时，经与基金托管人协商确认后，基金管理人应当暂停估值** |
| **（4）**|**中国证监会和基金合同认定的其他情形** |

#### （四）侧袋机制（流动性管理工具，重点） P549–P550

> **侧袋机制是开放式基金重要的流动性管理工具之一，是指将基金投资组合中的特定资产从原有账户分离至一个专门账户进行清算，目的在于有效隔离并化解风险，确保投资者得到公平对待**。

##### ① 特定资产的范围（三类） P549–P550

> **特定资产包括但不限于违约债券、因重大事项长期停牌股票、债券回购等**：

| # | 特定资产 |
|---|---|
| **（1）**|**无可参考的活跃市场价格且采用估值技术仍导致公允价值存在重大不确定性的资产** |
| **（2）**|**按摊余成本计量且计提资产减值准备仍导致资产价值存在重大不确定性的资产** |
| **（3）**|**其他资产价值存在重大不确定性的资产** |

##### ② 启用条件与程序 P550

> **当基金持有特定资产时，由于特定资产的公允价值存在较高的不确定性，基金的净值很难进行客观、准确的计算，这对开放式基金的估值和申购赎回都造成重大挑战**；**为最大限度保护基金份额持有人利益的原则，基金管理人经与基金托管人协商一致，并咨询会计师事务所意见后，可以依照法律法规及基金合同的约定启用侧袋机制**。

> **特定资产进入侧袋，与基金本身的主袋分隔**。

##### ③ 侧袋运作的六条规则（必背） P550

| # | 规则 |
|---|---|
| **1**|**侧袋在启用后，相关份额不能进行申购或赎回，需等待侧袋中特定资产恢复流动性后，特定资产被处置变现并向投资者分配** |
| **2**|**侧袋机制启用后，主袋的申购和赎回不受影响，投资者只能参与主袋的申购** |
| **3**|**单个侧袋账户中可包含不同类别的特定资产** |
| **4**|**单一基金产品可存在多个侧袋账户，不同侧袋账户需单独设置账号，分开进行核算** |
| **5**|**因侧袋资产价值存在重大不确定性，为避免产生误导，基金管理人应当暂停披露侧袋账户份额净值，并对基金简称进行特殊标识** |
| **6**|**货币市场基金与交易型开放式指数基金（ETF）原则上不采用侧袋机制** |

##### ④ 侧袋机制与估值调整、暂停估值的优先顺序（易考） P550

> **当基金投资组合出现风险时，相关资产存在可参考的活跃市场价格或使用估值技术确定的公允价值不存在重大不确定性的，基金管理人应优先调整估值而非启用侧袋机制**。

> **当基金持有特定资产的比例超过 50% 时，基金管理人应暂停估值而非启用侧袋机制**。

**决策顺序记忆**：**能调整估值 → 优先调整估值；调整估值仍有重大不确定性 → 启用侧袋；特定资产超 50% → 暂停估值**。

#### （五）估值方法速查表

| 品种 | 关键估值基准 |
|---|---|
| **IPO 未上市股票**|**估值技术** |
| **送股/转增/配股/公开增发未上市**|**同一股票市价；无交易用最近一日收盘价** |
| **上市非流通受限**|**估值日收盘价** |
| **上市流通受限**|**FV = S × (1 − LoMD)，LoMD = P/S（AAP 模型）** |
| **不含权固收**|**第三方估值机构当日估值全价** |
| **含权固收**|**唯一估值全价或推荐估值全价** |
| **可转债（全价/净价交易）**|**收盘价 / 收盘价＋每百元税前应计利息（8 位）** |
| **FOF 投境内非货基、LOF、ETF 联接**|**份额净值** |
| **FOF 投 ETF、定期开放、封闭式**|**收盘价** |
| **FOF 投货币基金**|**万份收益计提** |
| **期货、期权**|**当日结算价** |
| **凭证类信用衍生品**|**活跃市场未调整报价／调整报价／估值技术** |
| **贵金属现货／集中定价／延期**|**收盘价／午盘基准价／结算价** |

### 15.1.d 【了解】QDII 基金资产估值的特殊规定 P550–P551

**大纲原文**：了解 QDII 基金资产估值的特殊规定

#### （一）估值依据与责任主体 P550

> **根据《合格境内机构投资者境外证券投资管理试行办法》的有关规定，基金托管人在履行职责时应确保基金的份额净值按照有关法律法规、基金合同和集合资产管理合同规定的方法进行计算**。

> **在实践中，基金管理公司是 QDII 基金的会计核算和资产估值的责任主体，托管人负有复核责任**。

#### （二）净值计算及披露的八项规定（必背） P550–P551

> **在《关于实施〈合格境内机构投资者境外证券投资管理试行办法〉有关问题的通知》（证监发〔2007〕81 号）中，对 QDII 基金的净值计算及披露做了明确规定**：

| # | 规定 |
|---|---|
| **（1）**|**基金份额净值应当至少每周计算并披露一次，如基金投资衍生品，应当在每个工作日计算并披露** |
| **（2）**|**基金份额净值应当在估值日后 2 个工作日内披露** |
| **（3）**|**基金份额净值应当以人民币或美元等主要外汇货币单独或同时计算并披露** |
| **（4）**|**基金资产的每一买入、卖出交易应当在最近份额净值的计算中得到反映** |
| **（5）**|**流动性受限的证券估值可以参照国际会计准则进行** |
| **（6）**|**衍生品的估值可以参照国际会计准则进行** |
| **（7）**|**境内机构投资者应当合理确定开放式基金资产价格的选取时间，并在招募说明书和基金合同中载明** |
| **（8）**|**开放式基金净值及申购、赎回价格的具体计算方法应当在基金、集合计划合同和招募说明书中载明，并明确小数点后的位数** |

#### （三）QDII 与普通公募基金估值对比（必背）

| 维度 | **普通公募基金**|**QDII 基金** |
|---|---|---|
| **责任主体**|**基金管理人（托管人复核）**|**基金管理人（托管人复核）** |
| **估值频率**|**开放式：每个交易日估值、次日披露**|**至少每周计算并披露一次；投资衍生品的须每个工作日** |
| **披露时限**|**不晚于次日**|**估值日后 2 个工作日内** |
| **计价货币**|**人民币**|**人民币或美元等主要外汇货币，单独或同时** |
| **特殊方法**| — |**流动性受限证券、衍生品估值可参照国际会计准则** |

## 15.2 基金费用

### 15.2.a 【掌握】基金费用的种类，基金管理费、托管费和销售服务费的计提标准和计提方式 P551–P553

**大纲原文**：掌握基金费用的种类，基金管理费、托管费和销售服务费的计提标准和计提方式

#### （一）两类费用的本质区分（核心考点） P551

> **在基金运作过程中涉及的费用可分为两大类**：

| 类别 | 内容 | 承担者 | 是否参与会计核算 |
|---|---|---|---|
| **第一类：基金销售过程中发生的费用**|**主要包括申购费、赎回费及基金转换费**；**这些费用直接从投资者申购、赎回或转换的金额中收取**|**由基金投资者自己承担**|**并不参与基金的会计核算** |
| **第二类：基金管理过程中发生的费用**|**主要包括基金管理费、基金托管费、持有人大会费用等**|**由基金资产承担**|**需直接从基金资产中列支** |

> **对于不收取申购费（认购费）、赎回费的基金，基金管理人可以依照相关规定从基金财产中持续计提一定比例的销售服务费，专门用于本基金的销售和对基金持有人的服务**。

> **上述两大类费用的性质是截然不同的**；**本节所述基金费用仅指第二类费用，其种类及计提标准一般都在基金合同及基金招募说明书中明确规定**。

#### （二）可从基金财产中列支的九项费用（必背） P551–P552

> **下列与基金有关的费用可以从基金财产中列支**：

| # | 费用项目 |
|---|---|
| **（1）**|**基金管理人报酬** |
| **（2）**|**基金托管费** |
| **（3）**|**基金销售服务费** |
| **（4）**|**基金运作过程中发生的注册登记费、上市年费、信息披露费用和账户服务费** |
| **（5）**|**基金运作过程中发生的会计师费、审计费、律师费、公证费、诉讼费和仲裁费** |
| **（6）**|**基金份额持有人大会费用** |
| **（7）**|**基金的银行汇划费用** |
| **（8）**|**基金运作过程中发生的证券、期货、期权等交易费用** |
| **（9）**|**按照国家有关规定和基金合同约定，可以在基金财产中列支的其他费用** |

#### （三）基金管理人报酬（三种浮动方式必背） P552

> **基金管理人报酬，是指基金管理人管理基金资产而向基金收取的费用，包括基础管理费和业绩报酬**。

> **我国绝大多数公募基金采用固定费率收取管理人报酬，也有部分公募基金采用浮动费率的模式**。

**三种浮动方式（必考）**：

| # | 浮动方式 | 具体内容 |
|---|---|---|
| **一**|**与基金规模挂钩**|**基金规模超过一定数值后管理费率降低** |
| **二**|**与基金业绩挂钩**|**分为基础管理费及或有管理费**——**如基金累计净值低于期初净值，则或有管理费返还基金资产；如基金年化收益率超过一定数值，则计提业绩报酬** |
| **三**|**与投资者持有时间挂钩**|**根据投资者持有基金时间长短进行不同的管理费率设置，持有时间越长，管理费率越低** |

##### 案例 15-4：阶梯式（与规模挂钩）管理费率（必考） P552

> **某基金在其基金合同中约定，基金根据总规模设置阶梯式管理费率，当基金总规模超过一定值时，对于超出部分按较低的管理费率收取管理费**。

| 基金规模（亿元） | 分档固定费率水平/年 | 整体年固定管理费率水平 |
|---|---|---|
| **100**|**1.20%**|**1.20%** |
| **X>100** | **对超过 100 亿元的部分按 0.60% 的费率收取** | $$[1.2\%\times100+0.6\%\times(X-100)]/X$$ |

> **可以看出，该基金是一只浮动费率基金，其浮动方式为与基金规模挂钩**——**当基金资产净值不高于 100 亿元时，管理费年费费率为 1.20%；当大于 100 亿元时，100 亿元以内的部分适用 1.20%，超过 100 亿元的部分适用 0.60%**。

> **私募基金因投资运作特点和投资者结构不同，一般会在基金合同中约定管理人业绩报酬相关条款，例如计提基准、计提比例、计提时点和计提频率等**。

#### （四）基金托管费与销售服务费 P552

| 费用 | 定义 |
|---|---|
| **基金托管费**|**基金托管人为基金提供托管服务而向基金收取的费用** |
| **基金销售服务费**|**从基金资产中扣除的用于支付销售机构佣金以及基金管理人的基金营销广告费、促销活动费、持有人服务费等方面的费用** |

#### （五）计提公式（必考） P552–P553

> **目前，我国基金的基础管理费、基金托管费及基金销售服务费一般是按前一日基金资产净值的一定比例逐日计提，按月支付**。

$$H=\frac{E\times R}{\text{当年实际天数}}$$

| 符号 | 含义 |
|---|---|
| **H**|**每日计提的费用** |
| **E**|**前一日的基金资产净值** |
| **R**|**年费率** |

##### 案例 15-5：每日管理费计提（必考） P553

> **假设某封闭式基金 7 月 18 日的基金资产净值为 35 000 万元，7 月 19 日的基金资产净值为 35 125 万元，该基金的管理费为固定费率模式，年费率为 0.25%，该年实际天数为 365 天**。

$$H=\frac{35\,000\times0.25\%}{365}=0.2397\ (\text{万元})$$

**易错点**：**分子用的是"前一日"（7 月 18 日）的基金资产净值 35 000 万元，不是 7 月 19 日的 35 125 万元**。

#### （六）基金交易费（境内 vs 港股通） P553

> **基金交易费，指基金在进行证券买卖交易时所发生的相关交易费用**。

| 投资范围 | 交易费用构成 |
|---|---|
| **境内股票**|**印花税、交易佣金、过户费、经手费、证管费等** |
| **港股通标的股票**|**印花税、交易佣金、股份交收费、交易征费等** |

> **交易佣金由证券公司按成交金额的一定比例向基金收取**；**印花税、过户费、经手费、证管费、股份交收费、交易征费等则由登记公司或交易所按有关规定收取**。

> **参与银行间债券市场交易的，还需向中央国债登记结算有限责任公司或银行间市场清算所股份有限公司支付银行间账户服务费和结算手续费，向全国银行间同业拆借中心支付交易手续费等服务费用**。

##### 案例 15-6：交易佣金计算 P553

> **某基金佣金协议约定，自 2024 年 7 月 1 日起，某交易单元股票交易佣金费率为 0.5‰；7 月 15 日，该基金通过该交易单元买入股票 A，成交金额为 1 928 370 元，成交数量为 73 000 股**。

$$\text{交易佣金}=1\,928\,370\times0.0005=964.19\ (\text{元})$$

#### （七）基金运作费 P553

> **基金运作费指为保证基金正常运作而发生的应由基金承担的费用**，包括：**审计费、律师费、上市年费、分红手续费、持有人大会费、开户费、银行汇划手续费等**。

#### （八）基金费用要点速查表

| 费用 | 计提基数 | 计提/支付方式 |
|---|---|---|
| **管理费**|**前一日基金资产净值**|**逐日计提，按月支付** |
| **托管费**|**前一日基金资产净值**|**逐日计提，按月支付** |
| **销售服务费**|**前一日基金资产净值**|**逐日计提，按月支付** |
| **交易佣金**|**成交金额**|**按笔收取** |
| **运作费**| — |**按实际发生列支** |

### 15.2.b 【了解】不列入基金费用的项目种类 P553–P554

**大纲原文**：了解不列入基金费用的项目种类

> **以下四项不得从基金财产中列支**：

| # | 不列入基金费用的项目 |
|---|---|
| **（1）**|**基金管理人和基金托管人因未履行或未完全履行义务导致的费用支出或基金财产的损失** |
| **（2）**|**基金管理人和基金托管人处理与基金运作无关的事项发生的费用** |
| **（3）**|**基金合同生效前的相关费用，包括但不限于验资费、会计师和律师费、信息披露费用等费用** |
| **（4）**|**指数基金标的指数许可使用费** |

**记忆逻辑**：
- **(1)(2) 是"过错方自担"**——**管理人与托管人自身失职或与基金运作无关的花费不能由基金财产买单**；
- **(3) 是"时点界限"**——**基金合同生效前的费用不属于基金运作费用**；
- **(4) 是"特殊排除"**——**指数许可使用费由管理人承担，不从基金财产列支**。

## 15.3 基金会计核算

### 15.3.a 【掌握】基金会计核算的特点和主要内容 P554–P557

**大纲原文**：掌握基金会计核算的特点和主要内容

#### （一）基金会计核算的总体框架 P554

> **基金会计核算是指收集、整理、加工有关基金投资运作的会计信息，准确记录基金资产变化情况，及时向相关各方提供财务数据以及会计报表的过程**。

> **基金管理公司是证券投资基金会计核算的责任主体，应当以所管理的单只基金为主体进行会计确认、计量和报告**；**基金启用侧袋机制的，侧袋账户与主袋账户仍属同一会计主体**。

> **基金管理公司应确保每只基金单独管理、单独建账、单独核算，保证不同基金在名册登记、账户设置、资金划拨、账簿记录等方面相互独立**。

> **同时，由于基金托管人对基金管理公司计算的基金资产净值以及信息披露事项有复核责任，因此基金托管人也需要对所托管的证券投资基金进行会计核算，并将有关结果同基金管理公司相核对**。

**会计期间与记账本位币**：

> **我国基金的会计年度为公历 1 月 1 日起至 12 月 31 日止，首期会计期间的起始日为基金成立日，末期会计期间的结束日为基金终止日**；**基金核算以人民币为记账本位币**。

#### （二）四个特点（核心考点） P554–P556

##### ① 基金会计核算主体 P554

> **会计核算主体是会计为之服务的特定对象**；**企业会计核算以企业为会计核算主体，基金会计则以证券投资基金为会计核算主体**。

> **基金会计核算的责任主体是对基金进行会计核算的基金管理公司和基金托管人，其中前者承担主会计责任**。

**界定这一会计主体的两点意义（必考）**：

| # | 意义 |
|---|---|
| **一**|**将基金管理公司的经营活动与证券投资基金的投资管理活动区别开来** |
| **二**|**将基金管理公司管理的不同基金之间的投资管理活动区别开来** |

> **明确了会计主体，就界定了从事会计工作和提供会计信息的空间范围**。

##### ② 基金会计分期 P555

> **传统的会计分期一般以年度、半年、季度和月份为单位**；**但对于证券投资基金来说，这种期间的划分远远不能满足投资者的需要**；**因此，从及时性原则出发，基金会计期间划分必然更加细化，即以周甚至是以日为核算披露期间**。

> **目前，我国公募基金会计核算均已细化到日**——**开放式基金的申购、赎回逐日进行，逐日计算债券利息、银行存款利息等，逐日预提或待摊对基金资产净值影响重大的费用，逐日对基金资产进行估值确认，货币市场基金一般每日结转损益等**。

##### ③ 基金资产会计分类（三类，必背） P555

> **根据《企业会计准则第 22 号——金融工具确认和计量》，依据管理金融资产的业务模式和金融资产的合同现金流量特征，金融资产在初始确认时分为三类**：

| # | 分类 |
|---|---|
| **1**|**以公允价值计量且其变动计入当期损益的金融资产** |
| **2**|**以公允价值计量且其变动计入其他综合收益的金融资产** |
| **3**|**以摊余成本计量的金融资产** |

> **基金通常将所持有的金融资产划分为以公允价值计量且其变动计入当期损益的金融资产**。

**划为摊余成本计量的两个条件（易考）**：

| # | 条件 |
|---|---|
| **1**|**相关金融资产的合同现金流量特征必须与基本借贷安排一致，即相关金融资产在特定日期产生的合同现金流量仅为本金和以未偿付本金金额为基础的利息的支付** |
| **2**|**应采用适当的风险控制手段，对金融资产净值的公允性进行评估**；**当摊余成本计量已不能真实公允反映金融资产净值时，应当调整会计核算和估值方法** |

##### ④ 基金资产会计计量（预期信用损失三阶段，必考） P555–P556

> **基金应当按照《企业会计准则第 39 号——公允价值计量》的规定，确定金融资产的公允价值**。

> **基金应当按照《企业会计准则第 22 号——金融工具确认和计量》的规定，对以摊余成本计量的金融资产，以预期信用损失为基础进行减值会计处理并确认损失准备**。

> **预期信用损失，是指在考虑有关过去事项、当前状况以及对未来经济状况的预测等合理且有依据的信息的基础上，以发生违约的风险为权重，计算合同应收的现金流量与预期能收到的现金流量之间差额的现值的概率加权金额**。

**信用风险三阶段与损失准备计量（必背）**：

| 阶段 | 情形 | 损失准备计量 |
|---|---|---|
| **第一阶段**|**金融工具自初始确认后信用风险未显著增加**|**按照未来 12 个月内（若预期存续期少于 12 个月，则为预期存续期内）的预期信用损失计量损失准备** |
| **第二阶段**|**金融工具自初始确认后信用风险已显著增加但尚未发生信用减值**|**按照该工具整个存续期的预期信用损失计量损失准备** |
| **第三阶段**|**金融工具自初始确认后已经发生信用减值**|**按照该工具整个存续期的预期信用损失计量损失准备** |

> **基金确定金融工具在估值日只具有较低的信用风险的，可以假设该金融工具信用风险自初始确认后并未显著增加（即处于第一阶段）**。

#### （三）基金会计核算的九类主要内容（必背） P556–P557

> **根据《企业会计准则》《资产管理产品相关会计处理规定》《证券投资基金会计核算操作实务手册》，基金的会计核算对象包括资产类、负债类、资产负债共同类、所有者权益类和损益类的核算**。

| # | 业务类别 | 内容要点 |
|---|---|---|
| **（1）**|**证券和衍生工具交易核算**|**主要投资于政策允许范围内的有价证券和衍生金融工具，包括股票、债券、资产支持证券、基金等有价证券和衍生金融工具的买卖及回购交易等** |
| **（2）**|**权益核算**|**指与基金持有证券的上市公司有关的、所有涉及该证券权益变动并进而影响基金权益变动的事项，包括发行新股、发放股息和红利、配股等公司行为的核算** |
| **（3）**|**利息和利息调整核算**|**利息主要包括债券利息、银行存款利息、清算备付金利息、回购利息、转融通利息等**；**各类资产利息均应按日计提，并于当日确认收益**；**利息调整是按票面或合同利率计算确定的利息与按实际利率法计算确定的利息收入之间的差额，主要应用于以摊余成本计量的资产** |
| **（4）**|**费用核算**|**主要包括计提基金管理费、业绩报酬、托管费、预提费用、摊销费用、交易费用等**；**这些费用一般也按日计提，并于当日确认为费用** |
| **（5）**|**基金申购与赎回核算**|**开放式基金还需对基金份额的申购与赎回情况、转入与转出情况以及基金份额拆分进行会计核算** |
| **（6）**|**估值核算**|**基金逐日对其资产按规定进行估值，并于当日将投资估值增（减）值确认为公允价值变动损益** |
| **（7）**|**利润核算**|**指会计期末结转基金损益，并按照规定对基金分红、除权、红利再投资等进行核算**；**证券投资基金一般在月末结转当期损益，按固定价格报价的货币市场基金一般逐日结转损益** |
| **（8）**|**基金财务会计报告**|**分为年度、半年度、季度和月度财务会计报告**；**季度、月度通常仅指会计报表；半年度、年度至少应披露会计报表和会计报表附注**；**基金会计报表包括资产负债表、利润表及净值变动表等** |
| **（9）**|**基金会计核算的复核**|**基金管理人与基金托管人分别进行账簿设置、账套管理、账务处理及基金净值计算**；**基金托管人按照规定对基金管理人的会计核算结果进行复核审查并出具意见** |

**摊销费用与预提费用的区分（易考）**：

| 类型 | 定义 |
|---|---|
| **摊销费用**|**在基金受益期内已经发生且金额较大影响基金份额净值小数点后第 n 位（合同约定的保留位数）、应分摊至当期及未来会计期间的费用** |
| **预提费用**|**预计将发生且金额较大影响基金份额净值小数点后第 n 位、应在受益期内预提计入当期的费用** |

> **待摊费用和预提费用包括注册登记费、上市年费、信息披露费、账户服务费、审计费和律师费等**。

## 15.4 基金财务会计报告分析

### 15.4.a 【理解】基金财务报告分析的目的和主要内容 P557–P561

**大纲原文**：理解基金财务报告分析的目的和主要内容

#### （一）基金财务会计报告的构成 P557

> **基金财务会计报告是指基金对外提供的反映基金某一特定日期的财务状况和某一会计期间的经营成果、现金流量等会计信息的文件**。

| 构成 | 内容 |
|---|---|
| **会计报表**|**资产负债表、利润表和净资产变动表等报表** |
| **会计报表附注**|**重要会计政策和会计估计、会计政策和会计估计变更、差错更正的说明、报表重要项目的说明和关联方关系及其交易等内容** |

#### （二）分析的目的（三点，必背） P557

> **从基金投资者的角度来看，除了关注基金净值的变化外，还需要分析能够引起基金净值变化的各种因素**；**通过对基金财务会计报告以及基金所披露的其他信息资料（如投资组合报告）的分析，能够更为深入地了解基金情况，从而为投资决策提供参考**。

**一般而言，基金财务会计报告分析可以达到以下目的**：

| # | 目的 |
|---|---|
| **1**|**评价基金过去的经营业绩及投资管理能力** |
| **2**|**通过分析基金现时的资产配置及投资组合状况来了解基金的投资状况** |
| **3**|**预测基金未来的发展趋势，为基金投资者的投资决策提供依据** |

#### （三）分析的五个方面（核心考点） P557–P561

> **一般来说，对股票基金及混合基金的财务会计报告的分析包括五个方面**。

##### ① 基金持仓结构分析 P558

> **基金定期报告的投资组合报告中要求披露基金资产组合情况，包括权益投资、固定收益投资、银行存款和结算备付金合计等项目占基金总资产的比例**。

$$\text{权益投资占基金总资产的比例}=\frac{\text{权益投资}}{\text{基金总资产}}\times100\%$$

$$\text{固定收益投资占基金总资产的比例}=\frac{\text{固定收益投资}}{\text{基金总资产}}\times100\%$$

$$\text{银行存款和结算备付金合计占基金总资产的比例}=\frac{\text{银行存款和结算备付金合计}}{\text{基金总资产}}\times100\%$$

> **在基金的定期报告中，还披露股票投资在各行业的分布情况，通过行业分布可以分析出基金的重点投资方向**：

$$\text{某行业投资占基金资产净值的比例}=\frac{\text{该行业股票投资市值}}{\text{基金资产净值}}\times100\%$$

##### 案例 15-7：固定收益投资占比 P558

> **假设某基金债券投资金额为 50 000 元，资产支持证券投资金额为 30 000 元，基金总资产为 1 000 000 元**。

$$\text{固定收益投资占基金总资产的比例}=\frac{50\,000+30\,000}{1\,000\,000}\times100\%=8\%$$

##### 案例 15-8：市场波动导致占比下降（易错点） P558

> **期初某基金总资产为 1 亿元，股票市值 7 000 万元，现金 3 000 万元，权益投资占基金总资产的比例为 70%；期间基金经理未进行任何操作，但由于期间市场波动，期末股票市值变为 6 000 万元，基金总资产变为 9 000 万元**。

$$\frac{6\,000}{9\,000}\times100\%=66.7\%$$

**在进行持仓结构的分析时应注意，权益投资占基金总资产的比例如因发生少量变动，并不意味着基金经理一定进行了增仓或减仓操作，因为市场波动也可能引起计算结果的变动**。

##### ② 基金盈利能力和分红能力分析 P558–P560

> **在基金定期报告中，基金一般会披露本期利润、本期已实现收益、加权平均基金份额本期利润、本期加权平均净值利润率、本期基金份额净值增长率、期末可供分配利润、期末可供分配基金份额利润、期末基金资产净值、期末基金份额净值等指标**。

| 指标 | 定义 |
|---|---|
| **本期利润**|**反映基金本期产生的净收益（或净亏损），是指本期利息收入、投资收益、公允价值变动收益、其他收入等收入项目扣除管理人报酬、托管费、利息支出等费用项目后的余额** |
| **本期已实现收益**|**反映基金本期产生的已实现净收益（或净亏损），是指本期利润扣除公允价值变动收益后的余额** |
| **期末可供分配利润**|**反映基金截至目前的可分红金额，是指期末未分配利润与未分配利润中已实现部分的孰低数** |
| **期末可供分配基金份额利润**|**反映基金截至目前每份额可分红的金额** |

$$\text{本期已实现收益}=\text{本期利润}-\text{公允价值变动收益}$$

$$\text{期末可供分配基金份额利润}=\frac{\text{期末可供分配利润}}{\text{期末基金单位总份额}}$$

> **本期利润和本期已实现收益反映的都是基金的盈利能力，但并不能反映出不同基金的盈利能力强弱**——**例如 A、B 两只基金，A 基金的本期利润高于 B 基金，有可能是因为 A 基金的盈利能力强，也有可能是因为 A 基金的基金规模大**；**如果想要比较不同基金的盈利能力，则更应关注基金的净值表现指标，比如基金份额净值增长率**。

##### 案例 15-9：本期利润与本期已实现收益（必考） P559

> **某开放式基金 2023 年年度报告利润表节选**：

| 项目 | 本期金额（元） |
|---|---|
| **一、营业总收入** | — |
| **1. 利息收入**|**100 000.00** |
| **2. 投资收益**|**30 000.00** |
| **3. 公允价值变动收益**|**−10 000.00** |
| **5. 其他收入**|**5 000.00** |
| **二、营业总支出** | — |
| **1. 管理人报酬**|**3 000.00** |
| **2. 托管费**|**1 000.00** |
| **7. 税金及附加**|**200.00** |
| **8. 其他费用**|**500.00** |

$$\text{本期利润}=(100\,000+30\,000-10\,000+5\,000)-(3\,000+1\,000+200+500)=120\,300\ (\text{元})$$

$$\text{本期已实现收益}=120\,300-(-10\,000)=130\,300\ (\text{元})$$

**注意**：**公允价值变动收益为负数时，本期已实现收益反而高于本期利润（−(−10 000) 相当于加回 10 000）**。

##### 案例 15-10：期末可供分配利润（必考） P560

> **假设某基金在 2023 年 12 月 31 日的未分配利润为 600 000 元，未分配利润已实现部分为 500 000 元，基金单位总份额为 10 000 000 份**。

| 项目 | 结果 |
|---|---|
| **期末可供分配利润**（**取孰低数**） |**500 000（元）** |
| **期末可供分配基金份额利润**|**500 000 ÷ 10 000 000 = 0.02（元/份）** |

##### ③ 基金收入情况分析 P560

> **基金收入包括利息收入、投资收益、公允价值变动损益和其他收入**。

| 收入类别 | 构成 |
|---|---|
| **利息收入**|**存款利息收入、债券利息收入、资产支持证券利息收入、证券出借利息收入和买入返售金融资产收入** |
| **投资收益**|**股票投资收益、基金投资收益、债券投资收益、资产支持证券投资收益、贵金属投资收益、衍生工具收益、股利收益和其他投资收益** |

> **对于证券投资基金来说，这些收入是其份额净值变动的源泉，通过分析基金的收入结构可以了解基金的投资情况**；**通过对基金收入来源的分析，尤其是通过基金间收入来源结构的比较分析，可以更为深入地了解该基金具体投资状况**。

##### ④ 基金费用情况分析 P560

> **基金费用一般包括管理人报酬、托管费、销售服务费、利息支出、信用减值损失、税金及附加和其他费用**。

> **可以看到，基金费用中并没有单独列示交易费用，这是因为在新金融工具准则下，基金发生的交易费用都已经反映在了投资收益**。

##### 案例 15-11：股票投资收益（必考） P560

$$\text{股票投资收益}=\text{卖出股票成交总额}-\text{卖出股票成本总额}-\text{交易费用}$$

| 项目 | 本期金额（元） |
|---|---|
| **卖出股票成交总额**|**900 000.00** |
| **减：卖出股票成本总额**|**800 000.00** |
| **减：交易费用**|**1 000.00** |
| **买卖股票差价收入**|**799 000.00** |

##### ⑤ 基金份额变动分析 P560–P561

> **对于开放式基金来说，基金的份额会随申购、赎回活动而变动，基金定期报告中会披露基金份额的变动情况**——**通过分析份额变动可以了解基金的规模变化与投资者申赎行为**。

#### （四）分析目的与内容速查表

| 分析方面 | 核心指标/公式 |
|---|---|
| **持仓结构**|**权益投资/基金总资产；固定收益投资/基金总资产；银行存款和结算备付金合计/基金总资产；某行业股票投资市值/基金资产净值** |
| **盈利能力**|**本期利润、本期已实现收益（本期利润−公允价值变动收益）、本期基金份额净值增长率** |
| **分红能力**|**期末可供分配利润（未分配利润与已实现部分的孰低数）、期末可供分配基金份额利润** |
| **收入情况**|**利息收入、投资收益、公允价值变动损益、其他收入** |
| **费用情况**|**管理人报酬、托管费、销售服务费、利息支出、信用减值损失、税金及附加、其他费用**（**不含单列交易费用**） |
| **份额变动**|**申购、赎回引起的份额变化** |

## 本章小结

#### 一、核心数字速查

| 数字 | 含义 |
|---|---|
| **0.25%**|**改变估值技术致净值变化须咨询会计师的阈值；估值原则第 3 条的调整门槛；计价错误须报告证监会的阈值** |
| **0.5%**|**计价错误须编制临时报告书并登载指定报刊网站的阈值** |
| **50%**|**暂停估值的前一估值日资产比例门槛；特定资产超此比例应暂停估值而非启用侧袋** |
| **次日**|**开放式基金披露份额净值的最迟时限** |
| **每周**|**封闭式基金披露份额净值的最低频率；QDII 计算并披露份额净值的最低频率** |
| **2 个工作日**|**QDII 份额净值披露时限** |
| **12 个月**|**预期信用损失第一阶段计量期限；恒生综合小型股纳入港股通的市值考察期** |
| **8 位**|**可转债净价交易时每百元税前应计利息保留位数；ETF 折算比例保留位数** |
| **1.20% / 0.60%**|**案例 15-4 阶梯式管理费率（100 亿元以内 / 超出部分）** |
| **当年实际天数**|**逐日计提费用的分母（通常 365 天）** |
| **1 月 1 日—12 月 31 日**|**基金会计年度** |
| **人民币**|**基金核算记账本位币** |

#### 二、易错点清单

1. **估值第一责任主体是基金管理人，托管人只负复核责任**；
2. **参考中基协估值指引、委托基金服务机构估值，均不能免除管理人责任**；
3. **限制"针对资产持有者"的，不作为特征考虑；管理人大量持有不考虑溢价折价**；
4. **经济环境或发行人重大变化致潜在估值调整影响 ≥0.25% 才需调整估值**；
5. **期货与期权均按当日结算价估值，无结算价用最近交易日结算价**；
6. **FOF 投 ETF 按收盘价，ETF 联接基金投 ETF 按份额净值**；
7. **可转债全价交易取收盘价，净价交易取收盘价＋应计利息**；
8. **计价错误 0.25% 报告证监会、0.5% 编临时报告书**；
9. **共同行为致损承担连带赔偿责任**；
10. **侧袋份额不能申赎、主袋不受影响；货基与 ETF 原则上不采用侧袋**；
11. **销售过程费用（申购费、赎回费、转换费）不参与会计核算，由投资者承担**；
12. **管理费、托管费、销售服务费按前一日净值逐日计提、按月支付**；
13. **计提公式分子用前一日净值，不是当日净值**；
14. **基金合同生效前的验资费等、指数许可使用费不列入基金费用**；
15. **侧袋账户与主袋账户仍属同一会计主体**；
16. **基金会计分期细化到日（以周甚至以日）**；
17. **基金通常将金融资产划为"以公允价值计量且其变动计入当期损益"**；
18. **证券投资基金月末结转损益；固定价格报价的货币市场基金逐日结转**；
19. **本期已实现收益 = 本期利润 − 公允价值变动收益（公允价值变动为负时反而更高）**；
20. **期末可供分配利润取"未分配利润"与"已实现部分"的孰低数**；
21. **基金费用中不单独列示交易费用（已反映在投资收益）**；
22. **持仓结构占比下降不一定代表减仓，可能是市场波动**。
