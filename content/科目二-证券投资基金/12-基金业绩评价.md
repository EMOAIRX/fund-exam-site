## 12.1 基金业绩评价概述

### 12.1.a 【理解】基金业绩评价的定义、目的、意义和应考虑的因素 P410–P415

**大纲原文**：理解基金业绩评价的定义、目的、意义和应考虑的因素

#### （一）定义 P410

> **基金业绩评价是指通过一系列科学、系统的量化和定性分析方法，对基金的业绩表现进行全面、客观的衡量、分析和评估的过程**。

> **系统的基金业绩评价不仅有助于提升基金管理人的运作效率和决策质量，还能提高市场透明度，为基金投资者提供决策参考，进而推动整个基金业的健康发展**。

#### （二）四个层面的目的与意义（必背） P410–P411

| 层面 | 目的与意义 |
|---|---|
| **① 对基金管理人** | **基金业绩评价是一种重要的管理工具**——**基金管理人通过基金业绩评价审视基金产品的投资目标、风格和策略之间的一致性和匹配度，及时发现潜在问题，优化投资策略和产品结构**；**同时，基金业绩评价还能客观、准确地评价基金经理的投资管理能力，为内部绩效考核提供重要依据** |
| **② 对基金经理** | **业绩评价是一个重要的自我反思和提升工具**——**通过深入的归因分析，基金经理可以厘清基金的收益与亏损来源，检验投资逻辑的有效性，并据此调整投资策略，优化投资组合，提升投资业绩** |
| **③ 对基金投资者** | **专业的业绩评价结果是选择基金的重要参考**——**它帮助投资者理解基金产品的风险收益特征，更好地选择符合自身投资目标的产品**；**基金业绩评价也使投资者能够更全面地认识基金管理人的能力，评估基金管理人是否致力于为其创造长期且可持续的投资回报** |
| **④ 对整个基金行业** | **基金评价机构作为行业中的重要参与者，通过专业且系统的业绩评价，一方面督促基金管理人遵循基金合同，践行"以投资者为本"的理念，提升其为投资者创造长期、可持续回报的投资管理能力，并引导整个行业更为关注投资者长期回报与实际盈利体验；另一方面，帮助投资者更好地理解基金产品，选择与其风险收益特征相匹配的投资工具**——**这有利于维护基金行业秩序，促进基金行业持续健康发展** |

#### （三）理论发展的五个阶段（核心考点） P411–P413

> **基金业绩评价的发展是金融学理论进步、市场复杂化和投资者需求变化的共同结果**；**从早期单纯依赖收益率的衡量，到现代多维度、多因子的分析方法，基金业绩评价经历了显著的演进**。

| 阶段 | 时间 | 核心内容 |
|---|---|---|
| **① 早期阶段** | **20 世纪 60 年代以前** | **主要依赖于两个简单指标——单位净值和投资收益率**；**这一时期的评价方法虽然直观，但缺乏对基金风险的系统性分析，难以反映其综合绩效，也无法为投资者提供准确的风险调整后回报衡量工具** |
| **② 现代投资组合理论与风险调整收益** | **20 世纪 60 年代至 70 年代** | **随着现代投资组合理论（MPT）的提出，基金业绩评价进入了新的阶段**——**马科维茨的均值—方差模型为投资决策引入了量化的风险管理工具，并强调通过分散化投资来降低非系统性风险**；**夏普比率（Sharpe Ratio）和詹森阿尔法（Jensen's Alpha）是这一时期的重要创新，它们为基金业绩评价引入了"风险调整后回报"的概念**——**夏普比率衡量基金在单位风险下的超额回报，而詹森阿尔法则用于评估基金是否跑赢其基于市场风险的预期回报** |
| **③ 主动与被动管理的分野与业绩归因分析** | **20 世纪 70 年代至 80 年代** | **随着有效市场假说（EMH）的提出，基金业绩评价面临新的挑战**——**有效市场假说认为，市场价格已经反映了所有公开信息，因此很难通过主动管理持续战胜市场**；**然而，在半强有效市场和弱有效市场的假设下，主动管理仍然有可能通过信息不对称或市场无效性获取超额收益**；**此时，基金业绩评价不仅关注基金的绝对收益，还开始评估基金经理的主动管理能力**——**业绩归因分析（Performance Attribution）成为重要工具，帮助投资者分解基金的回报来源，区分基金经理的决策能力与市场整体走势**；**投资者开始认识到，基金业绩的持续性是评价基金表现的重要维度**——**研究者们开发了诸如或然表和击中率等方法，用以衡量基金在不同时期内能否保持相对稳定的业绩表现** |
| **④ 多因子模型与基金风格分析** | **20 世纪 90 年代** | **引入了多因子模型，如 Fama-French 三因子模型**——**这一模型扩展了资本资产定价模型（CAPM），表明市场之外的其他因素（如规模效应和价值效应）也会影响基金表现**；**多因子模型的引入推动了基金评价从单一市场基准走向多维度的分析**；**与此同时，基金业绩评价方法中引入了风格分析**——**不同风格的基金在同一市场环境下表现各异，因此基于收益数据和持仓数据的风格分析方法越来越受到重视**；**特别是对于主动管理型基金，风格分析有助于揭示基金经理的投资偏好和策略一致性** |
| **⑤ 技术进步与新趋势** | **2000 年以来** | **技术进步显著提升了数据采集和处理能力，基金业绩评价得以实时处理海量数据、计算复杂指标**；**随着投资者对可持续发展因素（如环境、社会和治理）的关注不断增加，基金业绩评价开始纳入 ESG 指标**；**风险管理因素在现代基金业绩评价中变得越来越重要**——**下行风险、最大回撤等风险指标已成为基金业绩评价的标准工具**；**此外，机器学习和自然语言处理（NLP）技术也开始在基金评价中得到应用** |

**未来趋势**：

> **随着金融市场的不断演进，基金业绩评价将继续发展**；**未来的基金业绩评价将更加注重透明度和责任性，并进一步整合新兴的技术手段和风险管理方法**；**动态基准和多维度风险评估将成为基金业绩评价的重要趋势**。

#### （四）评价应考虑的五类因素（必背） P413–P415

> **为了客观、公正地对基金进行业绩评价，除了业绩本身之外，以下因素也不可忽视**。

##### ① 基金的管理规模 P413

> **基金管理规模对其投资运作效率有着显著影响**：

| 方向 | 影响 |
|---|---|
| **规模较大的优势** | **单位份额的固定费用较低**；**可以通过分散投资更有效地应对非系统性风险** |
| **规模过大的问题** | **规模过大的基金在调仓时可能会对市场产生流动性冲击，导致交易成本上升** |

> **因此，在评价基金业绩时，需要考虑管理规模带来的成本效益和投资交易上的局限性**。

##### ② 业绩的时间区间与市场环境 P413

> **基金的表现既受到时间区间的影响，也与市场环境和经济周期密切相关**；**在不同的时间段内，市场可能经历牛市、熊市或震荡市等不同的阶段，这些市场环境会显著影响基金的业绩表现**；**因此，评价基金业绩时，必须明确分析时间区间，并结合当时的市场环境进行解读**。

> **短期表现可能更多地反映市场的短期波动，而长期表现则能够更好地反映基金经理的投资能力和策略的持续性**；**尤其是主动管理型基金，其业绩不仅依赖于市场的整体走势，还与基金经理的主动决策密切相关**；**因此，基金在不同市场周期中的表现，尤其是在市场下行期的抗风险能力，能为投资者提供更为全面的业绩表现分析**。

**一个关键比较原则**：

> **另外，同一基金在不同时间区间内的业绩表现可能有很大差异，不同基金在不同时间区间内的收益、风险度量不能直接比较**；**因此，进行基金业绩评价时，需要将同一类型基金的业绩在同一时段内比较**。

##### ③ 风险调整后收益（评价核心） P413

> **基金业绩评价的核心在于衡量其风险调整后的收益能力**——**投资管理的本质是风险管理，投资者期望在承担合理风险的基础上获得超额收益**。

> **所以，基金业绩评价重在评价基金产生风险调整后的超额收益的能力**——**基金产生正的风险调整后超额收益的能力是反映基金投资管理能力的最重要的指标，正的风险调整后的超额收益是主动管理型基金为投资者创造经济效益的重要体现**。

##### ④ 幸存者偏差（Survivorship Bias） P414

> **幸存者偏差指的是在评估基金业绩时，只考虑当前仍然存续的基金，而忽略了那些由于表现不佳或其他原因而终止运作的基金**。

> **这种偏差会导致对整体基金业绩的过高估计**——**因为表现不佳的基金往往已经退出市场，而幸存的基金可能表现相对较好**。

**避免方法**：

> **为了避免幸存者偏差，基金评价应包括已终止运作或合并的基金，以确保评价结果的全面性和准确性**；**尤其是在私募基金领域，由于其淘汰率较高，幸存者偏差的影响会更加显著，因此必须特别加以防范**。

##### ⑤ 基金费用 P414

> **基金的各项费用支出直接影响基金最终的净回报，因此理解和分析基金费用构成，对于基金评价至关重要**；**基金管理过程中，从基金资产中列支的费用可归为三类**：

| # | 类别 | 内容 |
|---|---|---|
| **1** | **基金交易成本** | **指基金在进行证券、期货、期权等投资交易时发生的直接成本，如交易佣金、印花税、过户费、经手费及结算费用等**；**这些是投资策略执行过程中不可避免的支出** |
| **2** | **管理人报酬** | **是支付给基金管理人的核心费用，通常包括基础管理费，部分基金还可能涉及浮动管理费或业绩报酬，这些费用通常与基金业绩或规模等因素挂钩**——例如，**基金业绩超越特定基准时可能计提业绩报酬，或者根据投资者持有期限调整管理费率**；**这些激励机制在鼓励管理人有效管理基金的同时，也可能增加投资者成本，因此需重点关注相关条款与潜在成本影响** |
| **3** | **其他基金运营费用** | **用于基金日常运营和合规管理的费用，包括基金托管费、基金销售服务费（适用于某些份额类型）、审计费、律师费、上市年费、信息披露费、分红手续费、持有人大会费、开户费、银行汇划手续费等** |

**三条费用规律**：

> **上述费用的种类和计提标准均在基金合同和招募说明书中明确规定**；**不同类型基金的费用结构和水平可能存在显著差异**——**例如，主动管理型基金的管理人报酬往往较高，反映其较高的研究和管理投入；而被动型基金则相对较低**；**此外，基金规模也可能影响单位基金份额的费用负担，规模较大的基金分摊固定运营成本时往往具备规模效应**；**同时，基金费用可能因合同修订或市场条件变化而发生调整，投资者应持续关注**。

##### ⑥ 两个费用分析指标（必背） P414

| 指标 | 英文 | 定义 |
|---|---|---|
| **费前收益率** | **Gross-of-Fees Return** | **指扣除基金交易成本，但未扣除管理人报酬及其他运营费用前的收益率**；**该指标能够反映基金投资活动本身的表现** |
| **费后收益率** | **Net-of-Fees Return** | **指扣除基金交易成本，并进一步扣除所有管理人报酬及其他运营费用后的收益率**；**该指标反映基金在承担所有费用后的实际净回报** |

> **需要注意的是，费前收益率和费后收益率并非严格定义的法定披露术语，在跨基金或跨管理人进行业绩比较时，应仔细核对各项指标的具体计算方法和费用扣除标准，确保分析时采用的是一致、可比的口径**。

##### ⑥ 投资风格一致性 P415

> **基金的投资风格和策略在很大程度上决定了其业绩表现，而基金的表现通常需要与一个适当的基准进行比较**；**基金的表现只有在与恰当的基准对比时，才能准确反映其真实的超额回报（即阿尔法）**；**如果基准选择不当，可能会导致对基金业绩的误导性解读**；**基准必须与基金的投资风格、资产配置及风险水平相匹配，才能为业绩评价提供客观依据**。

> **在评价基金业绩时，还应重点关注基金实际投资行为与其声明的投资策略之间的一致性**；**当基金的实际持仓结构、行业分布或风险特征显著偏离其公开承诺的投资策略时，可能导致投资者面临与预期不符的风险收益特征**——**这种情况下，即使基金取得了短期的良好业绩，也难以对其进行有效的归因分析和长期评价**。

> **因此，业绩评价应综合考察基金的业绩表现与其投资策略的匹配度，检验其是否始终如一地执行既定策略，并确保所用基准能准确反映基金的投资风格**；**只有当基金保持风格一致性时，才能有效评估基金经理的主动管理能力和基金的相对表现，也才能为投资者提供可靠的资产配置决策依据**。

#### （五）六类考虑因素速查表

| 因素 | 关键影响 | 评价时的处理 |
|---|---|---|
| **管理规模** | **规模大→固定费用摊薄、分散更好；但也→调仓流动性冲击、交易成本上升** | **兼顾成本效益与交易局限性** |
| **时间区间与市场环境** | **牛熊震荡市差异大；短期看波动、长期看能力** | **明确区间、结合环境；同类型基金同时段比较** |
| **风险调整后收益** | **评价的核心** | **以正的风险调整后超额收益能力为最重要指标** |
| **幸存者偏差** | **只算存续基金 → 高估整体业绩** | **须纳入已终止/合并的基金；私募尤其显著** |
| **基金费用** | **直接侵蚀净回报** | **区分交易成本/管理人报酬/其他运营费用；用费前、费后收益率分析** |
| **投资风格一致性** | **基准须与风格、配置、风险水平匹配；实际持仓偏离申明策略 → 风险收益特征不符预期** | **考察业绩与策略匹配度、基准适当性；风格不一致则归因与长期评价失效** |

## 12.2 基金业绩评价指标

> **收益率计算是基金业绩评价的第一步**；**绝对收益指的是证券或投资组合在一定时间区间内所获得的回报，反映了资产的增值或贬值，常用百分比形式表示**；**绝对收益衡量的是投资标的的绝对表现，而不考虑与其他基准或市场的相对比较**。

### 12.2.a 【掌握】绝对收益中持有区间收益率、算术平均收益率、几何平均收益率、年化收益率的计算方法、应用和局限性 P415–P418

**大纲原文**：掌握绝对收益中持有区间收益率、算术平均收益率、几何平均收益率、年化收益率的计算方法、应用和局限性

#### （一）持有区间收益率 P415–P416

> **投资者通过买入并持有证券或其他投资标的获得收益**；**持有期收益率反映了投资者在某一持有周期内的收益情况**；**该收益通常由两部分构成**：

##### ① 两个组成部分 P416

| 组成部分 | 定义 | 公式 |
|---|---|---|
| **资产收益** | **指资产本身价格的增值或贬值，如股票价格的上涨或债券价格的变动** | **资产收益率 = (期末资产价格 − 期初资产价格) / 期初资产价格 × 100%** |
| **收入收益** | **指资产在持有期间产生的收益，如股票的分红或债券的利息** | **收入收益率 = 期间分红（利息）收入 / 期初资产价格 × 100%** |

##### ② 总公式（必背） P416

$$\text{持有期收益率}=\text{资产收益率}+\text{收入收益率}=\frac{\text{期末资产价格}-\text{期初资产价格}+\text{期间分红（利息）收入}}{\text{期初资产价格}}\times100\%$$

##### 案例 12-1：持有区间收益率计算 P416

> **假设某投资者在 2020 年 12 月 31 日，买入 1 手（即 100 股）A 公司股票，价格为 100 元**；**2021 年 12 月 31 日，股价上涨到 105 元**；**同日，A 公司发放 3 元分红**。

| 项目 | 计算 | 结果 |
|---|---|---|
| **资产收益率** | **(105 − 100) / 100 × 100%** | **5%** |
| **收入收益率** | **3 / 100 × 100%** | **3%** |
| **持有区间收益率** | **5% + 3%** | **8%** |

#### （二）平均收益率 P416–P417

> **平均收益率是评估和比较不同基金多期表现的重要指标，主要分为算术平均收益率和几何平均收益率**。

##### ① 算术平均收益率（必背） P416

> **算术平均收益率（R̄_A）计算各期收益率的算术平均值**。

$$\bar{R}_{A}=\frac{\sum_{i=1}^{n}R_{i}}{n}\times100\%$$

**符号**：**R_i** —— **第 i 期收益率**；**n** —— **期数**。

##### ② 几何平均收益率（必背） P416

> **相比之下，几何平均收益率采用了复利的概念，考虑了货币的时间价值**。

$$\bar{R}_{G}=\sqrt[n]{(1+R_{1})(1+R_{2})\cdots(1+R_{n})}-1=\sqrt[n]{\prod_{i=1}^{n}(1+R_{i})}-1$$

##### 案例 12-2：几何平均收益率 P417

> **已知某基金近 3 年来累计收益率为 26%**，**那么应用几何平均收益率计算的该基金的年平均收益率应为**：

$$\bar{R}_{G}=\left[(1+26\%)^{1/3}-1\right]\times100\%=8.01\%$$

##### ③ 两者的大小关系（高频考点） P417

> **通常，算术平均收益率会大于几何平均收益率，且收益率波动越大，两者差距越明显**。

**记忆**：**几何平均考虑复利与波动拖累（volatility drag），波动越剧烈，几何平均被拉得越低**。

#### （三）年化收益率（必背公式） P417–P418

> **年化收益率是一种重要的指标，用于比较不同投资期限或运作期限的基金表现**；**这个指标特别适用于那些运作期限不足一年或不是整年的基金，它能将各种不同期限的收益率标准化为年度基础，从而实现公平比较**。

> **年化收益率的计算通常以几何收益率为基础，将实际投资期限或运作期限转换为年度尺度**。

$$\bar{R}_{ann}=\left(1+R\right)^{\frac{D}{n}}-1$$

**符号**：**R̄_ann** —— **年化收益率**；**R** —— **基金持有期间收益率**；**n** —— **投资或运作时长**；**D** —— **年度标准天数，根据不同投资市场可有所不同**。

##### ① 年度标准天数 D 的三种选择（核心考点） P417

> **我们根据不同投资品种的特性和其交易市场的特点来确定适当的年度标准天数**：

| 投资品种 | 年度标准天数 | 理由 |
|---|---|---|
| **银行存款、票据和债券等金融产品** | **通常采用 360 天（少数情况下可能使用 365 天）** | **这反映了这类产品的标准计息方式** |
| **房地产、普通商业和实业等投资** | **365 天** | **由于它们每天都可能产生收益，不受交易日限制，因此采用 365 天作为计算基础更为合适** |
| **股票、期货等在公开交易市场上交易的产品** | **按实际交易日数量计算** | **应根据市场的实际交易日数量进行计算**；**实践中按实际交易日数量或根据近年的历史平均值进行计算** |

**中国 A 股市场年度交易日数量（表 12-1，必背 243 天）**：

> **中国 A 股市场年度交易天数随着节假日的安排略有变动，从 2012 年到 2023 年，平均值在 243 天**。

| 年份 | 交易日数 | 年份 | 交易日数 | 年份 | 交易日数 |
|---|---|---|---|---|---|
| **2012** | **243** | **2016** | **244** | **2020** | **243** |
| **2013** | **238** | **2017** | **244** | **2021** | **243** |
| **2014** | **245** | **2018** | **243** | **2022** | **242** |
| **2015** | **244** | **2019** | **244** | **2023** | **242** |

> **我国的公募基金的净值计算和公布与 A 股市场交易日一致**；**因此，在计算基金年化收益率时，一般也是用 243 天作为年度标准天数**。

##### 案例 12-3：年化收益率对比 P418

> **已知某股票基金 A 成立了近 9 个月，共计 180 个交易日，累计收益率为 7%；某股票基金 B 运作了近 2 年，共计 450 个交易日，累计收益率为 13%**。

| 基金 | 计算 | 年化收益率 |
|---|---|---|
| **基金 A** | **(1 + 7%)^(243/180) − 1** | **9.56%** |
| **基金 B** | **(1 + 13%)^(243/450) − 1** | **6.82%** |

> **年化收益率可以辅助投资者将不同运作期限基金的收益率统一为年化收益率的形式，从而进行比较与分析**。

#### （四）四个指标的定位、应用与局限性

| 指标 | 公式 | 应用 | 局限性 |
|---|---|---|---|
| **持有区间收益率** | **(期末价 − 期初价 + 分红) / 期初价** | **单一持有周期的总回报** | **仅适用于没有资金流入流出的简单投资情况**；无法处理多次申赎、分红再投资 |
| **算术平均收益率** | **ΣR_i / n** | **各期收益率的简单平均，衡量典型单期表现** | **不考虑复利；会高估长期实际收益（因波动拖累）** |
| **几何平均收益率** | **[Π(1+R_i)]^(1/n) − 1** | **考虑货币时间价值，反映真实的复合增长** | **计算较复杂；对零或负收益区间敏感** |
| **年化收益率** | **(1+R)^(D/n) − 1** | **标准化不同期限的收益，便于横向比较** | **D 的选择影响结果**（360/365/243）；**短期业绩年化会放大波动，不具代表性** |

**四个指标的关键辨析**：
- **算术平均 > 几何平均，波动越大差距越明显**；
- **年化以几何平均为基础**，不是简单乘以年数；
- **持有期收益率**只解决"一次买入持有到期"的问题，**时间加权/资金加权**才解决资金进出问题（见 12.2.b）。

### 12.2.b 【掌握】时间加权收益率、资金加权收益率的概念和运用，以及基金收益率计算中份额净值和复权份额净值的概念 P418–P421

**大纲原文**：掌握时间加权收益率、资金加权收益率的概念和运用，以及基金收益率计算中份额净值和复权份额净值的概念

#### （一）为什么需要加权收益率：持有期收益率的两个困境 P418

> **持有期收益率适用于没有资金流入流出的简单投资情况**；**然而，实际投资管理中有着更为复杂的情况需要处理**：

| # | 复杂情况 |
|---|---|
| **1** | **投资组合包含多个不同的证券，这些证券在持有期内某个或多个时间点进行分红或派息** |
| **2** | **基金在运作期间内遇到申购和赎回，资金量发生变化** |

##### 教材引例（理解难点） P418

> **以某股票基金为例，在 2023 年 12 月 31 日，其净值为 1 亿元，到 2024 年 12 月 31 日，净值变为 1.2 亿元**；**如果净值变化来源仅为资产增值和分红收入的再投资，其收益率 = (1.2 − 1) / 1 × 100% = 20%**。

> **然而，在此期间，基金经历了多次资金流动**：

| 时间 | 资金流动 |
|---|---|
| **2024 年 4 月 15 日** | **客户申购 2 000 万元**——**年末 1.2 亿元净值中有一部分是这笔申购及其投资回报带来的，实际投资回报率应低于 20%** |
| **2024 年 9 月 1 日** | **基金进行了 1 000 万元的分红，该分红也对基金资产有显著的影响** |

> **为了计算该基金 2024 年的收益率，我们可以按照资金进出的时间节点，将 2024 年分为 3 个区间，并分别计算区间收益率**；**每个区间的期末资产净值为对应时间节点现金流发生前的资产净值，期初资产净值则是对应时间节点现金流发生后的资产净值**。

**表 12-2 某基金 2024 年度收益率计算表（必背）**：

| 时间区间 | 期初资产净值（百万元） | 期末资产净值（百万元） | 区间收益率（%） |
|---|---|---|---|
| **2023-12-31 至 2024-04-15** | **100** | **95** | **−5.0** |
| **2024-04-15 至 2024-09-01** | **95 + 20 = 115** | **140** | **21.7** |
| **2024-09-01 至 2024-12-31** | **140 − 10 = 130** | **120** | **−7.7** |

#### （二）时间加权收益率（TWRR） P419

##### ① 计算过程（教材推演） P419

> **假设某投资者在 2023 年 12 月 31 日投资 1 元此基金**：

| 时点 | 推演 |
|---|---|
| **2024 年 4 月 15 日** | **这 1 元受到 5% 的损失，剩余金额 = 1 × (1 − 5%) = 0.95（元）** |
| **2024 年 9 月 1 日** | **0.95 元变为 0.95 × (1 + 21.7%) = 1.156（元）**（**假设将分红全部再投资**） |
| **2024 年 12 月 31 日** | **1.156 元变为 1.156 × (1 − 7.7%) = 1.067（元）** |

> **也就是 2023 年底投资的 1 元，到 2024 年底可获得 (1.067 − 1) / 1 × 100% = 6.7% 的收益**。

**公式（必背）**：

$$R=(1+R_{1})\times(1+R_{2})\times(1+R_{3})-1=(1-5\%)\times(1+21.7\%)\times(1-7.7\%)-1=6.7\%$$

##### ② 定义与三大属性（核心） P419

> **时间加权收益率计算方法将收益率计算区间分为若干个子区间，每个子区间按现金流发生时间点进行划分，我们先计算每个子区间的收益率，然后以几何平均的方式将子区间的收益率连接起来**。

> **时间加权收益率计算方法剔除了资金进出对持有期收益率计算的影响**，并且：

| # | 属性 |
|---|---|
| **1** | **符合中国证监会关于基金净值增长率计算的规定** |
| **2** | **也是全球投资业绩标准（GIPS）的基本要求之一** |

**因此，在评估公募基金业绩时更为常用**（**见下文**）。

#### （三）资金加权收益率（MWRR） P419–P420

##### ① 定义与公式 P419

> **资金加权收益率又称内部收益率（Internal Rate of Return，IRR），一般用于投资项目的整体收益率计算**；**与时间加权收益率不同，资金加权收益率着重考量资金流入流出及其对整体投资回报的影响**。

> **资金加权收益率的计算公式较为复杂，通常通过迭代法求解内部收益率**。

$$0=\sum_{t}\frac{C_{t}}{(1+IRR)^{t}}$$

**符号**：**C_t** —— **第 t 期的现金流**；**IRR** —— **内部收益率**。

> **资金加权收益率适用于投资者资金流动频繁的场景，能够更好地反映实际的资金使用效率**。

##### 案例 12-4：用迭代法求 IRR P419–P420

> **假设一位投资者在一年内进行了以下投资活动**：

| 时间 | 现金流 |
|---|---|
| **1 月 1 日** | **初始投资 100 000 元** |
| **4 月 1 日** | **追加投资 50 000 元** |
| **7 月 1 日** | **撤出 30 000 元** |
| **12 月 31 日** | **投资组合最终价值为 140 000 元** |

**划分期间**：**期间 1：1 月 1 日至 4 月 1 日（3 个月）；期间 2：4 月 1 日至 7 月 1 日（3 个月）；期间 3：7 月 1 日至 12 月 31 日（6 个月）**。

**建立方程**：

$$0=\frac{-100\,000}{(1+IRR)^{0}}+\frac{-50\,000}{(1+IRR)^{3/12}}+\frac{30\,000}{(1+IRR)^{6/12}}+\frac{140\,000}{(1+IRR)^{12/12}}$$

> **这个方程通常需要通过数值方法（如迭代）或者金融计算器来求解**；**解得 IRR ≈ 16.35%**。

##### ② 优点与适用性 P420

> **资金加权收益率是一个能够精确反映投资者实际收益情况的指标，它对资金流动的时间点具有高度敏感性，从而更好地体现了资金的时间价值**；**这种方法尤其适用于资金流动频繁的情况，能够为投资者提供一个更贴近现实的投资回报画面**；**因此，对于那些希望了解自身投资实际回报的投资者来说，资金加权收益率无疑是一个更为合适的衡量标准**。

##### ③ 为什么公募基金不用 MWRR（最高频考点） P420

> **然而，在公募基金的情境下，情况则有所不同**：

> **公募基金通常管理着来自多名投资者的资金，这些投资者可能在不同时间点进行申购和赎回操作**；**这些资金流动与基金经理的投资决策并无直接关联**；**若在此类情况下采用资金加权收益率，计算结果将不可避免地受到这些外部资金流动的影响，从而无法准确反映基金经理的真实投资能力**。

> **相比之下，时间加权收益率能够有效地排除这些外部因素对收益率计算的干扰，从而更加聚焦于基金经理的投资决策和市场表现**；**这种方法不仅符合全球投资业的标准做法，也满足了监管机构的要求，因此在评估公募基金业绩时更为常用**。

#### （四）时间加权 vs 资金加权对比表（必背）

| 维度 | **时间加权收益率（TWRR）** | **资金加权收益率（MWRR / IRR）** |
|---|---|---|
| **核心思想** | **按现金流时点分段，用几何方式连接各段收益率** | **求解使净现值为 0 的内部收益率** |
| **是否考虑资金进出的影响** | **剔除资金进出影响** | **着重考量资金流入流出及其影响** |
| **计算难度** | **分段计算后连乘，较直观** | **需迭代法求解，计算复杂** |
| **反映谁的能力** | **基金经理的投资决策与市场表现** | **投资者自身的实际资金使用效率与回报** |
| **适用场景** | **公募基金业绩评价（监管规定、GIPS 要求）** | **投资者个人账户、资金流动频繁的场景** |
| **教材结论** | **评估公募基金业绩时更为常用** | **更贴近投资者实际回报画面** |

#### （五）基金收益率的计算：三个净值概念 P420–P421

##### ① 基金资产净值 P420

> **基金资产净值是基金总资产减去总负债后的余额，与公司账面价值/权益的概念相似**。

- **资产端**：**主要包括所投资的各类证券，如股票、债券、现金等**；
- **负债端**：**主要包括应付管理人报酬、应付托管费、应付销售服务费等**。

##### ② 份额净值（基金单位资产净值） P420

> **公募基金的资产净值通常以基金单位资产净值的形式公布，即基金净值除以总份额数，亦称"份额净值"**。

$$\text{期末基金单位资产净值}=\frac{\text{期末基金资产净值}}{\text{期末基金总份额}}$$

> **与资产净值不同，基金单位资产净值未考虑基金份额申购赎回的影响**；**利用基金单位资产净值计算收益率，需考虑分红**。

##### ③ 用份额净值计算时间加权收益率（必背公式） P420

> **假定红利发放后立即对本基金进行再投资，且红利以除息前一日的单位净值为计算基准立即进行再投资，分别计算每次分红期间的分段收益率，考察期间的时间加权收益率可由分段收益率连乘得到**。

$$R=\left[(1+R_{1})(1+R_{2})(1+R_{3})\cdots(1+R_{n})-1\right]\times100\%$$

$$R=\left[\frac{NAV_{1}}{NAV_{0}}\times\frac{NAV_{2}}{NAV_{1}-D_{1}}\times\cdots\times\frac{NAV_{n}}{NAV_{n-1}-D_{n-1}}-1\right]\times100\%$$

**符号**：**R_1** —— **第一次分红前的收益率**；**R_2** —— **第一次分红后到第二次分红前的收益率**，以此类推；**NAV_0** —— **期初份额净值**；**NAV_1, …, NAV_{n−1}** —— **各期除息日前一日的份额净值**；**NAV_n** —— **期末份额净值**；**D_1, D_2, …, D_{n−1}** —— **各期份额分红**。

##### 案例 12-5：含分红的时间加权收益率 P421

> **假设某基金在 2020 年 12 月 3 日的单位净值为 1.4848 元，2021 年 9 月 1 日的单位净值为 1.7886 元**；**期间该基金曾于 2021 年 2 月 28 日每份额派发红利 0.275 元**；**该基金 2021 年 2 月 27 日（除息日前一天）的单位净值为 1.8976 元**。

$$R=\left[\frac{1.8976}{1.4848}\times\frac{1.7886}{1.8976-0.275}-1\right]\times100\%=40.87\%$$

> **在实际操作中，基金计算红利一般以除息日的单位净值为计算基准，确定再投资份额**。

##### ④ 复权单位净值（核心概念） P421

> **以上案例中的时间加权收益率即为衡量基金收益率的最重要指标**；**实际工作中，通常会根据该收益率反推基金的复权单位净值，以便其他运用**。

$$\text{复权单位净值}=NAV_{0}\times(1+R)$$

**案例延续**：

> **该基金 2020 年 12 月 3 日的单位净值为 1.4848 元，截至 2021 年 9 月 1 日，该基金收益率为 40.87%**，则：

$$\text{该基金的复权单位净值}=1.4848\times(1+40.87\%)=2.0916\text{（元）}$$

- **脚注**：**目前基金公司尚无披露基金复权单位净值的义务，但常用的基金分析、咨询等软件以及媒体都会计算这一数据**。

##### ⑤ 三个净值概念的对比（必背） P420–P421

| 概念 | 定义 | 是否考虑分红 | 是否考虑分红再投资 | 用途 |
|---|---|---|---|---|
| **基金单位净值（份额净值）** | **基金资产净值 / 基金总份额** | **未考虑** | 否 | **公布净值；直接算收益率会低估（含分红时）** |
| **复权单位净值** | **期初净值 × (1 + 时间加权收益率)** | 是 | **假设分红立即再投资** | **基金收益率计算的基础**；**分析软件与媒体常用** |
| **累计单位净值** | **基金单位净值 + 期间累计基金单位分红** | 是 | **未考虑分红再投资的影响** | **实际分析中并不常用** |

**一句话记忆**：**份额净值是"裸净值"、累计净值是"净值和"、复权净值是"含再投资的真实增长"**。

### 12.2.c 【掌握】相对收益的概念，算术法与几何法的计算和比较，以及捕获率的概念、计算、应用和局限性 P421–P426

**大纲原文**：掌握相对收益的概念，算术法与几何法的计算和比较，以及捕获率的概念、计算、应用和局限性

#### （一）为什么需要相对收益 P421

> **基金的绝对收益水平不足以完整评价基金业绩的优劣**——**在牛市环境中获得 30% 的收益并不一定意味着投资组合业绩突出；相反，在熊市环境中取得 −5% 的收益也并不一定意味着基金业绩不佳**。

> **因此，在衡量基金业绩时，除了绝对收益，还需要和同期的业绩比较基准和市场同类产品的收益率作比较，才能得出更加公正客观的结论**。

#### （二）相对收益的定义 P421

> **相对收益（Relative Return），也被称为超额收益（Excess Return），指在一定时间区间内，基金收益超出业绩比较基准收益的部分**。

> **广义而言，相对收益的概念涵盖主动收益（Active Return）、阿尔法收益（Alpha Return）等**；**业绩比较基准不同，超额收益亦不相同**；**因此，选择适当的业绩比较基准对评价基金业绩至关重要**。

#### （三）两种计算方法（必背） P421–P422

##### ① 算术法 P422

$$ER_{A}=R_{P}-R_{b}$$

**符号**：**ER_A** —— **算术法计算的相对收益**；**R_P** —— **基金收益**；**R_b** —— **基准收益**。

##### ② 几何法 P422

$$ER_{G}=\frac{1+R_{P}}{1+R_{b}}-1$$

**符号**：**ER_G** —— **几何法计算的相对收益**。

##### ③ 教材数值示例 P422

> **假定某基金收益为 7%，其业绩比较基准收益为 5%，则两种方法计算出来的超额收益分别为 2% 和 1.9%**。

| 方法 | 计算 | 结果 |
|---|---|---|
| **算术法** | **7% − 5%** | **2%** |
| **几何法** | **(1 + 7%)/(1 + 5%) − 1** | **1.9%** |

#### （四）两种方法的比较（高频考点） P422

##### ① 算术法的特点 P422

> **算术法计算相对收益较为直观，便于理解和计算，尤其适合进行基金业绩的快速比较和分析**。

##### ② 几何法的特点 P422

> **几何法计算相对收益的核心思想是通过相对比例来衡量基金收益率与业绩比较基准收益率的差异**；**它的主要优势是能够更精确地反映收益率的复合效应，尤其在多个时间段内，它可以更合理地比较收益率的变化**。

##### ③ 两者关系式与大小规律（必考） P422

$$\frac{1+R_{P}}{1+R_{b}}=\frac{R_{P}-R_{b}}{1+R_{b}}+1\quad\Longrightarrow\quad ER_{G}=\frac{ER_{A}}{1+R_{b}}$$

> **可以看到，在市场上涨（业绩比较基准收益率为正）时，几何法计算的超额收益率总是小于算术法计算的超额收益率；在市场下跌（业绩比较基准收益率为负）时，几何法计算的超额收益率总是大于算术法计算的超额收益率**。

> **在市场变动较大的情况下，两种算法的结果会有显著差异**；**在较长时间段或收益波动较大的情况下，几何法能够更合理地体现收益的复合增长**；**在实践中，算术法因其简单性和直观性，应用更为广泛**。

**记忆技巧**：**分母 (1 + R_b) 大于 1 → 几何法被缩小；小于 1 → 几何法被放大**。

#### （五）捕获率（Capture Ratios） P422–P426

##### ① 概念 P422

> **在评估基金业绩时，除了考察其绝对收益和相对收益，分析基金在基准上涨和下跌等不同市场阶段的相对表现也具有重要意义**；**捕获率（Capture Ratios）为此提供了有效的衡量工具**。

> **它通过上行捕获率（Upside Capture Ratio，UCR）和下行捕获率（Downside Capture Ratio，DCR）的区分，揭示基金经理在多变市场环境下的适应能力及投资策略的有效性**。

##### ② 数据频率的选择 P422

> **计算捕获率需基于基金及其业绩比较基准的历史回报数据**；**在实际应用中，数据频率的选择对结果解读有直接影响，理想情况下应与基金投资策略的周期相匹配**。

| 频率 | 适用性 |
|---|---|
| **月度数据（行业惯例）** | **能较好地平滑市场短期噪音，更清晰地反映多数主动管理型基金的中长期选股和风险控制能力，而且月度数据的易得性也便于进行跨越牛熊周期的长期评估** |
| **周度数据** | **对于周度判断的策略选用周度数据更具相关性** |
| **日度数据** | **对于更加短期的日频策略，采用日度数据计算捕获率能更精确地捕捉基金在短期市场波动中的表现** |

##### ③ 上行与下行阶段的界定（核心） P423

> **上行与下行阶段的界定，通常依据业绩比较基准在每个数据周期（如月度）内回报率的正负进行客观划分，此为计算捕获率的常用标准方法**。

> **作为补充，分析师有时亦会依据宏观经济周期或重大市场事件，人为划定更长期的市场阶段以计算捕获率**——**旨在评估基金对市场大趋势的适应性，例如股市牛市阶段及熊市阶段、债市收益率上行阶段及下行阶段、通胀上行及下行阶段等等**。

> **尽管如此，此类人为划分因其主观性强、易引入后见之明偏误、且缺乏统一标准进而影响可比性，在常规业绩评价中，基于数据周期的客观划分仍是主流**；**若确需采用人为划分，分析师必须清晰阐述其逻辑与依据**。

**重要计算原则**：

> **为确保准确反映复利效应，在计算基金及基准在各自上行与下行市场阶段的平均回报时应采用几何平均法**。

##### ④ 上行捕获率（UCR） P423

> **上行捕获率用于衡量当业绩比较基准实现正收益时，基金获取收益的能力**；**具体而言，它比较的是在业绩比较基准上涨的子期间内，基金的平均收益率与基准的平均收益率之间的关系**。

$$UCR=\frac{\text{基金在基准上行期的几何平均收益率}}{\text{基准在上行期的几何平均收益率}}\times100\%$$

| 取值 | 含义 |
|---|---|
| **UCR > 100%** | **表明在基准上涨的市场环境中，该基金的平均涨幅超过了业绩比较基准，展现出较强的收益捕获能力** |
| **UCR < 100%** | **说明基金在上涨市中未能完全跟上或超越基准的表现** |

##### ⑤ 下行捕获率（DCR） P423

> **下行捕获率则用于衡量当业绩比较基准出现负收益时，基金控制风险、减少损失的能力**；**它比较的是在业绩比较基准下跌的子期间内，基金的平均收益率与基准的平均收益率之间的关系**。

$$DCR=\frac{\text{基金在基准下行期的几何平均收益率}}{\text{基准在下行期的几何平均收益率}}\times100\%$$

> **由于在基准下跌期间，基金和基准的平均收益率通常均为负值，它们的比率（即下行捕获率）仍为正数**。

| 取值 | 含义 |
|---|---|
| **DCR < 100%** | **意味着在基准下跌的市场环境中，基金的平均跌幅小于业绩比较基准，反映了基金较好的下行风险管理能力** |
| **DCR > 100%** | **表明基金在市场下跌时期的表现劣于基准，跌幅更大** |

##### ⑥ 理想组合与整体捕获率（必背） P423–P424

> **理想的情况是，一只基金能够展现出较高的上行捕获率（例如大于 100%）和较低的下行捕获率（例如小于 100%）**——**这样的组合表明基金不仅能在市场上涨时争取到超越基准的更高回报，还能在市场下跌时有效地控制风险，使损失小于基准**。

> **此外，还可以计算整体捕获率（Overall Capture Ratio），定义为上行捕获率与下行捕获率之比（UCR/DCR）**；**该比率越高，通常意味着基金每承受一单位的下行风险（或相对市场下行表现），能捕获更多的上行回报（或相对市场上行表现），即具有更优的非对称收益特征**。

$$\text{整体捕获率}=\frac{UCR}{DCR}$$

##### ⑦ 考察区间 P423

> **在实际运用中，捕获率应结合基金的投资目标、策略以及考察区间的长度和市场特征进行综合评估**；**常见的考察区间长度包括 1 年、3 年、5 年等，更长的周期有助于平滑短期市场波动的影响，从而更可靠地评估基金的长期表现**。

|---|---|
| **相对收益** | **基准选择决定结果**——**基准不同，超额收益亦不相同**；**几何法与算术法在基准为负时结论方向相反** |
| **捕获率** | **主观划分上下行阶段会引入后见之明偏误、缺乏可比性**；**数据频率须与策略周期匹配**；**须结合投资目标、策略与区间长度（1/3/5 年）综合评估** |

### 12.2.d 【掌握】主要的风险调整收益指标的概念、计算方法、应用和局限性 P426–P430

**大纲原文**：掌握主要的风险调整收益指标的概念、计算方法、应用和局限性

#### （一）为什么需要风险调整收益 P426

> **基金投资组合获取收益的同时也承担了风险**；**因此，评价基金业绩既需考虑收益水平，还需兼顾所承担的风险**；**风险调整收益指标的计算尤为重要，因为这类指标通过计算单位风险所对应的收益水平，实现将不同风险水平的投资组合在同一风险基准下进行比较**。

> **衡量风险的指标很多，包含总风险、系统风险、下行风险、主动风险等，由此也产生了多种风险调整收益指标**；**进行基金评价时，使用不同指标，分析结果可能会存在显著差异**。

#### （二）五大指标总览（核心考点）

| # | 指标 | 提出者/时间 | 分母（风险度量） | 一句话 |
|---|---|---|---|---|
| **1** | **夏普比率（SR）** | **威廉·夏普，1966 年** | **标准差 σ_p（总风险）** | **单位总风险的超额收益** |
| **2** | **特雷诺比率（TR）** | **杰克·特雷诺，1965 年** | **β_p（系统性风险）** | **单位系统性风险的超额收益** |
| **3** | **卡玛比率（CR）** | **Terry W. Young，1991 年** | **最大回撤 MD** | **单位最大回撤的超额收益** |
| **4** | **索提诺比率（SoR）** | **弗兰克·索提诺，20 世纪 80 年代** | **下行标准差 DD** | **单位下行风险的超额收益** |
| **5** | **信息比率（IR）** | — | **跟踪误差 TE** | **单位跟踪误差的超额收益** |

#### （三）夏普比率（Sharpe Ratio，SR） P426–P427

##### ① 思想与定义 P426

> **夏普比率由诺贝尔经济学奖得主威廉·夏普（William F. Sharpe）于 1966 年提出，是基于资本资产定价模型（CAPM）框架的风险调整收益指标**。

> **夏普认为，基金的收益不仅包含因承担系统性风险所获得的收益，还应包括基金经理通过主动管理产生的收益**；**因此，夏普比率衡量的是基金在承担总风险（即系统性风险和非系统性风险）下的超额收益率**。

##### ② 公式（必背） P427

$$S_{p}=\frac{R_{P}-R_{f}}{\sigma_{p}}$$

**符号**：**S_p** —— **夏普比率**；**R_P** —— **基金收益率**；**R_f** —— **无风险收益率**；**σ_p** —— **基金收益率的标准差**；**R_P 和 σ_p 一般都用年化值**。

> **因分母采用基金收益率的标准差，可知夏普比率是经总风险调整后的收益指标**；**该指标数值越大，表示单位总风险下超额收益率越高**。

##### 案例 12-7：夏普比率与市场对比 P427

> **假设一年期定期存款利率（无风险收益率）为 1.35%**。

**表 12-6 基金 P 和证券市场的年化收益率和标准差**：

| 项目 | 基金 P | 证券市场（M） |
|---|---|---|
| **年化收益率** | **15%** | **10%** |
| **标准差** | **0.5** | **0.3** |

| 对象 | 计算 | 夏普比率 |
|---|---|---|
| **基金 P** | **(15% − 1.35%) / 0.5** | **0.27** |
| **市场 M** | **(10% − 1.35%) / 0.3** | **0.29** |

> **可见，风险调整前，基金 P 的收益率达到 15%，高于市场年化收益率 10%**；**但基金 P 波动性大，其标准差 0.5 高于市场的标准差 0.3，因此，经风险调整后，基金 P 的夏普比率低于市场水平**；**由此看来，虽然基金 P 的年化收益率高于市场水平，但 P 承担了比市场更高的总体风险，因而 P 的风险调整后超额收益低于后者**。

##### ③ 一个重要性质 P427

> **由于夏普比率计算中并未涉及业绩比较基准，而是选用市场的无风险收益率，因此是对绝对收益率的风险调整分析指标**。

#### （四）特雷诺比率（Treynor Ratio，TR） P427–P428

##### ① 思想与定义 P427

> **特雷诺比率由杰克·特雷诺（Jack Treynor）在 1965 年提出，基于 CAPM 的假设**；**他认为，基金的收益主要来自对系统性风险的承担，因此以基金系统性风险作为基金绩效调整的因子，考察基金承担单位系统性风险所获得的超额收益**；**特雷诺比率衡量的是基金在单位系统性风险下的超额收益率**。

##### ② 公式（必背） P428

$$T_{p}=\frac{R_{P}-R_{f}}{\beta_{p}}$$

**符号**：**T_p** —— **特雷诺比率**；**R_P** —— **基金收益率**；**R_f** —— **无风险收益率**；**β_p** —— **系统风险**；**R_P 和 R_f 一般采用年化值计算**。

> **在风险偏好一定的情况下，较大的 T_p 值对应的投资组合对投资者的吸引力更大**。

##### 案例 12-8：三位基金经理的特雷诺比率 P428

> **假设最近 5 年里，市场组合的平均收益率为 14%，短期国库券的名义收益率为 6%**。

**表 12-7 三个基金经理的业绩**：

| 投资经理 | 年化收益率（%） | β 值 |
|---|---|---|
| **A** | **12** | **0.8** |
| **B** | **16** | **1.05** |
| **C** | **18** | **1.2** |

| 对象 | 计算 | 特雷诺比率 |
|---|---|---|
| **市场组合** | **(14% − 6%) / 1** | **0.080** |
| **经理 A** | **(12% − 6%) / 0.8** | **0.075** |
| **经理 B** | **(16% − 6%) / 1.05** | **0.095** |
| **经理 C** | **(18% − 6%) / 1.2** | **0.100** |

> **结果表明，投资经理 A 的表现不仅低于其他两位经理，且低于市场组合的表现**；**相比之下，基金经理 B 和 C 都取得了比市场投资组合更好的业绩，且基金经理 C 的业绩要好于基金经理 B**；**相对证券市场线而言，基金经理 B 和基金经理 C 管理的投资组合的坐标值都位于证券市场线的上方**。

##### ③ 与夏普比率的关系（高频考点） P428

> **特雷诺比率与夏普比率相似，均假定风险与收益之间呈线性关系**；**两者区别在于特雷诺比率使用系统性风险，夏普比率则衡量总体风险（包括系统性风险和非系统性风险）**。

> **对于充分分散化的组合，其总风险即为系统性风险，特雷诺比率则等于夏普比率**。

#### （五）卡玛比率（Calmar Ratio，CR） P428–P429

##### ① 定义与公式 P428–P429

> **卡玛比率由基金经理 Terry W. Young 于 1991 年提出，衡量的是基金单位最大回撤所获得的超额收益**。

$$C_{p}=\frac{R_{P}-R_{f}}{MD}$$

**符号**：**C_p** —— **卡玛比率**；**R_P** —— **基金在区间内的收益率**；**R_f** —— **区间内的无风险收益率**；**MD** —— **基金在区间内的最大回撤，一般用绝对值**；**R_P 和 R_f 一般使用年化值**。

##### ② 三个判断区间（必背） P429

> **卡玛比率和夏普比率计算方法相似，只是将分母上的风险度量改为最大回撤**；**该比率越高，说明基金在承受单位损失时所获得的回报也就越大**。

| 取值 | 含义 |
|---|---|
| **< 0（负值）** | **表示投资组合收益不及无风险利率，此时该指标失效** |
| **0 至 1 之间** | **表示投资组合的超额收益不及该时期内的最大回撤** |
| **> 1** | **则相反（超额收益超过最大回撤）** |

#### （六）索提诺比率（Sortino Ratio，SoR） P429

##### ① 思想与定义 P429

> **根据预期理论，个人投资者对风险本身的中性特征并不敏感，其更为偏好会带来回报的上行风险，而更厌恶下行风险**；**因此，弗兰克·索提诺（Frank Sortino）在 20 世纪 80 年代提出下行标准差代替标准差衡量风险的索提诺比率，即仅考虑基金每单位亏损不确定性下的超额收益**。

##### ② 公式 P429

$$SoR=\frac{R_{P}-R_{T}}{DD_{p}}$$

**符号**：**SoR** —— **索提诺比率**；**R_P** —— **基金在区间内的收益率**；**R_T** —— **区间最低可接受的收益率**；**DD_p** —— **基金在区间内的下行标准差**；**三者一般使用年化后的数值**。

- **计算方法和夏普比率相似**，**只是分母由标准差换为下行标准差、分子减去最低可接受收益率（而非无风险利率）**。

#### （七）信息比率（Information Ratio，IR） P429

> **主动管理的投资组合通过偏离业绩比较基准获得超额收益，偏离幅度越大，主动风险越高**；**信息比率衡量基金相对于业绩比较基准的超额收益与跟踪误差之间的关系**。

$$IR=\frac{R_{P}-R_{b}}{\sigma_{p-b}}$$

**符号**：**R_P** —— **投资组合收益率**；**R_b** —— **业绩比较基准收益率，两者之差即超额收益**；**σ_{p−b}** —— **跟踪误差**；**R_P、R_b 和 σ_{p−b} 一般使用年化值**。

> **信息比率衡量单位跟踪误差所对应的超额收益**；**信息比率越大，说明该基金在同样的跟踪误差水平上能获得更大的超额收益，或者在同样的超额收益水平下跟踪误差更小**。

#### （八）五大指标对比表（必背）

| 指标 | 公式 | 风险口径 | 是否有基准 | 越大越好？ |
|---|---|---|---|---|
| **夏普比率** | **(R_P − R_f) / σ_p** | **总风险** | **无基准（绝对收益的风险调整）** | 是 |
| **特雷诺比率** | **(R_P − R_f) / β_p** | **系统性风险** | **用市场组合与 SML 判断** | 是 |
| **卡玛比率** | **(R_P − R_f) / MD** | **最大回撤** | 否 | **（负值失效；>1 为佳）** |
| **索提诺比率** | **(R_P − R_T) / DD_p** | **下行风险** | 否 | 是 |
| **信息比率** | **(R_P − R_b) / TE** | **主动风险（跟踪误差）** | **有基准** | 是 |

#### （九）使用注意与局限 P429–P430

##### ① 数据频率与时间跨度的影响 P429

> **值得注意的是，数据频率和时间跨度对风险调整收益的计算结果有显著影响**——**使用日频和月频数据计算会得出不同的结果，而不同历史时期的基金表现也可能存在显著差异**；**因此，在比较不同基金的风险调整收益指标时，需保持数据口径一致**。

> **通常，较长的观察期能够提供更有价值的信息；太短的观察期可能受到随机因素的严重干扰，导致计算结果失真**——例如，**短期内较高的信息比率可能仅仅反映了暂时的好运，而非真正的主动投资能力**；**此外，投资策略的调整和基金经理变动等因素也会影响数据的参考价值**。

##### ② 共同的假设局限 P430

> **风险调整收益指标值从不同角度对基金收益进行风险补偿，使评价结果兼顾风险和收益两个维度**；**然而，这些指标的计算通常基于一些假设，如投资组合的风险与收益之间存在线性相关，且这种相关性在整个观察期内保持不变**；**这些假设在实际市场中可能不总是成立，因此在解释结果时需要注意这一局限性**。

##### ③ CAPM 事后风险调整的四点注意（必背） P430

> **在应用资本资产定价模型（CAPM）进行事后风险调整时，还需要注意以下几点**：

| # | 注意点 |
|---|---|
| **1** | **理论上的无风险收益率与实际使用的国债收益率往往不同** |
| **2** | **没有一个完全具有代表性的市场指数，选择不同的基准可能会影响结果** |
| **3** | **证券的高波动性可能导致显著的统计误差，进而影响超额收益 α 的准确测量** |
| **4** | **β 系数并非恒定不变，市场条件的变化可能导致 β 值的波动** |

### 12.2.e 【了解】证券选择能力和时机选择能力评价模型的概念和应用 P430–P433

**大纲原文**：了解证券选择能力和时机选择能力评价模型的概念和应用

> **为有效评价基金的主动投资管理能力，学者们提出了不同的基于收益率的时间序列回归模型来检验基金有效获取超额收益的能力**。

#### （一）五个模型总览

| # | 模型 | 提出者/时间 | 衡量择时的方式 | 选股能力 |
|---|---|---|---|---|
| **1** | **詹森阿尔法** | **迈克尔·詹森，1968 年** | **不衡量择时能力** | **截距项 α** |
| **2** | **T-M 模型** | **特雷诺、玛泽，1966 年** | **市场超额收益的二次项** | **截距项 α** |
| **3** | **H-M 模型** | **亨利克森、莫顿，1981 年** | **市场上涨/下跌的虚拟变量** | **截距项 α** |
| **4** | **C-L 模型** | **Chang、Lewellen，1984 年** | **分段市场收益（上升/下降）** | **截距项 α** |
| **5** | **Fama-French 三因子** | **法玛、弗伦奇，1993 年** | **不衡量择时能力** | **截距项 α** |

#### （二）詹森阿尔法（Jensen's Alpha） P430–P431

##### ① 定义 P430

> **詹森阿尔法由迈克尔·詹森（Michael C. Jensen）于 1968 年提出，是用于衡量基金经理通过主动管理获得的超额收益的一个指标**；**詹森阿尔法基于资本资产定价模型（CAPM），通过比较基金投资组合的收益率与相同系统性风险水平下市场组合的收益率，来评估基金经理的表现**。

##### ② 回归方程与简化公式 P430–P431

$$R_{p}-R_{f}=\alpha+\beta_{p}\left(R_{m}-R_{f}\right)+\varepsilon$$

**符号**：**R_P** —— **投资组合在各时期的收益率**；**R_f** —— **各时期的无风险收益率**；**β_p** —— **投资组合的系统性风险**；**R_m** —— **各时期的市场组合收益率**；**α** —— **回归阿尔法（Regression Alpha），表示基金通过主动管理获得的超额收益**；**ε** —— **回归方程的残差项**。

**简化公式（必背）** P431：

> **为了简化计算，詹森阿尔法有时会被表示为一个简化公式，它省略了回归分析中的残差项，直接通过历史数据计算超额收益**。

$$\alpha=\bar{R}_{p}-\bar{R}_{f}-\beta_{p}\left(\bar{R}_{m}-\bar{R}_{f}\right)$$

> **在这个简化公式中，我们直接使用历史数据中的平均值来计算詹森阿尔法**——**R̄_p、R̄_m 和 R̄_f 分别是基金的平均收益率、市场的平均收益率和无风险收益率，β_p 是基金的系统性风险（可以通过历史回归分析得出）**。

> **这个公式表示的是基金的超额收益减去由于市场波动（用 β_p 衡量）产生的预期收益**[**即 β_p(R̄_m − R̄_f)**]；**简化的詹森阿尔法忽略了回归模型中的残差项 ε，因此它假设所有的收益都可以用市场收益和系统性风险解释**。

##### ③ α 的判读 P430

> **当 α 在统计上显著为正，则说明主动管理（证券选择和时机选择等）在测算区间内贡献了正收益；统计上显著为正的 α 值越大，投资组合相对于市场基准的表现越好**；**反之，则说明主动管理在测算区间内没有贡献正收益；统计上显著为负的 α 绝对值越大，投资组合相对于市场基准的表现越差**。

##### ④ 局限性 + 评估比率（AR） P431

> **由于詹森阿尔法只考虑了投资组合的系统性风险，未考虑非系统性风险，在此基础上，特雷诺和布莱克提出了评估比率（Appraisal Ratio，AR），用于衡量每单位非系统性风险所获得的詹森阿尔法**。

$$AR=\frac{\alpha}{\sigma(\varepsilon)}$$

**符号**：**α** —— **詹森阿尔法**；**σ(ε)** —— **回归模型中残差项 ε 的标准差**。

#### （三）T-M 模型（Treynor-Mazuy 模型） P431–P432

> **T-M 模型由特雷诺（Jack Treynor）和玛泽（Mazuy）于 1966 年提出，旨在对基金经理的时机选择能力进行量化分析**；**该模型在詹森模型的基础上引入了市场风险溢价的二次项，用以区分基金经理的择时能力和选股能力**。

$$R_{p}-R_{f}=\alpha+\beta_{1}\left(R_{m}-R_{f}\right)+\beta_{2}\left(R_{m}-R_{f}\right)^{2}+\varepsilon$$

**符号**：**α** —— **回归方程的截距项，表示基金经理的选股能力**；**β_1** —— **投资组合的系统性风险**；**β_2** —— **回归方程中的二次项系数，表示基金经理的择时能力**；**ε** —— **残差项**。

**判读规则（必背）**：

| 参数 | 判读 |
|---|---|
| **α 统计上显著大于 0** | **说明管理人具有正向的证券选择能力** |
| **β_2 显著为正** | **表明基金经理具有正向择时能力，能够根据市场走势适时调整风险暴露** |
| **β_2 为零或为负** | **表明基金经理缺乏择时能力或择时能力较差** |

> **模型中的二次项用于捕捉基金经理的择时能力**——**当市场表现极佳或极差时，二次项的影响会被放大**；**这反映了基金经理是否能在市场波动较大时进行有效调整，从而获得更高收益**。

#### （四）H-M 模型（Henriksson-Merton 模型） P432

> **1981 年，亨利克森（Henriksson）和莫顿（Merton）在 T-M 模型的基础上将二次项改为市场风险溢价与代表市场环境的虚拟变量的乘积，由此提出 H-M 模型**。

> **以计算不同市场环境即市场上涨和下跌情况下的基金绩效表现，考察不同市场环境中基金捕捉机会的能力，使得基金择时能力判断的可理解性更高**。

$$R_{p}-R_{f}=\alpha+\beta_{1}\left(R_{m}-R_{f}\right)+\beta_{2}\left(R_{m}-R_{f}\right)D+\varepsilon$$

**虚拟变量 D 的定义（关键）**：

> **D 是虚拟变量，当 R_m > R_f 时，D = 1，否则 D = 0**；**如果 β_2 在统计上显著大于零，表明基金经理具有时机选择能力**。

#### （五）C-L 模型（Chang-Lewellen 模型） P432

> **1984 年，Chang 和 Lewellen 在 H-M 模型基础上进行线性变换，将市场环境划分为上升期与下降期，测算不同市场环境中的风险水平 β，以考察在各环境下捕捉机会的能力水平，在应用过程中准确度量基金经理在不同市场中的风险暴露**。

$$R_{p}-R_{f}=\alpha+\beta_{1}\max\left(R_{m}-R_{f},\,0\right)+\beta_{2}\min\left(R_{m}-R_{f},\,0\right)+\varepsilon$$

**符号含义（必背）**：

> **max(R_m − R_f, 0) 的值总是大于或等于 0，代表市场组合收益优于无风险收益的区间**；**min(R_m − R_f, 0) 的值总是小于或等于 0，代表市场组合收益劣于无风险收益的区间**。

**判读规则**：

> **如果回归结果中 β_1 和 β_2 显著不为 0，且 β_1 > β_2，说明基金经理具有时机选择能力**。

**逻辑**：**上涨期的 β_1 大于下跌期的 β_2，意味着"涨时重仓、跌时轻仓"，即成功择时**。

#### （六）Fama-French 三因子模型 P432–P433

> **Fama-French 三因子模型由尤金·法玛（Eugene Fama）和肯尼斯·弗伦奇（Kenneth French）于 1993 年提出，用于扩展 CAPM 的单一市场因子，增加了公司规模因子和估值因子，以更好地解释股票组合的收益**。

$$R_{pt}-R_{ft}=\alpha+\beta_{1}\left(R_{mt}-R_{ft}\right)+\beta_{2}SMB_{t}+\beta_{3}HML_{t}+\varepsilon$$

**符号**：**R_pt** —— **投资组合收益率**；**R_ft** —— **市场无风险利率**；**R_mt** —— **市场组合的收益率**；**SMB_t** —— **公司规模因子**；**HML_t** —— **公司估值因子**。

**五因子扩展**：

> **在 2013 年，Fama 和 French 进一步扩展了三因子模型，将风险因子扩展为市场因子、规模因子、估值因子、盈利因子和投资因子，形成了五因子模型**；**该模型更为细致地解析了不同类型风险的收益来源，使得投资者能够更全面地了解基金经理承担不同风险所获得的回报**。

#### （七）表 12-8 五模型比较总结（必背） P433

| 模型 | 择时能力的衡量方式 | 选股能力衡量方式 | 择时行为假设 | 优点 | 缺点 |
|---|---|---|---|---|---|
| **詹森阿尔法** | **不衡量择时能力** | **回归中的截距项 α** | **无择时假设** | **简单易懂，广泛应用** | **未考虑择时能力和其他风险因子** |
| **T-M 模型** | **市场超额收益的二次项** | **回归中的截距项 α** | **择时行为是连续的** | **能捕捉市场波动较大时的择时行为** | **假设择时行为是连续的，可能不符合实际情况** |
| **H-M 模型** | **市场上涨/下跌的虚拟变量** | **回归中的截距项 α** | **择时行为是非连续的** | **更符合现实，基金经理只在特定市场条件下调整** | **只考虑两种市场状态，无法捕捉中间状态的细微变化** |
| **C-L 模型** | **分段市场收益（上升/下降）** | **回归中的截距项 α** | **择时行为是非连续的** | **更精确地衡量基金经理在上涨和下跌期的表现差异** | **仍假设市场只有两种状态，忽略连续变化** |
| **Fama-French 模型** | **不衡量择时能力** | **回归中的截距项 α** | **无择时假设** | **能解释更多收益来源，考虑多种风险因子** | **未考虑择时能力，模型复杂度较高** |

#### （八）模型演进逻辑与共同局限 P432–P433

> **上述模型从不同角度对基金经理的选股能力和择时能力进行了评估，从最早的詹森阿尔法到后来更复杂的多因子模型，这些方法为投资者提供了衡量基金表现的有效工具**。

> **需要注意的是，虽然这些模型在理论上假设了风险与收益之间的线性关系，但在实际应用中，市场波动性、基金经理的策略变化等因素都可能影响模型的准确性**；**因此，在使用这些模型时，应结合实际情况进行综合分析**。

**演进主线记忆**：**詹森（只看选股）→ T-M（加二次项，连续择时）→ H-M（加虚拟变量，非连续择时）→ C-L（分上涨/下跌两段 β，更精确）→ 三因子/五因子（扩展风险因子）**。

## 12.3 基金业绩归因

> **基金业绩归因是一种分析投资组合收益来源的技术，旨在揭示"收益从何而来"的问题**；**通过业绩归因，投资者和基金管理人可以明确基金收益的构成，进而评估投资策略的有效性与管理人的能力**。

> **基金的收益来源多样，既可能来自于牛市阶段的高股权配置，也可能源于精确的行业或个股选择，甚至是对利率变化的精准判断**。

### 12.3.a 【掌握】基金业绩归因的目的以及绝对收益归因的基本方法 P433–P438

**大纲原文**：掌握基金业绩归因的目的以及绝对收益归因的基本方法

#### （一）业绩归因的两种角度与模型选择 P433–P434

> **业绩归因可以从不同角度进行分析：可以对基金的绝对收益进行归因，也可以对其相对于业绩基准的相对收益进行归因**。

| 角度 | 目的 |
|---|---|
| **绝对收益归因** | **旨在分解基金的总收益，考察每个因素为整体收益所作的贡献** |
| **相对收益归因** | **则侧重于分析基金与基准在资产配置、证券选择等方面的差异，解释基金跑赢或跑输基准的原因** |

**按基金类型的模型选择（必背）** P434：

> **在主动型投资中，归因分析常通过 Brinson 模型或 Campisi 模型等方法进行**，**前者主要用于股票组合的归因，而后者则专门用于债券组合的归因**。

| 基金类型 | 归因方法 |
|---|---|
| **主动股票组合** | **Brinson 模型** |
| **主动债券组合** | **Campisi 模型** |
| **被动型基金** | **归因分析则侧重于跟踪误差的计算，确保基金紧密跟踪标的指数的表现** |
| **货币基金** | **作为一种现金管理工具，其业绩基准通常为存款利率或市场回购利率等**；**由于其投资目标相对稳定，归因分析往往侧重于个券的收益与风险，较少涉及相对收益的归因** |

> **通过全面的业绩归因分析，投资者能够更好地理解基金收益的驱动因素，基金管理人则可以据此优化投资策略，从而提升基金管理的有效性**。

#### （二）绝对收益归因的基本方法 P434

> **在绝对收益归因中，我们考察在特定区间内，每个证券或每类证券对组合整体收益的贡献**；**假设在考察区间内没有交易行为，每个证券的贡献为其初始权重乘以其自身的收益率**。

$$C_{i}=\sum_{i=1}^{n}\frac{MV_{i}}{MV_{P}}\times R_{i}$$

**符号**：**MV_i** —— **证券 i 的期初市值**；**R_i** —— **证券 i 的区间收益率**；**C_i** —— **证券 i 的收益率贡献**；**n** —— **贡献因素总数量，此处即为所持有证券的总数**。

> **绝对收益归因提供了一个考察证券和行业收益的直观方式**。

#### （四）动态组合的归因：考虑交易与分红 P436

> **上述分析主要是针对静态的投资组合，假设没有发生交易以及付息、分红等情况**；**而在实际投资组合中，以上因素都会影响证券收益率**；**因此进行归因分析时需要考虑这些动态因素，并通过时间加权收益率方法将单期收益率拓展至多期**。

##### ① 单只股票的日收益率公式（必背） P436

$$R_{i,t}=\frac{MV_{i,t}+S_{i,t}+D_{i,t}-B_{i,t}}{MV_{i,t-1}}-1$$

**符号**：**R_i,t** —— **股票 i 在 t 日的收益率**；**MV_i,t** —— **股票 i 在 t 日末的市值**；**MV_i,t−1** —— **股票 i 在 t−1 日末的市值**；**B_i,t** —— **股票 i 在 t 日的买入金额**；**S_i,t** —— **股票 i 在 t 日的卖出金额**；**D_i,t** —— **股票 i 在 t 日的分红金额**。

**关键时点假设（易考）**：

> **在此公式中，假设将股票 t 日的卖出与分红均视作发生在 t 日末，而买入则视作发生在 t 日初**；**也就是说，假设 t 日初在组合净值不变的情况下，部分现金用于买入等值的股票 i，使其持仓比例发生变化**；**由于 t 日初可以被视作与 t−1 日末是同一时间点，因此在计算 t 日股票 i 的收益贡献时，股票 i 的日末权重需要调整为包含该次买入操作的权重**。

##### ② 日末权重的调整公式 P436

$$w_{i,t}=\frac{MV_{i,t-1}+B_{i,t}}{MV_{P,t-1}}$$

**符号**：**w_i,t** —— **股票 i 的 t 日末权重**；**MV_P,t−1** —— **整个投资组合 t−1 日的市值**。

##### ③ 收益率贡献 P436

$$C_{i,t}=w_{i,t-1}\times R_{i,t}$$

**展开后可得股票 i 在 t 日对组合收益的贡献为**：

$$C_{i,t}=\frac{\left(MV_{i,t}+S_{i,t}+D_{i,t}-B_{i,t}\right)-MV_{i,t-1}}{MV_{P,t-1}}$$

#### （五）案例 12-10：动态组合的单日收益归因 P436–P437

#### （六）多期归因 P437–P438

> **以上只讨论了投资组合单日的收益归因，在多期条件下，则需要进行相对复杂的拆分**。

##### ① 多期组合收益（时间加权思路） P437

$$R_{P,T}=\prod_{t=1}^{T}\left(1+R_{P,t}\right)-1$$

**符号**：**R_P,t** —— **第 t 期的组合收益率**。

##### ② 单期组合收益的分解 P437

$$R_{P,t}=\sum_{i=1}^{n}w_{i,t-1}\times R_{i,t}$$

##### ③ 多期总收益的展开 P437

$$R_{P,T}=\prod_{t=1}^{T}\left(1+\sum_{i=1}^{n}w_{i,t-1}R_{i,t}\right)-1$$

##### ④ 单只股票的多期贡献（核心公式） P437–P438

> **为了计算某只股票在整个多期内对组合收益的贡献，我们需要考虑每一期的收益叠加效应**；**股票 i 在整个多期 T 内对组合收益的贡献可以表示为**：

$$C_{i,T}=\sum_{t=1}^{T}\left[w_{i,t-1}\times R_{i,t}\times\prod_{j=1}^{t-1}\left(1+R_{P,j}\right)\right]$$

> **其中，Π(1 + R_P,j) 是第 t 期之前的复利效应**——**这是多期归因的关键：早期贡献会被后续复利放大**。

#### （七）绝对收益归因的三种粒度对比

| 粒度 | 公式 | 用途 |
|---|---|---|
| **个股（静态）** | **C_i = (MV_i / MV_P) × R_i** | **哪只股票贡献最大** |
| **行业（静态）** | **行业内个股贡献加总** | **哪个行业是真凶/功臣** |
| **个股（动态单日）** | **C_i,t = w_i,t−1 × R_i,t**（**含买卖分红**） | **考虑交易的真实贡献** |
| **个股（多期）** | **C_i,T = Σ[w_i,t−1 × R_i,t × Π(1+R_P,j)]** | **跨期复利叠加后的总贡献** |

### 12.3.b 【理解】Brinson 模型的相对收益归因方法、Campisi 债券组合归因模型的基本思想 P438–P443

**大纲原文**：理解 Brinson 模型的相对收益归因方法、Campisi 债券组合归因模型的基本思想

#### （一）相对收益归因的思路 P438

> **对于追求相对收益的基金，管理人和投资者更关心的是基金是如何跑赢或跑输其业绩比较基准的**；**此时，需要使用更加复杂的相对收益归因方法**。

> **股票组合投资经理为战胜业绩比较基准，会采取与业绩比较基准不同的资产或行业配置，或者挑选不同的证券**；**为了系统地分析这些差异带来的影响，Brinson 等人在 20 世纪 80 年代中期提出了一种将组合收益拆解为基准收益和超额收益的模型，并进一步将超越基准的部分细化为资产配置贡献和证券选择贡献**；**这就是投资组合业绩归因分析中的经典方法——Brinson 业绩归因模型**。

> **Brinson 业绩归因模型可进一步分为 BHB 模型和 BF 模型两种**。

#### （二）BHB 模型：四个组合与四块收益 P438–P439

> **Brinson、Hood 和 Beebower（1986）提出的 BHB 模型是最早的业绩归因模型**；**以单期为例，该模型将投资组合收益分为四个部分：资产配置收益、个股选择收益、交互收益和基准收益，由此构建四个组合**。

| 代号 | 组合名称 | 含义 |
|---|---|---|
| **Q1** | **基准组合（Benchmark Portfolio）** | **即基金的业绩比较基准** |
| **Q2** | **积极资产配置组合（Active Asset Allocation Portfolio）** | **即基金管理人在资产或行业层面的配置对基准的偏离** |
| **Q3** | **积极股票选择组合（Active Security Selection Portfolio）** | **即基金管理人在个券层面的选择上相对基准的偏离** |
| **Q4** | **真实组合（Actual Portfolio）** | **即基金的实际持仓和表现** |

##### ① 四块收益的计算公式（必背） P439

**符号**：**w_p,i** —— **真实组合中证券 i 权重**；**w_b,i** —— **基准组合中证券 i 权重**；**r_p,i** —— **真实组合中证券 i 的收益率**；**r_b,i** —— **基准组合中证券 i 收益率**。

| 收益 | 公式 | 计算方式 |
|---|---|---|
| **基准组合收益率 R_B** | **R_B = Q1** | **Σ w_b,i × r_b,i** |
| **真实组合收益率 R_P** | **R_P = Q4** | **Σ w_p,i × r_p,i** |
| **资产/行业配置收益 AR** | **AR = Q2 − Q1 = Σ(w_p,i − w_b,i) × r_b,i** | **权重偏离 × 基准收益** |
| **个券选择收益 SR** | **SR = Q3 − Q1 = Σ w_b,i × (r_p,i − r_b,i)** | **基准权重 × 收益偏离** |
| **交互收益 IR** | **IR = Q4 − Q3 − Q2 + Q1 = Σ(w_p,i − w_b,i) × (r_p,i − r_b,i)** | **权重偏离 × 收益偏离** |
| **总超额收益 TR** | **TR = R_P − R_B = Q4 − Q1 = SR + AR + IR** | **三块之和** |

**记忆口诀**：**配置看"权重差 × 基准收益"、选股看"基准权重 × 收益差"、交互看"权重差 × 收益差"**。

#### （三）BF 模型：把交互收益并入选股 P439

> **Brinson 和 Fachler 后来提出了 BF 模型，进一步改进了 BHB 模型，主要在于对资产/行业配置收益的重新定义**；**BF 模型将超额收益分解为两部分**。

##### ① 资产/行业配置收益（重新定义） P439

> **与 BHB 模型不同，BF 模型在考虑每一项资产的配置收益时，不仅考虑权重的偏离，还考虑资产相对于基准收益的差异**。

$$AR_{i}^{BF}=\left(w_{p,i}-w_{b,i}\right)\times\left(r_{b,i}-r_{b}\right)$$

> **这种算法使得 BF 模型能够更精确地反映基金管理人在每项资产配置上的决策如何影响组合的超额收益**。

**一个重要的数值性质**：

> **各项资产配置贡献加总后的值，在数值上和 BHB 是相等的**：

$$\sum_{i=1}^{n}\left(w_{p,i}-w_{b,i}\right)\left(r_{b,i}-r_{b}\right)=AR-\sum_{i=1}^{n}\left(w_{p,i}-w_{b,i}\right)r_{b}=AR$$

> **原因：Σ(w_p,i − w_b,i) × r_b = 0（因为两组权重各自加总都等于 1）**。

##### ② 个股选择收益（并入交互收益） P439

> **BF 模型将交互收益并入个股选择部分，简化了收益的归因分析**。

$$SR^{BF}=\sum_{i=1}^{n}w_{p,i}\left(r_{p,i}-r_{b,i}\right)$$

##### ③ 总超额收益 P439

> **在 BF 模型下，真实组合的总超额收益简化为资产/行业配置收益和个股选择收益的加总**：

$$TR=AR^{BF}+SR^{BF}$$

#### （四）案例 12-11：Brinson 模型完整演算（必考） P440–P441

> **表 12-13 为基金 P 及其业绩比较基准 B 的相关数据**；**基金和基准均包含股票、债券、现金三个大类资产**；**在基准中，股票资产为沪深 300 指数，债券资产为中证全债指数，现金资产为上海银行间同业拆放利率（Shibor）**。

**表 12-13 基金 P 及其业绩比较基准 B 的组成和收益情况**：

| 大类资产/基准指数 | **基金收益率** | **基金权重** | **基准收益率** | **基准权重** |
|---|---|---|---|---|
| **股票/沪深 300 指数** | **7.28%** | **70%** | **5.81%** | **60%** |
| **债券/中证全债指数** | **1.89%** | **7%** | **1.45%** | **30%** |
| **现金/Shibor** | **0.48%** | **23%** | **0.48%** | **10%** |

**第一步：总收益与超额收益**

#### （五）Brinson 模型的局限与应用现状 P441

> **以上探讨的只是单期 Brinson 业绩归因模型，未考虑期间个券的交易情况**；**在此基础上，海外学者和基金研究机构不断丰富 Brinson 模型，包括在投资组合层面对资产进行细分，对组合的主动行业配置、主动风格配置乃至个股选择进行业绩归因**；**此外，还包括在单期业绩归因基础上进行多期归因**。

**两类使用者的差异（易考）**：

> **实际分析中，基金组合持仓的业绩归因具备较高的精度，且基于相对基准的考核特征符合资产配置的需求，因此被机构投资者广泛认可**——**海外诸多基金评价研究工具供应商基于 Brinson 模型提供不同的归因框架**；**各大资产管理机构广泛采用以作为内部基金评价和考核的重要工具**；**对于外部机构，由于基金持仓披露频率较低，难以获得高频且完整的数据**。

#### （六）Campisi 模型：债券组合归因 P441–P443

##### ① 为什么需要专门的债券归因模型 P441

> **债券投资与股票投资有着不同的逻辑与驱动因素，因此，传统的股票归因方法并不能完全适用于债券组合**；**为此，Stephen Campisi 在 2000 年提出了一个专门用于纯债基金的业绩归因模型，即 Campisi 模型**。

> **Campisi 模型的核心在于对债券收益的细化分解，特别是分析市场利率、信用利差等因素对债券价格的影响**。

##### ② 第一步：票息收入 + 价格收益 P441

> **债券的收益主要分为票息收入和资本利得两部分**；**前者主要由债券本身约定的票息产生，相对稳定可预测**；**后者源于债券市场价格的变动，受多个因素影响**。

$$R_{i,t}=\frac{P_{i,t}-P_{i,t-1}+C_{i,t}}{P_{i,t-1}}$$

**符号**：**P_i,t** —— **债券 i 在 t 时刻的价格**；**P_i,t−1** —— **债券 i 在 t−1 时刻的价格**；**C_i,t** —— **债券 i 在 t−1 至 t 期间的票息收益**。

> **这个公式可进一步拆解为两个部分**：

| 部分 | 公式 | 含义 |
|---|---|---|
| **票息收益** | **C_i,t / P_i,t−1** | **表示持有期间获得的票息收益** |
| **价格收益** | **(P_i,t − P_i,t−1) / P_i,t−1** | **表示债券价格的变动带来的收益** |

##### ③ 第二步：价格收益再拆为三效应（核心） P442

> **债券价格的变动受到多个因素的影响，如久期、凸性、信用利差等**；**Campisi 模型将价格收益进一步分为国债效应、利差效应、凸性效应和其他剩余因素**。

| 效应 | 反映什么 | 机制 |
|---|---|---|
| **国债效应** | **债券价格对无风险利率变化的敏感度** | **通常使用国债收益率作为无风险利率的代替，因为国债被视为最安全的投资**；**国债收益率的变化代表了整体市场利率的变动趋势**；**因此，国债效应描述了市场基准利率变化对债券价格的影响** |
| **利差效应** | **债券价格对信用风险溢价变化的敏感度** | **信用利差是债券收益率超过同期限国债收益率的部分，用于补偿投资者承担的额外信用风险**；**当信用利差扩大时，债券价格会下跌；当信用利差收窄时，债券价格会上涨** |
| **凸性效应** | **利率变化对债券价格的非线性反应** | **在利率大幅波动的情况下，久期无法完全捕捉债券价格的变化，凸性就成为一个重要的补充指标**；**通常，凸性越高，债券价格在利率变化时的反应越温和** |

**单期收益率的完整分解（必背）**：

$$R_{i}=R_{income,i}+R_{treasury,i}+R_{spread,i}+R_{convexity,i}+R_{other,i}$$

| 符号 | 名称 |
|---|---|
| **R_income,i** | **票息收益** |
| **R_treasury,i** | **国债效应——由于市场利率（国债收益率）变化引起的价格波动** |
| **R_spread,i** | **利差效应——由于信用利差变化引起的价格波动** |
| **R_convexity,i** | **凸性效应——由于利率变化的非线性反应带来的价格波动** |
| **R_other,i** | **其他剩余因素，通常为可忽略的高阶项** |

##### ④ 案例 12-12：Campisi 模型完整演算（必考） P442–P443

**债券设定**：

> **假设某 10 年期债券 A 票面价格为 100 元，发行价格为 89.22 元，票息为 5%，每年付息一次，同期 10 年期国债利率为 3%**；**经计算可得该债券到期收益率为 6.5%，久期为 7.98 年，凸性为 71.38**。

**一年后的变化**：

> **一年后，投资者获得票息 5 元，10 年期国债利率下降 0.25%，为 2.75%，债券 A 价格上升至 90.45 元，到期收益率为 6.43%**。

**① 总收益率**：

$$R_{A}=\frac{5+90.45-89.22}{89.22}\times100\%=6.98\%$$

**② 五效应分解（必背数字）**：

| 效应 | 计算 | 结果 |
|---|---|---|
| **收入效应** | **5 / 89.22 × 100%** | **5.60%** |
| **国债效应** | **−7.98/(1+6.5%) × (−0.25%)** | **1.87%** |
| **利差效应** | **⟨见下⟩** | **−1.35%** |
| **凸性效应** | **½ × 71.38 × (−0.25%)²** | **0.02%** |
| **其他因素** | **6.98% − 5.60% − 1.87% − (−1.35%) − 0.02%** | **0.84%** |
| **合计** | **5.60% + 1.87% − 1.35% + 0.02% + 0.84%** | **6.98%** 是 |

**利差效应的详细计算（难点）**：

> **Y_spread,old = 6.5% − 3% = 3.5%**；**Y_spread,new = 6.43% − 2.75% = 3.68%**（**利差扩大**）

$$R_{spread}=-\frac{D}{1+Y}\times\left(\Delta Y_{spread,new}-\Delta Y_{spread,old}\right)=-\frac{7.98}{1+6.5\%}\times(3.68\%-3.5\%)=-1.35\%$$

**利差从 3.5% 扩大到 3.68% → 信用溢价上升 → 债券价格下跌 → 利差效应为负（−1.35%）**。

##### ⑤ 组合层面与多期应用 P443

> **以上即为单只债券单期收益的 Campisi 模型归因**。

> **对债券组合进行分析时，我们需要对每只债券进行业绩拆分，然后根据其在组合中的权重计算绝对收益率贡献，从而得到绝对归因结果**；**进行相对业绩归因时，还需要对基准中的债券进行同样的拆分，以获得相对归因结果**。

> **Campisi 模型的多期应用，类似于 Brinson 模型，具有一定复杂性**；**它需要考虑每只债券的每笔交易情况，包括交易时间、价格变化等因素**。

##### ⑥ 实际分析的复杂性 P443

> **实际分析中，情况往往比理论模型更为复杂**；需要考虑的因素包括**债券的估值、交易费用、税收费用以及实际交易价格等**。

> **另外，国债收益率曲线的变化常常呈现非线性特征，如扭转和蝶式移动等，而非简单的平移**；**这种非线性变化使得债券价格的反应更加复杂，需要更精细的分析方法来捕捉这些效应**。

#### （七）Brinson vs Campisi 对比表

| 维度 | **Brinson 模型** | **Campisi 模型** |
|---|---|---|
| **适用对象** | **股票组合（也可用于大类资产）** | **专门用于（纯债）债券组合** |
| **核心分解** | **资产配置收益 + 选股收益（+ 交互收益）** | **票息收益 + 国债效应 + 利差效应 + 凸性效应 + 其他** |
| **两个子模型** | **BHB（四组合）与 BF（两分解）** | — |
| **提出者/时间** | **Brinson、Hood、Beebower，1986；Brinson、Fachler（BF）** | **Stephen Campisi，2000** |
| **关键局限** | **单期模型未考虑期间个券交易** | **多期复杂；未考虑曲线非线性变化、估值与税费** |

## 12.4 基金风格分析

> **基金投资风格分析是现代投资理论和实践中的重要组成部分**；**它不仅帮助投资者更好地理解和选择适合自己风险偏好的基金产品，也为基金管理公司提供了重要的产品设计和风险管理工具**。

### 12.4.a 【理解】基金投资风格的形成、分析方法以及风格漂移的概念 P444–P447

**大纲原文**：理解基金投资风格的形成、分析方法以及风格漂移的概念

#### （一）基金投资风格的形成（双因素决定） P444

> **基金公司在设计产品时，会确定投资目标、投资范围、业绩比较基准等产品要素**；**这些要素基本决定了该基金的资产配置范围、比例和基本投资风格**；**基金产品发行和运作后，基金经理需要在产品契约规定范围内根据既定的产品要素进行资产配置和投资**。

> **主动型基金经理在实际投资运作中，会根据市场和资金情况，在合同允许范围内相对于基准做出适当的主动偏离，以获得超额收益**。

**核心结论（必背）**：

> **基金的实际投资风格是由产品契约约定和基金经理的投资决策共同决定的**。

> **基金投资风格分析是基金业绩评价的一个重要方面，甚至是一些重要的基金业绩评价方法和指标的基础**。

#### （二）两种分析路径（事前 vs 事后） P444

> **确定基金的投资风格主要有事前分析和事后分析两种方法**。

| 路径 | 依据 | 对应的具体方法 |
|---|---|---|
| **事前分析** | **依据基金招募说明书中关于投资目标和投资策略的说明来确定其投资风格** | — |
| **事后分析** | **根据基金的实际证券组合构成或对基金业绩的特征分析来判别其投资风格** | **① 基于组合构成的风格分析；② 基于收益特征的风格分析** |

#### （三）基于组合构成的风格分析 P444–P445

##### ① 方法步骤（三步骤，必背） P444

> **基于组合构成的风格分析方法是目前评估基金投资风格的常用方法**。

| 步骤 | 内容 |
|---|---|
| **① 证券分类** | **在某个时点上先将市场上的证券（如股票）按某些特征值（如市值、市盈率、账面值、账面市值比率等）进行风格分类（如大盘价值、小盘成长等）** |
| **② 计算加权平均值** | **然后根据基金实际所持证券的各项特征值计算出该基金在每一项特征上的加权平均值（权重为各证券在投资组合中的市值比重）** |
| **③ 综合判定** | **再对基金各项特征值进行综合以确定每只基金在该时点上的投资风格** |

> **此方法已被基金公司和基金评价机构广泛采用**。

##### ② 晨星投资风格箱（经典案例） P444

> **例如，美国晨星（Morning Star）公司的基金投资风格箱从规模和成长性两个维度来划分股票风格，每个维度分为三类**：

| 维度 | 三个类别 |
|---|---|
| **规模风格** | **大盘、中盘、小盘** |
| **价值—成长特性** | **价值型、平衡型、成长型** |

> **如图 12-1 所示，晨星投资风格箱是一个 3×3 的矩阵，共有 9 种投资风格**；**图中左上角单元格显示的基金投资风格即为"大盘价值型"**。

**3×3 = 9 种风格**（**大盘价值、大盘平衡、大盘成长、中盘价值、中盘平衡、中盘成长、小盘价值、小盘平衡、小盘成长**）。

##### ③ 优点与数据约束 P445

> **投资风格箱简单直观地展现了基金实际投资组合的资产配置风格**；**使用这种方法需要及时掌握基金投资组合持仓信息**。

**披露频率的约束（必背）**：

> **对于外部评价机构，依据当前证券投资基金在季报中披露的前十大重仓股，在半年报和年报中披露全部持仓信息，且有一定延迟**。

| 报告 | 披露内容 | 局限 |
|---|---|---|
| **季报** | **前十大重仓股** | **非全部持仓** |
| **半年报、年报** | **全部持仓信息** | **有一定延迟** |

#### （四）基于收益特征的风格分析 P445–P446

##### ① 方法原理 P445

> **基于收益特征的风格分析是运用多因子模型来确定基金投资风格的一种方法**；**该方法通过分析基金收益率对各种风格资产（通常由相应的风格指数代表）收益率的敏感性，来识别基金的实际投资风格**。

> **这种方法假定基金的收益可以分解为多个风格因子的线性组合，每个因子代表某种系统性风险**。

##### ② 夏普的多因子回归模型（核心公式） P445

> **这一方法最早由夏普基于多因子模型提出，他认为基金投资风格可以通过其收益率与预先设定的一组风格指数收益率之间的关系来确定**。

$$R_{pt}=\sum_{j=1}^{n}\beta_{pj}F_{jt}+\varepsilon_{t}$$

**符号**：**R_pt** —— **基金组合 p 在第 t 期的收益率**；**F_jt** —— **第 j 种风格因子在第 t 期的收益率**；**β_pj** —— **基金收益率对第 j 种风格因子的敏感性，即基金在该风格因子上的暴露程度，且 Σβ_pj = 1**；**ε_t** —— **残差，表示基金收益中无法被这些风格因子解释的部分，通常反映了基金经理的主动管理能力**。

> **通过回归分析基金的历史收益率与这些风格因子的收益率，可以估计出每个因子的敏感系数 β_pj，从而确定基金的风格特征**；**这些敏感系数反映了基金在不同风格上的暴露程度**。

##### ③ 三项优点 P445

> **基于收益率的分析方法对数据要求较低，只需要基金投资组合与风格指数的历史收益率数据，不需要持仓数据**；**且可以区分来自风格的收益贡献和基金经理积极管理的收益贡献，模型残差 ε 代表了基金经理的主动投资能力**。

##### ④ 三项局限（必背） P445–P446

| # | 局限 |
|---|---|
| **1** | **为保证回归分析的准确性和有效性，通常要求 20～36 个月的业绩数据，所以不适用于新成立的基金** |
| **2** | **也无法用来检验基金短期的风格变化** |
| **3** | **高度依赖于风格指数的选择** |

#### （五）两种方法的对比（必背）

| 维度 | **基于组合构成** | **基于收益特征** |
|---|---|---|
| **数据基础** | **持仓数据（持仓结构）** | **只需收益率数据，不需持仓数据** |
| **时效性** | **受披露频率限制（季报仅前十大、半年报/年报全部且延迟）** | **可用历史收益率，但需 20～36 个月** |
| **能否识别主动管理能力** | **不能直接区分** | **残差 ε 代表基金经理主动投资能力** |
| **主要局限** | **持仓信息不及时、不完整** | **不适用新基金、无法测短期变化、依赖风格指数选择** |
| **代表工具** | **晨星投资风格箱（3×3）** | **夏普多因子回归** |

#### （六）基金风格漂移（Style Drift） P446

##### ① 定义（必背） P446

> **基金风格漂移是指基金的实际投资风格偏离其明确宣称的投资策略或长期形成的稳定风格特征**。

> **这种偏离不同于主动管理基金为追求超额收益而进行的策略性配置差异，而是指那些导致基金风险收益特征发生根本性变化的投资行为转变**。

> **风格漂移可能表现为超出基金合同约定范围的调整，或者虽在合同范围内但与基金长期形成的市场定位和投资者合理预期产生显著不符的变化**；**这种变化会导致基金的风险收益特征与其原本设定或投资者认知的风格不一致，进而影响投资者的资产配置决策和风险管理**。

##### ② 关键辨析：策略性偏离 ≠ 风格漂移（高频考点） P446

> **需要强调的是，主动管理型基金本身就是通过与基准的适度差异化来创造超额收益，这种有目的、可控的策略性偏离并不构成风格漂移**。

> **真正的风格漂移是指那些改变基金基本投资哲学和风险特征的重大转变**，如：

| # | 典型转变 |
|---|---|
| **1** | **从价值投资转向成长追逐** |
| **2** | **从大盘蓝筹转向小盘投机** |
| **3** | **从一个行业主题大幅转向另一个不相关领域** |

##### ③ 两个理解维度 P446

> **风格漂移可以从两个维度理解**：

| 维度 | 内涵 |
|---|---|
| **法律合规维度** | **是否违反基金合同约定** |
| **市场感知维度** | **是否违背了基于长期投资行为形成的投资者合理预期** |

> **即使基金经理的操作在合同允许范围内，如果突然改变长期稳定的投资风格而未充分沟通，也可能被视为"实质性风格漂移"**。

##### ④ 两种表现形式 P446

> **风格漂移通常发生在基金经理显著改变投资策略时**；**最典型的情况是基金经理为了追求短期业绩或应对市场变化，显著偏离原有的投资风格**。

| 形式 | 示例 |
|---|---|
| **基本面风格漂移** | **原本侧重大盘价值的基金转向小盘成长投资** |
| **主题风格漂移** | **消费主题基金大幅配置新能源概念股，或健康主题基金显著超配食品饮料板块** |

> **此外，基金经理更换也可能导致基金投资风格的改变**。

> **投资者需要通过持仓分析和收益特征分析来判断基金的实际风格，及时发现可能的风格漂移，以规避由此带来的潜在风险**。

##### ⑤ 案例 12-13：一只"大盘价值型"基金的漂移 P446–P447

**基金定位**：

> **某基金最初定位为"大盘价值型"基金，主要投资于具有稳定收益和低估值的大型蓝筹股，业绩比较基准为沪深 300 指数**。

**前三年表现（符合定位）**：

> **该基金在成立后的三年内，基金经理一直遵循价值投资理念，投资组合以金融、能源、消费等大型低估值蓝筹股为主，行业配置与权重相对稳定，风险收益特征与基金定位高度一致，基金业绩表现稳健且波动性较低，赢得了追求稳健回报的投资者认可**。

**漂移发生**：

> **随着市场行情的变化，中小盘成长股开始表现强劲**；**面对业绩排名下滑的压力，该基金经理在未充分披露投资策略调整的情况下，逐渐将高达 40% 的资产配置到中小市值科技成长股，持仓结构与基金最初定位和历史投资风格产生了显著差异**。

> **这一调整虽然在基金合同允许的投资范围内，但与该基金长期形成的"大盘价值"市场定位有明显不符**；**在短期内，基金的收益排名确实有所提升**。

**后果**：

> **之后，市场出现风格切换，成长股剧烈调整，基金净值在两个月内回撤 25%，远超过同期沪深 300 指数的跌幅**。

**投资者视角**：

> **投资者李女士一直认为自己投资的是一只稳健的"大盘价值型"基金，面对基金净值的大幅波动和与沪深 300 指数不同的走势，她感到十分意外**；**经过调查，她发现基金的投资风格已经发生了漂移**；**尽管该基金仍有可能在成长行情中获得较高收益，但其风险特征已经超出她的预期和接受范围**；**最终，李女士选择赎回了该基金，转而投资到风格更为稳定的真正"大盘价值型"基金产品**。

##### ⑥ 风格漂移的五大原因 P447

> **导致基金风格漂移的原因多种多样，既有外部压力也有内部因素**。

| 类别 | 原因 |
|---|---|
| **外部因素** | **① 追求短期业绩排名**；**② 应对市场风格剧烈转换时的绩效压力**；**③ 被动接受大规模申购后的仓位调整困难** |
| **内部因素** | **④ 基金经理投资理念的变化**；**⑤ 投资团队或决策机制的调整**；**⑥ 基金契约规定过于宽泛导致约束不足**；**⑦ 投资决策监控机制不完善** |

> **值得注意的是，从全市场角度看，当大量基金同时发生类似方向的风格漂移时，可能意味着投资行为趋同，形成"羊群效应"，进而加剧特定板块估值泡沫和市场波动**。

##### ⑦ 为什么会伤害投资者（必背） P447

> **对投资者而言，风格稳定的基金是资产配置的可靠工具**；**尤其是养老金、保险资金等长期机构投资者，通常按照严格的资产配置策略分配资金至不同风格的基金产品，以构建风险分散、收益互补的投资组合**；**如果底层基金发生风格漂移，会使整体资产配置策略失效，导致风险暴露超出预期范围**。

> **这也是《养老目标证券投资基金指引（试行）》第六条要求养老基金在选择子基金时"重点考察风格特征稳定性"的原因**。

##### ⑧ 防范风格漂移的四项措施 P447

> **基金公司可以通过完善的风格监控和业绩归因体系来防范风格漂移**。

| # | 措施 |
|---|---|
| **1** | **定期分析基金的持仓结构风格（如大小盘暴露、价值/成长特征）、交易行为风格（如换手率、持股集中度）和业绩来源特征（如风格因子贡献、行业贡献）** |
| **2** | **设定风格一致性的量化指标和预警阈值，对有可能导致风格漂移的投资行为进行及时提示** |
| **3** | **将风格稳定性纳入基金经理的考核体系，避免过度强调短期收益而忽视风格一致性的考核导向** |
| **4** | **对于可能影响风险收益特征的重大风格调整，应提前通过公告、投资策略会议等方式充分披露和沟通，确保投资者的知情权并给予其调整配置的时间和机会** |

##### ⑨ 行业趋势 P447

> **从行业发展趋势看，随着市场的成熟和投资者教育的深入，基金投资风格的清晰界定和一致性维护正成为重要的竞争维度**；**近年来，我国新发基金产品越来越注重明确的风格或主题定位，如"红利""科技创新""消费升级"等**。

> **保持投资风格的稳定性不仅有利于基金公司在竞争中建立专业声誉和塑造品牌特色，也是其实现长期战略规划和客户信任的重要基础**。

#### （一）为什么需要综合评价基金管理人 P448

##### ① 现实需求：两类投资者都面临同一个问题 P448

> **与此同时，个人投资者的理财意识不断增强，投资者根据不同的风险偏好和收益目标，积极寻找适合的基金产品**；**养老金、保险、银行等机构投资者，出于管理成本、法律法规约束、提升自身专业能力等方面的考虑，逐步将部分资产委托给包括基金管理公司在内的外部资产管理机构进行管理**。

##### ② 核心逻辑：历史业绩的预测价值有限（必背） P448

> **学术界和业界普遍认为，历史业绩对于预测未来业绩的参考价值有限，投资能力和投资业绩在短期可能出现背离**。

> **优秀的业绩需要稳定的公司发展框架和长期投资策略才能延续**；**历史经验表明，投资能力强的基金管理人更有可能在长期取得相对稳定的业绩表现**。

> **因此，评价基金管理人需要识别那些决定投资业绩的长期因素，将视角从单纯的历史业绩扩展到公司治理、投资管理、风险管理和合规性等方面，通过定性和定量指标综合评判其价值**。

##### ③ 实践方式 P448

> **在基金管理人评价方面，不同投资者或评价机构有各自的分析框架，但普遍关注基金管理人在合规、治理、经营、投研、内控等方面的能力和表现**。

> **评价机构通常会针对每一项能力制定细化的评估指标，借助公开信息、问卷调查及访谈等方式收集数据，计算指标，最终通过综合分析给出评定结果**。

##### ④ 监管导向的最新要求 P448

### 12.5.b 【了解】基金管理人评价分析框架 P448–P453

**大纲原文**：了解基金管理人评价分析框架

#### （一）维度一：公司和人员的合规性 P448–P449

> **作为受托理财的持牌机构，基金管理人受到严格的监管约束**；**投资者和基金评价机构可以通过公开渠道，如中国证监会和中国证券投资基金业协会的处罚和自律管理决定、交易所发布的相关公告、基金产品定期报告、媒体曝光等，密切关注基金管理人在合规方面的表现**。

**重点跟踪的违法违规行为（必背）**：

> **持续跟踪其是否涉及"老鼠仓"、市场操纵、利益输送、不公平交易、违规销售和宣传等违法违规行为**。

> **对于存在严重损害基金份额持有人利益的违法违规行为，一些投资者和基金评价机构会采用黑名单制度，将相关基金管理人排除在待选或待评范围之外**。

#### （二）维度二：治理结构（最详细，考点集中） P449–P450

> **公司治理是确保公司高效运作的关键机制，旨在协调并约束内外部各利益相关方的行为**；**公司治理领域的核心问题主要包括股东与管理层之间的关系，以及股东之间的关系**。

> **基金管理是以人力资本为主要资本形态的行业，管理运作的是投资者的受托资产，因此必须坚持投资者利益优先原则**；**一个治理良好的基金管理公司应具备能够有效统一持有人、员工和股东三方利益的治理结构**。

##### 六个评估方面（必背） P449–P450

**① 治理架构与制衡机制**：

> **评估重点在于公司是否建立了清晰的治理架构，明确界定股东会、董事会、监事会/审计委员会和管理层的职责边界，并确保各方之间的有效制衡**；**特别关注独立董事、监事和督察长是否能够切实履行监督职能，强化高管人员的责任意识**；**同时，评估公司是否具备防范大股东或实际控制人滥用控制权干预正常经营的机制，以及是否能有效防范股东缺位和内部人控制的风险**。

**② 股东结构的稳定性与股权准入管理**：

> **稳定的股东结构是公司长期健康发展的基石**；**评估关注点包括股东变动频率、股权准入管理的严格程度，以及是否有效防范股权代持、变相套取或倒卖牌照等违规行为**。

**③ 独立董事制度的实施与效能（有具体数字，必背）**：

> **根据监管规定，基金管理公司的独立董事人数不得少于 3 人，且不得少于董事会人数的 1/3；基金管理公司第一大股东为自然人的，独立董事人数不得少于董事会人数的 1/2**。

> **评估重点在于独立董事制度的实际运作情况，包括独立董事的选聘程序、履职能力和实际发挥的作用**。

**④ 从业人员的绩效考核和薪酬管理（五项，考点密集）**：

| 子项 | 具体要求 |
|---|---|
| **（1）长周期考核机制** | **是否建立了以基金投资收益为核心的考核体系，对基金公司高管和基金经理的考核中，基金投资收益相关指标的权重分别不低于 50% 和 80%；是否全面实施长周期考核，3 年以上中长期收益考核权重不低于 80%** |
| **（2）与投资收益挂钩的薪酬管理** | **薪酬是否与基金投资收益相挂钩，对产品业绩长期显著低于业绩比较基准的基金经理，其绩效薪酬是否明显下降；对业绩显著超越基准的，是否可以合理适度提高** |
| **（3）考核指标的合理性** | **是否适当弱化了对规模排名、短期业绩和利润收入等短期或经营性指标的考核权重，引导基金管理人关注长期业绩和投资者实际盈利** |
| **（4）员工持股等长效激励** | **是否支持符合条件的基金公司依法实施员工持股等长效激励措施，增强核心团队的稳定性和凝聚力** |
| **（5）约束机制** | **是否强化基金公司、高管与基金经理的强制跟投比例与锁定期要求；是否严格落实绩效薪酬延期支付制度，以及对于严重违法违规的责任人员薪酬是否依法予以追索扣回** |

**⑤ 内部监督与控制机制的健全性**：

> **评估公司是否设立了独立的监察稽核和风险管理部门，是否建立了架构清晰、控制有效的内部控制机制，以及是否制定了系统全面、切实可行的内部控制流程**。

**⑥ 行业文化的践行**：

> **基金行业深入践行以"合规、诚信、专业、稳健"为核心的行业文化理念，并通过 2023 年 4 月中国证券投资基金业协会发布的《公募基金行业文化建设自律公约》予以明确**；**同时，坚持"五要五不要"原则，践行中国特色金融文化**。

> **基金评价机构通常会针对以上各个维度设置细化的评估指标，并根据不同指标的权重进行综合评分**。

#### （三）维度三：经营能力（四方面） P450–P451

> **经营能力是基金公司生存和发展的基石，主要体现在管理规模、产品结构、创新能力以及客户构成等方面**；**深入了解基金公司的发展历史，有助于评估其发展策略和未来潜力**。

| # | 方面 | 评估要点 |
|---|---|---|
| **1** | **管理规模** | **既要观察当前的总量，也要分析近年来的规模增长情况，包括新基金发行和存量基金持续营销带来的规模增长**；**也需要考察基金规模是否与基金公司的投资管理能力、运营能力、风险控制能力和营销服务能力相匹配，避免盲目扩张规模，影响投资业绩**；**在评估时，需要综合考虑市场容量、交易活跃度及流动性等因素** |
| **2** | **产品结构** | **关注公司产品的数量、类型覆盖及各类产品的规模分布等**；**通过公司的产品布局与行业其他公司的比较，分析公司在各类产品上的竞争力**；**产品线的广度和深度不仅反映了公司适应市场需求的能力，也体现了其在不同市场周期中的抗风险能力** |
| **3** | **创新能力** | **评估基金公司在产品和业务创新方面的表现，尤其是其是否能够在风险可控的前提下推出创新型产品以满足不同投资者的需求**；**创新不仅体现在产品线的拓展与优化，还体现在公司应对市场变化的灵活性和前瞻性** |
| **4** | **客户结构** | **考察公司客户结构，包括机构投资者和个人投资者占比、渠道及机构客户集中度、长短期资金的比例等**；**多元化的资金来源和较高的中长期资金占比，有助于公司保持稳健的经营，减少因短期资金流动导致的风险** |

#### （四）维度四：投资管理与研究能力（三方面） P451–P452

> **投研能力是基金管理人的核心竞争力**；**投资管理和研究能力评价包含对历史业绩、投研团队和投资流程的评价等**。

**① 历史业绩**：

> **即对基金管理人旗下不同类别基金产品基于不同指标进行定量分析**；**这些指标包括绝对收益、相对收益、风险调整收益、主动管理能力以及业绩归因等**；**在评估基金管理人旗下产品的总体历史业绩时，可以通过规模加权或者算术平均等方式衡量其整体的风险收益表现**。

> **值得注意的是，任何业绩指标都只能从一个维度反映基金表现，因此必须结合多种评价指标才能较为全面地衡量基金管理人的业绩水平和收益来源**；**同时，结合定性分析可以判断基金管理人的历史业绩是否能够代表其当前的投资管理能力，并根据不同资产类别（如股票和债券）对管理人的投资能力进行分类评估**。

**② 投研团队**：

> **投研团队是基金业绩的核心驱动力**；**投资决策过程中的每个环节——从研究、决策、组合构建、交易、风险管理到再平衡，都依赖于团队的协作和专业能力**。

**评价方式与七项内容（必背）**：

> **可以通过问卷调查、现场调研以及访谈等方式，深入了解投研团队的构成、协作情况以及其研究覆盖能力**。

| # | 评价内容 |
|---|---|
| **1** | **投研团队的资质、背景和从业经验** |
| **2** | **投资人员在投资过程中的实际参与度和协作情况** |
| **3** | **团队在宏观经济、投资策略、行业分析以及公司研究方面的覆盖能力和成果转化能力** |
| **4** | **薪酬和激励机制的合理性** |
| **5** | **投研梯队建设是否支持投研团队的长期发展和能力传承** |
| **6** | **核心人员稳定性** |
| **7** | **基金经理的投资理念和实际投资行为是否保持一致** |

**③ 投资管理流程**：

> **投资管理流程是基金管理人投资活动的制度规范和操作程序的综合**；**良好的投资流程能够确保投资过程的可重复性，减少主观随意性带来的风险**；**可以评估基金管理人的投资流程是否有制度化的规范，并且是否能够严格执行**。

> **优秀的基金公司通常采用自上而下的投研体系管理，而不是依赖单一投资经理主导基金产品的投资风格，考核机制注重中长期业绩表现**。

**这一制度设计的三大好处（必背）**：

| # | 好处 |
|---|---|
| **1** | **保证了投资风格的稳定性** |
| **2** | **保证了投研产出的持续性** |
| **3** | **能有效减缓因投资经理变更而引发的风格和业绩波动** |

> **因此，良好的投资管理流程能够帮助基金管理人更有效地接受长期资金的委托**。

#### （五）维度五：内部控制和风险管理能力 P452

> **基金管理人的内部控制是指公司为防范和化解风险，保证经营运作符合公司发展规划，保护投资者利益，通过建立组织机制、运用管理方法、实施操作程序和控制措施而形成的系统**。

**三个评估方面（必背）**：

| # | 评估方面 |
|---|---|
| **1** | **是否建立了健全的内控体系，包括设立独立的监察稽核部门，以及是否制定并严格执行相关制度和流程**——**这些流程应涵盖证券的出入库管理、员工行为规范、投资交易的监测分析与跟踪检验等**；**还需评估公司能否在研究、交易、风控、合规、监察等关键环节中实施有效的监督与制衡** |
| **2** | **评估公司在信息披露方面是否遵循了真实、准确、完整、及时和公平的原则**——**信息披露不仅是保障投资者知情权的重要手段，也是衡量基金管理人透明度和合规能力的关键指标** |
| **3** | **评估公司是否建立了涵盖各类风险的全面管理体系，包括市场风险、流动性风险、信用风险等，并是否有相应的管理方法和应急预案**——例如，**应对市场波动的措施、确保资产流动性的机制以应对大规模赎回、评估和管理投资组合中的信用风险、制定防范操作失误和系统故障的控制措施，以及在数据安全、系统容量管理和灾难备份方面进行投入**；**此外，公司应定期进行安全评估、压力测试和应急演练** |

#### （六）维度六：投资者服务能力 P452

> **基金管理人的投资者服务能力体现在其依托专业的投资及研究能力，通过一系列高质量的服务和措施，与销售机构协同合作，为投资者提供全方位支持**；**这不仅可以帮助投资者深入了解基金产品，还可以引导其合理进行资产配置，贯彻长期投资和价值投资理念，并实现良好的投资回报**。

**四个具体表现**：

> **具体表现包括逆周期布局和持续营销的效果、信息披露的透明度与质量、投资者教育的广度和深度以及政策宣传和舆论引导的有效性**。

#### （七）维度七：可持续投资实践情况 P453

> **环境、社会和公司治理（ESG）因素在投资决策中的重要性日益凸显**；**评估基金管理人的可持续发展实践，应从投资实践和自身运营两个维度展开**。

##### ① 投资实践层面（三项） P453

| # | 内容 |
|---|---|
| **1** | **考察基金管理人是否系统性地将 ESG 因素融入投资决策和风险管理**——**包括明确的可持续投资政策、专业团队及资源配备，在投资分析、决策及组合管理中全面体现 ESG 考量** |
| **2** | **关注基金管理人的信息披露质量**——**应定期向投资者及利益相关方披露其可持续发展政策、实施情况和投资组合的 ESG 表现，确保透明度与及时性** |
| **3** | **评估基金管理人在积极所有权方面的表现**——**应制定清晰的参与策略，主动参与被投资企业的重大决策过程，促进企业提升 ESG 绩效与长期价值**；**包括系统性关注企业的环境责任、社会贡献及公司治理状况，设定明确的改善目标与路线；通过独立判断表决股东大会中涉及 ESG 的议案，并与企业管理层开展建设性对话** |

##### ② 自身运营层面 P453

> **基金管理人还应在自身运营中贯彻可持续发展承诺，包括建立健全的公司治理结构、承担环境责任、保障员工公平待遇以及积极履行社会责任等**；**同时，在商业道德、反腐败措施、数据安全与隐私保护方面设立高标准**。

##### ③ 本土化结合（中国特色，易考） P453

> **此外，基金管理人能否将国际 ESG 标准与本土市场实际情况有效结合，也是评估的重要方面**。

| 领域 | 具体做法 |
|---|---|
| **绿色金融** | **积极支持国家碳中和目标、推动低碳经济转型** |
| **科技金融** | **优先投资能够推动产业升级与技术创新的企业** |
| **普惠金融** | **通过金融手段促进社会公平与共同富裕** |

> **这些做法体现了基金管理人对本土市场的深刻理解与实践创新能力**。

#### （八）七大维度速查表（必背）

| 维度 | 核心要点 | 关键数字/名称 |
|---|---|---|
| **合规性** | **跟踪老鼠仓、市场操纵、利益输送、不公平交易、违规销售宣传；严重者列入黑名单** | **公开渠道：证监会与中基协处罚决定、交易所公告、定期报告、媒体** |
| **治理结构** | **治理架构与制衡、股东结构与股权准入、独立董事、绩效考核与薪酬、内部监督、行业文化** | **独董 ≥3 人且 ≥1/3 董事；第一大股东为自然人时 ≥1/2**；**高管投资收益权重 ≥50%、基金经理 ≥80%；3 年以上中长期收益权重 ≥80%** |
| **经营能力** | **管理规模、产品结构、创新能力、客户结构** | **规模须与投管/运营/风控/营销能力匹配** |
| **投研能力** | **历史业绩、投研团队、投资管理流程** | **七项团队评价内容；自上而下投研体系** |
| **内控与风险** | **健全内控体系、信息披露五原则、全面风险管理** | **真实、准确、完整、及时、公平** |
| **投资者服务** | **逆周期布局与持续营销、信息披露、投资者教育、政策宣传与舆论引导** | — |
| **可持续投资** | **投资实践（融入决策、披露、积极所有权）+ 自身运营 + 本土化** | **ESG；绿色金融/科技金融/普惠金融** |

## 12.6 基金评价业务体系

> **随着基金行业的发展，基金产品数量不断增多，产品种类和投资策略不断丰富**；**同时，基金因其低成本、高效率的投资运作优势，使得基金成为越来越多投资者的投资选择**；**基金业绩评价和研究业务，在帮助投资者选择基金、鞭策基金管理人遵照契约、主动提升投资管理能力、促进基金行业健康发展方面发挥着重要作用**。

### 12.6.a 【了解】基金产品评价分析框架 P454–P457

**大纲原文**：了解基金产品评价分析框架

#### （一）基金评价业务概述 P454

> **基金业绩评价业务涉及基金分类、评价指标计算、评价结果发布等多个环节**；**经过多年的发展和实践，国内外基金评价机构已经形成各具特色、各有侧重的基金业绩评价方法体系**。

##### ① 监管依据与资质要求 P454

> **2009 年底、2010 年初，中国证监会和中国证券业协会相继发布《证券投资基金评价业务管理暂行办法》和《证券投资基金评价业务自律管理规则（试行）》**。

> **依照规定，基金评价机构对证券投资基金进行评价并通过公开形式发布基金评价结果的，要有相关的基金从业人员并有一定的研究经历、基金数据对接及科学的评价体系与内控机制，通过相关严格审核等，从而取得相应的资质**。

##### ② 首批 10 家基金评价机构（必背） P454

> **2010 年 5 月，经过评审，首批 10 家机构获得基金评价业务资质**：

| 类别 | 机构 |
|---|---|
| **证券公司（4 家）** | **中国银河证券股份有限公司、海通证券股份有限公司、招商证券股份有限公司、上海证券有限责任公司** |
| **独立基金评价机构（2 家）** | **晨星资讯（深圳）有限公司、北京济安金信科技有限公司** |
| **证券投资咨询机构（1 家）** | **天相投资顾问有限公司** |
| **媒体（3 家）** | **中国证券报、上海证券报、证券时报** |

##### ③ 长期评价倡议 P454

> **2019 年，10 家基金评价机构共同签署了《坚持长期评价，发挥专业价值》倡议书**，提出了三大方面的倡议：

| # | 倡议 |
|---|---|
| **1** | **坚持长期评价，树立长期投资理念** |
| **2** | **提升专业价值，优化基金评价机制** |
| **3** | **宣传长期投资，引导投资者关注长期收益** |

> **以强化长期评价导向，促进权益类基金发展，培育基金业长期发展的良好环境**。

#### （二）基金评价的六项原则（必背） P454–P455

> **根据《证券投资基金评价业务管理暂行办法（2020 修订版）》规定，从事基金评价业务应遵循如下原则**：

| # | 原则 | 内涵 |
|---|---|---|
| **1** | **长期性原则** | **即注重对基金的长期评价，培育和引导投资人的长期投资理念，不得以短期、频繁的基金评价结果误导投资人** |
| **2** | **公正性原则** | **即保持中立地位，公平对待所有评价对象，不得歪曲、诋毁评价对象，防范可能发生的利益冲突** |
| **3** | **全面性原则** | **即全面综合评价基金的投资收益和风险或基金管理人的管理能力，不得将单一指标作为基金评级的唯一标准** |
| **4** | **客观性原则** | **即基金评价过程和结果客观准确，不得使用虚假信息作为基金评价的依据，不得发布虚假的基金评价结果** |
| **5** | **一致性原则** | **即基金评价标准、方法和程序保持一致，不得使用未经公开披露的评价标准、方法和程序** |
| **6** | **公开性原则** | **即使用市场公开披露的信息，不得使用公开披露信息以外的数据** |

**记忆口诀**：**长期、公正、全面、客观、一致、公开**（**注：部分资料亦将"公开性"表述为"透明性"，以教材为准**）。

#### （三）环节一：基金分类（基础与核心） P455–P456

> **基金分类是基金业绩评价的基础和核心环节，对整个评价过程和结果都具有重大影响**。

##### 六项重要性（必背） P455–P456

| # | 重要性 | 说明 |
|---|---|---|
| **1** | **确保评价的公平性和可比性** | **不同类别的基金具有不同的风险收益特征、投资策略和业绩基准**；**通过合理的分类，可以确保在同类基金间进行比较，避免"苹果对比橘子"的情况出现**——例如，**将高风险的股票型基金与低风险的货币市场基金进行直接比较是没有意义的，甚至可能产生误导性结果** |
| **2** | **提高评价的精确度和专业性** | **细致的分类可以更好地反映各类基金的特点和表现**——例如，**在混合型基金中，可以根据股票投资比例进一步细分为偏股型、平衡型和偏债型等** |
| **3** | **满足投资者的差异化需求** | **不同投资者有不同的风险偏好和投资目标**；**通过明确的基金分类，投资者可以更容易地找到符合自身需求的基金产品** |
| **4** | **促进行业的规范发展** | **清晰的基金分类体系有助于规范基金产品的设计和运作，减少"风格漂移"等问题的发生**；**同时，它也为监管机构提供了更好的监督基础** |
| **5** | **提升评价结果的实用性** | **基于科学的分类体系，评价机构可以开发更多维度的评价指标，如同类排名、风险调整后收益等** |
| **6** | **适应市场发展的需要** | **随着基金行业的不断创新和发展，新的基金类型不断涌现**；**分类体系应允许评价机构及时调整和更新分类标准** |

#### （四）环节二：评价指标计算（核心环节） P456

> **评价指标计算是基金业绩评价的核心环节，它体现了各评价机构的业务逻辑和关注重点**。

**六个步骤（必背）**：

| # | 步骤 | 内容 |
|---|---|---|
| **1** | **数据收集与处理** | **从可靠来源获取基金净值、市场指数等原始数据，并进行清洗和验证** |
| **2** | **指标选择** | **根据评价目的和基金类型，选择合适的评价指标**；**这些指标通常涵盖收益性、风险性、风险调整后收益等多个维度** |
| **3** | **计算方法确定** | **针对每个指标，制定科学合理的计算方法和参数设置** |
| **4** | **数据分析** | **运用统计学和金融工程等方法，对基金表现进行全面分析** |
| **5** | **结果验证** | **通过交叉检验、历史数据比对等方式，确保计算结果的准确性和一致性** |
| **6** | **动态调整** | **根据市场变化和监管要求，适时调整和优化计算方法** |

> **评价机构在这一环节中的专业能力直接影响评价结果的质量和公信力**。

#### （五）环节三：评价结果发布 P456–P457

> **评价结果发布是向市场传递评价信息的重要环节**，主要包括以下几个方面：

| # | 方面 | 内容 |
|---|---|---|
| **1** | **发布形式** | **评级结果通常以评级或单一指标排名的形式发布**——例如，**多数评价机构会发布基于长期业绩的综合星级评级** |
| **2** | **发布渠道** | **结果可通过评价机构官网、专业金融终端、合作媒体等多种渠道发布** |
| **3** | **发布频率** | **根据评价对象和市场需求，可能采用日频、周频、月频或季频等不同的发布频率** |
| **4** | **信息展示** | **除了评级结果，通常还会提供评价方法说明、数据来源等辅助信息，以增加透明度** |
| **5** | **合规性审查** | **在发布前，需确保评价结果符合监管要求和行业规范** |
| **6** | **持续更新** | **定期更新评价结果，反映最新的市场变化和基金表现** |
| **7** | **投资者教育** | **在发布评价结果时，同时提供必要的解读和风险提示，帮助投资者正确理解和使用评价信息** |

> **评价结果的发布不仅是向市场传递信息，也是评价机构树立公信力和影响力的重要途径**；**因此，评价机构需要在及时性、准确性和公正性等方面严格把关**。

#### （六）基金评价业务的六项重要性和作用（必背） P457

> **基金评价业务在投资市场中的重要性和作用主要体现在以下几个方面**：

| # | 作用 | 说明 |
|---|---|---|
| **1** | **为投资者提供客观参考** | **专业的基金评价机构秉持对投资者负责的态度，坚持长期性和科学性原则，持续提供客观、中立的评价结果**；**这些评价基于专业、公开的标准，为投资者提供中长期风险收益评估，作为投资决策的重要参考** |
| **2** | **引导长期投资理念** | **基金评价引导投资者从短期业绩转向中长期表现，培养理性、长期的投资理念**；**这不仅有助于投资者获得更加稳定的回报，也促进市场的健康发展** |
| **3** | **促进行业良性发展** | **科学合理的基金评价结果对基金公司具有积极意义**——**能监督和激励基金管理人提升投资管理水平，作为内部绩效考核的参考**；**长期的评价导向促使基金公司逐渐将考核重点转向长期表现，遏制过度追求短期规模效应的行为，从而扶优抑劣** |
| **4** | **助力机构投资者决策** | **对于养老金、保险、银行等机构投资者，专业评价机构的意见能够补充和完善投资管理业务，优化投研资源配置**；**机构投资者可以将评价结果纳入其投研体系，帮助框定基金管理人和产品的研究范围** |
| **5** | **提升市场透明度** | **通过提供标准化、可比较的评价结果，基金评价业务提高了市场透明度，有助于减少信息不对称，促进市场的有效性** |
| **6** | **传播投资知识** | **基金评价机构在发布评价结果的同时，通过传播基金信息和投资知识，提升投资者的金融素养** |

> **综上所述，基金评价业务在维护投资者利益、促进行业发展、提升市场效率等方面发挥着重要作用，是健康、成熟的基金市场不可或缺的组成部分**。

#### （七）基金评价业务框架速查表

| 层次 | 内容 |
|---|---|

| **环节（三个）** | **① 基金分类（基础与核心，六项重要性）→ ② 评价指标计算（核心环节，六步骤）→ ③ 评价结果发布（七方面）** |

## 12.7 全球投资业绩标准（GIPS）

> **投资业绩的计算和比较有多种方法，不同方法产生的业绩报告往往缺乏可比性，这使得投资者难以比较不同投资管理管理机构的表现**；**为解决这一问题，全球投资业绩标准（Global Investment Performance Standards，GIPS）应运而生**。

### 12.7.a 【理解】GIPS 标准的定义、主要目标和核心特点 P457–P459

**大纲原文**：理解 GIPS 标准的定义、主要目标和核心特点

#### （一）GIPS 的定义 P457–P458

> **GIPS 是一套全球范围内广泛认可的、自愿性的道德标准，旨在确保投资管理机构和资产所有者能够公平、一致地列报其投资业绩，并充分披露相关信息，从而提升市场的透明度和效率**。

#### （二）发展沿革（时间线必背） P458

| 时间 | 事件 |
|---|---|
| **1987 年** | **由投资管理与研究协会（AIMR，CFA Institute 的前身）推出 AIMR 绩效呈现标准（AIMR-PPS），最初用于规范美国和加拿大的投资业绩报告** |
| **1995 年** | **GIPS 委员会成立，着手制定一套统一的国际标准** |
| **1999 年** | **首版 GIPS 发布，为全球投资业绩的计算与披露提供了统一框架** |
| **2005 年** | **修订版整合了各国家/地区的特定版本，进一步推动了全球标准化** |
| **2010 年 / 2020 年** | **继续更新，以确保其在全球投资行业中的前瞻性和实用性** |

- **2020 年版特别引入了针对资产所有者（如养老基金、主权财富基金、捐赠基金等）的具体指引和规定**。

#### （三）四项主要目标（必背） P458

> **GIPS 的制定旨在实现以下几个关键目标**：

| # | 目标 |
|---|---|
| **1** | **维护投资者利益，建立信任**——**通过确保投资管理机构以公平、一致且透明的方式展示其业绩，帮助投资者与管理机构建立信任**；**这种信任是构建稳固投资者关系的基石，有助于减少信息不对称，提升市场整体效率** |
| **2** | **确保业绩数据的准确性、一致性和可比性**——**要求对投资业绩进行一致的计算和呈现，确保不同机构间、不同投资产品之间的业绩数据具有可比性** |
| **3** | **提供全球统一的投资业绩报告框架**——**为全球投资行业提供了一个通用的报告框架，使得投资者能够更轻松地比较不同投资管理机构的业绩表现** |
| **4** | **推动行业的自律和专业化**——**通过鼓励广泛采纳 GIPS 标准，可以促进行业范围内的自律行为，提升投资管理和业绩报告的整体专业水平** |

#### （四）五大核心特点（必背） P458–P459

##### ① 自愿性与合规要求 P458

> **GIPS 是一套自愿遵守的标准，并非法律强制**；**然而，一旦一家机构宣称其遵守 GIPS 标准，就必须满足该标准的所有适用要求**。

> **如 GIPS 条款与当地法律法规有冲突，则机构必须遵守当地法律法规，并充分披露该冲突及处理方式**。

##### ② "全机构遵守"原则 P458–P459

> **GIPS 合规要求适用于整个机构（firm-wide basis），而非仅针对机构旗下的单个产品或组合群**；**机构必须在全面遵守所有适用规定的情况下，方可宣称其已符合 GIPS 标准**。

> **GIPS 标准中包含必须遵守的"规定"（Requirements）和推荐采纳的"建议"（Recommendations），后者代表了行业的最高标准和最佳实践**。

##### ③ 组合群（Composite）的构建 P459

> **为防止机构仅选择性展示业绩良好的投资组合，GIPS 规定投资管理机构应将所有实际管理的、可自由裁量投资的、具有相似投资策略或投资目标的收费组合，纳入至少一个组合群中**；**组合群的构建必须基于清晰、预设的标准**。

##### ④ 业绩历史的要求（必背） P459

> **除成立未满 5 年的机构外，所有宣称符合 GIPS 标准的机构必须报告至少 5 年的符合 GIPS 的业绩记录，并在此后每年更新，逐步增加业绩记录直至达到最少 10 年**。

> **对于 2000 年 1 月 1 日之前的业绩记录，如果其不完全符合 GIPS 标准，机构可以选择性地将其作为补充信息在 GIPS 报告中列报，但必须清晰地标明其不合规的性质以及具体不合规之处**；**自该日期起（或机构选择的更早的合规起始日期起）的业绩则必须完全符合 GIPS 标准**。

##### ⑤ 对输入数据的依赖与计算方法的规范 P459

> **GIPS 的有效性依赖于输入数据的真实性与准确性**；**投资管理机构应遵守 GIPS 规定的估值原则、收益率计算方法和列报要求，并必须完整列报和披露所有 GIPS 要求的内容**。

#### （五）GIPS 特点速查

| 特点 | 一句话 |
|---|---|
| **自愿性** | **非法律强制；一旦宣称遵守，则必须满足全部适用要求** |
| **全机构遵守** | **firm-wide，不是单个产品或组合群** |
| **组合群构建** | **所有实际管理、可自由裁量、相似策略的收费组合必须纳入** |
| **业绩历史** | **至少 5 年，逐步增至最少 10 年** |
| **数据与方法规范** | **依赖输入数据真实性，须遵守估值原则与收益率计算规范** |

### 12.7.b 【了解】GIPS 对主要分析指标的规定 P459–P462

**大纲原文**：了解 GIPS 对主要分析指标的规定

#### （一）对输入数据的规定（必背） P459

| # | 规定 |
|---|---|
| **1** | **自 2011 年 1 月 1 日起，组合必须以公允价值（Fair Value）进行估值**——**公允价值是指在计量日，市场参与者在有序交易中出售一项资产所能收到或者转移一项负债所需支付的价格**；**对于交易不频繁或难以获取市场价格的证券（如某些私募股权、房地产等），机构应采用层级化的估值方法，并遵循 GIPS 估值原则中关于使用模型和输入的指引** |
| **2** | **2001 年 1 月 1 日前，投资组合必须至少每季度进行一次估值；2001 年 1 月 1 日起，对于估值周期的要求由季度变更为月度**；**自 2010 年 1 月 1 日起，组合须至少每月估值一次，并在所有出现重大外部现金流的日期也必须进行估值** |
| **3** | **自 2005 年 1 月 1 日起，投资管理机构必须采用交易日会计制（Trade Date Accounting），即在交易发生日而非结算日确认资产和负债** |
| **4** | **对固定收益类产品等产生应计利息的证券，以及所有其他产生应计收入的资产，必须采用权责发生制确认收入，即在收入赚取时（而非实际收到时）予以确认** |

#### （二）对收益率计算的规定（核心考点） P459–P460

| # | 规定 |
|---|---|
| **1** | **必须采用总收益率**——**总收益率应包括已实现和未实现的资本利得与损失，并加上所有投资收入（如股息、利息等）** |
| **2** | **除非满足特定条件，否则须使用经现金流调整后的时间加权收益率来反映其投资管理能力，因其可以消除现金流入流出对业绩的扭曲影响**——**最低要求为：自 2005 年 1 月 1 日起，必须采用经每日加权现金流调整后的时间加权收益率；自 2010 年 1 月 1 日起，必须在所有出现大额现金流的日期对投资组合进行估值** |
| **3** | **投资组合的期间收益率必须通过将各子期间收益率进行几何连接得到**；**在计算组合群（Composite）的收益率时，必须使用组合群内各个投资组合的期初资产市值（或期初资产市值加上期间加权现金流）作为权重进行加权平均计算**；**必须计入投资组合中持有的现金及现金等价物（Cash and Cash Equivalents）及其产生的收益** |
| **4** | **所有的收益计算必须扣除期间内实际发生的直接交易费用（Actual Direct Trading Expenses），如经纪佣金、交易税费等**——**不得使用估计的交易费用** |
| **5** | **自 2006 年 1 月 1 日起，投资管理机构必须至少每季度一次计算组合群的收益，并使用个别投资组合的收益以资产加权计算**；**自 2010 年 1 月 1 日起，必须至少每月一次计算组合群收益** |

**关于"综合费用"打包的特别规定（易考）** P460：

> **有关直接交易费用的计算都必须严格依据实际发生的金额，不允许使用估计值**；**当实际发生的直接交易费用与投资管理费及其他间接运营费用一同被打包在一笔不可拆分的综合费用中时，业绩收益率的计算与列报需遵循特定指引**：

| 情形 | 处理 |
|---|---|
| **能从综合费用中准确识别并分离出直接交易费用** | **仅从总收益中扣除这部分已识别的直接交易费用** |
| **直接交易费用无法清晰分离** | **在计算收益率时必须扣除整笔综合费用**；**此时算出的"费前收益率"可能实际上已扣除了投资管理费和其他间接运营费用，必须充分、明确披露** |

#### （三）对组合群设定的规定（必背） P460–P461

| # | 规定 |
|---|---|
| **1** | **组合群必须以相同投资目标或策略定义**——**定义应当具有合理性，有利于投资者在投资管理机构间进行业绩比较**；**既不能过宽泛以至于掩盖不同策略的差异，也不能过狭窄以至于失去代表性** |
| **2** | **一个组合群必须包含所有实际管理的、符合该组合群预定标准的收费的可自由裁量投资组合** |
| **3** | **投资管理机构应及时将新的符合组合群定义的投资组合纳入相应的组合群** |
| **4** | **已终止投资组合的历史业绩应保留在组合群内，并包含在该组合被管理的最后一个完整计量期间（例如月份或季度）的业绩中**——例如，**一个于 7 月 15 日终止的投资组合，若按月进行业绩计量，其截至 6 月 30 日的业绩应被纳入组合群的历史业绩，并参与当年度组合群业绩的计算** |
| **5** | **除非正式修订组合的投资目标、范围、策略等充分且合理的理由，并且这种变动得到适当的文件记录和客户沟通，否则投资管理机构不可随意将投资组合在不同组合群之间转换** |

#### （四）信息披露与报告展示 P461

> **GIPS 标准中包含了大量关于信息披露和业绩报告展示的条款，详细规定了哪些信息必须公开，哪些内容必须在业绩报告（GIPS Report）中进行展示**；**这些披露要求旨在确保投资者获得全面、透明的信息**。

> **GIPS 也允许投资管理机构在其营销材料中按照 GIPS 的相关规定，展示 GIPS 报告的简略版本（如 GIPS Advertisement），但前提是必须清晰注明，包含所有强制性披露信息的完整 GIPS 报告可根据投资者要求提供**。

#### （五）另类资产及单独管理账户的业绩标准（必背） P461

| 资产/账户类型 | 特点 | GIPS 要求 |
|---|---|---|
| **房地产** | **流动性较低且估值具有特殊性** | **对估值方法、收益率计算（通常包括收入回报和资本回报）以及信息披露有特定规定** |
| **私募股权** | **长期性、非流动性以及现金流分布的不规则性** | **通常要求或推荐使用内部收益率（IRR）作为主要的业绩衡量指标，并对基金募集、投资、退出各阶段的信息披露作出规范** |
| **单独管理账户** | **费用（管理费、托管费、咨询费等）与其他服务成本捆绑** | **有特定规定，以确保即使在费用结构复杂的情况下，其投资业绩也能得到公平、可比的呈现** |

#### （六）GIPS 关键时间节点速查表（必背）

| 时间 | 规定 |
|---|---|
| **2000-01-01** | **此前不完全合规的业绩可作补充信息列报，须标明不合规性质** |
| **2001-01-01** | **估值周期由季度变更为月度** |
| **2005-01-01** | **必须采用交易日会计制；必须采用经每日加权现金流调整的时间加权收益率** |
| **2006-01-01** | **必须至少每季度计算一次组合群收益（资产加权）** |
| **2010-01-01** | **组合至少每月估值一次，重大外部现金流日也须估值；所有大额现金流日须估值；至少每月计算一次组合群收益** |
| **2011-01-01** | **组合必须以公允价值估值** |
| **业绩历史** | **至少 5 年，逐步增至最少 10 年** |

### 12.7.c 【了解】GIPS 合规鉴证的含义和作用，以及本土化应用原则 P461–P462

**大纲原文**：了解 GIPS 合规鉴证的含义和作用，以及本土化应用原则

#### （一）合规鉴证的含义 P461

> **为了增加投资管理机构声明其符合 GIPS 标准的可信度，机构可以自愿聘请独立的第三方鉴证机构对其 GIPS 合规情况进行审计和鉴证**。

**鉴证的范围（必背）**：

> **鉴证的范围包括机构是否在全机构范围内符合 GIPS 的所有适用要求，以及机构的政策和程序设计是否合理并已得到执行以确保其持续合规**。

#### （二）合规鉴证的作用 P461–P462

> **若机构未能满足 GIPS 标准的要求，鉴证机构通常会向机构指出不合规之处，机构需进行整改后方能通过鉴证**；**在成功通过鉴证后，机构可以在其 GIPS 报告中声明其已经过第三方独立鉴证**。

> **合规鉴证不是强制性的，但可以显著提升机构业绩报告的公信力**。

**一句话**：**自愿聘请 + 独立第三方 + 全机构范围 + 非强制但提升公信力**。

#### （三）GIPS 的本土化应用原则（核心考点） P462

##### ① 本土化的基本要求 P462

> **在中国市场应用 GIPS 标准时，相关机构应在遵循 GIPS 原则的基础上，按照本土监管法规的各项具体规定和精神实质，进行必要的调整和补充**。

**四项具体要求（必背）**：

| # | 要求 |
|---|---|
| **1** | **从严设定与规范使用业绩比较基准** |
| **2** | **注重透明和长周期的业绩披露** |
| **3** | **确保投资业绩的呈现和评价既符合国际通行做法，又能充分体现中国市场特点** |
| **4** | **提升专业性和透明度，切实保护投资者利益，并助力公募基金行业的高质量发展** |

##### ② 冲突处理原则（最重要） P462

> **在此过程中，若 GIPS 标准的具体条款与中国现行的法律法规（包括但不限于法律、行政法规、部门规章及其他具有法律约束力的规范性文件）的要求发生冲突，相关机构必须优先遵守中国的法律法规**。

**四项披露义务（必背）**：

> **同时，该机构应在其 GIPS 合规报告中，就该冲突的具体情况、所遵循的中国法律法规的具体条款与要求、未能遵循的 GIPS 条款，以及由此对业绩列报可能产生的影响等进行全面、清晰、显著的披露**。

| # | 披露内容 |
|---|---|
| **1** | **冲突的具体情况** |
| **2** | **所遵循的中国法律法规的具体条款与要求** |
| **3** | **未能遵循的 GIPS 条款** |
| **4** | **由此对业绩列报可能产生的影响** |

> **这种透明的披露是确保业绩信息完整性和维护投资者知情权的重要措施，也是 GIPS 标准所强调的道德责任和专业实践的核心组成部分**；**通过此类披露，即使在特定规定上与 GIPS 标准有所偏离，机构仍可在最大可能范围内展现其遵循 GIPS 精神的努力**。

#### （四）GIPS 三节速查表

| 主题 | 核心内容 |
|---|---|
| **12.7.a 定义与目标** | **自愿性道德标准；四大目标（投资者信任、数据准确可比、全球统一框架、行业自律专业化）；五大特点（自愿性、全机构、组合群、业绩历史 5→10 年、数据方法规范）** |
| **12.7.b 主要指标规定** | **公允价值估值、交易日会计制、权责发生制、总收益率、现金流调整 TWRR、几何连接、扣实际直接交易费用、组合群规则、另类资产（私募股权用 IRR）** |
| **12.7.c 鉴证与本土化** | **合规鉴证自愿、独立第三方、全机构范围、非强制但提升公信力；与本土法规冲突时优先遵守中国法律并四项披露** |

**一、单选题**

1. **B** —— **(1 + 26%)^(1/3) − 1 = 8.01%**。**A 是算术法（26%/3 ≈ 8.67%），大于几何法**。（12.2.a、案例 12-2）

**三、简答题**

8. **核心区别**：<br>① **时间加权收益率（TWRR）**：**将收益率计算区间分为若干子区间，每个子区间按现金流发生时间点划分，先计算每个子区间的收益率，然后以几何平均的方式将子区间的收益率连接起来**；**它剔除了资金进出对持有期收益率计算的影响**，**符合中国证监会关于基金净值增长率计算的规定，也是 GIPS 的基本要求之一**。<br>② **资金加权收益率（MWRR / IRR）**：**一般用于投资项目的整体收益率计算**，**着重考量资金流入流出及其对整体投资回报的影响**；**通常通过迭代法求解内部收益率**，**适用于投资者资金流动频繁的场景，能够更好地反映实际的资金使用效率**。<br><br>**公募基金更常用 TWRR 的原因**：**公募基金通常管理着来自多名投资者的资金，这些投资者可能在不同时间点进行申购和赎回操作；这些资金流动与基金经理的投资决策并无直接关联**；**若采用资金加权收益率，计算结果将不可避免地受到这些外部资金流动的影响，从而无法准确反映基金经理的真实投资能力**；**相比之下，时间加权收益率能够有效地排除这些外部因素对收益率计算的干扰，从而更加聚焦于基金经理的投资决策和市场表现**；**这种方法不仅符合全球投资业的标准做法，也满足了监管机构的要求**。（12.2.b）

#### 一、核心公式速查

| 公式 | 表达式 |
|---|---|
| **持有期收益率** | **(期末价 − 期初价 + 分红) / 期初价** |
| **算术平均** | **ΣR_i / n** |
| **几何平均** | **[Π(1+R_i)]^(1/n) − 1** |
| **年化收益率** | **(1+R)^(D/n) − 1**（**股票 D = 243**） |
| **时间加权收益率** | **(1+R_1)(1+R_2)…(1+R_n) − 1** |
| **资金加权（IRR）** | **Σ C_t/(1+IRR)^t = 0** |
| **复权单位净值** | **NAV_0 × (1 + TWRR)** |
| **相对收益（算术/几何）** | **R_P − R_b ／ (1+R_P)/(1+R_b) − 1** |
| **上行捕获率** | **基金上行期几何平均 / 基准上行期几何平均** |
| **下行捕获率** | **基金下行期几何平均 / 基准下行期几何平均** |
| **整体捕获率** | **UCR / DCR** |
| **夏普比率** | **(R_P − R_f) / σ_p** |
| **特雷诺比率** | **(R_P − R_f) / β_p** |
| **卡玛比率** | **(R_P − R_f) / MD** |
| **索提诺比率** | **(R_P − R_T) / DD_p** |
| **信息比率** | **(R_P − R_b) / TE** |
| **詹森阿尔法（简化）** | **R̄_P − R̄_f − β_p(R̄_m − R̄_f)** |
| **评估比率** | **α / σ(ε)** |
| **绝对收益归因** | **C_i = (MV_i/MV_P) × R_i** |
| **Brinson BHB 配置收益** | **Σ(w_p,i − w_b,i) × r_b,i** |
| **Brinson BHB 选股收益** | **Σ w_b,i × (r_p,i − r_b,i)** |
| **Brinson 交互收益** | **Σ(w_p,i − w_b,i)(r_p,i − r_b,i)** |

| 数字 | 含义 |
|---|---|
| **243 天** | **A 股年均交易日（基金年化标准天数）** |
| **360 / 365 天** | **债券类／房地产实业类年度标准天数** |
| **20～36 个月** | **基于收益特征风格分析所需数据** |
| **3×3 = 9 种** | **晨星投资风格箱** |
| **5 年 → 10 年** | **GIPS 业绩历史最低要求** |
| **2011-01-01** | **GIPS 公允价值估值起点** |

#### 三、易错点清单

1. **算术平均 > 几何平均，波动越大差距越明显**；
2. **年化以几何平均为基础**，不是简单乘以年数；
3. **持有期收益率只适用无资金进出**；有申赎须用 TWRR/MWRR；
4. **复权净值含分红再投资，累计净值不含**；
5. **基准为正时几何法 < 算术法；基准为负时几何法 > 算术法**；
6. **DCR 与基金收益同为负值，比值仍为正**；**负 DCR 表示基金与市场反向**；
7. **夏普用总风险（无基准），信息比率才用基准**；
8. **卡玛比率 < 0 时指标失效**；
9. **索提诺分子减最低可接受收益率 R_T，不是无风险利率**；
10. **特雷诺比率与夏普比率在充分分散化组合下相等**；
11. **詹森阿尔法不考虑择时；T-M 连续择时；H-M 非连续（虚拟变量 D=1 当 R_m>R_f）；C-L 判据为 β_1 > β_2**；
12. **Brinson BF 与 BHB 配置收益数值相等**（因 Σ(w_p−w_b)×r_b = 0）；
13. **Campisi 利差效应为负说明信用利差扩大**；
14. **策略性偏离 ≠ 风格漂移**；
15. **GIPS 一旦宣称遵守就必须满足全部适用要求；与本土法规冲突时优先遵守当地法律并披露**。
