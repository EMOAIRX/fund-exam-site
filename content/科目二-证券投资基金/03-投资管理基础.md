## 3.1 财务报表

### 3.1.a 【掌握】财务报表的定义、作用和基本构成 P59–P68

**大纲原文**：掌握财务报表的定义、作用和基本构成

#### （1）定义与作用 P59

> 在进行股票、债券及相关衍生工具投资时，**对目标公司（或其他主体）财务状况的深入分析是投资决策的基础**。

**财务报表（Financial Statements）**：

- 是投资者**据以了解和评估公司财务健康状况、经营业绩及现金流情况**的**核心工具**；
- 是**依据会计准则定期编制**的**标准化报告**，**系统反映了公司在特定时点或期间的经济活动全貌**。

#### （2）编制基础：会计基本假设与一般原则 P59

**会计基本假设**（会计核算工作应当明确的**前提条件**，**四个方面**）：

| # | 基本假设 |
|---|---|
| 1 | **会计主体** |
| 2 | **持续经营** |
| 3 | **会计分期** |
| 4 | **货币计量** |

- 这些假设为**会计核算的开展和财务信息的编制**提供了**统一的框架**。

**会计一般原则**：

- 指在**会计核算和财务报告编制过程中普遍适用**的一系列**基本规则、指导方针和惯例**，旨在**规范会计行为、确保信息质量**；
- 建立在**会计基本假设**基础之上，用于指导会计人员**如何确认、计量、记录和报告** 经济交易与事项；
- 以确保财务信息的**可靠性、相关性、可理解性和可比性**；
- 同时体现 **实质重于形式、重要性、谨慎性和及时性**等**信息质量要求**。

**六个会计要素与两个会计等式** P59–P60：

| 要素 | 反映 | 会计等式 |
|---|---|---|
| **资产、负债、所有者权益**|**财务状况**|**资产 = 负债 + 所有者权益**（揭示**特定时点** 的财务结构） |
| **收入、费用、利润**|**经营成果**|**收入 − 费用 = 利润**（反映**特定期间** 的经营成果） |

#### （3）基本构成：四张主表 + 附注 P60

> 财务报表主要包括**资产负债表、利润表、现金流量表和所有者权益变动表**四个**相互关联的核心部分**，共同勾勒出企业财务活动的全貌。

| # | 报表 | 别称/定位 | 反映内容 |
|---|---|---|---|
| 1 | **资产负债表**| 企业的"**财务快照**" | 反映其在**特定时点**拥有的**资产、承担的负债以及所有者拥有的权益** |
| 2 | **利润表**| — | 展示企业在**特定期间**的**经营成果**，详细列明**收入、成本费用及最终实现的净利润或亏损** |
| 3 | **现金流量表**| — | 追踪企业在**特定期间**内**所有现金的流入和流出**，并按**经营、投资和筹资活动**分类，有助于评估其**支付能力和现金管理效率** |
| 4 | **所有者权益变动表**| — | 详细记录并解释**报告期内所有者权益各组成部分的变动情况**，如**股本、资本公积和留存收益** 的变化 |

- **财务报表附注**：是**不可或缺**的部分，提供对**报表中重要项目的详细解释、会计政策说明及其他关键补充信息**。

#### （4）会计准则 P60

| 准则 | 适用范围 |
|---|---|
| **国际财务报告准则（IFRS）**| 国际上**最广泛使用** |
| **美国公认会计原则（US GAAP）**| 国际上**最广泛使用** |
| **中国企业会计准则（CAS）**| 中国**普遍遵循**，由**财政部**制定发布，也称"**新十准则**"（应为"**新准则**"） |

**我国会计准则的演进**：

| 时间 | 事件 |
|---|---|
| **2006 年 2 月 15 日**| 财政部发布**新企业会计准则体系**，**自 2007 年 1 月 1 日起在上市公司范围内全面实施**；包括**38 项具体准则**，涵盖**存货、长期股权投资、固定资产、无形资产、收入**等重要会计领域；此后还陆续发布**多项解释性公告** |
| **2014 年 7 月**| 财政部发布《**关于修改〈企业会计准则——基本准则〉的决定**》，**完善了会计信息质量要求，改进了会计要素定义和确认条件，增加了公允价值等计量属性**，使我国企业会计准则**更加符合 IFRS 的要求** |

- 我国的会计准则**在很大程度上与 IFRS 趋同，但仍保留一些本土特色**；投资者在分析**跨国公司或跨境投资**时，需注意**不同会计准则的差异**；
- 近年来财政部针对**收入确认、金融工具、租赁**等领域发布了**重要的新准则或修订**；分析**历史数据**时要注意**新旧准则变更可能带来的会计科目和数据口径差异**。

#### （5）资产负债表（Balance Sheet） P60–P63

**① 定义**：

> 资产负债表记录了公司在**某一时点**的**资产、负债和所有者权益**及其相互关系的信息，**报告时点通常为会计季末、半年末或年末**；它反映了公司在**特定时点的财务状况**，是**公司经营管理活动结果的集中体现**。

**作用**：通过分析资产负债表，投资者可以了解公司**资产要素、长期或短期偿还债务能力、资本结构的合理性，以及股东权益结构**；还可以**评估公司经营的稳健性和面临的风险**。

**② 三个要素** P61：

| 要素 | 定义 |
|---|---|
| **资产**| 公司**因过去的交易或事项形成**的、**由公司拥有或控制**的资源，**预期会带来未来经济利益** |
| **负债**| 企业**因过去的交易或事项形成**的、**预期会导致经济利益流出**的义务，并且**该义务能够可靠计量** |
| **所有者权益**（又称"**股东权益**"或"**净资产**"） | 公司**总资产在清偿所有负债之后，最终归属于所有者**的那部分**剩余权益**；体现了平衡关系：**所有者权益 = 资产 − 负债** |

**所有者权益的两大来源**：

| 来源 | 具体项目 |
|---|---|
| **① 所有者直接投入的资本**|**实收资本（或股本）** 以及**资本公积**（特别是**资本或股本溢价** 部分） |
| **② 企业通过自身经营活动累积**|**留存收益**（具体由按规定提取的**盈余公积**——如**法定盈余公积和任意盈余公积**——和**尚未分配的未分配利润**构成）和**其他综合收益**（指那些**未通过当期利润表确认、但直接计入所有者权益** 的累积额） |

**资产负债表中所有者权益的主要项目**：

> **实收资本（或股本）、资本公积、盈余公积、未分配利润**以及**其他综合收益**。

- 如果公司**回购并持有自己的股份**，形成的**库存股**会作为**所有者权益的一个抵减项目** 列示；
- 根据特定会计准则（如**安全生产费规定**），还可能存在**专项储备**这一特殊项目；**专项储备通常有明确的用途限制，使用后需按规定转回至留存收益**。

**③ 资产结构与资本结构分析** P63：

| 分析 | 内涵 |
|---|---|
| **资产结构**| 指公司**各类资产（如固定资产、流动资产和无形资产）的构成比例**；不同类别的资产在**资产形态、流动性**等方面有明显差异，在**公司持续经营过程中的角色**也不一样；**资产的规模和结构等对于公司盈利与风险控制有着决定性的影响** |
| **资本结构**| 指**资产负债表右边各个项目的结构**，即**资本来源比例及其相互关系**，包括**负债与所有者权益的结构、负债内部长短期债务的结构、所有者权益各构成项目的结构以及实收资本内部有分红权的股东出资规模结构**；<br>**短期资本是资金余缺的调节器，但筹资风险高**；**长期资本是筹资风险的保障**；**债务资本能为权益资本产生财务杠杆效用**；公司可通过**调整资本结构，利用财务杠杆来均衡筹资风险与资本成本** |

**④ 资产结构与资本结构的匹配** P63：

> 按照财务理论，**公司筹集资金的用途决定筹集资金的类型**：

| 情形 | 正确做法 | 若错配的后果 |
|---|---|---|
| **增加长期资产**| 应通过**长期性来源**（**所有者权益和长期负债**）来支持 | — |
| **增加经营性流动资产**或**由于季节性、临时性增加的流动资产**| 应由**短期性来源** 解决 | — |
| **用长期性来源支持短期、波动性流动资产**| — | 由于**长期性来源的资本成本相对较高**，最终会导致**公司的效益下降**，但**财务风险较低** |
| **用短期来源支持长期资产**| — | 由于**长期资产周转时间相对较长**，公司可能**经常需要承受短期偿债的压力，违约风险较高** |

#### （6）利润表（Income Statement） P64–P66

**① 定义**：

> 利润表，又称**损益表**，反映公司**在一定期间（如一个季度或年度）的经营成果**；是一份**动态报告**，通过展示**收入、费用和利润的变化**，揭示其**经营趋势**。

**② 三部分构成** P64：

| 要素 | 定义 |
|---|---|
| **收入**| 公司通过**销售商品、提供服务或让渡资产使用权**等**经营活动**获得的**经济利益流入**；反映公司的**营业规模**，是**公司业绩的主要来源**；**营业收入包括主营业务收入和其他业务收入**（后者通常指**非核心业务** 产生的收入） |
| **费用**| 公司为**获取收入而在日常活动中发生**的**经济利益流出**，主要包括**营业成本、税金和附加、销售费用、管理费用、研发费用、财务费用**等；**投资损失和营业外支出**属于**非日常经营活动**产生的项目，通常**不计入日常经营费用，而是在损益表中单独列示** |
| **利润**| 公司在**特定会计期间内**的**经营成果总和**；主要由**营业利润**（即**营业收入减去营业成本和期间费用后的结果**）、**投资收益、其他收益、公允价值变动损益**以及**营业外收支** 等组成 |

- **营业利润**反映公司**主营业务的盈利能力**，是**日常经营活动的核心成果**；
- **非经常性损益项目**（如**投资收益、资产处置损益和营业外收支**）反映公司在**非日常经营活动** 中的表现；
- 这些项目共同构成**利润总额**，**扣除所得税费用后得到净利润**。

**③ 经营性利润与息税前利润（EBIT）** P65–P66：

> **息税前利润（EBIT）** 是**不扣除所得税和利息的利润**；反映了公司在**不考虑税收和融资成本**的情况下的**盈利能力**，适合**不同税率和资本结构的公司之间的对比分析**。

**推导公式**：

$$EBIT = 净利润 + 所得税 + (利息费用 - 利息收入)$$

- **原因**：EBIT 旨在衡量**核心经营活动的盈利能力**，需**剔除非经营性的利息收支和所得税影响**；对于**非金融企业**，其**利息收入通常来自闲置资金管理等非主营活动，应视为非经营性收益**，因此在基于"净利润"推导 EBIT 时，**需要将已包含在净利润中的利息收入扣除**；
- **金融企业**或将**资金融通作为主营业务**的企业，其**利息收入属于经营性收入**，**计算 EBIT 时无需调整利息收入项**。

**教材示例**（A 股某上市公司，非金融企业）：

$$EBIT = 4\,676\,103.45 + 715\,301.88 + (344\,651.58 - 832\,180.21) = 4\,903\,876.65 \text{（万元）}$$

**计算 EBIT 时的注意事项**：

> 利润表中列示的"**利息费用**"通常**仅为费用化的利息**。根据会计准则，**符合条件的借款费用（利息）会被资本化计入相关资产（如在建工程）的成本，而非计入当期损益**。因此，本处基于利润表数据计算的 EBIT**未包含资本化利息部分**，**可能无法完全反映企业真实的、剔除总利息负担前的经营成果**。更精确的分析可能需要参考**财务报表附注中关于借款费用资本化的详细信息**。

**④ 营业收入与盈利水平分析** P66：

- 公司**盈利水平的高低是资本市场投资的关键指标**，投资者应**高度关注利润表反映的盈利水平及其变化**；
- 分析营业收入时应注意**两个方面**：

| 方面 | 要点 |
|---|---|
| **营业收入结构**| 不同**产品或服务的收入构成**对公司**业绩和风险**有重要影响；应关注**占总收入比重较大的产品或服务是否是公司利润增长的主要来源**；此外要关注**关联方交易的收入比重**——关联方交易可能涉及**非市场化因素，如人为制造收入以包装公司业绩**，因此应特别关注**关联交易的价格、规模和实现时间** 等细节 |
| **变动趋势**|**持续增长的收入是公司生存和发展的基础**，**收入增长率的变化**能够反映公司**市场份额和财务状况** 的变化 |

#### （7）现金流量表（Cash Flow Statement） P66–P68

**① 定义与编制基础**：

> 现金流量表反映公司在**特定会计期间内**的**现金及现金等价物的流入和流出情况**。与利润表不同，现金流量表**采用收付实现制编制**，反映公司**实际的现金流入和流出情况**。

**② 三部分结构** P66–P67：

| # | 类别 | 英文 | 现金流入 | 现金流出 |
|---|---|---|---|---|
| 1 | **经营活动产生的现金流量**|**CFO**（Cash Flow from Operations） |**销售商品或提供劳务收到的现金、收到的税费返还**，以及其他与经营活动相关的现金收入 |**购买商品、接受劳务支付的现金，支付给员工及为员工支付的现金，支付的各项税费**，以及其他与经营活动相关的现金支出 |
| 2 | **投资活动产生的现金流量**|**CFI**（Cash Flow from Investment） |**出售固定资产、无形资产及长期股权投资所收回的现金**；**取得投资收益所收到的现金**（如**股利、利润及利息收入**） |**购建固定资产和无形资产所支付的现金**（反映公司为**扩展或维护生产能力**的支出）；**长期股权投资和其他长期投资所支付的现金** |
| 3 | **筹资活动产生的现金流量**|**CFF**（Cash Flow from Financing） |**吸收投资所收到的现金**（如**发行股票**）、**借款所收到的现金**（如**银行贷款**），以及其他与筹资活动有关的现金收入（如**接受捐赠**） |**偿还债务所支付的现金**（如**偿还借款本金**）、**分配股利、利润或偿还利息所支付的现金**，以及其他与筹资活动相关的现金支出（如**筹资相关费用**） |

- **CFO**是评估公司**经营效率和现金产生能力** 的重要指标。

**③ 净现金流公式**：

$$NCF = CFO + CFI + CFF$$

- **三部分现金流加总后得到净现金流（Net Cash Flow，NCF）**。

**④ 现金流量表的意义** P68：

> **现金流量是公司持续经营的基本保障，也是公司扩大再生产的资源保障**。它反映的是**公司财务状况的动态变化**，是评估公司**偿债能力、现金获取能力以及股利支付能力** 的重要依据。

#### （8）四张报表速记

| 报表 | 一句话 | 时点/期间 | 编制基础 | 核心等式/结构 |
|---|---|---|---|---|
| **资产负债表**| "**财务快照**" |**时点**| 权责发生制 |**资产 = 负债 + 所有者权益** |
| **利润表**|**动态**经营成果 |**期间**| 权责发生制 |**收入 − 费用 = 利润** |
| **现金流量表**|**实际**现金进出 |**期间**|**收付实现制**|**NCF = CFO + CFI + CFF** |
| **所有者权益变动表**| 权益**各组成部分**的变动 |**期间** | 权责发生制 | 股本、资本公积、留存收益等 |

最高频陷阱：**现金流量表是唯一采用"收付实现制"的主表**；利润表与资产负债表都是**权责发生制**。

## 3.2 财务报表分析

### 3.2.a 【理解】财务报表分析的目的、主要内容和基本方法 P69–P70

**大纲原文**：理解财务报表分析的目的、主要内容和基本方法

#### （1）分析目的 P69

> 财务报表分析的目的是**评价上市公司的财务质量**，并**识别可能存在的财务操纵行为**。

**财务质量的三个方面**：

| 方面 | 内涵 |
|---|---|
| **财务状况**| 主要涉及**资产负债结构和资产质量** |
| **盈利能力**| 指公司在**常规经营期间从主营业务所取得的经常性净利润**，以及这些利润的**稳定性和可持续性**；**盈利质量分析**涵盖**盈利水平、盈利结构和盈利趋势** 等多方面内容 |
| **现金流量**| 核心是**经营活动产生的现金流量** |

- 通过对**资产负债表、利润表和现金流量表**的深入分析，投资者可以**全面了解公司的财务质量**。

#### （2）报表可信度与财务操纵 P69–P70

> 财务报表分析还需要**关注报表的可信度**。公司管理层可能会出于某些需求，在编制财务报表时**选择最有利的会计方法，调节应计科目**，从而**掩饰公司真实情况**。

**财务操纵的两类**：

| 类型 | 界定 |
|---|---|
| **财务粉饰（盈余管理）**| 一般是**在会计准则允许的范围内调整财务数据** |
| **财务舞弊**| 往往涉及**管理层组织的系统性造假** |

- 经过操纵的财务报表**无法反映公司真实的经营情况，可能误导投资者并影响其决策**；因此，**识别财务操纵行为是财务报表分析的重要环节，贯穿整个分析流程**。

#### （3）分析的三个方面 P70

| # | 方面 | 内容 |
|---|---|---|
| 1 | **会计方法**| 分析公司在财务报表中运用的**会计政策和会计估计**是否**合理、是否可控，和同类公司是否可比** |
| 2 | **报表项目**| 包括对报表中各项目之间的**勾稽关系、项目结构和项目内容**的分析；**勾稽关系**是指财务项目之间的**逻辑关系**，通过勾稽关系验证可以**找出报表中的潜在错误**；**项目结构分析**有助于了解**行业特征、营运模式和投融资方式**；**项目分析的要点**是观察**重点项目的金额、性质以及变化情况** |
| 3 | **财务比率**|**财务报表上用两个或以上数据计算的比率**；可划分为**偿债能力、营运能力、盈利能力、发展能力** 四大类 |

#### （4）基本方法：纵向比较 + 横向比较 P70

> 财务报表分析**并不仅限于单个会计期间的财务数据**。

| 比较方向 | 含义 | 作用 |
|---|---|---|
| **纵向比较**| 将各项财务指标或比率和**本公司前期情况**进行比较 |**发现趋势或差异，并分析其背后的原因** |
| **横向比较**| 与**同行业公司**比较 | 评估**相对地位** |

- 此外还应结合**宏观环境、公司所处行业情况、公司在行业中的市场地位、公司内部管理情况**等，**深入挖掘公司的经营信息**；
- 通过**纵向（同一公司不同期间）和横向（与同行业公司）比较**，可以**更全面地评估公司的财务健康状况**。

#### （5）不同投资者的侧重点 P70

| 投资者类型 | 关注点 |
|---|---|
| **商业银行和债券投资者**| 通常关注公司的**偿债能力、支付能力以及现金流风险**，进行**信用分析** |
| **股票投资者**| 更注重**公司经营现状、发展前景、潜在风险和投资价值** |

#### （6）分析局限性 P70

> 对于**无法直接通过会计计量**的事项，例如**公司治理、人力资源、专利技术和社会价值**等，**仅靠财务报表分析难以得出准确判断**，还需要**结合其他信息和分析方法** 来综合考量。

### 3.2.b 【掌握】反映公司经营和财务情况的主要财务比率的计算方法和含义 P70–P77

**大纲原文**：掌握反映公司经营和财务情况的主要财务比率的计算方法和含义

#### （0）财务比率分析的作用与四大类 P70

**财务报表分析可以回答的四个关键问题**：

1. 公司**资产的流动性** 如何？
2. 公司面临的**财务风险** 有多大？
3. 公司**资产的使用效率** 如何？
4. 公司的**盈利能力** 有多强？

> **财务比率分析**是指用**财务比率**来描述公司**财务状况、盈利能力以及流动性**的分析方法。财务比率通过不同的会计数据计算得出，**通常以比值的形式展现**；这种计算方法**消除了公司规模的影响**，既可以用来比较**不同行业、不同规模公司之间**的财务状况，也可以用来比较**同一公司在不同会计期间** 的变动情况。

**四大类比率**：**偿债能力、营运效率、盈利能力、发展能力**。

---

#### （1）偿债能力比率 P71–P73

> **偿债能力**是指公司**在一定时间内清偿各种到期债务**的能力；一般可分为**短期偿债能力**和**长期偿债能力**。

##### ① 短期偿债能力

- **定义**：短期内公司在**不致使财务状况恶化**的前提下，**利用手中持有的流动资产偿还短期负债**的能力，其**关注重点是公司的流动资产和流动负债**；
- **流动资产**主要包括**现金及现金等价物、应收票据、应收账款和存货**等，这些资产**能够在短期内快速变现**，因而**具有较强的流动性**；
- **流动负债**是指公司需在**一年或一个营业周期内**偿付的各类短期债务，包括**短期借款、应付票据、应付账款** 等；
- 由于流动资产和流动负债的**存续期较短**，它们的**市场价值通常与账面价值接近**；
- **速动资产**是指**流动资产中扣除变现能力相对较差的项目（主要是存货，有时也包括预付账款等）**，主要包括**货币资金、交易性金融资产、应收票据、应收账款**等；与流动资产相比，**速动资产更具流动性**。

**两个指标**：

| 指标 | 公式 | 判断标准与含义 |
|---|---|---|
| **流动比率** | $$\text{流动比率}=\frac{\text{流动资产}}{\text{流动负债}}$$ | 衡量公司**流动资产对流动负债的覆盖率**，反映公司**利用流动资产偿还短期负债的能力**；一般认为**流动比率大于 2** 表明公司具备**较强的短期偿付能力** |
| **速动比率** | $$\text{速动比率}=\frac{\text{速动资产}}{\text{流动负债}}$$ | **更加保守**地衡量公司短期偿债能力，因为**只考虑可以快速变现的资产，不包括存货**等流动性相对较差的流动资产；通常**速动比率大于 1** 被认为是**健康**的 |

**四个易错要点**：

1. **行业差异**：不同行业的公司在**销售收款方式、应收账款回收效率**等方面往往存在差异，因此**不同行业的速动比率通常会有所不同**；
2. **内部转换的影响**：**流动资产的内部转换不会影响流动比率，但可能会改变速动比率**——例如**使用现金购买存货不会影响流动比率，但会降低速动比率**；
3. **计算口径**：速动比率的**具体计算口径可能存在不同理解**（例如**是否扣除预付账款**），但**最核心的是剔除存货**；
4. **并非越高越好**：**应收账款和存货的增加可以提高流动比率**，**应收账款的增加可以提高速动比率**，而**提早付款给供应商可以减少流动负债**——但这些做法**无法真正提高流动性**；事实上，对于某些**在供应链上占据强势地位**的公司，其**流动比率和速动比率可能远低于 1**；实际分析中需要**结合资产结构、资本结构和营运效率综合判断**。

**静态指标的局限**：**流动比率、速动比率和资产负债率**都是**来源于资产负债表的静态比率**，体现的是**期末时点的静态偿债能力**；作为**静态指标**，其高低可能**受到报表日前后短期异常因素的影响**，因此分析时**需要考虑更长时间段的变化趋势**；此外，由于基于**特定时点数据**，**理论上存在被人为操纵的可能性**。

##### ② 长期偿债能力

> **长期偿债能力**关注**公司长期债务的风险**。由于公司的**长期负债与其资本结构中的财务杠杆有关**，因此常常用**财务杠杆比率** 来衡量长期偿债能力。

**三种常用财务杠杆比率**：

| 指标 | 公式 | 说明 |
|---|---|---|
| **资产负债率** | $$\text{资产负债率}=\frac{\text{负债总额}}{\text{资产总额}}\times 100\%$$ | **负债总额包括短期负债和长期负债**；是**使用频率较高**的债务比率 |
| **权益乘数**（又称"**杠杆比率**"） | $$\text{权益乘数}=\frac{\text{资产总额}}{\text{所有者权益总额}}$$ | 由资产负债率**衍生** |
| **负债权益比** | $$\text{负债权益比}=\frac{\text{负债总额}}{\text{所有者权益总额}}$$ | 由资产负债率**衍生** |

**三者之间的换算关系**（因为**资产 = 负债 + 所有者权益**）：

$$\text{权益乘数}=\frac{1}{1-\text{资产负债率}} \qquad \text{负债权益比}=\frac{\text{资产负债率}}{1-\text{资产负债率}}$$

> 这三个比率**实际上表达了相同的含义**，即公司的**财务杠杆水平**；**由其中一个比率可以很容易计算出另外两个**；这些指标的**数值越大**，意味着**财务杠杆比率越高，公司的负债程度越重**。

**关于资产负债率的深入理解**：

- 由于**债务尤其是长期负债的利息具有税盾效应**（指**利息在公司所得税前支付，利息费用可以减少公司应缴的税收**），因此**很多公司会使用财务杠杆举债经营**；
- 但**过大的债务负担会产生较大的利息支出和现金流压力**，**破产成本和财务困境成本可能会大幅增加**，**削弱甚至抵销税盾效应带来的价值**；
- 因此，**采用多大的杠杆（即资产负债率多大）最为合适，是难以精确计算决定的**；
- **资产负债率在同行业公司的比较中有较大的参考价值**，在其他情况下则需根据公司**具体的资本结构与价值关系，遵循适中原则** 进行判断。

**利息保障系数（利息保障倍数）**：

$$\text{利息保障系数}=\frac{\text{息税前利润}}{\text{利息费用}}$$

- **定位**：**资产负债率、权益乘数和负债权益比衡量的是公司长期债务的本金保障程度**，而**衡量公司对于长期债务利息保障程度**的指标是**利息保障系数**；
- **判断标准**：对于债权人来说，**利息保障系数越高越安全**；从基本关系看，**这个指标至少要大于 1**，否则**公司的利润就是负数**；例如**利息保障系数为 2**意味着公司的**息税前利润是利息费用的两倍**，表明公司**有足够的盈利来覆盖利息支出**；
- **两个局限性**：
  1. 它**只能反映公司偿还利息的能力，无法反映债务本金的偿还能力**；
  2. 分子"**息税前利润**"是**基于利润而非现金**，而**实际支付利息需要真正的现金流**；在**经营活动现金流与利润差距较大**的情况下（如**应收账款大幅增加或存货积压严重**时），**较高的利息保障系数也无法准确反映公司偿还利息的实际能力**；
- **行业差异**：**资本密集型行业（如制造业）可能需要更高的利息保障系数**，而**现金流稳定的行业（如公用事业）可能可以接受相对较低的利息保障系数**。

偿债能力分析须**结合公司的现金流量、融资渠道和授信额度、股东及相关方的资金支持意愿和能力**等因素**综合判断**，同时考虑**行业特性和公司的具体经营情况**。

#### （2）营运效率比率 P73–P75

> **营运效率**是指公司在**经营期间，资产从投入到产出的周转速度**；它反映了公司的**资产管理质量和利用效率**。

**三个衡量指标**：**存货周转率、应收账款周转率、总资产周转率**。

##### ① 存货周转率

$$\text{存货周转率}=\frac{\text{销售成本}}{\text{平均存货}} \qquad \text{存货周转天数}=\frac{360\text{ 天}}{\text{存货周转率}}$$

- **销售成本**指公司**销售产品的成本（即营业成本）**；**平均存货**通常是**期初存货与期末存货的算术平均数**；
- **存货周转率越大**，说明**存货变现速度越快，存货管理效率越高**；
- **示例**：年度报告的**存货周转率是 4**，意味着这家公司**平均每 90 天（360/4）存货周转一次**；
- **决定因素**：**业务模式、生产周期、供应链管理能力、生产组织能力和市场销售能力**；
- **两点注意**：
  1. 对于**存在多项不同性质业务**的公司，使用**全部销售成本**作为分子计算的存货周转率**缺乏明确的经济含义，难以进行有效比较**；
  2. 存货一般包含**原材料、在产品和产成品**，**不同类型存货的周转率可能存在较大差异**，实际应用中**可以根据存货类型进行分类计算**。

##### ② 应收账款周转率

$$\text{应收账款周转率}=\frac{\text{销售收入}}{\text{平均应收账款}} \qquad \text{应收账款周转天数}=\frac{360\text{ 天}}{\text{应收账款周转率}}$$

$$\text{平均应收账款}=\frac{\text{期初应收账款}+\text{期末应收账款}}{2}$$

- **简单平均法**适用于**应收账款余额变动较为平稳**的情况，但在**应收账款波动较大**时，**可能无法准确反映实际的资金占用水平**；
- **精细分析口径**：会将**应收票据包含在内**，并将客户预付的**预收账款从中抵扣**，以更准确地反映企业的**真实应收款项情况**；这通常适用于**行业特征明确、信用管理复杂** 的企业：

$$\text{平均应收账款}=\frac{(\text{期初应收账款}+\text{期初应收票据}-\text{期初预收账款})+(\text{期末应收账款}+\text{期末应收票据}-\text{期末预收账款})}{2}$$

- **含义**：应收账款周转率**越高**，说明**应收账款变现速度越快，公司能够更快地收回销售收入**；这可能反映企业拥有**较强的议价能力或严格的信用政策**；反之，**周转率较低**可能提示企业的**收款效率较低或信用政策较为宽松**；
- **周转天数**：**360 天是一个常规假设值**，企业也可以根据**实际经营天数（如 365 天）** 调整计算；**数值越小**，说明**资金回笼速度越快**；
- **示例**：某年度**应收账款周转率是 5**，则**平均需花 72 天（360/5）** 收回一次账面上的全部应收账款；
- **影响因素**：**公司的议价能力越强、账期管理能力越好，应收账款周转率就越高**；此外**行业特点、客户结构以及企业的信用政策** 也会对周转率产生重要影响。

##### ③ 总资产周转率

$$\text{总资产周转率}=\frac{\text{销售收入}}{\text{平均总资产}}$$

- **平均总资产**通常是公司财务年度内**期初总资产和期末总资产的算术平均数**；
- 反映了公司的**资产使用效率及其与市场需求的匹配程度**；
- **示例**：年销售收入**1 000 万元**，平均总资产**500 万元**，则**总资产周转率为 2**，意味着**每 1 元资产在一年内可以创造 2 元的销售收入**；
- **较高的总资产周转率**通常表明公司**能够更有效地利用其资产生成销售收入**；
- **行业差异大**：**资本密集型行业（如制造业、能源行业）的总资产周转率通常较低**，而**服务型企业或轻资产公司（如软件公司）会较高**；因此应**结合行业平均水平以及其他盈利能力指标（如净利润率）综合分析**。

---

#### （3）盈利能力比率 P75–P76

> 公司的**盈利能力**决定了其**能否在市场上生存和发展**。评价公司盈利能力的比率很多，其中**最重要的有四种**：**毛利率（GPM）、销售利润率（ROS）、资产收益率（ROA）、净资产收益率（ROE）**；这四种比率**通常使用公司的年度净利润作为计算基础**。

| # | 指标 | 公式 | 含义与要点 |
|---|---|---|---|
| 1 | **毛利率（GPM）** | $$\text{毛利率}=\frac{\text{毛利}}{\text{营业收入}}=\frac{\text{营业收入}-\text{营业成本}}{\text{营业收入}}\times100\%$$ | 衡量公司的**产品定价能力和成本控制能力**；分析中需要了解公司**业务和产品结构、产品和服务售价、成本结构、原材料成本、能耗水平、人工成本**等因素；**毛利率通常是盈利能力分析的起点** |
| 2 | **销售利润率（ROS）** | $$\text{销售利润率}=\frac{\text{净利润}}{\text{营业收入}}\times100\%$$ | 指**每单位营业收入所产生的利润**；一般来说，**其他条件不变时，销售利润率越高越好**；如果**净利润中包含了大量与主营业务无关的收入**（如**投资收益、公允价值变动、资产处置收益**等），则**销售利润率的经济意义可能失真**；为更准确反映主营业务的盈利能力，可使用**扣除非经常性损益后的净利润**计算**调整后的销售利润率** |
| 3 | **总资产收益率（ROA）** | $$\text{总资产收益率}=\frac{\text{净利润}}{\text{总资产}}\times100\%$$ | 计算**每单位资产能带来的利润**；**ROA 高**表明公司**利用资产创造利润的能力强**；**问题在于**：它使用的**净利润仅是股东可以获得的利润**，而**总资产却包括少数股东权益和债权人权益**，这**可能导致对公司盈利能力的高估/低估**；为更准确衡量公司盈利对于股东的价值，通常**结合使用净资产收益率** |
| 4 | **净资产收益率（ROE）** | $$\text{净资产收益率}=\frac{\text{净利润}}{\text{所有者权益}}\times100\%$$ | 也称"**权益报酬率**"，衡量**每单位所有者权益能够带来的利润**；由于现代公司**主要经营目标之一是股东利润最大化**，因而 **ROE 是衡量公司最大化股东财富能力的比率**；**ROE 高**说明公司**利用其自由资本盈利的能力强，投资带来的收益高** |

**四个数字示例**（教材原例）：

| 指标 | 数据 | 结果 |
|---|---|---|
| **毛利率**| 营业收入**100 万元**，营业成本**60 万元**|**（100−60）/100×100% = 40%** |
| **销售利润率**| 净利润**10 万元**，营业收入**100 万元**|**10/100×100% = 10%** |
| **总资产收益率**| 净利润**10 万元**，总资产**200 万元**|**10/200×100% = 5%** |
| **净资产收益率**| 净利润**10 万元**，所有者权益**100 万元**|**10/100×100% = 10%** |

**必须结合使用，不能孤立分析**：

- 一家公司可能有**很高的毛利率**，但如果其**运营成本过高**，可能导致**较低的销售利润率**；
- 同样，**高净资产收益率可能是由于高杠杆而不是高效率** 造成的；
- 因此，在使用这些指标时，需要**结合公司的具体情况、行业特征以及其他财务指标**进行**综合分析**。

#### （4）发展能力比率 P76–P77

> **发展能力**反映了公司在**未来持续扩展市场、提高盈利水平以及增强竞争力**的潜力；通过发展能力的分析，投资者可以评估公司**是否具备足够的增长动力**，以应对**市场变化和行业竞争**。

**最常用的三个比率**：**销售增长率、净利润增长率、每股收益增长率**。

**① 销售增长率**：

$$\text{销售增长率}=\frac{\text{本期销售收入}-\text{上期销售收入}}{\text{上期销售收入}}\times100\%$$

- **定位**：反映公司**经营规模扩张速度**的**基础指标**；
- **示例**：上年销售收入**500 万元**，本年**600 万元**，则**销售增长率为（600−500）/500×100% = 20%**；
- **分析重点关注**：
  1. **销售收入的构成和质量**——不同类型收入的增长具有不同的战略意义，应**区分主营业务收入和其他业务收入的增长情况**，**重点分析主营业务的增长态势**；同时，**销售收入确认的时点和政策变化** 也会影响增长率；
  2. （教材续）**增长的可持续性**——需结合**行业景气度、市场份额** 变化判断增长能否延续。

**② 净利润增长率**：

$$\text{净利润增长率}=\frac{\text{本期净利润}-\text{上期净利润}}{\text{上期净利润}}\times100\%$$

**③ 每股收益增长率**：

$$\text{每股收益（EPS）}=\frac{\text{净利润}}{\text{普通股股数}} \qquad \text{每股收益增长率}=\frac{\text{本期每股收益}-\text{上期每股收益}}{\text{上期每股收益}}\times100\%$$

**EPS 的稀释效应**：公司**增发新股或可转债转股**会**增加股数**，即使**净利润增长**，**EPS 也可能下降**；因此**净利润增长率与 EPS 增长率不一致**时，要**检查股本变动**。

#### （5）四类比率速查表

| 类别 | 指标 | 公式 | 关键判断值 |
|---|---|---|---|
| **短期偿债**|**流动比率**| 流动资产/流动负债 |**>2** 较强 |
| **短期偿债**|**速动比率**| 速动资产/流动负债 |**>1** 健康 |

| **盈利能力**|**销售利润率** | 净利润/营业收入 | 注意非经常性损益 |
| **盈利能力**|**总资产收益率** | 净利润/总资产 | 分母含债权人权益 |
| **盈利能力**|**净资产收益率** | 净利润/所有者权益 | 衡量股东财富最大化能力 |
| **发展能力**|**销售增长率** | （本期−上期）/上期销售收入 | 关注收入质量 |
| **发展能力**|**净利润增长率** | （本期−上期）/上期净利润 | — |
| **发展能力**|**每股收益增长率** | （本期−上期）/上期 EPS | 注意股本变动稀释 |

### 3.2.c 【掌握】杜邦分析法的基本思想、核心公式、应用及其主要局限性 P78–P80

**大纲原文**：掌握杜邦分析法的基本思想、核心公式、应用及其主要局限性

#### （1）基本思想 P78

> **杜邦分析法（DuPont Analysis）** 因最早由**美国杜邦公司**使用而得名，是一种用来**评价公司盈利能力和股东权益回报水平**的方法，它**利用主要的财务比率之间的关系**来**综合评价公司的财务状况**。

**基本思想**：

> 将公司**净资产收益率逐级分解为多项财务比率的乘积**，从而帮助**深入分析和比较公司经营业绩**。

#### （2）核心公式：杜邦恒等式 P78

**第一步：把 ROE 分解为"资产收益率 × 权益乘数"**

$$\text{净资产收益率}=\frac{\text{净利润}}{\text{所有者权益}}=\frac{\text{净利润}}{\text{总资产}}\times\frac{\text{总资产}}{\text{所有者权益}}=\text{资产收益率}\times\text{权益乘数}$$

**第二步：把资产收益率分解为"销售利润率 × 总资产周转率"**

$$\text{资产收益率}=\frac{\text{净利润}}{\text{总资产}}=\frac{\text{净利润}}{\text{销售收入}}\times\frac{\text{销售收入}}{\text{总资产}}=\text{销售利润率}\times\text{总资产周转率}$$

**第三步：合并得到杜邦恒等式**

$$\boxed{\text{净资产收益率}=\text{销售利润率}\times\text{总资产周转率}\times\text{权益乘数}}$$

> 通过杜邦恒等式可以看到，公司的**盈利能力由销售利润率、资产使用效率和财务杠杆共同决定**；这三个方面是**相互独立**的，**构成了解释公司盈利能力的三个维度**。

**三个维度的含义**：

| 维度 | 指标 | 反映什么 |
|---|---|---|
| **盈利能力（经营效率）**|**销售利润率**| 每 1 元收入能留下多少利润——**产品定价与成本控制** |
| **资产使用效率**|**总资产周转率**| 每 1 元资产能创造多少收入——**营运效率** |
| **财务杠杆**|**权益乘数**| 每 1 元自有资金撬动多少资产——**负债程度** |

#### （3）应用方法 P78

- 当分析**不同公司同一时期**或**同一公司不同发展阶段**所存在的**盈利差异**时，可以利用杜邦恒等式，**从净资产收益率出发，根据财务报表信息逐步分解各指标**；
- 对各指标进行**公司间的横向对比分析**，或对同一公司不同时期进行**纵向对比分析**，**找到差异产生的原因**。

#### 案例 3-1：三家制造业上市公司的杜邦分析 P79

**表 3-4 三家上市公司 2023 年度杜邦分析（节选）**：

| 项目 | **A 公司**|**B 公司**|**C 公司** |
|---|---|---|---|
| **净资产收益率（ROE）**|**25.82%**|**17.34%**|**6.96%** |
| **销售利润率**|**11.66%**|**20.29%**|**3.98%** |
| **资产周转率（次）**|**0.61**|**0.55**|**0.89** |
| **权益乘数**|**3.64**|**1.56**|**1.99** |

**解读**：

- **A 公司 ROE 最高（25.82%）**：虽然其**销售利润率（11.66%）低于 B 公司（20.29%）**，但其**资产周转率更快（0.61 > 0.55）**、**权益乘数更高（3.64 > 1.56）**；
- **与 C 公司相比**：虽然 A 公司的**资产周转率（0.61）低于 C 公司（0.89）**，但其**销售利润率（11.66% > 3.98%）和权益乘数（3.64 > 1.99）更高**；
- **结论**：**杜邦分析法有助于公司管理层和投资者清晰地看到净资产收益率的各个决定因素**，为**经营管理和投资决策**提供依据；对公司管理者而言，**只有协调好各个因素之间的关系，才能使净资产收益率最大化**。

这说明一个关键结论： **ROE 高不等于经营好**——A 公司靠的是**高杠杆（3.64）** 和**快周转**，而 B 公司靠的是**高利润率**。**三种模式各有风险**。

#### （4）主要局限性（三条） P79–P80

| # | 局限性 | 说明 |
|---|---|---|
| 1 | **侧重单一报告期，无法反映发展前景**| 杜邦分析法的**核心是净资产收益率**，侧重分析**单一报告期内**公司的经营状况，是**对过去业绩的评价**，**无法反映公司的发展前景**；例如当公司为**新业务、新产品的技术研发和市场开发**而进行**大量资源投入**时，**短期内净资产收益率指标可能会下降**，但这种下降**往往是阶段性的，对公司的长远发展也是有利的**；此时**单纯从净资产收益率指标分析，难以准确评价公司经营管理的能力和效率** |
| 2 | **"净利润"与"总资产"不匹配**| 在计算过程中，**总资产收益率中的"净利润"和"总资产"不匹配**——**净利润是归属于股东的**，而**总资产归属于全部资金提供者**；因此该指标**不能反映实际的总资产收益率** |
| 3 | **未区分经营损益和非经营损益**| 对**制造业公司**而言，判断其财务状况**主要应关注经营活动的情况**；如果一个制造业公司**利润增长很快，但主要来源于股票或房地产交易**，则**不能认为该公司经营状况良好** |

#### （5）使用杜邦分析法的四点建议 P80

| # | 建议 |
|---|---|
| 1 | **结合行业特性分析**——因为不同行业可能关注的重点指标有所不同，例如**制造业可能更注重资产周转率**，而**高科技行业则可能更关注销售利润率** |
| 2 | **横向比较 + 纵向分析**——除横向比较不同公司外，还应**观察同一公司多年的数据变化趋势**，以全面评估公司的**长期发展状况** |
| 3 | **与其他财务分析工具结合使用**——如**比率分析和现金流分析**等，可以获得**更全面的公司评估** |
| 4 | **考虑非财务因素**——不应仅局限于财务数据，还应考虑公司的**市场地位、品牌价值、研发能力**等，以全面评估公司的**竞争力和发展潜力** |

### 3.2.d 【了解】财务舞弊及其识别方法 P80–P86

**大纲原文**：了解财务舞弊及其识别方法

#### （1）定义与五种形式 P80

> **财务舞弊**是指公司**内部人员以误导投资者和其他利益相关方对公司财务状况的认知为目的，蓄意操纵或歪曲财务数据** 的行为。

- 财务舞弊涉及**有意的不诚实行为**，如**伪造或篡改会计记录**，对财务报告中的**重要信息进行错误陈述或故意忽略**，以及对**会计准则的有意误用**；
- **与无意的会计错误不同，舞弊行为具有蓄意性和欺骗性**。

**五种常见形式**：

| # | 形式 | 具体手段 |
|---|---|---|
| 1 | **收入确认舞弊**|**虚增收入或提前确认收入** |
| 2 | **费用操纵**|**推迟费用确认或虚减费用** |
| 3 | **资产虚增**|**虚构资产或夸大资产价值** |
| 4 | **负债隐瞒**|**未披露或低估负债** |
| 5 | （教材归纳的总体） | 上述手段的组合与系统性造假 |

**危害**：

- 市场资源配置功能的发挥**以真实与公允的信息为前提**，财务舞弊让公司的**会计信息失真**，**严重威胁市场的正常经营和竞争秩序**，会**误导市场并导致资源的错误配置**；
- 在证券市场上，财务舞弊会使**投资者基于错误信息作出错误决策，蒙受经济损失，损害投资者利益**；
- 财务舞弊是**公司内部的诚信问题**，**损害公司的信誉和投资者的信心**，并可能**面临严厉的法律制裁**。

#### （2）成因 P80–P81

| # | 成因 |
|---|---|
| 1 | **业绩压力**——来自**市场和股东**的业绩压力可能**驱使管理层采取不当手段以达到短期目标** |
| 2 | **道德风险与薪酬激励**——管理层的**道德风险和不合理的薪酬激励机制**可能**引发短视行为** |
| 3 | **内控缺陷与治理不健全**——公司**内部控制系统的缺陷和公司治理机制的不健全**也为舞弊行为**提供了可乘之机** |

**舞弊的恶化路径（逐步失控的过程）**：

> **初期**，参与者可能只是在**准则允许的范围内利用会计政策选择操纵利润**，试图**美化财务状况**→**随着时间推移**，舞弊程度不断加深，发展到**虚构交易、伪造单据**，直至**虚构大量资产**→**舞弊涉及的人员和交易越来越多**，欺诈行为**变得难以掩盖**，参与者**发现自己深陷泥潭，难以自拔**→**最终整个局面演变成失控的恶性循环**。

#### （3）识别方法 P81–P82

**① 通用识别技术**：

| 方法 | 要点 |
|---|---|
| **财务报表分析**|**深入分析财务报表，比较多个会计期间的数据，计算各种财务比率**，可以发现**异常变动** |
| **审查会计记录**| 特别是**总账和日记账分录**，有助于发现**可疑交易** |
| **评估内部控制系统**| 包括检查**职责分离和授权程序** |
| **详细分析大额/异常/关联方交易**| 并**利用计算机辅助审计技术**进行数据分析，可以揭示**潜在的舞弊模式** |
| **员工访谈、文件审查和外部确认**| 获取更多**信息和证据** |
| **实地考察、建立举报机制、关注管理层行为**| 提供**有价值的线索** |
| **保持专业怀疑态度**| 运用**专业判断**，结合具体情况**灵活使用各种方法** |
| **舞弊风险评估模型及人工智能技术**| 进一步提高识别的**效率和准确性** |

**② 三张报表结合分析（核心）**：

> 资产负债表、利润表和现金流量表这三张报表之间**存在密切的逻辑关系**，因此在分析时应当**结合考虑，而不是孤立地看待每一张报表**。

**（a）资产负债表——为分析收入来源性质及其稳定性提供基础**：

- 资产负债表列示的**公司资源与利润表中的收入和盈利存在重要关联**；如果公司**盈利缺乏相应的资产价值支持**，其**可靠性和准确性就值得怀疑**；
- **示例**：当公司**持续增加固定资产投资**，同时在资产负债表和利润表上呈现**固定资产原值和净利润的上升**时，投资者需要关注**固定资产的折旧费用是否与收入同比例增长**；如果**不是**，可能需要进一步调查公司的**折旧费用是否合理**、公司通过固定资产投入所扩大的**盈利规模是否合理**、**是否存在通过调整固定资产折旧政策来操纵当期利润** 的情况。

**（b）利润表——利润结构的合理性是公司经营是否稳健的重要体现**：

| # | 分析角度 | 要点 |
|---|---|---|
| 1 | **利润结构与资产结构的匹配性**| 利润表中的利润结构应与资产负债表中的**资产结构相匹配**；一般而言，**公司的资产总额带来了息税前利润**，其中**对外投资带来了投资收益**；在**投资结构和规模未发生实质性变化**的情况下，**投资收益的异常波动就需要特别关注** |
| 2 | **利润结构合理性**| 公司的**利润总额由营业利润、投资收益和营业外收支差额**三个主要部分构成；在正常情况下，**营业利润（主营业务利润）应该是公司利润的主要来源**，其**持续稳定增长**可能意味着公司**具有较好的盈利前景**；**投资收益的比例和变化**应该与**投资规模的变化和投资项目的效益相匹配** |
| 3 | **费用变化的合理性**|**费用的减少会直接导致利润的增加**；费用通常是**很难抵减**的，分析公司费用时应**对公司在年度间下降的合理性进行分析**；除**当期必须支付的费用**外，应特别关注那些**不需要在本期支付货币资金的预提费用和摊销费用的变化** |

**（c）现金流量表——判断公司利润质量的重要工具**：

> **现金流量分析法**是将**经营活动、投资活动和总体现金净流量**分别与**主营业务利润、投资收益和净利润**进行比较分析，以判断公司**主营业务利润、投资收益和净利润的质量**。

- **一般而言，没有相应现金净流量的利润，其质量是值得怀疑的**；
- 如果公司的**现金净流量长期低于净利润**，意味着**与已经确认为利润相对应的资产可能属于不能转化为现金流量的虚拟资产**，表明公司**可能存在着操纵财务报告的现象**。

**（d）检验货币资金（针对复杂舞弊）**：

> 一些复杂的财务舞弊可能**同时涉及对利润表和现金流量表的操纵**；在这种情况下，可以通过**检验公司的货币资金** 来进一步判断是否存在舞弊行为。

- **典型组合**：如果一家上市公司的**净利润可观**，其**经营现金流持续地高于净利润或与净利润离差不大**，但**货币资金却出现持续大幅下降**，同时**应付款项持续上升**，这可能意味着其**经营现金流并未真正改善公司的资金链**；
- 在这种情况下，**如果公司没有大额投资行为，就应该考虑财务造假的可能性**。

**③ 识别时还应注意的五点**：

| # | 要点 |
|---|---|
| 1 | **横向比较**——将公司的财务指标与**同行业其他公司**进行比较，**发现异常差异** |
| 2 | **纵向分析**——观察公司**多个会计期间**的财务数据变化趋势，**识别不合理的波动** |
| 3 | **比率分析**——使用各种财务比率，如**毛利率、资产周转率、应收账款周转率** 等，全面评估公司的财务状况 |
| 4 | **关注关键性指标**——如**收入增长率、净利润增长率、经营活动现金流**等，这些指标通常是**财务舞弊的重点领域** |
| 5 | **结合非财务信息**——将财务数据与公司的**经营环境、行业特点和市场情况**相结合，**综合判断财务数据的合理性** |

#### 案例 3-2：K 公司财务舞弊分析 P82–P86

**背景**：K 公司作为**中药材生产和销售的龙头企业**，凭借上市后的快速增长，曾被视为**资本市场的明星企业**；然而**2018 年爆出的财务造假丑闻**，以及**2019 年因涉嫌财务舞弊被中国证监会立案调查**，使其成为**A 股市场上一个影响深远的财务造假典型案例**。

**① 三个财务指标的异常信号**：

**（a）货币资金异常** P83：

- 从 **2014 年末到 2017 年末**，K 公司报告的**货币资金从 99.85 亿元增至 341.51 亿元**，**年复合增长率（CAGR）高达 50.7%**，而同期**营业收入的 CAGR 仅为 18.4%**；
- **货币资金占总资产的比例从 35.82% 升至 49.69%**，**远超行业平均的 15% 左右**；
- **关键矛盾**：K 公司的**利息收入与其庞大的货币资金规模极不匹配**——尽管同期**银行存款基准利率在 1.5%~3% 之间**，公司**利息收入却显著偏低**，显示其**资金未获得合理的回报**。

**三个疑点**：

| # | 疑点 | 说明 |
|---|---|---|
| 1 | **虚增货币资金**| 公司可能通过**虚构银行存款或伪造银行对账单**夸大货币资金规模，导致**账面资金与实际资金不符** |
| 2 | **资金被占用**|**异常低的利息收入**可能暗示公司资金**被关联方或其他实体占用**，未能产生应有的利息回报；部分货币资金可能**被虚增，以掩盖资金被占用的事实**，规避监管和投资者质疑 |
| 3 | **系统性财务造假**|**利息收入与货币资金规模之间的巨大不匹配**，可能不仅反映货币资金的**虚假陈述**，还可能涉及**其他财务数据的系统性造假** |

**（b）"存贷双高"现象** P84：

- 公司的**银行存款从 99.55 亿元激增至 340.45 亿元**，同时**有息负债也从 61.21 亿元攀升至 239.77 亿元**，这种**异常的资产负债结构严重偏离了正常的财务管理逻辑**；
- **尤其值得注意的是**：**2017 年公司 340.45 亿元的银行存款仅产生 2.69 亿元利息收入**，而**239.77 亿元的有息负债却产生了 12.18 亿元的利息支出**——**这一巨大的利率差异**不仅凸显了公司**资金使用效率极低**的问题，更**引发了对财务报告可信度的质疑**；
- **可能的解释**：**资金管理能力不足、潜在的关联方资金占用，甚至可能涉及资金套利行为**；这种异常状况还可能**掩盖了更深层次的问题**，如**经营现金流的真实性、可疑的投资活动或不当的筹资行为**。

**（c）经营活动现金流与净利润严重不匹配** P84：

> 一般而言，**经营质量较高的公司，其经营活动产生的现金流量净额应接近或高于净利润**——这是因为**净利润中包含折旧、摊销等非现金项目**，而这些项目**不会影响现金流**。

- K 公司 **2014 年至 2017 年**的**净现比**（**经营活动现金流量净额/净利润**）分别为**0.50、0.18、0.48 和 0.45**——意味着**每产生 1 元净利润，实际流入的现金不到 0.5 元**；
- **净现比持续低于 1**，表明公司的**经营活动产生的现金流量不足以支撑账面利润的增长**；这种情况提示公司可能存在**应收账款和存货大幅增加**的问题，导致**账面利润无法及时转化为现金流入**；还可能反映**收入确认不当或成本费用核算不准确** 等更深层次问题。

**（d）大股东高比例股权质押**：

- 截至 **2018 年 6 月 30 日**，**控股股东质押股份占其持股的 91.91%**——如此高比例的股权质押意味着**控股股东有可能面临严重的资金压力**，这可能成为**操纵财务数据以维持股价的动机**。

**② 舞弊手段（四种）** P84–P85：

**2019 年 4 月**，K 公司召开董事会并发布《**关于前期会计差错更正的公告**》，承认在**2016 年至 2018 年期间**存在**大规模财务数据差错**，包括**虚增货币资金、虚构收入、少计销售费用和财务费用**等；随后证监会通报调查结果，确认公司**使用虚假银行单据虚增存款、通过伪造业务凭证进行收入造假，并将部分资金转入关联方账户用于买卖公司股票**。

| # | 手段 | 具体数据 |
|---|---|---|
| 1 | **虚增货币资金**| 通过**伪造银行对账单、定期存单和销售回款**等手段大规模虚增。**2016 年年报虚增 225 亿元，占披露总资产的 41%**；**2017 年年报虚增 299 亿元，占总资产的 44%**；**2018 年半年报虚增 362 亿元，占总资产的 46%**；**虚增货币资金占公司净资产的比例从 2016 年的 77% 上升到 2018 年上半年的 108%**——**最终虚增金额甚至超过公司实际净资产** |
| 2 | **虚构收入**| 通过**伪造销售凭证和增值税发票**虚增。**2016 年虚增营业收入 90 亿元、虚增营业利润 6.6 亿元（占当年利润总额的 16%）**；**2017 年虚增收入 100 亿元、虚增利润 12.5 亿元（占利润总额的 26%）**；**2018 年全年虚增收入 16 亿元、虚增利润 1.7 亿元（占利润总额的 12%）**；公司还**相应虚增营业成本**，以使财务报表**看似合理** |
| 3 | **虚增固定资产、在建工程和投资性房地产**| 将**不符合会计确认条件**的项目纳入报表。**2018 年年报**中，公司将**多个未完成或不符合确认条件的工程项目**纳入报表，**虚增固定资产 11.89 亿元、在建工程 4.01 亿元、投资性房地产 20.15 亿元，总计调增资产 36.05 亿元** |
| 4 | **隐瞒关联交易**| 长期向**控股股东及其关联方提供资金但未如实披露**。**2016—2018 年间累计向控股股东及其关联方提供 116 亿元的非经营性资金**，这些资金被用于**购买股票、偿还贷款**等目的，而**未在财务报表中披露** |

**③ 舞弊动因（四点）** P85–P86：

| # | 动因 | 说明 |
|---|---|---|
| 1 | **管理层的利益驱动**| 实际控制人通过**虚增收入和粉饰业绩**，试图**维持公司股价的高位**，从而**在资本市场上谋取私利**；**高管薪酬和股权激励方案与公司业绩表现直接挂钩**，这种激励机制在某种程度上**促使管理层采取违规手段** |
| 2 | **融资需求压力**| 通过财务舞弊**夸大资产负债表**（尤其是**货币资金和资产规模**），使**财务状况看起来较为健康**，从而**获取更多的融资渠道和资金支持**；**控股股东质押股份占其持股比例的 91.91%** 反映了公司面临的**巨大资金压力**，公司通过造假**试图掩盖资金链紧张的事实，避免因股权质押爆仓而引发的市场恐慌** |
| 3 | **公司治理的缺失**| ①**股权高度集中**——实际控制人家族持有**32.98%** 的股份，掌握**绝对控制权**；②**董事会独立性不足**——**9 名董事仅有 3 名为独立董事，仅达到证监会规定的最低要求（1/3）**；③**监事会形同虚设**——**未能有效履行监督职责**，对虚假信息**未提出质疑**；④**内部控制机制薄弱**——**财务透明度、资金管理和信息披露**方面存在严重缺陷，**未建立有效的内部举报和监督机制** |
| 4 | **审计机构失职**| 外部审计机构**未能履行应有的监督职责**，尽管货币资金和收入等数据**存在明显异常**，审计过程中**未能采取有效措施进行核实**，导致**财务造假行为得以长期持续** |

**案例的三条应试启示**：
1. **利息收入/货币资金**与**利息支出/有息负债**的**利率倒挂**是"**存贷双高**"的经典破绽；
2. **净现比长期 < 1**是**利润质量差** 的强信号；
3. **独董比例 1/3**是**监管最低要求**，案例中"刚好达标"即意味着**治理薄弱**。

## 3.3 货币的时间价值与利率

> **货币的时间价值与利率**是金融领域的两个**基础概念**：**货币的时间价值**反映的是**资金在不同时间点上的价值差异**，而**利率**则衡量了**资金在一定时间内的增值率**；这两个概念在**投资、借贷、资本预算**等金融活动中**密切相关**。

### 3.3.a 【掌握】货币时间价值的概念、影响因素，以及现值与终值的概念、计算和应用 P87–P88

**大纲原文**：掌握货币时间价值的概念、影响因素，以及现值（PV）和终值（FV）的概念、计算和应用

#### （1）货币时间价值（TVM）的定义 P87

> **货币的时间价值（Time Value of Money，TVM）** 是指**相同金额的货币在不同时间点上具有不同的价值**。

**核心命题**：**通常情况下，现在的一元比未来的一元更有价值。**

#### （2）三个影响因素（原因） P87

| # | 因素 | 内涵 |
|---|---|---|
| 1 | **机会成本**|**当前的资金可以立即投资并产生未来收益**，因此其价值**高于未来的同等金额** |
| 2 | **通货膨胀**| 随着时间推移，**货币购买力可能下降**，导致**未来的货币价值缩水** |
| 3 | **风险**|**未来的现金流存在不确定性**，存在**无法按预期收到** 的风险 |

> 由于货币具有时间价值，**即使两笔金额相等的资金，如果发生在不同的时间点，其实际价值也是不同的**；因此，在表述资金价值时，**必须明确其发生的时间**，才能准确评估其真实价值。

#### （3）现金流量与净现金流量 P87

> 在投资分析中，我们通常将**某一投资活动视为一个独立的系统**，其中资金的收支称为"**现金流量**"。

| 概念 | 定义 |
|---|---|
| **现金流出**|**资金的支出** |
| **现金流入**|**资金的收入** |
| **净现金流量** | 某一段时间段的净现金流量是指**该时段内现金流量的代数和**：<br>$$\text{净现金流量}=\text{现金流入}-\text{现金流出}$$ |

#### （4）终值（FV） P87–P88

> **终值（Future Value，FV）** 是指**货币在未来某一时点的价值**。已知期初投入的现值为**PV**，终值**FV**即为**第 n 期期末的本利和**，假设每期利率为 i。

**计算方式**：在资金的时间价值计算中，**通常采用复利方式**——**每期期末的利息加入本金形成新的本金，再计算下期的利息，逐期滚利**。

$$\boxed{FV=PV\times(1+i)^{n}}$$

**符号含义**：

| 符号 | 含义 |
|---|---|
| **FV**|**终值**，即第 n 期期末的货币价值 |
| **PV**|**现值**，即初始投入的本金 |
| **i**|**每期的利率** |
| **n**|**期数** |

**关键约束：利率 i 和期数 n 必须在同一时间单位上**。例如，如果**i 是年利率**，那么**n 就表示年数**；如果**i 是月利率**，那么**n 就表示月数**。

**两个前提与限制**：
1. 该公式**假设利率 i 在整个期间内保持不变**；实际应用中，**如果利率发生变化，可能需要使用更复杂的计算方法**；
2. 在某些情况下，可能需要**考虑通货膨胀率来计算实际终值**（即**剔除通胀后的购买力**）。

**终值的应用场景**：**投资规划、退休计划、贷款偿还**等；理解和正确应用终值概念，有助于**更好地评估长期财务决策的影响**。

#### 案例 3-3：贷款到期一次偿清 P88

> 某公司从银行取得**贷款 30 万元**，**年利率 6%**，**贷款期限 3 年**，到**第 3 年年末一次偿清** 贷款。

$$FV=30\times(1+6\%)^{3}=35.73\ (\text{万元})$$

- **公司应付银行本利和 = 35.73 万元**。

#### （5）现值（PV）与贴现 P88

> **现值（Present Value，PV）** 是指**未来某一时点上的货币金额在当前的价值**；现值计算是**将未来某一时点的终值折算为当前的价值**。

**现值计算公式**（可通过终值公式推导得出）：

$$\boxed{PV=\frac{FV}{(1+i)^{n}}=FV\times(1+i)^{-n}}$$

**符号含义**：**PV**为现值；**FV**为未来某时点的终值；**i**为**贴现率（即利率）**；**n** 为期数。

**贴现（Discounting）**：

> **贴现**是指**将未来的资金折算为当前的价值**；在现值计算中，**利率 i 被称为贴现率**，它反映了**资金的时间价值和风险溢价**。

#### 案例 3-4：零息债券的现值 P88

> 某公司发行了**面值为 1 000 元的 5 年期零息债券**，**现在的市场利率为 8%**，那么该债券的现值为：

$$PV=\frac{1\,000}{(1+8\%)^{5}}=680.58\ (\text{元})$$

#### （6）PV 与 FV 的关系速记

| | 公式 | 方向 | 含义 |
|---|---|---|---|
| **终值** | $$FV=PV(1+i)^n$$ | **从现在到未来** | **滚利**（compounding） |
| **现值** | $$PV=FV(1+i)^{-n}$$ | **从未来到现在** | **贴现**（discounting） |

**互为逆运算**：**复利与贴现是相反的过程**。

### 3.3.b 【掌握】名义利率和实际利率、单利和复利、即期利率和远期利率的概念和应用 P88–P95

**大纲原文**：掌握名义利率和实际利率、单利和复利、即期利率和远期利率的概念和应用

#### （1）利率与名义利率、实际利率 P88–P89

> **利息率（Interest Rate）**，简称"**利率**"，是**资金的增值与投入资金价值的比率**，也是**衡量资金增值量的基本单位**；我们一般**以年为计息周期**，所说的**年利率通常是指名义年利率**。

**按债权人取得报酬的情况**，利率可分为**名义利率**和**实际利率**：

| 类型 | 定义 |
|---|---|
| **名义利率（Nominal Interest Rate）**|**包含通货膨胀补偿**的利率，反映了**未扣除通货膨胀因素** 的资金增值率 |
| **实际利率（Real Interest Rate）**| 指**在扣除通货膨胀影响后**的利率，反映了**资金的实际购买力变化**；换句话说，实际利率表示**在剔除物价变动因素后，资金的真实增值程度**；它**考虑了通货膨胀对货币价值的侵蚀**，体现了资金**在物价不变或已考虑物价变化时的回报率** |

> 当**物价持续上涨（即存在通货膨胀）** 时，**名义利率高于实际利率**——这是因为**名义利率不仅包含了资金的实际增值，还包括了对通货膨胀的补偿**。

**费雪方程式（Fisher Equation）**：

**近似形式**（适用于**通货膨胀率较低** 的情况）：

$$i_{n}\approx i_{r}+\rho$$

**精确形式**：

$$(1+i_{r})=\frac{1+i_{n}}{1+\rho}$$

**符号**：**i_n**——**名义利率**；**i_r**——**实际利率**；**ρ**——**通货膨胀率**。

**应用意义**：

- 在**评估投资回报**时，应该**关注实际利率而不仅仅是名义利率**，因为它**更真实地反映了投资的购买力变化**，**仅看名义利率可能会导致对投资效果的误判**；
- 在**比较不同时期或不同国家的利率**时，**考虑通货膨胀率的影响也是必要的**。

#### （2）单利 P89

> **单利**是计算利息的一种方法：**利息仅根据本金计算**，无论经过多长时间，**所产生的利息均不会加入本金继续计算新的利息**；换句话说，**利息只在最初的本金上累积，而不会形成"利滚利"的效果**。

**单利利息公式**：

$$I=PV\times i\times t$$

**符号**：**I**——**利息**；**PV**——**本金**；**i**——**利率**；**t**——**计息时间**（利率通常**以年计**）。

**单利终值与现值**：

$$FV=PV(1+i\cdot t) \qquad PV=\frac{FV}{1+i\cdot t}=FV(1-i\cdot t)\ (\text{近似})$$

#### 案例 3-5：单利计息（按日） P89

> 某公司持有一张**带息期票**，**面额为 12 000 元**，**票面利率为 4%**，**出票日期为 4 月 15 日**，**6 月 14 日到期（共 60 天）**，则**到期日利息** 为：

$$I=12\,000\times4\%\times\frac{60}{360}=80\ (\text{元})$$

注意分母用 **360 天**（**银行惯例年基数**），而非 365 天。

#### （3）复利 P90

> 与单利不同，**复利**的特点是**每经过一个计息期，所产生的利息会加入本金，形成新的本金，并在下一个计息期继续计算利息**；这样，**利息逐期累积，使得资金增长呈现加速趋势**。

- **计息期**：指**相邻两次计息的时间间隔**，通常为**年、月或日**等；**除非特别说明，计息期默认为一年**。

**复利终值**（与货币终值公式等同）：

$$FV=PV\times(1+i)^{n}$$

- 其中， **(1+i)^n 称为"复利终值系数"或"1 元的复利终值"**，用符号 **(F/P, i, n)** 表示；
- 例如， **(F/P, 6%, 3)** 表示**利率为 6%、3 期的复利终值系数**。

**复利现值**：

$$PV=\frac{FV}{(1+i)^{n}}=FV\times(1+i)^{-n}$$

- 其中， **(1+i)^{-n} 称为"复利现值系数"或"1 元的复利现值"**，用符号 **(P/F, i, n)** 表示。

**复利与贴现是相反的过程**（图 3-2）：

| 曲线 | 计算方式 | 1 000 元、9%、10 年的结果 |
|---|---|---|
| **最上面（复利终值）** | $$1\,000\times(1+0.09)^{10}$$ | **2 367.36 元** |
| **中间（单利终值）** | $$1\,000+10\times(1\,000\times0.09)$$ | **1 900 元** |
| **最下面（贴现值）** | $$\frac{1\,000}{(1+0.09)^{10}}$$ | **422.41 元** |

#### 案例 3-6：等额本息法偿还住房贷款 P91

> 以**等额本息法**偿还**本金为 100 万元**、**利率为 7%** 的**5 年期住房贷款**；假设**每年年末需要偿还的本金利息总额为 M 元**，则有：

$$1\,000\,000=M\cdot(P/F,7\%,1)+M\cdot(P/F,7\%,2)+\cdots+M\cdot(P/F,7\%,5)$$

$$=M\times(1+7\%)^{-1}+M\times(1+7\%)^{-2}+\cdots+M\times(1+7\%)^{-5}$$

- **计算可知，M = 243 890.69 元**。

#### （4）连续复利 P91–P92

> 当**计息期无限缩短**时，即当**利息的复利频率趋近于无穷大**，我们可以用"**连续复利**"来描述资金的增长；这种情况下，**利息在每一时刻都在累积，并形成新的本金**。

**连续复利终值公式**：

$$FV=PV\times e^{i\times t}$$

**符号**：**e**是**自然对数的底数（约为 2.71828）**；**i**是**年利率**；**t**是**计息的年数**。

> 与普通复利相比，**连续复利的增长略高**，因为它假设**利息可以在无限小的时间间隔内不断复利**。

#### 案例 3-7：不同复利频率的终值对比 P91–P92

> 假设**本金为 1 000 元**，**年利率为 9%**，**10 年后的终值** 为：

$$1\,000\times e^{0.09\times10}=1\,000\times e^{0.9}\approx1\,000\times2.4596=2\,459.60\ (\text{元})$$

**不同复利频率的计算结果**：

| 复利频率 | 计算式 | 终值（元） |
|---|---|---|
| **按年复利** | $$1\,000\times(1+0.09)^{10}$$ | **2 367.36** |
| **按半年复利** | $$1\,000\times\left(1+\frac{0.09}{2}\right)^{2\times10}$$ | **2 411.71** |
| **按季度复利** | $$1\,000\times\left(1+\frac{0.09}{4}\right)^{4\times10}$$ | **2 435.19** |
| **连续复利** | $$1\,000\times e^{0.09\times10}$$ | **2 459.60** |

> 从这些结果可以看出，**随着复利频率的增加，最终的资金终值逐渐接近连续复利的结果**。

**连续复利的适用性**：

- 在**金融工具定价**中作为**近似工具**具有**较强的实用性**；同时，它在**构建无套利定价模型和风险度量框架**时**非常便利**；
- 然而实际应用时必须根据**具体场景权衡使用连续复利还是离散复利**，并**充分理解两者之间的关系和差异**；**特别是在利息结算频率较低的市场中，离散复利往往更符合实际**。

#### （5）即期利率与即期利率曲线 P92–P93

> **即期利率（Spot Rate）**，通常记作**s_t**（其中下标 t 表示期限），是金融市场中的**基础利率**，指**从当前时刻（t=0）到未来某个特定时点 t 的零息债券年化收益率**。

**作用**：

- **即期利率反映了不同期限资金的时间价值**，被用于**将未来现金流贴现到现值**；**许多金融产品的定价都基于即期利率**；
- 随着**期限的不同，利率通常会变化**；为了反映这种变化，人们使用**即期利率曲线（Spot Rate Curve）**——它**描述了随时间变化的即期利率水平**，展示了**从短期到长期的收益率走势**，能够帮助投资者理解**资金的时间价值如何随期限变化**；
- 实际应用中，金融分析师和投资者经常使用**即期利率曲线**来**评估不同期限投资的相对价值，预测未来利率走势，以及进行风险对冲和资产负债管理**。

#### （6）贴现因子 P93

> 通过即期利率，我们可以为**每个时间点定义相应的贴现因子 d_t（t = 1, 2, …, k）**。

$$d_{t}=\frac{1}{(1+s_{t})^{t}}$$

- 其中 **s_t 为即期利率**；
- **贴现因子将未来现金流直接转化为相应的现值**，可以看作是**未来某个时间点上收到 1 单位现金的现值**；
- 随着时间 t 的增加，**贴现因子通常会变小**，反映出**远期现金流的现值较低**——这是因为**时间越久，资金的时间价值越大**，即**未来的现金流在当前的价值越小**。

**任意现金流的现值公式**：

> 对于任意现金流 **(x₀, x₁, x₂, …, x_k)** 与相应的市场即期利率，现值计算公式为：

$$PV=x_{0}+d_{1}x_{1}+d_{2}x_{2}+\cdots+d_{k}x_{k}$$

- **d_t 的作用可以理解为"时间 k 收到的单位现金的价格"**；
- 通过该笔现金流的**所有单笔现金**用"**价格乘以数量**"的方法计算现值，然后将**所有结果相加**，可以得到**整个现金流的现值**。

#### （7）远期利率 P94–P95

> **远期利率（Forward Rate）** 是指**资金在未来某一时点到另一时点的隐含利率**，也可以理解为**未来指定期间的借贷成本或投资收益率**。

**三个要点**：

1. 它反映了**市场对未来利率水平的预期**，通常**通过当前的即期利率推导得出**；
2. 远期利率还可用于表示**投资者在未来特定日期购买零息债券的到期收益率**；
3. **远期利率和即期利率的区别在于计息日起点不同**——**即期利率的起点在当前时刻**，而**远期利率的起点在未来某一时刻**。

**推导（无套利原则）**：

> 假设在当前时刻， **1 年期和 2 年期的即期利率分别为 s₁ = 7% 和 s₂ = 8%**；之所以**2 年到期与 1 年到期的债券收益率不一样**，主要是**投资者预期第 2 年的 1 年期利率相对于第 1 年的 1 年期利率会发生变化**。

- **方式一**：将 1 元存入**2 年期账户**，到第 2 年末货币价值将增长至 **(1 + s₂)²**；
- **方式二**：将 1 元存入**1 年期账户**，到第 1 年末的价值为 **(1 + s₁)**，然后以**远期利率 f₁,₂**将本金和收益借出；这样，第 2 年末的价值为 **(1 + s₁)(1 + f₁,₂)**。

**根据无套利原则，这两种方式的结果应该相等**：

$$(1+s_{2})^{2}=(1+s_{1})(1+f_{1,2})$$

**解得远期利率**：

$$\boxed{f_{1,2}=\frac{(1+s_{2})^{2}}{1+s_{1}}-1}$$

**代入 s₁ = 7%、s₂ = 8%**：

$$f_{1,2}=\frac{(1+8\%)^{2}}{1+7\%}-1=9.01\%$$

> 因此，**第 2 年的远期利率为 9.01%**。

通式： **f_{n,n+1} = (1+s_{n+1})^{n+1} / (1+s_n)^{n} − 1**。

**远期利率的四个应用**：

| # | 应用 |
|---|---|
| 1 | **货币政策参考**——远期利率**反映了市场对未来利率走势的预期**，因此是**中央银行制定和执行货币政策的重要参考工具**；通过观察远期利率的变化，**政策制定者可以更好地了解市场对未来经济和通胀状况的预期**，从而**采取相应的政策措施** |
| 2 | **金融衍生品定价**——例如**利率互换和远期利率协议（FRA）** 等产品的定价都**依赖于远期利率**；投资者和交易员通过远期利率来**评估这些产品的价值和风险** |
| 3 | **投资决策和风险管理**——投资者可以利用远期利率来**评估未来的投资机会和风险**，而风险管理人员则可以利用它来**度量和管理利率风险** |
| 4 | **债券交易策略**——远期利率也是**设计利率期限结构套利策略** 的重要工具 |

**两点注意**：

1. **实际市场中的远期利率可能与理论计算有所差异**——这种差异可能是由于**市场的流动性、风险溢价** 等因素造成的；
2. **远期利率仅是市场对未来利率的预期，并不一定能准确预测未来的实际利率**；因此在使用远期利率时，需要**考虑市场的效率性和信息的完备性**。

## 3.4 常用描述性统计概念

> 金融市场的**核心特征之一是随机性**——公司是否发生**债务违约**、投资项目的**到期收益率**、未来的**资产价格**等都是**难以预测**的；为了研究这些不确定事件，我们将它们和**数值变量**联系起来，并运用**统计量** 来描述它们的特征。

### 3.4.a 【理解】随机变量的定义、分类和分布，方差和标准差，以及分位数和中位数的定义和应用 P96–P101

**大纲原文**：理解随机变量的定义、分类和分布，方差和标准差，以及分位数和中位数的定义和应用

#### （1）随机变量的定义 P96

> **随机变量**是一个**能取得多个可能值**的数值变量，是**统计学中的核心概念**，用于**描述不确定性**。

**教材示例**：对某公司发行的债券，可以定义一个**违约变量**：

$$\text{Default}=\begin{cases}1 & \text{债券违约}\\ 0 & \text{债券不违约}\end{cases}$$

- 在这个例子中，**违约变量是一个随机变量**，**Default = 1**表示**债券违约**，**Default = 0**表示**债券不违约**；
- 同样，某公司发行的**普通股股价在未来某一天的收盘价**也可以是一个**随机变量**。

#### （2）随机变量的分类 P96

| 类型 | 定义 | 特点 | 典型例子 |
|---|---|---|---|
| **离散型随机变量**| 如果随机变量 X**只能取有限个或可数无限多个不同的值**|**取值是跳跃的，中间可能存在间隔**|**抛硬币的结果**（正面或反面）、**骰子的点数**（1 到 6 的整数）、**家庭的子女数量**、**债券的违约状态**（0 未违约，1 违约） |
| **连续型随机变量**| 如果随机变量 X**可以取某个区间内的任意实数**|**取值是连续的**，**任意两个不同的取值之间总存在其他取值**|**人的身高或体重**、**某地区的年降雨量**、**制造过程中产品的重量误差**、**股票在交易时间内的价格** |

#### （3）随机变量的分布 P96

> **随机变量的分布**描述了**它取不同值的概率**。

**① 离散型随机变量**：

> 如果 X 是离散型随机变量，其**最多可能取 x₁, x₂, …, xₙ**，并且记**pᵢ 是 X 取 xᵢ 的概率**，**所有概率的总和 = 1**：

$$\sum_{i=1}^{n}p_{i}=1$$

**② 连续型随机变量**：

> 如果 X 是一个连续型随机变量，由于**无法列出 X 取每个特定值的概率**，我们使用**概率密度函数** 来刻画 X 的分布。

- **概率密度函数**衡量随机变量 X 在**特定范围内取值的可能性**，其**图像称为概率密度函数曲线**；
- 例如图 3-5 中画出某连续型随机变量的概率密度函数曲线，其中的**阴影部分面积**就是该变量**取值在（0, 10] 的概率 P(0 < X ≤ 10)**。

**关键理解**：连续型随机变量的**概率 = 概率密度曲线下的面积**，而不是某个点的函数值。

#### （4）期望（均值） P97–P98

> 随机变量 X 的**期望**，或称"**均值**"，记作**E(X)**，衡量了**X 取值的平均水平**；**期望值是对 X 所有可能取值按照其概率加权后得到的平均值**。

$$E(X)=\sum_{i=1}^{n}p_{i}x_{i}=p_{1}x_{1}+p_{2}x_{2}+\cdots+p_{n}x_{n}$$

**样本均值**（当 X 的分布**未知**时，通过**抽样计算样本均值** 来估计期望值）：

$$\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_{i}$$

- 在金融领域，期望值通常用于**评估投资的长期平均回报率**。

#### 案例 3-9：三种经济情景下的期望收益率 P97–P98

| 情景 | 收益率 | 概率 |
|---|---|---|
| **经济上行**|**10%**|**10%** |
| **经济平稳**|**8%**|**50%** |
| **经济下行**|**3%**|**40%** |

$$E(r)=10\%\times10\%+50\%\times8\%+40\%\times3\%=6.2\%$$

注意教材原式写法中的顺序错位（写成"10%×10% + 50%×8% + 40%×3%"，其中**概率与收益率的对应**为：上行 10% 收益 × 10% 概率、平稳 8% 收益 × 50% 概率、下行 3% 收益 × 40% 概率），结果为**6.2%**。

#### 案例 3-10：10 个交易日收益率的样本均值 P98

样本值： **r₁ = 4.684%，r₂ = 4.597%，r₃ = 4.321%，r₄ = 4.373%，r₅ = 4.280%，r₆ = 4.136%，r₇ = 4.150%，r₈ = 3.982%，r₉ = 4.270%，r₁₀ = 4.261%**

$$\bar{r}=\frac{1}{10}\sum_{i=1}^{10}r_{i}=4.305\%$$

> 此**样本均值**为该基金**预期收益的估计值**。

#### （5）资产组合的期望收益率 P98

> 利用**随机变量期望的线性性质**，可以计算**按比例分配资金构造的资产组合的总体期望收益率**。

假设由 **n 项资产 A₁, A₂, …, Aₙ**构成资产组合 A，其中**wᵢ 为投资于资产 Aᵢ 的资金所占总资金的比例**，满足**Σwᵢ = 1**；若**Aᵢ 的期望收益率为 rᵢ**，则资产组合 A 的期望收益率为：

$$E(r_{A})=w_{1}r_{1}+w_{2}r_{2}+\cdots+w_{n}r_{n}=\sum_{i=1}^{n}w_{i}r_{i}$$

#### 案例 3-11：三只股票组合的期望收益率 P98

| 股票 | 资金占比 | 期望收益率 |
|---|---|---|
| **A**|**40%**|**14%** |
| **B**|**40%**|**20%** |
| **C**|**20%**|**8%** |

$$\bar{r}=40\%\times14\%+40\%\times20\%+20\%\times8\%=15.2\%$$

#### （6）方差与标准差 P98–P99

> 很多情况下，我们**不仅需要了解数据的期望值和平均水平，还要了解这组数据分布的离散程度**；**分布越分散，波动性和不可预测性也就越强**。

- 投资者**不仅关心投资的期望收益率，也关心实际收益率相对预期的收益率可能有多大的偏差**，即该**投资回报的风险水平**；
- 对于投资收益率 r，我们用**方差（σ²）** 或者**标准差（σ）** 来衡量它**偏离期望值的程度**；
- **方差和标准差越大**，表明**收益率 r 偏离期望收益率 E(r) 的程度越大**；反之，**方差和标准差越小**，说明**数据分布更集中，波动性也越小**。

**① 离散分布的方差与标准差**：

$$\sigma^{2}=\sum_{i=1}^{n}p_{i}[r_{i}-E(r)]^{2} \qquad \sigma=\sqrt{\sum_{i=1}^{n}p_{i}[r_{i}-E(r)]^{2}}$$

- 其中 **pᵢ 是每个可能收益率 rᵢ 的概率**，**E(r) 是收益率的期望值**。

**② 样本方差与样本标准差**（当 r 的分布**未知** 时）：

$$s^{2}=\frac{1}{n-1}\sum_{i=1}^{n}(r_{i}-\bar{r})^{2} \qquad s=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(r_{i}-\bar{r})^{2}}$$

**关键细节**：这里**n−1 是自由度调整**，是为了使**样本方差成为总体方差的无偏估计量**。**考试中若给"样本方差/标准差"，分母是 n−1，不是 n**。

#### 案例 3-12：基金收益率的标准差 P99

> 在案例 3-10 的基金收益率中，投资者在该基金上能获得的**期望收益率 E(r) = r̄ = 4.305%**，则**收益率的标准差**：

$$\sigma=\sqrt{\frac{1}{9}\sum_{i=1}^{10}(r_{i}-\bar{r})^{2}}=0.209\%$$

> **标准差远低于其期望收益率**，这意味着**该产品的波动相对较小**。

#### （7）分位数 P99–P100

> 在统计学中，**分位数（Quantile）** 是指将**一个概率分布按从小到大的顺序排列后，在特定位置上的数值点**；该数值点**将数据分成两部分**，**一部分小于等于该值，另一部分大于等于该值**。

**精确定义**：

> **p 分位数**是指**至少有 p 比例的数据小于或等于该值**，并且**至少有（1−p）比例的数据大于或等于该值**。

**严格定义**：对于一个随机变量 X 的概率分布 F，以及一个概率**p（0 < p < 1）**，**p 分位数 q(p)** 定义为满足以下条件的数值：

$$P[X\le q(p)]\ge p \quad \text{并且} \quad P[X\ge q(p)]\ge 1-p$$

**估计方法**：

> 直接计算随机变量 X 的分位数**比较困难**，尤其是**X 分布未知**时；通常我们使用**样本数据来估计分位数**。
>
> 假设有一个样本 **x₁, …, xₙ**，我们首先将样本**按照数值从小到大排序**，记为**x₍₁₎, …, x₍ₙ₎**；然后，**p 分位数的估计值** 可以通过以下方式获得：
>
> **样本中第 np 个数用于估计 p 分位数**；**如果 np 不是整数，则取相邻两个整数位置的样本值的平均数** 作为分位数估计值。

#### 案例 3-13：ETF 日净值变化的下 5% 分位数与下 2.5% 分位数 P100

> 为了计算某 ETF 的风险，我们选择了 **100 个交易日**的每日基金净值变化的**基点值 Δ（单位：点）**，并**从小到大排列**为 Δ₍₁₎ ~ Δ₍₁₀₀₎；其中**Δ₍₁₎ ~ Δ₍₁₀₎ 的值依次为**：

**−18.63、−17.29、−15.61、−12.37、−12.02、−11.28、−9.76、−8.84、−7.25、−6.63**

**求 Δ 的下 5% 分位数和下 2.5% 分位数**：

| 分位数 | 计算 | 结果 |
|---|---|---|
| **下 5% 分位数**|**100 × 5% = 5**（整数）→ 取第 5 个 →**Δ₍₅₎**|**−12.02** |
| **下 2.5% 分位数**|**100 × 2.5% = 2.5**（**不是整数**）→ 取相邻两个整数**2 和 3**的平均 |**(−17.29 + (−15.61))/2 = −16.45** |

**计算套路**：**先算 np，整数直接取第 np 个；非整数取相邻两个的平均**。

#### （8）中位数 P100–P101

> **中位数**，又称**中值**，指**按顺序排列的一组数据中居于中间位置的数**；对于一组数据，**有一半的数据大于或等于中位数，有一半的数据小于或等于中位数**。

**取值规则**：

| 数据个数 | 中位数 |
|---|---|
| **奇数**|**中间的那个数**（如容量为 5 的样本 x₍₁₎~x₍₅₎，中位数是**x₍₃₎**） |
| **偶数**|**中间两个数的平均值**（如容量为 10 的样本，中位数是 **(x₍₅₎ + x₍₆₎)/2**） |

#### 案例 3-14：336 只股票型基金的年度业绩基准 P100

> 选取**净值年增长率**这个指标来考察基金的业绩，我们把某年度国内**336 只股票型基金**的净值增长率**按从高到低排列**，其中**排名第 168 位、第 169 位**的某两只基金年度净值增长率分别为**13.69%** 和**13.64%**。

- **中位数 = (13.69% + 13.64%)/2 = 13.665%**；
- 于是，我们将 **13.665%** 作为**评价国内股票型基金当年度业绩的基准**——**净值增长率高于 13.665% 的基金表现优于行业一般水平**，而**低于 13.665% 的基金表现劣于行业一般水平**；
- **与另一个经常用来反映数据一般水平的统计量——均值相比，中位数的评价结果往往更为合理和贴近实际**。

#### 案例 3-15：中位数 vs 均值（极端值的影响） P100–P101

> 某债券投资者近年的**年收益率由低到高**分别为 **−16%、4%、5%、5%、6%、8%**。

- **中位数为 5%**（偶数个，中间两个都是 5%）；
- **均值却只有 2%**（(−16% + 4% + 5% + 5% + 6% + 8%)/6 = 2%）；
- 进一步考察可知，**−16% 的收益率其实是受到金融危机的影响而发生的小概率极端事件**；**剔除掉这一异常值后**，该投资者的投资策略可以取得**平均 5.6% 的收益率**。

**结论**：

> 在这种情况下，**中位数不易受极端值影响，能较好地反映投资策略的真实水平**；**平均数（或均值）则很容易受到极端值的冲击**，使其**对数据的判别效果产生较大的误差**。

#### （9）描述性统计量速查

| 统计量 | 符号 | 衡量什么 | 关键公式/规则 |
|---|---|---|---|
| **期望（均值）**|**E(X) / x̄**|**平均水平**|**Σpᵢxᵢ**；样本均值**Σxᵢ/n** |
| **方差**|**σ² / s²**|**偏离期望的程度**| 总体**Σpᵢ[rᵢ−E(r)]²**；样本**Σ(rᵢ−r̄)²/(n−1)** |
| **标准差**|**σ / s**| 同方差，**与原数据同单位**|**方差的平方根** |
| **分位数**|**q(p)**|**特定位置上的值**|**第 np 个**；**np 非整数取相邻平均** |
| **中位数**| — |**中间位置**|**奇数取中间，偶数取中间平均**；**抗极端值** |

### 3.4.b 【了解】正态分布的含义、主要特征、经验法则，以及标准正态分布分位数的含义 P101–P103

**大纲原文**：了解正态分布的含义、主要特征、经验法则，以及标准正态分布分位数的含义

#### （1）含义 P101

> **正态分布**是**最重要的一类连续型随机变量分布**。

**两个产生背景**：

1. 当一个随机变量的**取值受到众多微小且独立因素的共同影响**时，该变量就**服从或近似服从正态分布**；
2. 在金融市场中，以股票为例，根据**有效市场假说的弱式有效性**，**股票价格变动通常被视为随机漫步过程**，而**随机漫步假设股价的波动接近服从正态分布**。

#### （2）概率密度函数 P101

> 如果连续型随机变量 X 的**概率密度函数曲线** 为：

$$f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^{2}}{2\sigma^{2}}}$$

> 则称 **X 服从参数为（μ, σ²）的正态分布**，记为**X ~ N(μ, σ²)**，其中**μ 是 X 的期望**，**σ > 0，为 X 的标准差**。

**标准正态分布**：

> 特别地，当 **μ = 0，σ = 1**，称 X 服从**标准正态分布**，记作**X ~ N(0, 1)**。

#### （3）两个显著特征 P101

> 正态分布的概率密度曲线呈现**中间高、两边低的钟形**，**以均值 μ 为中心向两侧对称递减**。

| # | 特征 | 内涵 |
|---|---|---|
| 1 | **集中性**|**数据在均值附近最为集中**，**距离均值越远，则出现的概率越低**；这意味着**极端值出现的概率较小**，而**接近均值的值出现的概率较大** |
| 2 | **波动性**| 正态分布的**形状由标准差 σ 决定**：**σ 越小，分布越"窄"，数据越集中于均值附近**；**σ 越大，分布越"宽"，数据的离散程度越大** |

#### （4）经验法则：68-95-99.7 法则 P101

> 正态分布有一个重要的**经验法则**，称为"**68-95-99.7 法则**"：

| 区间 | 覆盖数据比例（约） | 更精确数字 |
|---|---|---|
| **μ ± σ**|**约 68%**|**68.27%** |
| **μ ± 2σ**|**约 95%**|**95.45%** |
| **μ ± 3σ**|**约 99.7%**|**99.73%** |

- 这个特性在金融分析中**经常用于评估风险和设定置信区间**。

#### （5）正态性检验 P102

> 检验一个随机变量是否服从正态分布，可以**绘制它的样本频率直方图**——如果频率直方图**呈现出"钟形"特征**，可认为该变量**大致服从正态分布**；
>
> 对于**更严格的检验**，可以使用统计方法如**Shapiro-Wilk 检验**或**Kolmogorov-Smirnov 检验**。

#### 案例 3-16：沪深 300 指数日涨跌幅的频率直方图 P102–P103

> 我们以**沪深 300 指数在某年连续 240 个交易日**的**日涨跌幅数据**为样本，绘制其分布的**频率直方图**。

**从图形上看，该频率直方图大致呈现中间高、两边低的特征，但需要注意以下三点**：

| # | 偏离 | 内涵 |
|---|---|---|
| 1 | **趋势性**|**股市数据常常表现出一定的趋势性**，导致**日涨跌幅的均值不为 0** |
| 2 | **尖峰厚尾**| 金融市场的波动性可能会导致出现"**尖峰厚尾**"特征，即**相比正态分布，中心附近的概率更高，而尾部（极端值）的概率也更高** |
| 3 | **偏度**| 市场数据可能存在**偏度**，即**正向和负向波动的概率不对称** |

**"尖峰厚尾"是金融收益率最著名的"非正态"特征**——它意味着**极端行情比正态分布预测的更频繁**，因此用正态分布度量风险（如 VaR）会**低估尾部风险**。

#### （6）标准正态分布上分位数 P103

**表 3-10 常用标准正态分布上分位数表**：

| α | 50% | 10% | 5% | 2.5% |
|---|---|---|---|---|
| **u_α**|**0**|**1.28**|**1.65**|**1.96** |

| α | 1% | 0.5% | 0.25% | 0.1% |
|---|---|---|---|---|
| **u_α**|**2.33**|**2.58**|**2.81**|**3.01** |

> 以 **u₅% = 1.65**为例，图 3-8 中的**阴影部分面积正好等于标准正态分布变量 X 取值大于 1.65 的概率 5%**。

**含义**：

- **上分位数 u_α**表示**标准正态分布中，取值大于 u_α 的概率恰好为 α** 的那个临界值；
- 因此 **P(X > u_α) = α**，且由**对称性**，**P(X < −u_α) = α**；
- **常用记忆值**：**90% 置信水平 → 1.65**；**95% → 1.96**；**99% → 2.33**。

**金融应用**：若某资产收益率服从**N(μ, σ²)**，在**95% 置信水平**下的**单侧风险值**约为**μ − 1.65σ**，**双侧**为**μ ± 1.96σ**。

### 3.4.a+ 【教材延伸】随机变量的相关关系：协方差与相关系数 P103–P106

> **本小节不计入知识点统计**：2026 年大纲未单列该条目（相关系数的考核放在第九章"投资组合管理"），但教材第三章第四节第三目系统讲授，且是第 9 章的必备前置知识。

#### （1）为什么需要相关性 P103–P104

> 以上讨论的都是**单个随机变量**的问题；但在金融市场中，**多个不同随机变量之间的联系同样重要**。

- 投资者希望了解**不同资产之间的相关性**，例如：
  1. 通过**期货与现货价格的相关性实现套期保值**；
  2. 分析**持有的投资组合内各项证券的价格联动性**；
  3. 分析**组合整体表现与市场组合收益的关系**；
- 为此，我们可以用**协方差和相关系数**来衡量**随机变量的相关性**。

#### （2）协方差 P104

> 在统计学中，人们用**协方差（Covariance）** 衡量**两个随机变量共同变化的程度**。

设 **rᵢ 和 rⱼ**分别表示**证券 i 和证券 j 的收益率**，它们的协方差可以记作**Cov(rᵢ, rⱼ)** 或**σᵢⱼ**：

$$\text{Cov}(r_{i},r_{j})=\sigma_{ij}=E\{[r_{i}-E(r_{i})][r_{j}-E(r_{j})]\}=E(r_{i}r_{j})-E(r_{i})E(r_{j})$$

- **当 i = j 时，协方差退化为单个随机变量的方差**，即**σᵢᵢ = σᵢ²**。

**符号含义**：

| 协方差符号 | 含义 |
|---|---|
| **正值**| 两个变量的**变化趋势一致**——当**一个变量高于其期望值**时，**另一个变量也倾向于高于自身的期望值** |
| **负值**| 两个变量的**变化趋势相反**——当**一个变量高于其期望值**时，**另一个变量通常低于其期望值** |

**协方差的局限**：**协方差的数值大小依赖于变量的单位和尺度**，因此**不易直接用来比较不同资产之间的相关性**。

#### （3）相关系数 P104

> 为了**消除协方差的单位影响**，统计学家引入了**相关系数**的概念，用于衡量**两个变量相关性的强度和方向**。

证券 i 和证券 j 的**收益率相关系数 ρᵢⱼ**定义为**协方差与各自标准差的比值**：

$$\rho_{ij}=\frac{\text{Cov}(r_{i},r_{j})}{\sigma_{i}\sigma_{j}}=\frac{\sigma_{ij}}{\sigma_{i}\sigma_{j}}$$

- 其中 **σᵢ 和 σⱼ 分别是 rᵢ 和 rⱼ 的标准差**。

**取值范围：−1 ≤ ρᵢⱼ ≤ 1**：

| 取值 | 含义 |
|---|---|
| **ρ = 1**| 表示 rᵢ 和 rⱼ**完全正相关**，即它们**总是同向变化** |
| **ρ = −1**| 表示 rᵢ 和 rⱼ**完全负相关**，即它们**总是反向变化** |
| **ρ = 0**| 表示 rᵢ 和 rⱼ 之间**没有线性关系**，即**零相关** |

- **相关系数反映了两个变量线性相关性的强弱，且不受原始数据单位的影响**；因此，它可以**用于比较不同单位或尺度的变量之间的关系**；
- **实际市场中，完全正相关或完全负相关的情况极为少见**，大多数情况下**相关系数在（−1, 1）之间**：
  - 若 **0 < ρ < 1**，则 rᵢ 与 rⱼ**呈正相关**；
  - 若 **−1 < ρ < 0**，则 rᵢ 与 rⱼ**呈负相关**。

**散点图**：我们常常用**散点图**来**直观判断两个变量之间的相关性**——通过展示**两组数据的坐标点分布**，可以帮助我们**初步判断变量间的相关强度和方向**。

#### 案例 3-17：A 股四只股票的相关性 P105–P106

> 以我国 A 股市场为例，选取某段**连续 317 个交易日**的**中国工商银行（GS）、中国银行（ZG）、中石油（ZSY）与宝钢股份（BG）** 四只股票的**每日收盘价** 数据。

| 股票对 | 相关系数 | 解读 |
|---|---|---|
| **工商银行 vs 中国银行**|**0.89（高度正相关）**| 因为它们**同属银行业**，受到**相似的经济因素和政策影响** |
| **中石油 vs 宝钢股份**|**−0.72（高度负相关）**| 这可能反映了**这两个行业（能源和钢铁）在某些经济环境下的对立关系**——例如，**当能源价格上涨时，钢铁生产成本增加，可能导致钢铁企业盈利下降** |

**在现代投资组合理论中的意义**：

> 资产间的**相关系数是构建有效投资组合的重要参数**；通过**合理配置相关性较低的资产**，投资者可以**在不显著增加风险的情况下提高组合的预期收益**；这种策略被称为**分散化投资**，是**降低投资组合非系统性风险的有效方法**。（详见**第九章** 现代投资组合理论。）

## 本章小结

#### 一、四张报表对照

| 报表 | 别称 | 时点/期间 | 编制基础 | 核心恒等式 |
|---|---|---|---|---|
| **资产负债表**|**财务快照**|**时点**| 权责发生制 |**资产 = 负债 + 所有者权益** |
| **利润表**| 损益表 |**期间**| 权责发生制 |**收入 − 费用 = 利润** |
| **现金流量表**| — |**期间**|**收付实现制**|**NCF = CFO + CFI + CFF** |
| **所有者权益变动表**| — |**期间** | 权责发生制 | 股本、资本公积、留存收益变动 |

#### 二、公式集中背诵

| 类别 | 公式 |
|---|---|
| **流动比率**| 流动资产 / 流动负债（**>2** 较强） |
| **速动比率**| 速动资产 / 流动负债（**>1**健康）；**速动资产 = 流动资产 − 存货（− 预付账款）** |
| **资产负债率** | 负债总额 / 资产总额 |
| **权益乘数**| 资产总额 / 所有者权益 =**1/(1−资产负债率)** |
| **负债权益比**| 负债总额 / 所有者权益 =**资产负债率/(1−资产负债率)** |
| **利息保障系数**|**EBIT / 利息费用**（**≥1**） |
| **存货周转率**| 销售成本 / 平均存货；**天数 = 360/周转率** |
| **应收账款周转率**| 销售收入 / 平均应收账款；**天数 = 360/周转率** |
| **总资产周转率** | 销售收入 / 平均总资产 |
| **毛利率** | （营业收入 − 营业成本）/ 营业收入 |
| **销售利润率** | 净利润 / 营业收入 |
| **总资产收益率** | 净利润 / 总资产 |
| **净资产收益率** | 净利润 / 所有者权益 |
| **销售增长率** | （本期 − 上期）/ 上期销售收入 |
| **杜邦恒等式**|**ROE = 销售利润率 × 总资产周转率 × 权益乘数** |
| **EBIT**|**净利润 + 所得税 + (利息费用 − 利息收入)** |
| **终值 FV**|**PV(1+i)ⁿ** |
| **现值 PV**|**FV/(1+i)ⁿ** |
| **单利利息**|**PV × i × t** |
| **费雪（近似）**|**i_n ≈ i_r + ρ** |
| **费雪（精确）**|**(1+i_r) = (1+i_n)/(1+ρ)** |
| **连续复利**|**FV = PV × e^{i×t}** |
| **贴现因子**|**d_t = 1/(1+s_t)^t** |
| **远期利率**|**f₁,₂ = (1+s₂)²/(1+s₁) − 1** |
| **期望**|**E(X) = Σpᵢxᵢ** |
| **样本方差**|**Σ(rᵢ−r̄)²/(n−1)** |
| **相关系数**|**ρ = Cov(rᵢ,rⱼ)/(σᵢσⱼ)** |

#### 三、必背数字

| 数字 | 含义 |
|---|---|
| **80%** | 股票基金/债券基金/FOF 的资产投向门槛（见第二章） |
| **2 / 1**| 流动比率 **>2**、速动比率 **>1** |
| **360 天** | 周转天数、单利计息（银行惯例年基数） |
| **68.27% / 95.45% / 99.73%**| 正态分布 **±1σ / ±2σ / ±3σ** |
| **1.65 / 1.96 / 2.33**| 标准正态上分位数**5% / 2.5% / 1%** |
| **1/3** | 独立董事最低比例（案例 3-2） |

#### 四、易错点清单

1. **现金流量表是唯一采用收付实现制的主表**；
2. **计算 EBIT 时**：非金融企业需**扣除已含在净利润中的利息收入**；**金融企业无需调整**；且**利润表中"利息费用"仅为费用化部分，不含资本化利息**；
3. **速动比率的"内部转换陷阱"**：**现金购买存货不影响流动比率，但会降低速动比率**；
4. **样本方差分母是 n−1**，不是 n；
5. **分位数：np 为整数直接取第 np 个，非整数取相邻两个的平均**；
6. **中位数抗极端值，均值不抗**（案例 3-15：中位数 5%，均值仅 2%）；
7. **杜邦分析法 ROE 高不等于经营好**——可能来自**高杠杆**（案例 3-1 中 A 公司权益乘数 3.64）；
8. **连续复利 > 高频离散复利 > 低频离散复利**（同为 9%、10 年：2 459.60 > 2 435.19 > 2 411.71 > 2 367.36）；
9. **即期利率起点在当前，远期利率起点在未来**；
10. **金融收益率"尖峰厚尾"**——极端值比正态预测更多，**用正态测风险会低估尾部**。
