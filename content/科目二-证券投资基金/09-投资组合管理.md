## 9.1 现代投资组合理论

### 9.1.a 【了解】现代投资组合理论与资本市场理论的形成和主要发展脉络 P279–P281

**大纲原文**：了解现代投资组合理论与资本市场理论的形成和主要发展脉络

#### （一）六个里程碑（必背时间轴）

| 时间 | 人物 | 贡献 | 意义 |
|---|---|---|---|
| **1952 年**|**哈里·马科维茨（Harry Markowitz）**|**在《金融杂志》发表《资产组合的选择》，首次提出均值—方差模型**|**奠定了投资组合理论的基础，标志着现代投资组合理论（MPT）的开端**；**1990 年获诺贝尔经济学奖** |
| **1964 / 1965 / 1966 年**|**威廉·夏普（William Sharpe）、约翰·林特耐（John Lintner）、简·莫辛（John Mossin）** 三人**分别独立研究**|**资本资产定价模型（CAPM）**|**CAPM 引入了贝塔系数（Beta）的概念，用以衡量单个资产对市场整体风险的敏感度，从而为资产定价提供了一个简洁而有力的工具** |
| **1973 年**|**费雪·布莱克（Fischer Black）与迈伦·斯克尔斯（Myron Scholes）**|**运用随机微分方程理论推导出期权定价模型**；**同期罗伯特·默顿（Robert Merton）也发现了同样的公式并扩展了模型的内涵**|**默顿和斯克尔斯因此获得 1997 年诺贝尔经济学奖** |
| **1976 年**|**斯蒂芬·罗斯（Stephen Ross）**|**套利定价理论（APT）**|**该理论认为风险资产的收益与多个共同因素之间存在线性关系，从而将单因子 CAPM 发展为多因子模型** |
| **1970 年**|**尤金·法玛（Eugene F. Fama）**|**有效市场假说（EMH）**，**并把有效市场分为三种不同类型**|**法玛因此贡献获得 2013 年诺贝尔经济学奖** |
| **近年来**|**行为金融学、Fama-French 三因子模型**|**对传统金融理论提出挑战，强调投资者的非理性行为对市场的影响**|**进一步丰富了资产定价理论** |

#### （二）马科维茨的三个核心贡献 P279–P280

| # | 贡献 |
|---|---|
| 1 | **用收益率的期望值来度量收益，用收益率的标准差来度量风险** |
| 2 | **核心观点是投资者应该通过同时购买多种证券进行分散化投资，以降低整体风险** |
| 3 | **引入了"有效前沿"（Efficient Frontier）的概念**——这是一条曲线，**代表了在给定风险水平下能够获得最高预期回报的投资组合集合** |

**MPT 的分解思想与局限** P280：

> **现代投资组合理论把多种证券的投资组合看作一个整体来进行分析和度量，然后把投资组合的风险分解为两部分——系统性风险和非系统性风险**；**投资者可以通过持有多种类型的证券以达到分散非系统性风险，从而进一步降低整个组合的风险**。

**MPT 的三大局限**：

> 但是**它也具有一定的局限性**——**没有进一步说明如何为证券估值和定价**，**也不能说明投资组合期望回报率与风险之间的关系**，**其理论难以付诸实际应用**。

> **正是这个"未解决的问题"，引出了 CAPM**——**CAPM 从而解决了这个问题**。

#### （三）CAPM 的两层结论 P280

> **CAPM 在一系列假设条件下得出结论：对于所有投资者，最优的资产组合都是市场资产组合和无风险资产的组合**；**这种组合的所有可能情况形成一条被称为"资本市场线"的直线**。

> **CAPM 自从被夏普提出以来，已经被应用于各种投资决策，尤其是在度量各种风险证券或者风险证券组合的系统性风险方面发挥了重要作用**。

#### （四）APT 的核心主张 P280

> **鉴于 CAPM 是一个单因子模型，且难以通过实证完全验证**，**斯蒂芬·罗斯于 1976 年提出了套利定价理论（APT）**；**该理论认为风险资产的收益与多个共同因素之间存在线性关系，从而将单因子 CAPM 发展为多因子模型**。

> **APT 认为，只要任何一个投资者不能通过套利获得收益，那么期望收益率一定与风险相联系**；**这个理论的前提是完全竞争和有效资本市场**。

#### （五）EMH 的提出路径与三种类型 P280

**提出路径**：

> **资产组合理论产生后，Kendall（1953）与 Roberts（1959）发现股票价格序列类似于随机漫步**，他们**对这种现象的解释是：在给足所有已知信息后，这些信息一定已经被反映于股价中了，所以股价只对新信息作出上涨或下跌的反应**；**由于新信息是不可预测的，那么随新信息变动的股价必然是随机且不可预测的**。

**法玛的三种市场类型（必背）**：

| 类型 | 股价已反映的信息 |
|---|---|
| **弱有效市场**|**股价已反映了全部能从市场交易数据中得到的信息** |
| **半强有效市场**|**股价已反映了所有公开的信息** |
| **强有效市场**|**股价已反映了全部与公司有关的信息，包括所有公开信息及内部信息** |

#### （六）总体评价 P281

> **综上所述，自 1952 年马科维茨提出"资产组合的选择"以来，现代投资组合理论和资本市场理论已逐步发展成熟，形成了较为完备的理论框架**。

| 理论 | 贡献 |
|---|---|
| **现代投资组合理论**|**提供了一种理性决策的投资分析方法，革新了投资管理实践** |
| **资本市场理论**|**其诞生标志着金融问题分析从定性向向定量的转变，其核心理论得到了广泛认可** |

> **在专业投资实践中，投资组合方法和定量分析方法得到了广泛应用，定量与定性分析方法相辅相成，共同助力投资管理**。

### 9.1.b 【掌握】资产收益率的期望、方差、协方差、标准差、资产收益相关性等的概念、计算和应用 P281–P285

**大纲原文**：掌握资产收益率的期望、方差、协方差、标准差、资产收益相关性等的概念、计算和应用

#### （一）单个资产：期望收益率、方差与标准差 P281–P282

> **在均值—方差模型中，每个资产的期望收益率、方差和标准差是基础数据**。

| 统计量 | 符号 | 含义 |
|---|---|---|
| **期望收益率**|**E(r_i)**|**指其在未来各种可能收益情况下，基于概率加权获得的平均收益率**；**这可以通过历史数据的样本均值或其他估计方法获得**；**期望收益率是构建投资组合的核心指标之一** |
| **方差**|**σ_i²**|**衡量其收益率波动的程度** |
| **标准差**|**σ_i**|**为方差的平方根，表示收益率的平均偏差程度** |

> **方差和标准差反映了资产的风险性，是均值—方差分析的重要依据**。

#### （二）两个资产之间：协方差与相关系数 P282

> **在投资组合理论使用协方差和相关系数测度两个风险资产的收益之间的相关性**。

**协方差（Covariance）**：

> **协方差衡量两个变量变化趋势的一致性**；对于**已知资产 i 和 j 的收益率的联合分布**，其**协方差** 为：

$$\text{Cov}(r_{i},r_{j})=E\{[r_{i}-E(r_{i})][r_{j}-E(r_{j})]\}$$

**离散情形**（**s 种状态，每种状态的可能性为 p_k**）：

$$\text{Cov}(r_{i},r_{j})=\sum_{k=1}^{s}p_{k}[r_{ik}-E(r_{i})][r_{jk}-E(r_{j})]$$

**样本情形**：**若使用历史上 m 期样本计算资产 i 和 j 的收益率的协方差**，则用**样本协方差公式**（除以**m − 1**）。

**相关系数（Correlation Coefficient）**：

> **两个资产收益率的相关系数表示二者相关关系的密切程度，以希腊字母 ρ 表示**。

$$\boxed{\rho_{ij}=\frac{\text{Cov}(r_{i},r_{j})}{\sigma_{i}\sigma_{j}}}$$

**ρ 的取值含义（必背）** P282：

| 取值 | 含义 |
|---|---|
| **取值范围**|**[-1, +1]** |
| **ρ > 0**|**两变量为正线性相关** |
| **ρ < 0**|**两变量为负线性相关** |
| **ρ = 0**|**两变量间无线性相关关系** |
| **0 < \|ρ\| < 1**|**表示两变量存在一定程度的线性相关**，且 **\|ρ\| 越接近 1，表示两变量间线性关系越密切；\|ρ\| 越接近 0，表示两变量间线性关系越弱** |
| **\|ρ\| = 1** | **表示两变量完全线性相关**——**+1 为完全正相关，-1 为完全负相关** |

#### （三）投资组合的期望收益率 P282

> **对于多个资产组成的投资组合，期望收益率为其所包含各个资产的期望收益率的加权平均**。

$$\boxed{E(r_{p})=\sum_{i=1}^{n}w_{i}E(r_{i})}$$

**符号**：**E(r_p)** 为**投资组合的期望收益率**；**E(r_i)** 为**第 i 个资产的期望收益率**；**w_i**为**第 i 个资产的权重**；**n**为**资产数目**。

#### （四）投资组合的方差与标准差（核心公式） P282–P283

> **投资组合收益率的方差和标准差，取决于各资产的方差、权重以及互相之间的相关系数**。

**两个资产 i、j 组成的组合**：

$$\sigma_{p}^{2}=w_{i}^{2}\sigma_{i}^{2}+w_{j}^{2}\sigma_{j}^{2}+2w_{i}w_{j}\rho_{ij}\sigma_{i}\sigma_{j}$$

**扩展到 n 个资产**：

$$\sigma_{p}^{2}=\sum_{i=1}^{n}\sum_{j=1}^{n}w_{i}w_{j}\text{Cov}(r_{i},r_{j})=\sum_{i=1}^{n}\sum_{j=1}^{n}w_{i}w_{j}\rho_{ij}\sigma_{i}\sigma_{j}$$

**符号**：**σ_p²**代表**组合方差**；**w_i 与 w_j**代表**相应资产在组合中的权重**；**Cov(r_i, r_j)** 代表**任意两个资产收益率的协方差**；**ρ_ij**代表**任意两个资产收益率的相关系数**；**σ_i、σ_j**分别代表**资产 i、资产 j 和投资组合收益率的标准差**。

**组合标准差**：

$$\sigma_{p}=\sqrt{\sum_{i=1}^{n}\sum_{j=1}^{n}w_{i}w_{j}\text{Cov}(r_{i},r_{j})}$$

**一句话结论（必背）**：

> **可见，资产组合的方差是各单一资产的方差与资产间相关系数的组合**；**单一资产方差不变，相关系数越小，资产组合的方差也越小**。

#### （五）资产收益的相关性：三种极端情形 P283–P285

##### ① 相关性的来源 P283

> **资产收益之间的相关性主要源于共同影响因素的存在**；**多数资产收益间都存在一定程度的相关性，这主要是受宏观经济状况、行业政策和技术革新等因素的共同影响**——**宏观经济状况会影响大多数公司的整体业绩表现，行业政策则对同一行业内的公司产生普遍影响，而新技术的开发和应用可能会影响一系列相关产业的业绩**。

##### ② 相关系数如何改变组合的形态 P283–P284

> 对于**由两个资产 i 和 j 构成的组合**，**给定一个特定的投资比例，则得到一个特定的投资组合，它具有特定的预期收益率和标准差**，这在**图 9-1 的标准差—预期收益率平面中表现为一个特定的点**；**如果让投资比例在一个范围内连续变化，则得到的投资组合点在标准差—预期收益率平面中构成一条连续曲线**——**给定不同的相关系数，得到不同的曲线**。

**情形一：ρ = +1（完全正相关）**

$$\sigma_{p}^{2}=w_{i}^{2}\sigma_{i}^{2}+w_{j}^{2}\sigma_{j}^{2}+2w_{i}w_{j}\sigma_{i}\sigma_{j}$$

> **此时两个资产的投资组合呈一条直线，直线上的每一个点表示不同权重的投资组合**；**如果我们把 100% 的资金投资于资产 i（0 给资产 j），那么投资组合就是 i 点**；**随着 i 的权重越来越小，j 的权重越来越大，投资组合的点就沿着直线向右上方移动**；**直到 j 的权重达到 100%（i 的权重为 0），那么投资组合就到 j 点**。

**ρ = +1 时无任何分散化效果**——**组合风险是两者的线性插值，不能低于较低风险资产的单独风险**。

**情形二：ρ = −1（完全负相关）**

$$\sigma_{p}=|w_{i}\sigma_{i}-w_{j}\sigma_{j}|$$

> **可见，当两个资产收益率的相关系数等于 -1，一定能找到一点，使得投资组合的标准差为 0**；**在图 9-1 中，两个资产的可能组合是一条转折点在 y 轴的折线**；**转折点即标准差为 0 的组合，等效于无风险资产**。

**ρ = −1 时可构造"无风险组合"**——**令 w_iσ_i = w_jσ_j 即可使 σ_p = 0**。

**情形三：ρ = 0（不相关）**

$$\sigma_{p}^{2}=w_{i}^{2}\sigma_{i}^{2}+w_{j}^{2}\sigma_{j}^{2}$$

**一般情形（−1 < ρ < 1）**：

> **如果资产 i 和资产 j 的收益率和相关系数在 -1 和 1 之间，那么两个资产的投资组合将呈一条向左上方弯曲的曲线**，**曲线上的每一个点表示资产权重不同的投资组合**；**相关系数越小，组合的曲线越往左边弯曲，组合风险越小（即在相同收益率的情况下，风险更小），组合的效用越高**。

#### （六）本节最重要的一句话（必背） P284

> **资产收益之间的相关性会影响投资组合的风险，而不会影响投资组合的预期收益率**。

#### 案例 9-1：不同相关系数对组合风险的影响 P284–P285

**表 9-1 资产预期收益率及标准差**：

| 资产 | 预期收益率（%） | 标准差（%） |
|---|---|---|
| **资产 1**|**6**|**5** |
| **资产 2**|**8**|**9** |

> **为比较不同相关系数对于投资组合风险的影响，我们考虑相关系数取 -1、-0.5、0、0.5、1 这五种情况**。

**两个关键观察**：

| # | 观察 |
|---|---|
| 1 | **无论相关系数取什么数值，图 9-2 中的曲线必定通过代表资产 1 的点（5%，6%）和代表资产 2 的点（8%，9%）**，**这两点分别对应于全额投资于资产 1 及全额投资于资产 2 的情形** |
| 2 | **卖空被限制时，投资组合的收益率介于资产 1 与资产 2 的收益率之间，因此曲线在资产 1 与资产 2 之间的部分对应于卖空被限制的情形，而两端的部分代表允许卖空的情形** |

> **观察不同曲线在资产 1 与资产 2 之间的部分，可以发现相关系数值越小，则曲线越靠左，即投资组合的风险越低**；**而预期收益率只与两种资产的比例有关，与相关系数无关**。

**再次强调**：**预期收益率只与权重有关（不受 ρ 影响），风险同时受权重与 ρ 影响**。

#### （七）统计量对比速查表

| 统计量 | 符号 | 度量什么 | 取值范围 | 在组合中的作用 |
|---|---|---|---|---|
| **期望收益率**|**E(r)**|**平均收益水平**| 任意实数 |**线性加权，决定组合收益** |
| **方差**|**σ²**|**收益波动的平方**|**≥ 0**|**组合风险的组成部分** |
| **标准差**|**σ**|**收益的平均偏差**|**≥ 0**|**风险的自然单位，与收益率同量纲** |
| **协方差**|**Cov(r_i,r_j)**|**两资产变化趋势的一致性**| 任意实数 |**决定组合风险能否被分散** |
| **相关系数**|**ρ_ij**|**两者相关关系的密切程度（标准化后的协方差）**|**[-1, +1]**|**ρ 越小，分散化效果越好** |

### 9.1.c 【理解】均值—方差模型的基本假设和核心思想，可行集、最小方差前沿、有效前沿、效用、无差异曲线的概念，投资者最优投资组合的确定逻辑 P281–P288

**大纲原文**：理解均值—方差模型的基本假设和核心思想，可行集、最小方差前沿、有效前沿、效用、无差异曲线的概念，投资者最优投资组合的确定逻辑

#### （一）基本假设与核心思想 P281

> **马科维茨投资组合理论的基本假设是投资者是厌恶风险的**；**该理论认为，在预期收益率相同的情况下，投资者会选择风险较小的证券；而承担更高的风险则需要更高的预期收益来补偿**。

**模型要点的四层逻辑（必背）**：

| # | 要点 |
|---|---|
| **首先**|**投资组合具有两个相关的特征：一是预期收益率；二是各种可能的收益率围绕其预期值的偏离程度，这种偏离程度可以用方差度量** |
| **其次**|**投资者将选择并持有有效的投资组合**——**有效投资组合是指在给定的风险水平下使得期望收益最大化的投资组合，在给定的期望收益率上使得风险最小化的投资组合** |
| **再次**|**通过对每种证券的期望收益率、收益率的方差和每一种证券与其他证券之间的相互关系（以协方差来度量）这三类信息的适当分析，可以在理论上识别出有效投资组合** |
| **最后**|**对上述三类信息进行计算，得出有效投资组合的集合，并根据投资者的偏好，从有效投资组合的集合中选择出最适合的投资组合** |

**严格假设与其局限**：

> **均值—方差模型建立在一系列严格假设之上，例如投资者是风险规避的、投资收益率服从正态分布等**；**在实际应用中，这些假设可能难以完全满足，因此模型的应用效果会受到一定限制，后续的理论发展（如行为金融学）也对这些假设提出了挑战和补充**。

#### （二）可行集（Feasible Set） P285

> **可行集（Feasible Set），又称"机会集"**，代表**市场上可投资产形成的所有可能的投资组合**；**所有这些组合都位于可行集的内部或边界上**。

#### （三）最小方差前沿（Minimum Variance Frontier） P285

> **如果做一条和横轴平行的直线，和可行集的边界交于 A、B 两点（见图 9-3），我们可以发现两点具有相同的预期收益率，但 A 点风险较低**；**在给定收益率下，投资者追求最小风险**；因此，**只有可行集最左边的点是有效的**；**可行集最左边的点构成最小方差前沿（见图 9-4）**。

> **这条曲线上的每个点代表在特定收益率水平下风险最小的组合，其中各风险资产的权重不同**。

#### （四）有效前沿（Efficient Frontier） P286

**三个关键概念**：

| 概念 | 界定 |
|---|---|
| **全局最小方差组合（点 C）**|**最小方差前沿的最左端点 C 称为全局最小方差组合**；**它是所有可能组合中风险最小的点，也是前沿上半部分和下半部分的分界点** |
| **为什么只有上半部分有效**|**上半部分的组合在相同风险水平下具有更高的预期收益率**——例如，**图 9-5 中组合 A 和 B 风险相同，但 A 的收益率更高**；因此，**最小方差前沿只有上半部分是有效的** |
| **有效前沿**|**从全局最小方差组合开始，最小方差前沿的上半部分就称为"马科维茨有效前沿"，简称"有效前沿"（Efficient Frontier）**；**它代表风险和收益的最优权衡，位于所有单个资产和其他组合的左上方** |

**有效组合的定义（必背）**：

> **如果一个投资组合在所有风险相同的投资组合中具有最高的预期收益率，或者在所有预期收益率相同的投资组合中具有最低的风险，那么这个投资组合就被称为"有效组合"（Efficient Portfolio）**。

> **有效前沿是由全部有效投资组合构成的集合**；**有效前沿中有无数组预期收益率和风险各不相同的投资组合**；**一个有效组合如果在预期收益率方面优于另一个，那么在风险方面就一定会劣于后者**。

**记忆要点**：**有效前沿上"收益高必然风险大"**——**没有免费的午餐**。

#### （五）三类风险态度 P286

> **根据投资者对风险不同的态度，可以将投资者分为风险偏好、风险中性和风险厌恶三类**。

| 类型 | 对不确定性的态度 | 决策依据 |
|---|---|---|
| **风险偏好者**|**喜欢投资结果的不确定性**|**在期望收益相同的投资方案中，会选择其中风险最大的** |
| **风险中性者**| — |**仅根据期望收益这一个指标作投资决策，不关心风险** |
| **风险厌恶者**|**不喜欢投资结果的不确定性，更喜欢确定的收益**|**在期望收益相同的投资方案中，他们会选择其中风险最小的** |

**MPT 的前提**：

> **马科维茨的现代投资组合理论假设投资者是风险厌恶的**；对于这些投资者来说，**他们不会选择无效的投资组合，因为可以通过调整投资组合，使其在相同风险下获得更高的预期收益，或者在相同预期收益下降低风险**。

**风险溢价（Risk Premium）** P286：

> **为了吸引风险厌恶者购买风险资产，市场必须提供风险溢价**；**风险溢价是指投资者为了承担更高的风险而要求的超过无风险收益率的额外回报**；**它通常表示为资产预期收益率与无风险收益率之间的差值**。

$$RP=E(r)-r_{f}$$

#### （六）效用与效用函数 P286–P287

> **效用是投资带给人的满意程度**；**投资者更喜欢高收益和低风险的资产，因此不同资产给投资者的效用是不一样的**；**投资者总是选择效用高的资产进行投资**。

> **假定每一个投资者可以根据资产（或资产组合）的预期收益与风险情况对效用进行量化比较，则可得出其效用函数**。

$$\boxed{U=E(r)-\frac{1}{2}A\sigma^{2}}$$

**符号**：**U**为**效用值**；**A**为**某投资者的风险厌恶系数**；**E(r)** 为**资产的预期收益率**；**σ²**为**资产收益的方差**。

**两条推论（必背）**：

> 从公式可以看出，**对于风险厌恶系数 A 一定的投资者来说，某资产的期望收益率越大，带给投资者的效用越大；资产的风险越大，效用越小**。

> **同一资产带给风险厌恶系数不同的投资者的效用并不相同**；**风险厌恶系数 A 越大的投资者感受到的效用越低**。

#### （七）无差异曲线（Indifference Curve） P287

> **根据投资者的效用函数，可以绘制无差异曲线**；**无差异曲线是在期望收益—标准差平面上由相同给定效用水平的所有点组成的曲线**。

**五个特点（必背）**：

| # | 特点 |
|---|---|
| **1**|**风险厌恶的投资者的无差异曲线是从左下方向右上方倾斜的** |
| **2**|**同一条无差异曲线上的所有点向投资者提供了相同的效用** |
| **3**|**对于给定风险厌恶系数 A 的某投资者来说，可以画出无数条无差异曲线，且这些曲线不会交叉** |
| **4**|**当向较高的无差异曲线移动时（如图 9-7 中，从 I₁ 向 I₂ 再向 I₃ 移动时），投资者的效用增加** |
| **5**|**风险厌恶程度高的投资者与风险厌恶程度低的投资者相比，其无差异曲线更陡，因为随着风险增加，其要求的风险溢价更高** |

#### （八）最优投资组合的确定逻辑 P287–P288

> **使投资者效用最大化的是无差异曲线和有效前沿相切的点所代表的投资组合，这一组合称为最优组合**；**投资者按照这一组合进行投资可以获得最大的投资效用**。

**为什么"切点"就是最优（两层理由，必背）**：

| # | 理由 |
|---|---|
| **1**|**因为这个点在有效前沿上，因此它是投资者可以实际选择的点** |
| **2**|**而它又是所有与有效前沿相交的无差异曲线中位于最上方的无差异曲线上的点，因此它又是投资者可以获得最大效用的点** |

**不同风险厌恶程度 → 不同切点**：

> **风险厌恶程度不同的投资者，其切点位置也不同**；**如图 9-8 所示，X 投资者比 Y 投资者更加厌恶风险，因此，X 的最优组合在 Y 最优组合的左下方**。

**几何直觉**：**约厌恶风险 → 无差异曲线越陡 → 切点越靠左（低风险、低收益）**。

#### （九）确定最优组合的四步逻辑链

| 步骤 | 动作 |
|---|---|
| **①**|**计算各资产的 E(r)、σ² 与协方差矩阵** |
| **②**|**求可行集 → 取最左边界得最小方差前沿** |
| **③**|**取前沿上半部分得有效前沿**（**下半部分同风险下收益更低，故无效**） |
| **④**|**按投资者风险厌恶系数 A 画无差异曲线族，与有效前沿的切点即最优组合** |

#### （十）五个概念对比速查

| 概念 | 几何位置 | 经济含义 |
|---|---|---|
| **可行集**|**一片区域（含内部与边界）**|**市场上所有可能的组合** |
| **最小方差前沿**|**可行集的最左边界（整条）**|**每个收益率水平下风险最小的组合** |
| **全局最小方差组合**|**前沿最左端点 C**|**所有组合中风险最小者**；**上下半部分的分界点** |
| **有效前沿**|**前沿的 C 点以上（上半部分）**|**风险收益最优权衡，位于所有组合左上方** |
| **最优组合**|**有效前沿与无差异曲线的切点**|**该投资者效用最大化的组合** |

## 9.2 资本市场理论

### 9.2.a 【理解】资本市场理论的前提假设，资本配置线和资本市场线的含义、构成和公式，以及系统性风险和非系统性风险的概念和风险分散化原理 P288–P294

**大纲原文**：理解资本市场理论的前提假设，资本配置线和资本市场线的含义、构成和公式，以及系统性风险和非系统性风险的概念和风险分散化原理

#### （一）七条前提假设（必背） P288–P289

> **20 世纪 60 年代，威廉·夏普、约翰·林特耐和简·莫辛三位学者基于马科维茨的均值方差模型，提出了资本市场理论和资本资产定价模型，研究在特定假设下均衡价格的形成**。

| # | 假设 | 关键内涵 |
|---|---|---|
| **1**|**所有投资者都是风险厌恶者**|**都以马科维茨均值—方差分析框架来分析证券，追求效用最大化，购买有效前沿与无差异曲线的切点的最优组合** |
| **2**|**投资者可以以无风险利率任意地借入或贷出资金（无限借贷）**|**在马科维茨的世界里，世界上所有的资产都是风险资产，没有无风险资产**；**威廉·夏普第一次引入了无风险资产**——**无风险资产的风险（标准差）为 0，收益率为无风险收益率**；**投资者的投资范围仅限于公开市场上可以交易的资产**，**这一假定排除了非流动性资产，如人力资本、私有企业、政府资产等** |
| **3**|**同质期望（同质信念）假定**|**所有投资者的期望相同**——**任何投资者认为同一个股票有相同的风险/收益分布**；**所有投资者都具有同样的信息，他们对各种资产的预期收益率、风险及资产间的相关性都具有同样的判断** |
| **4**|**所有投资者的投资期限都是相同的**|**并且不在投资期限内对投资组合作动态的调整** |
| **5**|**所有的投资都可以无限分割**|**投资数量任意** |
| **6**|**无摩擦市场**|**主要指没有税和交易费用**；**现实中的金融交易都会涉及交易佣金以及税收负担**，**这些因素都会直接影响投资者对投资资产的选择** |
| **7**|**投资者是价格的接受者**|**他们的买卖行为不会改变证券价格，每个投资者都不能对市场定价造成显著影响** |

**七条可归结为两条（核心考点）**：

> **资本市场理论的七条前提假设可以归结为两条：一是所有投资者都是一样的；二是市场是有效的**。

> **这七条假设是资本市场理论的前提假设，也是资本资产定价模型的前提假设**。

#### （二）四条市场均衡结论 P289

> **以上假设忽略了许多现实世界的复杂性，但却提供了认识市场均衡状态本质的方法**。

| # | 均衡结论 |
|---|---|
| **1**|**所有投资者将选择持有包括所有证券资产在内的市场组合 M**——**市场投资组合包含市场上所有的风险资产，并且其包含的各资产的投资比例与整个市场上风险资产的相对市值比例一致** |
| **2**|**市场组合处于有效前沿**——**市场组合是最优风险投资组合，即资本配置线（CAL）与有效边界的切点**；因此，**资本市场线（CML），即从无风险利率到市场组合 M 的线也是可获得的最佳资本配置线**；**所有投资者均将 M 作为其最佳风险投资组合，区别在于市场组合资产与无风险资产的配比** |
| **3**|**市场组合的风险溢价与市场组合的方差和投资者的典型风险偏好成正比** |
| **4**|**单个资产的风险溢价与市场投资组合 M 的风险溢价和该资产的 β 系数成比例**——**β 系数衡量资产收益率相对市场组合收益率变化的敏感度** |

#### （三）资本配置线（CAL） P289–P291

> **马科维茨有效前沿上的投资组合仅包含了所有风险资产，威廉·夏普对马科维茨有效前沿进行了改进，引入了无风险资产**。

**设定**：**一个由风险资产 x 和无风险资产组成的投资组合**——**风险资产 x 的权重为 w_x，收益率为 E(r_x)，标准差为 σ_x；无风险资产的权重为 (1 − w_x)，收益率为 r_f，标准差为 0**。

**组合期望收益率**：

$$E(r_{p})=w_{x}E(r_{x})+(1-w_{x})r_{f}=r_{f}+w_{x}[E(r_{x})-r_{f}]$$

**组合方差**：

$$\sigma_{p}^{2}=w_{x}^{2}\sigma_{x}^{2}+(1-w_{x})^{2}\sigma_{f}^{2}+2w_{x}(1-w_{x})\rho_{xf}\sigma_{x}\sigma_{f}$$

> **由于无风险资产的标准差为 0（σ_f = 0），所以右边第二项和第三项都等于 0**，可得到：

$$\sigma_{p}^{2}=w_{x}^{2}\sigma_{x}^{2}\ \Longrightarrow\ \sigma_{p}=w_{x}\sigma_{x}\ \Longrightarrow\ w_{x}=\frac{\sigma_{p}}{\sigma_{x}}$$

**代入期望收益率得 CAL 表达式**：

$$\boxed{E(r_{p})=r_{f}+\frac{E(r_{x})-r_{f}}{\sigma_{x}}\sigma_{p}}$$

**CAL 的两要素（必背）**：

> **资本配置线上的点表示无风险资产与风险资产 x 的线性组合**——**其截距是无风险收益率 r_f，斜率是 [E(r_x) − r_f]/σ_x**。

> **值得注意的是，这个斜率就是风险资产 x 的夏普比率（Sharpe Ratio），也是这条 CAL 上任一点的夏普比率**。

**为什么最优 CAL 是切点那条**：

> **每一个投资者对于收益和风险都有不同的预期和偏好**，因此，**每一个投资者都有不同的最优投资组合及不同的 CAL**；**有效前沿上的点表示所有投资者最优的风险资产组合**；**我们取无风险资产与有效前沿上的点相连，可以得到无数条 CAL**。

> **在这无数条 CAL 中，最优的 CAL 是与有效前沿相切的那条**——**因为在相同的风险水平下，最优的 CAL 期望收益率最高**。

#### （四）资本市场线（CML） P291–P292

**引入无风险资产后的形状变化**：

> **若不考虑无风险资产，由风险资产构成的马科维茨有效前沿在标准差—预期收益率平面中的形状为双曲线上半支**；**当引入无风险资产后，不同的投资者有不同的最优资产组合以及不同的资本配置线**。

> **对于投资者来说，最佳的资本配置线是与马科维茨有效前沿相切的一条直线，这条直线取代了马科维茨有效前沿，成为新的有效前沿，称为资本市场线（Capital Market Line，CML）**。

> **资本市场线从纵轴上无风险利率点处向上延伸，与原马科维茨有效前沿曲线相切于点 M，这条直线上包含了所有风险资产投资组合 M 与无风险资产的组合**；**当市场达到均衡时，切点 M 即为市场投资组合（Market Portfolio）**。

**CML 表达式**：

$$\boxed{E(r_{p})=r_{f}+\frac{E(r_{m})-r_{f}}{\sigma_{m}}\sigma_{p}}$$

**CML 的两层含义（必背）**：

> **从公式可以看出，CML 的斜率，即为市场组合的夏普比率，而 CML 上任一个组合的夏普比率都等于市场组合的夏普比率**。

> **因为 CML 取代了马科维茨有效前沿成为新的有效前沿，CML 上所有的组合都是有效组合，即所有的组合都是完全分散化了的资产组合**。

**为什么所有投资者都落到 CML 上**：

> **根据前述 CAPM 的假定，所有投资者都具有相同的预期，都是理性的**；**既然如此，那么所有投资者都会得到同样的有效前沿，所有投资者的选择最终都会落在 CML 上**。

> **因此，每一位投资者都将以无风险资产和市场投资组合 M 来构造适合自己需求的最优投资组合，所不同的仅是每个投资者在 M 上的资金投放比例不同而已**；**由于每个投资者都持有相同的风险投资组合 M，而市场投资组合是所有投资者持有的风险资产组合的加总，因此，风险投资组合 M 中各资产的比例恰好与市场投资组合一致，或者说 M 就是市场投资组合**。

**市场投资组合 M 的三个特征（必背）**：

| # | 特征 |
|---|---|
| **1**|**它是有效前沿上唯一一个不含无风险资产的投资组合** |
| **2**|**有效前沿上的任何投资组合都可看作是市场投资组合 M 与无风险资产的再组合** |
| **3**|**市场投资组合完全由市场决定，与投资者的偏好无关** |

> **因此，市场投资组合在资本资产定价理论中具有重要的地位**。

**CML 的经济意义** P292：

> **资本市场线实际上指出了有效投资组合风险与预期收益率之间的关系，提供了衡量有效投资组合风险的方法**；**有效投资组合即是分布于资本市场线上的点，代表了有效前沿**。

> **特别是它指出了以标准差来表示的有效投资组合的风险，其与回报率之间是一种线性关系，因此以标准差来度量风险是更为合适的**；**对于每一个有效投资组合而言，给定其风险的大小，便可根据资本市场线计算出其预期收益率的大小**。

#### （五）风险分散化原理与两类风险 P292–P294

##### 案例 9-2：橙汁公司与雨伞公司 P292–P293

> **假设有两家公司，一家是橙汁生产公司，一家是雨伞制造公司**；**两家公司的业绩都易受到天气的影响**——**橙汁生产公司的业绩在天气晴朗的情况下较好，而雨伞制造公司的业绩在天气阴雨的情况下较好**；**假设在未来一年天气平均较为晴朗的概率为 50%，平均较为阴雨的概率为 50%**。

**表 9-2 两公司在不同天气状态下的预期收益率**：

| 公司 | 晴朗 | 阴雨 |
|---|---|---|
| **橙汁生产公司**|**10%**|**−2%** |
| **雨伞制造公司**|**−2%**|**10%** |

**单只股票的收益与风险**：

- **橙汁公司的预期收益率 = 10% × 50% + (−2%) × 50% = 4%**；
- **预期收益率的标准差 = √[(10%−4%)²×50% + (−2%−4%)²×50%] = 6%**；
- **雨伞制造公司在未来一年的预期收益率和标准差同样分别为 4% 和 6%**。

> **投资者如果将所有的资金都投资于其中某一家公司，那么他的预期收益率为 4%，预期收益率的标准差为 6%**。

**分散化后的结果**：

> **如果投资者将资金平均投资于两家公司，那么在天气较晴朗的状态下，投资者的收益率为 10%×50% − 2%×50% = 4%**；**在天气较阴雨的状态下，投资者也将获得 4% 的收益率**；**此时投资者获得了确定性的收益率 4%，投资风险为零**。

**成功分散的关键（必背）**：

> **在上述案例中，通过分散化投资，投资者消除了风险**；**投资者之所以可以分散化风险，其中的关键原因是两种资产的收益波动存在相反的趋势**。

##### 为什么系统性风险无法分散 P293

> **我们也可以考虑另一个特别的情形，即两种资产的收益具有同样的波动规律**；在这种情况下，**如果不允许投资者卖空资产的话，那么投资者无法利用这样的两种资产来构建预期收益率相同而风险更低的投资组合来**；**这说明我们无法将各资产共同的风险分散化**。

> **我们通常无法分散化资产收益中的系统性风险**——**因为系统性风险通常使得所有资产的收益出现相同的变化**；**在不卖空资产的情形下，无论怎样搭配投资组合，系统性因素总是使得投资组合中的所有资产出现同向的收益波动，从而投资组合也出现同向的收益波动**。

##### 两类风险的定义与加总公式（核心） P293

> **通过投资资产组合，可以降低风险，但不能完全消除风险**。

| 类型 | 界定 |
|---|---|
| **非系统性风险（Non-systematic Risk）**|**可以通过构造资产组合分散掉的风险** |
| **系统性风险（Systematic Risk）**|**不能通过构造资产组合分散掉的风险** |

$$\boxed{\text{总风险}=\text{系统性风险}+\text{非系统性风险}}$$

##### 为什么只有系统性风险获得补偿（必背逻辑链） P293–P294

> **"天下没有免费的午餐"，投资者要求在承担风险的时候得到风险补偿，即风险溢价**；**非系统性风险可以通过构造资产组合分散掉，是可以避免的风险，因此，承担非系统性风险不能得到风险补偿**；**风险补偿只能是对于不可避免的风险的补偿，即承担系统性风险的补偿**。

> **当组合中资产的数目逐渐增多的时候，非系统性风险就会被逐步分散，但是无论资产数目有多少，系统性风险都是固定不变的**（**图 9-13**）。

**结论**：

> **在此前提下，资产在市场均衡状态下的收益率取决于该资产或资产组合的系统性风险，而不是由方差衡量的总风险**。

##### CML 上只有系统性风险 P294

> **资本市场线中，我们用方差/标准差来衡量总风险**；**但是资本市场线上的市场组合是一个完全分散化的资产组合，其非系统性风险都被分散掉了，只有系统性风险**。

> **而资本市场线上的任一组合都是对无风险资产和市场组合做配比得到的**——**因为无风险资产是没有风险的，市场组合只有系统风险，所以由这两者构成的组合也只有系统性风险**；**因此，资本市场线上的任一组合只有系统性风险，没有非系统性风险**。

#### （六）三个"线"的对比速查

| 项目 | **CAL（资本配置线）**|**CML（资本市场线）**|**马科维茨有效前沿** |
|---|---|---|---|
| **构成**|**无风险资产 + 任一风险资产 x**|**无风险资产 + 市场组合 M**|**仅含风险资产** |

### 9.2.b 【掌握】资本资产定价模型的基本原理、公式及其应用，以及证券市场线和资本市场线的区别 P294–P298

**大纲原文**：掌握资本资产定价模型的基本原理、公式及其应用，以及证券市场线和资本市场线的区别

#### （一）β 系数的衡量 P294

> **方差和标准差能够衡量资产的收益—风险特征，但不能对风险的构成进行分析**；这里我们**引入 β 系数（Beta Coefficient）来衡量资产所面临的系统性风险**。

> **β 系数衡量的是资产收益率和市场组合收益率之间的线性关系**。

**回归方程**：

$$r_{i,t}=\alpha_{i}+\beta_{i}r_{m,t}+\varepsilon_{i,t}$$

**符号**：**r_{i,t}** 为**t 期资产 i 的实际收益率**；**r_{m,t}** 为**t 期市场组合的收益率**；**β_i**为该资产的 β 系数，**是该线性方程的斜率**；**α_i**为**线性方程的截距项**；**ε_i**为**误差项**。

**用最小二乘法回归可得**：

$$\boxed{\beta_{i}=\frac{\text{Cov}(r_{i},r_{m})}{\sigma_{m}^{2}}=\rho_{im}\cdot\frac{\sigma_{i}}{\sigma_{m}}}$$

**符号**：**β_i**是**资产的 β 系数**；**Cov(r_i, r_m)** 是**资产收益率和市场组合收益率之间的协方差**；**σ_m²**是**市场组合收益率的方差**；**σ_i**是**资产收益率的标准差**；**ρ_im**是**资产收益率和市场组合收益率之间的相关系数**。

**β 的经济含义（必背）**：

> **β 系数度量的是资产收益率相对于市场组合收益率波动的敏感性**。

| 参照点 | 含义 |
|---|---|
| **市场组合本身**|**β 系数为 1** |
| **β_i = 1.5**|**市场组合上涨 1%，该资产随之上涨 1.5%** |
| **β_i = 0.5**|**市场组合上涨 1%，该资产随之上涨 0.5%** |

#### （二）CAPM 的主要思想 P295

> **资本资产定价模型（CAPM）以马科维茨证券组合理论为基础，研究如果投资者都按照分散化的理念去投资，最终证券市场达到均衡时，价格和收益率如何决定的问题**；**这种方法是描述性的，它用一般均衡模型刻画所有投资者的集体行为，揭示在均衡状态下，证券收益与风险之间的关系的经济本质**。

> **CAPM 的建立基于本节开头所述的一系列假设**；**这些假设虽然并不符合现实情况，但对问题的解决提出了基础理论**；在此基础上，**我们可以根据现实情况一步一步更改假设，修改模型，从而得到相对合理且贴近现实的模型**。

**核心逻辑（必背）**：

> **CAPM 假设所有的投资者都进行充分分散化的投资，没有投资者会"关心"非系统性风险**；因此，**只有证券或证券组合的系统性风险才能获得收益补偿，其非系统性风险将得不到收益补偿**；**按照该逻辑，投资者要想获得更高的报酬，必须承担更高的系统性风险；承担额外的非系统性风险将不会给投资者带来收益**。

**风险溢价与 β 成正比**：

$$\frac{E(r_{i})-r_{f}}{\beta_{i}}=\frac{E(r_{m})-r_{f}}{\beta_{m}}=\frac{E(r_{m})-r_{f}}{1}$$

**符号**：**E(r_i)**——资产 i 的预期收益率；**E(r_m)**——市场组合的预期收益率；**r_f**——无风险收益率；**β_i**——资产 i 的 β 系数，**市场组合的 β_m 为 1**；**E(r_i) − r_f**——资产风险溢价；**E(r_m) − r_f** ——市场组合风险溢价。

**变形即 CAPM 公式**：

$$\boxed{E(r_{i})=r_{f}+\beta_{i}[E(r_{m})-r_{f}]}$$

**经济含义（必背）**：

> **CAPM 体现了资产的期望收益率与系统风险之间的正向关系，即任何资产的市场风险溢价（收益率超过无风险利率的差额），等于资产的系统性风险（β 系数）乘以市场组合的风险溢价**。

> **β 系数与证券对最优风险组合的风险的贡献成正比**——**如果一个证券的 β 系数相对较低（如 0.5），风险溢价是另外一个 β 系数为 1.5 的证券的 1/3**；**对于可以进行充分分散化投资的投资者而言，只有系统风险才是最重要的，而系统风险用 β 系数来衡量**。

#### （三）证券市场线（SML） P296

> **预期收益率与 β 系数的关系式可以表示成证券市场线（Security Market Line，SML）**。

**SML 的四个要点**：

| # | 要点 |
|---|---|
| 1 | **证券市场线的斜率是市场组合的风险溢价** |
| 2 | **市场组合也恰好位于证券市场线上，即图中的 M 点，该点 β 系数为 1，相对应的预期收益率是市场组合的预期收益率** |
| 3 | **一项资产或资产组合的 β 系数越高，则它的预期收益率越高** |
| 4 | **β 系数为零的资产的预期收益率等于无风险收益率** |

#### （四）SML 与 CML 的本质区别（核心考点） P296–P297

> **SML 是以资本市场线为基础发展起来的**；**资本市场线给出了所有有效投资组合风险与预期收益率之间的关系，但没有指出每一个风险资产的风险与收益之间的关系**；而**证券市场线则给出每一个风险资产风险与预期收益率之间的关系，也就是说证券市场线能为每一个风险资产进行定价**。

> **这是 CAPM 的核心**。

**表 9-3 证券市场线和资本市场线的区别（必背）**：

| 比较维度 | **SML（证券市场线）**|**CML（资本市场线）** |
|---|---|---|
| **风险的衡量**|**系统性风险（用 β 值衡量）**|**总风险（用标准差衡量）** |
| **应用**|**决定资产最合理的预期收益率（定价）**|**决定最合适的资产配置点（资产配置）** |
| **斜率**|**市场组合的风险溢价**|**市场组合的夏普比率** |
| **适用范围**|**① 单个资产或投资组合；② 有效投资组合和无效投资组合**|**有效投资组合** |

**一句话记忆**：**CML 管"配置"（只能在有效组合上用，用 σ 衡量总风险）；SML 管"定价"（任何资产都能用，用 β 衡量系统性风险）**。

**补充对比**：

> **资本市场线描述了有效组合（由最优风险组合与无风险资产所构成的整个组合）的市场溢价与组合标准差之间的函数关系**——**之所以可以得到资本市场线，原因在于，标准差可用于有效地衡量组合的风险，因而可以作为衡量整个组合的风险的辅助工具**；**资本市场线是用来进行资产配置（在无风险资产和市场组合之间进行资产配置）的一个工具**；**因为资本市场线上的组合都是有效组合，它构成了一个新的有效前沿**。

> **证券市场线则描述了单个资产的风险溢价与市场风险之间的函数关系**——**用于评估单个资产（单个资产是高度分散化的投资组合中的一部分）对整个组合的风险贡献，这种贡献可以用资产的 β 值来衡量**；**证券市场线既适用于资产组合，又适用于单个资产**；**我们可以用证券市场线来给资产确定一个最合理的预期收益率**；**证券市场线是基于资本资产定价模型的，斜率是市场组合的风险溢价**。

#### （五）CAPM 的应用：如何用 SML 判断定价 P297

> **在 CAPM 中，证券市场线得以成立是投资者的最优选择以及市场均衡力量作用的结果**。

**回归机制（必背）**：

> **若某资产或资产组合的预期收益率高于与其 β 值对应的预期收益率，也就是说位于证券市场线的上方**，则**理性投资者将更偏好于该资产或资产组合，市场对该资产或资产组合的需求超过其供给，最终抬升其价格，导致其预期收益率降低，使其向证券市场线回归**。

> **反之，若某资产或资产组合位于证券市场线的下方**，则**理性投资者将不愿意投资该资产或资产组合，导致市场对它供过于求，价格下降，预期收益率上升，最终该资产或资产组合收益率也会向证券市场线回归**。

**三种位置的含义（高频，易错）**：

| 位置 | 价格判断 | 收益率判断 | 操作 |
|---|---|---|---|
| **位于 SML 线上**（A 点） |**定价合理**|**收益率合理**|**持有** |
| **位于 SML 线下方**（B 点） |**价格被高估**|**收益率被低估**|**卖出** |
| **位于 SML 线上方**（C 点） |**价格被低估**|**收益率被高估**|**买入** |

> **注意方向对应**：**价格高估 ↔ 收益率低估（在 SML 下方）**；**价格低估 ↔ 收益率高估（在 SML 上方）**。

**阿尔法（α）** P297：

> **在现实中，CAPM 的假设条件未必能得到满足**——**不是所有的投资者都会完全按照分散化的理念去投资，不同投资者对于各资产的预期收益率及风险的判断也不会完全一致**；**这将导致现实中各资产的预期收益率未必与 CAPM 的预测结果一致**；**CAPM 解释不了的收益部分习惯上用希腊字母阿尔法（α）来描述，有时称为"超额"收益**。

#### 案例 9-3：用 SML 比较两只股票 P298

**设定**：**市场期望收益率为 12%，无风险收益率为 6%**。

**A 股票（β = 1.2，投资者预计收益率 15%）**：

- **A 股票的期望收益率 = 6% + 1.2 × (12% − 6%) = 13.2%**；
- **预期投资该股票可获得超额收益 = 15% − 13.2% = 1.8%**；
- **因此，依据 CAPM，他可能作出买入的决策**。

**B 股票（β = 1.5，投资者预计收益率 16%）**：

- **B 股票的超额收益 = 16% − [6% + 1.5 × (12% − 6%)] = 16% − 15% = 1% < 1.8%**；
- **因此投资者仍会选择投资 A**。

**启示**：**超额收益要用"预计收益率 − CAPM 应得收益率"比较，而不是直接比较预计收益率（B 的 16% > A 的 15%，但 B 的 β 更高，风险调整后 A 更优）**。

**CAPM 作为业绩评价基准** P298：

> **CAPM 为投资业绩评价提供了一个基准**；**不同的资产组合由于风险不同，其收益率并不能直接比较，而 α 值则反映了市场风险调整后的超额收益**。

#### （六）CAPM 公式速查

| 要素 | 公式/数值 |
|---|---|
| **CAPM**|**E(r_i) = r_f + β_i[E(r_m) − r_f]** |
| **β（回归视角）**|**β_i = Cov(r_i, r_m) / σ_m²** |
| **β（相关系数视角）**|**β_i = ρ_im · σ_i / σ_m** |
| **市场组合 β**|**1** |
| **SML 斜率**|**E(r_m) − r_f（市场风险溢价）** |
| **α**|**实际（预计）收益率 − CAPM 应得收益率** |

### 9.2.c 【了解】套利定价理论的基本原理、假设及与资本资产定价模型的区别，以及多因子模型的基本概念 P298–P303

**大纲原文**：了解套利定价理论的基本原理、假设及与资本资产定价模型的区别，以及多因子模型的基本概念

#### （一）为什么需要 APT P298

> **CAPM 作为一种均衡定价模型在实际中的测量系统风险、证券估价等方面得到广泛运用**；**但是，CAPM 基于一系列严格的假设，并且将所有证券价格变化的可能解释归结为单一的系统性风险因素，因此，其在实际应用中的有效性和普遍性受到了质疑**。

> **1976 年，美国金融经济学家罗斯提出了套利定价理论（Arbitrage Pricing Theory，APT），这一理论建立在比资本资产定价模型更少且更合理的假设之上**；**APT 导出的均衡模型与资本资产定价模型有很多相似之处，但其灵活性和适用性更强**。

#### （二）套利的概念 P299

> **套利（Arbitrage）** 是指**利用一个或多个市场上同时存在的各种价格差异，在理论上不承担风险（或实际操作中承担较小风险）的情况下获取收益的金融交易行为**。

- **操作特征**：**套利行为常常需要同时进行等量证券或等价资产的买卖，以便从其价格的差异中获取利润**；
- **主要形式**：**套利作为一种广泛使用的投资策略，包括多种形式，如跨市场套利、跨期套利、统计套利等**。

#### 案例 9-4：一个可执行的套利组合 P299–P300

**设定**：**在一个有四类不同经济环境的市场中，只有四种股票在进行交易**——**高通胀率/低通胀率 × 高实际利率/低实际利率**，**四种环境的概率均为 0.25**。

**表 9-4 预期收益率（%）**：

| 股票 | 高通胀·高实际利率 | 高通胀·低实际利率 | 低通胀·高实际利率 | 低通胀·低实际利率 |
|---|---|---|---|---|
| **A**|**−20**|**20**|**40**|**60** |
| **B**|**0**|**70**|**30**|**−20** |
| **C**|**90**|**−20**|**−10**|**70** |
| **D**|**15**|**23**|**15**|**36** |

**表 9-5 收益率统计**：

| 股票 | 收益率（%） | 标准差（%） | 现价 |
|---|---|---|---|
| **A**|**10**|**29.58**|**10 元** |
| **B**|**10**|**33.91**|**10 元** |
| **C**|**10**|**48.15**|**10 元** |
| **D**|**22.25**|**8.58**|**10 元** |

**关键发现**：

> **构造一个由等权重的 A、B、C 三种股票组成的资产组合，将其可能的未来回报率与第四种股票 D 作对比，可以看到这个等权重组合在所有经济环境下的表现都优于股票 D**。

**表 9-6 资产组合与股票 D 的收益率**：

| 项目 | 收益率（%） | 标准差（%） | 相关系数 |
|---|---|---|---|
| **A、B、C 三种股票等权重组合**|**25.83**|**6.40**|**0.94** |
| **D 股票**|**22.25**|**8.58** | |

**套利操作步骤**：

> **投资者可以通过卖空 3 份 D 股票获得现金 30 元，同时承担未来回购 3 份 D 股票并归还的义务**（**此处忽略交易成本和费用**）；**然后，用这 30 元现金分别购买 1 份 A、1 份 B 和 1 份 C 股票（每份 10 元，合计 30 元）**。

**套利收益的来源**：

| 项目 | 数值 |
|---|---|
| **组合收益率**|**25.83%** |
| **卖空 D 的成本（D 预期涨幅）**|**22.25%** |
| **净收益差**|**3.58%** |

> **该策略在期初无需初始净投资**；**由于 A、B、C 三种股票等权重组合与 D 股票的相关系数高达 0.94，可以在很大程度上对冲系统性风险，仅承担较小的特质风险，实现套利收益**。

**套利如何消除机会（必背逻辑）**：

> **显然，其他投资者也会使用类似策略，导致 D 股票被频繁卖空，其价格随之下降，未来预期收益率相应提升；而 A、B、C 三种股票被投资者不断买入，价格上升，未来收益率下降**；**这意味着市场投资者迅速发现并利用这样的套利机会，推动股票价格趋于均衡，套利机会也随之消失**。

> **套利行为是维持市场有效性的重要机制**——**当套利机会出现时，投资者会迅速采取行动，导致这些机会很快消失**；**这一过程有助于保持市场的价格一致性和效率**；**然而，在实际市场中，套利机会的利用可能受到诸如交易成本、卖空限制、流动性问题等因素的制约**。

#### （三）APT 的基本原理 P300–P301

> **套利定价理论的核心思想是：在一个有效的市场上，具有相同属性（如风险、流动性等）的资产之间不存在无风险套利机会**。

> **如果投资者能够构建出一个初始净投资为零、不承担显著风险且能获得正收益的证券组合，那么所有投资者都会竞相投资这一组合，最终导致该组合的价格调整，直至其收益降为零**；**当市场达到这种均衡状态时，套利机会消失**。

**关键辨析：套利机会更多存在于"类似"证券之间**：

> **虽然单个证券在不同市场上的价格差异可能会产生明显的套利机会，但更常见的情况是，套利机会存在于"类似"的证券或投资组合之间**。

> **具有相同风险因素敞口（Factor Exposure）的证券或投资组合，在剔除特质风险（Idiosyncratic Risk）的影响后，理论上应该呈现相同的价格表现**；因此，**这些具有相同风险特征的证券或组合应当要求相同的预期收益率**。

> **如果出现预期收益率的不一致，套利机会就会产生**——**投资者会利用这些机会获利，最终导致价格趋同**；**这一过程体现了套利定价理论的核心原则——"一价定律"（Law of One Price）**。

**一价定律的表述**：

> **在无摩擦的市场中，通过套利行为，具有相同风险和收益特征的证券或投资组合的价格最终会趋于一致**。

> **这种定价机制确保了金融市场的效率，减少了错误定价的持续存在，并促进了资产价格的合理化**；**然而，在现实市场中，由于交易成本、信息不对称和其他市场摩擦的存在，完美的套利可能难以实现，这也为主动投资管理提供了潜在的机会**。

#### （四）APT 的四个关键假设 P301

| # | 假设 | 内涵与地位 |
|---|---|---|
| **1**|**资产收益的因子模型**|**证券的收益率被假定为由若干共同的、通常未明确指明具体内容的系统性因素线性驱动**，即**证券的收益率受这些潜在风险因素的线性影响**；**这是 APT 理论的结构性支柱** |
| **2**|**无套利原则**|**市场中不存在无风险的套利机会**——**投资者不可能在不承担额外风险或无需净投资的情况下获得超额收益**；**如果此类机会短暂出现，理性投资者的套利行为会迅速消除这些机会，使价格回归均衡状态**；**这是 APT 定价关系形成的核心驱动机制** |
| **3**|**非系统性风险可分散**|**投资者可以通过构建充分分散化的投资组合来消除特定于单个资产的非系统性风险（或称特质风险）**；因此，**在均衡状态下，只有不可分散的系统性风险因素才会被市场定价并获得相应的风险溢价作为补偿** |
| **4**|**竞争且交易成本有限的市场环境**|**APT 理论假设市场是高度竞争的，存在大量理性投资者**，**并且交易成本和限制（如卖空限制）极低乃至不存在**，**从而保证套利活动能够无障碍有效地进行** |

#### （五）APT 的数学表达 P301

$$\boxed{E(r_{i})=\lambda_{0}+b_{i1}\lambda_{1}+b_{i2}\lambda_{2}+\cdots+b_{ik}\lambda_{k}}$$

**符号**：**E(r_i)** 是**证券 i 的期望收益率**；**λ_0**是**与证券 i 和所有 k 个影响因素无关的常数**，**一般代表无风险收益率或市场定价中与风险因子无关的基准收益率**；**b_ik**是**证券 i 对第 k 个影响因素的敏感度系数**；**λ_k**是**第 k 个因素的单位风险溢价，代表投资者因承担该单位风险因素而期望获得的额外回报**。

#### （六）APT 与 CAPM 的三点区别（核心考点） P301–P302

| # | 区别 | CAPM | APT |
|---|---|---|---|
| **1**|**风险解释的差异**|**证券的风险用该证券相对于市场组合的 β 系数来衡量**，**而市场组合是世界上所有风险资产按其市值加权的组合**；**CAPM 只能告诉投资者风险的大小，而无法明确风险的来源**|**证券的风险由多个因素共同解释，如通货膨胀、工业生产、风险溢价、公司规模等**；**不仅告诉投资者证券风险的大小，还能揭示风险的来源** |
| **2**|**假设的不同**|**假定所有投资者都是风险回避者**|**并未对投资者的风险偏好作出特定假设，因此 APT 具有更广泛的适用性** |
| **3**|**投资策略的灵活性**| — |**投资者可以构建多个因素组合，并根据自己的风险偏好选择性地承担或回避某些风险**；**这为投资者提供了更灵活的资产配置策略** |

#### （七）多因子模型 P302–P303

**APT 的遗留问题**：

> **APT 的贡献在于从理论上证明了多个定价因子可能决定证券的收益率**；**然而，APT 并未明确这些定价因子具体是什么，这限制了其在现实中的应用**；**20 世纪 80 年代，围绕套利定价理论的有效性及定价因子的选择展开了大量实证研究**。

##### ① Fama-French 三因子模型（1993） P302

> **1993 年，Fama 和 French 通过实证研究，提出股票收益的风险溢价可以更有效地用市场风险、市值风险及账面市值比风险三个因素来解释，构建出著名的 Fama-French 三因子模型**。

> **他们认为，股票的风险溢价可以由市场风险、市值风险、账面市值比风险来共同解释，把个股的风险溢价分解成市值因素、账面市值比因素和其他未被解释的因素**。

$$R_{it}-R_{Ft}=a_{i}+b_{i}(R_{Mt}-R_{Ft})+s_{i}\text{SMB}_{t}+h_{i}\text{HML}_{t}+e_{it}$$

**符号**：**R_it**——**证券或组合 i 在 t 期的收益率**；**R_Ft**——**同期无风险收益率**；**R_Mt**——**同期以市值加权构造的市场组合收益率**；**SMB_t**——**充分分散化的小市值股票组合收益减去充分分散化的大市值股票组合收益率**；**HML_t**——**高账面市值比股票构成的分散化组合和低账面市值比股票构成的分散化组合收益率差额**；**e_it**——**回归残差**。

**检验标准**：

> **如果三因子模型中的三个因子可以完全解释各种风险带来的收益，那么任何一个股票以及任何一个投资组合的 α 应为 0**。

**实证结果**：

> **在过去 20 年里，很多学者（如 Novy-Marx，2012；Titman、Wei and Xie，2004）对三因子模型进行实证分析，发现有些股票的 α 显著不为 0，这说明三因子模型并不能解释所有风险溢价**。

##### ② Fama-French 五因子模型（2013） P302

> **2013 年 Fama 和 French 发现在上述风险之外，还有盈利水平风险、投资水平风险也能带来个股的超额收益，加入这两个因子后能更好地解释个股的风险溢价，由此提出了五因子模型**。

$$R_{it}-R_{Ft}=a_{i}+b_{i}(R_{Mt}-R_{Ft})+s_{i}\text{SMB}_{t}+h_{i}\text{HML}_{t}+r_{i}\text{RMW}_{t}+c_{i}\text{CMA}_{t}+e_{it}$$

**两个新增因子**：**RMW_t**——**分散化了的高/低盈利股票投资组合的回报之差**；**CMA_t**——**低/高再投资比例公司股票投资组合的回报之差**；**这两项分别描述了盈利水平风险、投资水平风险**。

- **估计方法**：**与三因子模型类似，参数估计的方法仍然是用多元线性回归的方法**；**这里的 α 则是五因子模型里尚未解释的风险溢价**。

##### ③ 对 Fama-French 模型的批评与认可 P302–P303

**批评**：

> **由于 Fama-French 模型缺乏严谨的经济学假设，三因子模型提出后就受到了很多学者的批评**——例如，**Fischer Black（1993）批评 Fama-French 模型存在数据挖掘（Data Mining）嫌疑，即通过反复尝试大量可能的因子组合，从而偶然发现能够解释历史数据的因子组合，缺乏理论基础**。

**认可**：

> **但是，也有很多研究指出三因子模型和五因子模型在不同国家长期适用，能够解释 90% 的资产个体收益差距**。

##### ④ 因子大爆炸 P303

> **随着实证研究的发展，学术界和量化投资机构已经发掘了超过 300 个定价因子**；**相比 CAPM 和 APT，多因子模型在实际应用中更受业界推崇**。

#### （八）CAPM / APT / 多因子模型三者对照

| 维度 | **CAPM**|**APT**|**多因子模型（Fama-French）** |
|---|---|---|---|
| **因子数**|**单因子（市场组合）**|**多因子（未指明具体是什么）**|**明确的三因子/五因子** |
| **风险度量**|**β**|**敏感性系数 b_ik**|**b、s、h、r、c** |
| **风险来源**|**不明**|**揭示来源但不具体**|**明确：市场、市值、账面市值比（+盈利、投资）** |
| **投资者偏好假设**|**假设风险回避**|**不作假设**|**不作严格经济学假设** |
| **理论 vs 实证**|**均衡模型**|**理论推导**|**实证回归（有数据挖掘争议）** |
| **解释力**| 有限 | — |**能解释 90% 的个股收益差距** |

## 9.3 市场有效性与行为金融

### 9.3.a 【理解】市场有效性的定义，三种市场分类和特征，以及市场竞争与套利行为的作用 P303–P305

**大纲原文**：理解市场有效性的定义，三种市场分类和特征，以及市场竞争与套利行为的作用

#### （一）市场有效性的定义与信息三分类 P303

> **在信息有效的市场中，投资工具的价格应当能够反映所有可获得的信息，包括历史价格信息、基本面信息及风险信息等**；**如果市场有效，证券价格已经反映了所有信息；如果市场无效，证券价格相对于公司的真实价值可能被高估或者低估，投资管理人若能发现定价的偏离，就有可能从中获得超额收益**。

> **20 世纪 70 年代，美国芝加哥大学的教授尤金·法马（Eugene F. Fama）提出了有效市场假说（Efficient Market Hypothesis，EMH），系统性地阐述了市场有效性的标准，并将信息分为历史信息、当前公开可得信息和内部信息三类**。

| 信息类型 | 界定 |
|---|---|
| **历史信息**|**主要包括证券交易的有关历史资料，如历史股价、成交量等** |
| **当前公开可得信息**|**即一切可公开获得的有关公司财务及其发展前景等方面的信息** |
| **内部信息**|**则为还未公开的只有公司内部人员才能获得的私人信息** |

> **在此基础上，法马界定了三种形式的有效市场：弱有效、半强有效与强有效**。

#### （二）三种有效市场的特征（核心考点） P304

##### ① 弱有效证券市场

> **弱有效市场**，是指**证券价格能够充分反映所有历史价格与成交量信息**，即**价格历史序列所包含的全部信息都已经被消化吸收至当前证券价格中**。

> 因此，**在一个弱有效的证券市场上，投资者无法仅凭借对历史价格、成交量等交易数据进行技术分析来预测证券未来的价格走势并持续获得超额收益**；**如果市场达到弱有效状态，纯粹依靠历史价格走势进行预测的技术分析将不再有效**。

**弱有效 ⇒ 技术分析无效**。

##### ② 半强有效证券市场

> **半强有效证券市场**，是指**证券价格不仅充分反映了历史价格信息，而且能迅速、充分地反映当前所有与公司证券相关的公开信息**，如**盈利预测、红利发放、股票分拆、公司并购等各种公告信息**。

> **如果市场达到半强有效状态，则意味着任何投资者都无法仅凭分析当前公开信息而持续获得超额利润**；换言之，**市场参与者不可能通过基本面分析（例如财务报表分析、估值分析等）等公开信息分析方法，持续地获得超过市场平均水平的投资收益**。

**半强有效 ⇒ 基本面分析无效**。

**一个重要的细节**：

> **需要注意的是，半强有效市场并不意味着证券价格对新信息的反应一定是瞬间完成的**——**信息被市场完全吸收和反映在价格上，可能需要一个短暂的调整过程**；**在信息发布后的短暂时段内，证券价格可能围绕新的均衡价格出现一定程度的波动，但整体而言，这种调整应迅速而充分**；**如果新信息发布后市场价格在较长时间内显著偏离新的均衡价格，则意味着投资者仍可能通过分析这些公开信息获取超额收益，说明市场尚未达到半强有效状态**。

##### ③ 强有效证券市场

> **强有效证券市场是一种理论上的理想状态**，指**证券价格能够充分、及时地反映所有信息，包括公开发布的信息和未公开发布的内部信息**。

> 换句话说，**由于强有效市场价格反映了所有信息，它自然也囊括了弱有效市场（价格反映历史信息）和半强有效市场（价格反映所有公开信息）的特征，并进一步包含了那些通常只有"内部人"才能掌握的私有信息**。

> **在证券市场上，总有一些人拥有一定的信息优势，如上市公司管理层掌握着尚未公开发布的公司信息**；**强有效市场则意味着即便是那些拥有"内部信息"的市场参与者也不能凭借该信息获得超额收益，因为市场价格已经完全体现了所有相关的私有信息**。

> **这意味着，在严格意义上的强有效的证券市场中，任何投资者都无法通过任何形式的信息优势，长期地、持续地获得超额收益，他们能够获得的超额收益只能归因于纯粹的运气因素**。

**强有效 ⇒ 连内幕信息也无效**。

##### 三种市场层次关系速查

| 市场类型 | 价格反映的信息 | 无效的分析方法 | 现实性 |
|---|---|---|---|
| **弱有效**|**历史价格与成交量**|**技术分析**|**较接近现实** |
| **半强有效**|**历史信息 + 所有公开信息**|**技术分析 + 基本面分析**|**中间** |
| **强有效**|**历史信息 + 公开信息 + 内部信息**|**一切信息优势**|**理论上的理想状态** |

**层次是包含关系**：**强有效 ⊃ 半强有效 ⊃ 弱有效**。

#### （三）竞争是市场效率的根源 P304–P305

> **市场有效性理论之所以成立，主要依赖两条假设**：

| # | 假设 |
|---|---|
| **1**|**投资者总体上是理性的，能够迅速、准确地利用所有可获得的信息** |
| **2**|**即使市场上存在非理性投资者，他们的交易行为也是随机且无系统性偏差的，并且市场中存在足够数量的理性套利者，能够迅速发现并纠正非理性行为所引起的价格偏离** |

**根本原因：市场竞争**：

> **归根结底，证券价格之所以能趋向于反映所有相关信息，其根本原因是市场竞争**；**投资者花费时间和金钱去收集、分析各类信息，其目的是提高期望收益，否则这种投入便得不偿失**；**由于市场上存在着大量的投资者，这些投资者都在努力寻求一切可能的获利机会，他们会将所掌握的信息运用于投资决策，这些决策行为共同推动信息反映到证券价格中**。

**套利机制的作用路径**：

> **在市场竞争的均衡状态下，证券价格趋向于充分体现那些能够影响投资者决策并已被他们运用的信息**；**一旦证券价格出现显著偏离基本价值的情况，就会产生套利获利机会，从而迅速吸引套利者介入**；**这些套利者的行动又会在极短时间内纠正价格偏差，使市场重新恢复到均衡状态**。

> **正是这种持续不断的信息竞争与套利机制，使得市场价格趋向于有效，最终促使证券价格能够持续地反映所有可获得的信息**。

### 9.3.b 【了解】行为金融学的基本概念、研究方法及其与有效市场假说的差异 P305–P312

**大纲原文**：了解行为金融学的基本概念、研究方法及其与有效市场假说的差异

#### （一）有效市场"异象" P305

> **在研究有效市场假说的过程中，学者们发现了一些与其相悖的现象，这些现象长时间存在或反复出现，无法用有效市场假说进行解释，被称为有效市场"异象"**。

**五类典型异象**：

| 异象 |
|---|
| **"1 月份效应"** |
| **"周历效应"** |
| **"规模效应"** |
| **"价值效应"** |
| **"盈利公告后的价格漂移现象"** |

**两种解释立场**：

> 对于**产生异象的成因**，存在有两种主要观点：**一种观点认为这些现象可以用风险溢价解释，从而依然支持有效市场假说**；**另一种观点则认为这些异象是市场无效性的表现，因此引入行为金融理论来进行解释**。

#### （二）行为金融的基本概念 P305

> **行为金融（Behavioral Finance）是一门研究投资者和市场参与者的心理和情感因素如何影响其金融决策和市场行为的学科**。

> 该学科**结合心理学和金融学，强调非理性因素在金融市场中的作用，挑战了传统金融理论中的理性假设，为理解金融市场提供了新的视角**。

> **行为金融学不仅关注个体决策的心理过程，更致力于揭示这些个体行为偏差如何汇聚并系统性地影响市场价格和整体市场特征，这些市场特征往往是传统金融理论难以解释的**。

> 行为金融**关注两个层次**：**个体决策的心理过程 + 个体偏差如何汇聚成系统性的市场价格特征**。

#### （三）发展历程的三个里程碑 P305–P306

> **行为金融的历史发展可以追溯到 20 世纪 70 年代，当时心理学家和经济学家开始研究市场参与者的行为和决策过程**。

| 时间 | 人物 | 贡献 |
|---|---|---|
| **1979 年**|**丹尼尔·卡尼曼（Daniel Kahneman）和阿莫斯·特沃斯基（Amos Tversky）**|**发表论文《Prospect Theory: An Analysis of Decision under Risk》，被广泛认为是行为金融学的奠基性工作之一**；该文**提出了前景理论，对传统的期望效用理论提出了挑战，为理解人们在风险和不确定性下的决策行为提供了新的框架** |
| **1984 年**|**罗伯特·席勒**|**发表代表性论文《Stock Prices and Social Dynamics》，探讨了股票价格波动与社会心理因素之间的关系**；他**提出市场价格不仅由基本面因素决定，还受到投资者情绪、社会动态等非理性因素的影响**；这篇论文**挑战了传统的有效市场假说，强调了市场中的非理性行为和心理因素在价格形成中的作用** |

#### （四）研究方法（五种） P306

> **行为金融通过结合心理学、行为理论和金融分析的研究方法，探索人类心理、情绪及行为对金融决策、金融产品价格和市场趋势的影响**，**尤其注重理解和解释情绪与非理性行为如何影响投资者的决策结果**。

| # | 方法 |
|---|---|
| **1**|**控制实验观察个体决策行为** |
| **2**|**收集大规模样本的行为和态度数据** |
| **3**|**利用脑成像技术的神经科学方法研究决策中的神经活动** |
| **4**|**通过计算机模拟构建基于行为假设的市场模型** |
| **5**|**大数据分析**——**随着技术的发展，新的数据来源，如大数据分析，也日益成为行为金融研究的重要工具，为洞察投资者行为提供了前所未有的深度和广度** |

#### （五）与有效市场假说的三大差异（核心考点） P306–P307

| # | 差异维度 | **有效市场假说（EMH）**|**行为金融** |
|---|---|---|---|
| **1**|**理性假设**|**认为投资者是理性的，能理性评估证券价格**|**认为投资者常常是非理性的** |
| **2**|**非理性行为的影响**|**认为即使部分投资者是非理性的，但由于他们的交易是随机的，所以能抵消彼此对价格的影响**|**认为投资者个体层面的非理性行为在群体中表现出系统性时，便可能导致市场层面的可预测模式，即所谓的"市场异象"** |
| **3**|**套利的有效性**|**认为即使存在非理性行为，市场中的套利者会纠正价格偏差，使价格回归理性**|**认为套利受到多种因素限制，常常无法完全纠正价格偏差** |

#### （六）认知偏差与情感偏差（两大类） P306

> **基于前景理论及其他行为心理学研究成果，行为金融学识别并归纳了多种在投资决策过程中常见的系统性判断偏差和行为倾向**；**这些个人行为偏差通常可以划分为认知偏差与情感偏差两大类别**。

| 类别 | 来源 | 典型表现 | 能否纠正 |
|---|---|---|---|
| **认知偏差**|**主要源于个体在信息处理过程中的逻辑缺陷、错误的统计推断，或对"启发式思维"（即个体在复杂不确定环境下为简化决策、节省认知资源而依赖的经验法则或心理捷径）的不当运用**|**代表性偏差**（**过度依赖刻板印象**）、**可得性偏差**（**更容易回忆起近期或鲜明事件**）、**锚定与调整效应**（**初始信息对后续判断造成过度影响**）；其他常见的有**保守型偏差、确认型偏差、控制错觉、后见之明偏差、心理账户以及框架依赖**等 |**从理论上讲，认知偏差通常可以通过加强相关知识教育、提供及时准确的反馈或进行针对性的决策训练来识别和纠正** |
| **情感偏差**|**根植于个体的情绪、感受或非理性冲动，而非纯粹的逻辑分析**|**损失厌恶**（**对损失的厌恶程度远超等量收益带来的喜悦感**）、**过度自信**（**对自身能力或判断过度高估**）、**自控力不足**（**缺乏延迟满足与规划能力**）、**惰性偏差**（**倾向于维持现状**）、**禀赋效应**（**对已拥有物品赋予过高价值**）、**后悔厌恶**（**为了避免未来可能的后悔情绪而做出非理性决策**） |**即便被投资者意识到，也往往难以仅通过认知层面的训练完全消除** |

> **认知偏差与情感偏差并非总是独立出现，它们常常相互交织、彼此强化，共同导致投资者在复杂和不确定性环境中的判断与决策偏离理性基准，从而可能对投资绩效产生不利影响**。

#### （七）前景理论（Prospect Theory） P307–P308

> **前景理论作为行为金融学的核心基石之一，深刻揭示了人们在面对潜在收益与损失时，真实的决策模式与传统期望效用理论的理性假设存在显著差异**。

##### ① 价值函数：S 形曲线与三大特征 P307

> **该理论的核心组成部分之一是价值函数**；它指出**人们评估决策结果时，并非依据其最终财富的绝对水平，而是关注相对于一个主观设定的"参考点"（如初始投资额）所产生的收益或损失**；**该价值函数呈现出独特的"S"形曲线**。

| # | 特征 | 内涵 |
|---|---|---|
| **1**|**参考点依赖**|**决策者关注的是相对于主观参考点的变化量（收益或损失），而非最终状态的绝对财富值** |
| **2**|**损失厌恶**|**相同数量的损失给人们带来的心理痛苦远大于等量收益所带来的心理愉悦**；**大量实验研究表明，损失带来的负面感受强度通常是等量收益正面感受的 2~2.5 倍**，**具体数值可能因个体特征（如风险偏好、财富水平）、文化背景以及具体决策情境而存在一定差异** |
| **3**|**边际敏感性递减**|**人们对收益或损失的边际变化量的敏感程度随变化量绝对值增加而降低**——具体而言，**价值函数在收益区域为凹函数，体现为风险厌恶**（**例如，从获得 100 元到获得 200 元所带来的额外喜悦，小于从 0 元到获得 100 元所带来的额外喜悦**）；**而在损失区域为凸函数，体现为风险寻求**（**例如，从损失 900 元到损失 1 000 元所带来的额外痛苦，小于从 0 元到损失 100 元所带来的额外痛苦**） |

##### 案例 9-5：抛硬币游戏（为什么人们拒绝公平赌局） P307

> **假设有一个抛硬币的游戏，规则是：硬币正面朝上时，玩家可获得 100 元；反面朝上时，玩家需支付 100 元作为游戏成本**；**在这样的规则下，玩家是否应参与这个游戏？**

| 视角 | 结论 |
|---|---|
| **经典金融学（风险中性）**|**由于正反面出现的概率均为 50%，该游戏的期望收益为 0 元，因此参与与否的期望效用是相同的** |
| **风险厌恶型理性投资者**|**其凹性效用函数决定了损失 100 元的负效用通常大于获得 100 元的正效用，导致参与该游戏的期望效用为负，因此即使期望收益为 0，他们也更倾向于不参与游戏** |
| **前景理论**|**通过"损失厌恶"这一概念，更为直接和有力地解释了为何即使在期望收益为零的情况下，多数人也会拒绝此类赌局** |

##### ② 决策权重函数 P307–P308

> **前景理论的另一重要组成部分是决策权重函数**；它**描述了人们对客观概率的主观感知和加权方式并非线性对应**。

| 概率区间 | 主观权重倾向 |
|---|---|
| **极低概率**|**过高估计**（**例如购买彩票中奖**） |
| **中等或较高但非确定的概率（如 60%、70% 或 90%）**|**倾向于低估** |

**确定性效应**：

> 此外，**卡尼曼与特沃斯基（Kahneman & Tversky，1979）首次提出并命名了"确定性效应"，即人们对确定性结果（概率 100%）所赋予的主观权重远超过略低于 100% 的事件**，**这体现为人们对"确定无疑"的结果存在额外的心理偏好**。

##### ③ 前景理论的总结（必背） P308

> **总结来说，前景理论通过价值函数和决策权重函数，揭示了个体在不确定条件下决策时并非总是追求期望效用最大化，而表现出对参考点的依赖、对损失的强烈厌恶以及对概率的主观扭曲**；**这些发现为理解后续将要讨论的多种投资者行为偏差提供了微观心理基础**。

#### （八）过度自信（最典型的认知偏差） P308–P309

> **过度自信是一种常见的认知偏差，是指投资者在进行金融决策时，过高地估计自身判断能力的准确性、信息优势以及成功概率**。

**三个来源**：

| # | 来源 |
|---|---|
| **1**|**"优于平均效应"**——**投资者对自我能力、知识水平和信息判断准确性的高估** |
| **2**|**控制错觉**——**投资活动本身也可能强化投资者的控制错觉，即认为自己能够在一定程度上控制随机事件的结果** |
| **3**|**情感因素交织**——**过度自信有时也与情感因素（如强烈的成功欲望或自我膨胀感）交织** |

- **概念辨析**：**虽然概率扭曲（例如前景理论中提到的高估小概率事件）也可能影响投资决策，但它与过度自信是不同类型的行为偏差，尽管两者有时会相互作用**。

**过度自信的后果**：

> **过度自信的投资者往往高估自己对信息的判断力，倾向于进行频繁的交易**；**然而，只有极少数真正具有信息优势或分析能力的投资者，才可能伴随高换手率而取得超额收益；对绝大多数投资者而言，频繁交易通常并不能带来更高的收益，反而可能因交易成本的累积而降低实际投资回报**。

**Barber & Odean（2000）的经典研究**：

> **2000 年，芝加哥大学学者巴伯（Brad Barber）和奥丁（Terrance Odean）利用美国某券商 3.5 万户个人投资者的交易数据，系统研究了换手率与实际投资收益之间的关系**。

| 分组 | 年平均周转率 |
|---|---|
| **换手率最低的 20%（第一组）**|**仅 2.4%** |
| **换手率最高的 20%（第五组）**|**超过 250%** |

> **研究发现，若不考虑交易费用，这五组投资者的年度收益率均在 18.7% 左右，表现差异并不……**（**即：交易频率并未带来更高收益，考虑交易成本后高频组反而更差**）。

## 9.4 被动投资

### 9.4.a 【理解】被动投资和主动投资的概念和区别，以及指数跟踪的核心目标和复制方法 P312–P317

**大纲原文**：理解被动投资和主动投资的概念和区别，以及指数跟踪的核心目标和复制方法

#### （一）被动投资的概念与理论基础 P312

> **有效市场假说的观点，是被动投资策略主要的理论基石，同时也构成了主动投资策略需要挑战和超越的理论背景**。

**被动投资的核心理念**：

> **被动投资策略的核心理念在于：市场定价相对有效，即资产价格已充分反映所有可用信息，从而使得持续系统性地跑赢市场极为困难**。

**两条成本理由**：

> **秉持此种观点的投资者认为，主动寻求超越市场的行为往往伴随着不必要的交易成本（如频繁买卖产生的佣金、税费、冲击成本）和较高的管理费用**。

**被动投资的做法与目标**：

> 因此，**他们选择构建一个能够紧密复制特定市场基准（通常是某个市场指数，如沪深 300 指数、标普 500 指数）的收益和风险特征的投资组合**；**其目标并非超越市场，而是获取与市场整体表现基本一致的回报**。

> **在市场定价被认为是有效的前提下，被动投资策略因其能够最大限度地降低上述成本，常被视为一种理性且高效的投资选择**；**被动投资理念最广泛和直接的应用便是指数基金，包括传统的开放式指数基金和在交易所交易的开放式指数基金（ETF）**。

#### （二）主动投资的概念 P312

> **与被动投资相对，主动投资策略则体现了另一种市场观点和投资哲学**；**主动型投资者相信市场并非完全有效，或者至少在某些领域、某些时刻存在定价偏差和非有效性，从而提供了获利机会**。

**三种分析方法**：

| # | 方法 | 内容 |
|---|---|---|
| **1**|**深入的基本面分析**|**研究公司财务、行业前景、宏观经济** |
| **2**|**敏锐的市场趋势判断**|**把握市场情绪、资金流向、政策导向** |
| **3**|**复杂的量化建模**|**运用数学、统计和计算机技术构建投资模型** |

**目标与手段**：

> 他们**致力于通过这些方法来识别那些被低估或高估的资产类别、行业或具体证券**；**其核心目标是通过精准的资产选择（Picking Stocks/Assets）和有效的市场择时（Market Timing），在承担可接受风险的前提下，获取超越市场基准的超额收益（Alpha）**。

> **主动型投资者的策略选择，在很大程度上取决于其对市场有效性及其程度的判断和信念，以及其获取和解读信息、分析和预测市场的能力**。

#### （三）被动与主动的五大区别（对比表）

| 维度 | **被动投资**|**主动投资** |
|---|---|---|
| **理论基础**|**有效市场假说（市场定价相对有效）**|**认为市场并非完全有效，存在定价偏差** |
| **目标**|**获取与市场整体表现基本一致的回报**|**获取超越市场基准的超额收益（Alpha）** |
| **核心手段**|**复制特定市场基准的收益与风险特征**|**资产选择（Picking）+ 市场择时（Timing）** |
| **成本**|**最低（避免不必要交易成本与高管理费）**|**较高（佣金、税费、冲击成本、管理费）** |
| **典型产品**|**指数基金、ETF**|**主动管理型基金** |

#### （四）中间地带：三种融合策略 P312–P313

> **在投资实践中，被动投资与主动投资并非泾渭分明**；**许多投资策略实际上融合了二者的元素，或者说介于两者之间**。

##### ① 指数增强型基金 P313

> **近年来发展迅速的指数增强型基金，就是在被动跟踪某一指数的基础上，通过有限的、相对主动的调整（如基于基金经理的分析或量化模型对成分股权重进行微调，或在严格控制跟踪误差的前提下配置少量非成分股），力求获取小幅超越基准指数的收益（即"增强"效果）**。

##### ② Smart Beta 策略 P313

> **Smart Beta 策略指的是那些不以传统市值加权方式构建指数或投资组合，而是基于一个或多个"因子"（如价值、成长、规模、动量、低波动、质量等）进行选股和加权，或者采用其他非市值加权方法（如等权重、基本面加权等）来构建指数和相应的投资产品**。

> **Smart Beta 策略虽然通常也是规则化、透明化的，具有被动投资的某些特征，但其目标是获取特定风险溢价或改善传统市值加权指数的风险收益特征，其偏离传统指数的程度可能较指数增强型基金更大**；因此，**Smart Beta 常被视为一种介于纯粹被动和主动投资之间的策略，它试图系统性地捕捉特定的市场回报驱动因素**。

##### ③ 主动基金的部分指数化 P313

> 另外，**一些主动型基金经理也可能将其投资组合中的一部分资金进行指数化配置**，**以此作为控制整体风险、获取市场贝塔收益，或在缺乏明确投资机会时保持市场敞口的手段**。

#### （五）指数跟踪的核心目标 P313

> **指数跟踪，通常也被称为"指数复制"**，其**核心目标是构建一个投资组合，使其收益率尽可能紧密地追踪特定基准指数的收益率**。

**实现方式**：

> **这个过程是通过策略性地投资于指数成分证券来实现的**；**在特定情况下，为了更精确地复制或应对市场限制，也可能审慎地纳入少量与成分证券特性高度相似的非成分证券**。

**方法选择的三个依据**：

> **基金管理人会根据目标指数的特性（如成分股数量、流动性、行业分布等）、基金自身的具体情况（如规模、费率结构、投资人结构等）以及可用的工具，选择最合适的指数复制策略**。

> **当前业界主流的指数复制方法主要包括完全复制法、抽样复制法、优化复制法以及衍生品辅助复制法**；**这些方法在构建投资组合时所选用的证券数量、预期的跟踪误差水平、管理操作的复杂度以及成本效益之间，存在着各自不同的权衡与侧重**。

#### （六）四种复制方法（核心考点）

##### ① 完全复制法 P313–P314

> **完全复制法是指基金管理人购入目标指数的全部成分证券，并严格按照各成分证券在指数中的权重比例来构建和维护投资组合**；**当指数的成分构成或其权重发生任何变动时，基金的投资组合也必须进行相应的、几乎同步的调整**。

**优点**：

> **理论上它能够最精确地复制指数的表现，因此其预期的跟踪误差通常是最小的，同时其运作逻辑相对简单明了，投资组合的透明度也较高**。

**缺点与限制**：

| # | 限制 |
|---|---|
| **1**|**对于成分股数量非常庞大（例如中证全指、中证 2000）或包含大量低流动性证券的指数，实施完全复制的交易成本（包括佣金和冲击成本）可能非常高昂，甚至操作上不切实际** |
| **2**|**在债券指数复制中，流动性问题尤为突出，许多债券品种流动性有限，使得对广泛覆盖的综合类债券指数进行完全复制几乎不可能** |
| **3**|**即使指数成分流动性尚可，小规模基金也可能因最小交易单位限制而难以精确匹配所有成分权重** |

**适用场景**：

> **完全复制法最适用于那些成分股数量相对较少、且成分证券整体流动性充裕的指数，例如跟踪上证 50、沪深 300 等核心大盘蓝筹股指数的 ETF**。

##### ② 抽样复制法 P314

> **当完全复制法因成本过高、操作难度过大或流动性不足而难以有效实施时，抽样复制法便成为一种更为现实和经济的选择**。

**核心思想**：

> **其核心思想是从目标指数的全部成分证券中，通过科学的方法选取一部分具有高度代表性的证券来构建投资组合**；**这样做的目的是使得这个由样本证券构成的"迷你版"组合，在关键的风险收益特征上（例如，股票组合的行业分布、市值结构、盈利能力、估值水平，或债券组合的期限结构、信用等级分布、券种构成等）能够与指数的整体水平尽可能相似**。

**优势与关键**：

> **这种方法通过显著减少持有证券的数量，能够有效降低交易成本和管理复杂度，并规避持有低流动性证券的操作难题**；**抽样复制成功的核心在于科学地选取样本，以确保样本组合能充分代表指数的整体特性**。

**分层抽样法（最常用）** P314：

> **在众多的抽样技术中，分层抽样法是最为常用且被广泛认可的一种**。

**操作流程（四步）**：

| 步骤 | 内容 |
|---|---|
| **①**|**将指数的全部成分证券按照一个或多个关键的特征变量（被称为"分层变量"）划分为若干个互不重叠的"层"** |
| **②**|**基金管理人会根据每一个"层"在原始指数中所占的权重和该层内部的特性，从该层中审慎地选取一个或多个具有代表性的证券** |
| **③**|**最终将从所有层中选出的样本证券集合起来，构成复制指数的投资组合** |
| **④**|**力求确保样本组合在各层（行业/市值层/风格层）的权重分布与指数高度一致** |

**分层变量的选择**：

| 指数类型 | 分层变量 |
|---|---|
| **股票指数**（如复制中证 500） |**所属行业、市值规模（如大盘、中盘、小盘）及风格因子（如价值、成长）** |
| **债券指数**（如复制中证企业债指数） |**信用等级、剩余期限/久期以及发行人行业**——**目标是确保样本组合在这些关键维度上的风险暴露与指数一致** |

**市值优先抽样法（另一种思路）** P314：

> **其核心逻辑是主要投资于指数中市值最大、权重最高的头部成分股（例如，选择那些合计占到指数总市值 70%~80% 的股票进行配置），而对于指数中剩余的尾部小市值、低流动性股票则选择不予投资或大幅度减少投资比例**。

- **优点**：**这种方法操作简便，能够抓住指数的主要驱动力**；
- **缺点**：**可能忽略指数在某些规模较小的行业或特定风格因子上的细微特征，从而可能导致相对分层抽样而言更大的跟踪误差**。

##### ③ 优化复制法 P314–P316

> **优化复制法通常是借助数量模型和数学优化算法来选择和加权样本证券**，其**目标是在预设的约束条件下，构建一个比完全复制法持有证券数量更少、但可能比传统分层抽样法更为精确地拟合指数动态特性的投资组合**。

**优化目标**：

> **其核心目标通常是最小化预期的跟踪误差，或者在控制跟踪误差在一定范围内的同时，寻求优化其他特定目标，例如最大化某种期望的风险调整后收益**。

**实施流程**：

> **该方法的实施流程从筛选样本池开始**——**样本池可包含目标指数的全部成分证券，或者是一个经过初步筛选（例如剔除流动性极差或存在特殊风险的证券后）的子集**；**为解决流动性或成本问题，基金管理人在极少数情况下可能纳入少量非成分证券，但须严格评估其对组合整体跟踪指数效果的改善作用**。

> **在确定样本池后，基金管理人会利用历史市场数据和基本面信息，并可能结合前瞻性分析，评估样本池中各只证券的过往收益率表现、价格波动特征、基本面属性、风格因子暴露以及它们之间收益变动的相关性**；**基于这些历史数据和分析结果，通过求解一个明确定义的数学最优化问题，来最终确定哪些证券被纳入投资组合以及它们各自应占的精确权重**。

**多目标与约束**：

> **优化的目标具有一定的灵活性**——**除了最基础的最小化跟踪误差外，也可以是多个目标的综合权衡，例如将交易成本、流动性、税务效应乃至 ESG（环境、社会和治理）因素等纳入综合考量**；**在整个优化过程中，还需要遵守一系列约束条件，比如持股数量限制、个股权重上限，以及行业配置不能与目标指数偏离过大等**。

**两个优点**：

| # | 优点 |
|---|---|
| **1**|**相比传统的分层抽样方法，优化模型在理论上可能用更少的证券数量就能达到相似甚至更好的指数跟踪效果，这有助于进一步降低交易成本和管理复杂度** |
| **2**|**通过在优化模型中明确设定对各种风险因子的暴露限制，基金管理人能够更精细地控制投资组合对多种系统性风险因素（如市场 Beta 值、市值因子、估值因子、动量因子、行业因子等）的敞口，使其与目标指数的风险画像更为吻合** |

**三个缺点**：

| # | 缺点 |
|---|---|
| **1**|**高度依赖于所使用的风险模型和历史数据的质量与代表性**——**如果未来的市场结构、证券之间的相关性模式或者驱动市场回报的因子与模型构建时所依据的历史时期发生了显著的变化，那么基于历史数据优化出来的投资组合在未来的实际运作中可能表现不佳，导致实际的跟踪误差超出预期，这一点在风格轮动快、结构变化显著的市场尤需警惕** |
| **2**|**存在"过拟合"风险**——**优化模型可能过度拟合了历史数据的特定噪声和偶然模式，导致其在样本内表现极佳，但在样本外的跟踪效果却出现明显下降** |
| **3**|**优化模型的构建、持续的维护、高质量数据的获取与处理，以及专业量化投研团队的建设本身也需要相当的成本投入** |

**我国实践** P315：

> **在我国股票市场的实际投资中，纯粹的优化复制法作为主要的独立策略并不如完全复制或分层抽样常见，尤其对于流动性良好、成分股数量适中的主流宽基指数而言**；**如果基金规模允许，基金管理人通常更倾向于采用完全复制或精细化分层抽样，以实现较低的跟踪误差和更高的投资透明度**。

> **优化复制技术可以作为分层抽样的有益补充，或用于管理成分股数量众多且流动性差异显著的指数**——例如，**某上证综合指数 ETF 采用最优化抽样复制技术，以更好地跟踪包含大量小市值、低流动性股票的上证综合指数**。

- **增强型用法**：**在实践中，优化模型也可用于构建"增强型"组合，其目标是在控制跟踪误差于预算范围内的基础上，通过调整模型参数或结合管理人的判断，力争获取超额收益**。

##### ④ 衍生品辅助复制 P316

> **除了直接投资于构成指数的现货证券之外，基金管理人在特定情况下，也可能审慎地利用金融衍生工具来辅助指数的复制过程**；**主要的工具包括股指期货（用于股票指数）和国债期货（用于债券指数）**；此外，**指数期权等其他衍生工具也可能在特定、更复杂的策略中被用于辅助复制**。

**两个主要应用**：

| # | 应用 | 说明 |
|---|---|---|
| **1**|**现金头寸管理**|**当指数基金收到大量投资者申购款项或因成分股派发股息而累积现金时，可以通过买入相应市值的股指期货合约，快速获得与指数表现基本一致的市场风险暴露，有效对冲"现金拖累"，后续基金经理可以从容地将现金逐步转换为指数成分股的现货持仓**；**类似地，在基金面临大额赎回压力时，可以先卖出股指期货以迅速降低整个投资组合的市场风险敞口，为后续平稳有序地卖出现货股票赢得时间和空间** |
| **2**|**组合调整期间的过渡管理**|**在指数进行成分股调整或权重定期更新时，利用股指期货来平滑大规模调仓操作对投资组合净值可能造成的短期波动和冲击** |

**严格的仓位下限约束（重要）**：

> **然而，需要特别注意的是，股票型指数基金通常存在严格的股票仓位下限要求**——例如，**许多股票型指数基金的基金合同中会明确规定，其投资于标的指数成分股及备选成分股的资产不低于基金资产净值的某一较高比例（例如 90% 或 95%）**。

> **高比例的现货持仓要求，意味着股指期货在股票指数基金的运作中，主要扮演的是辅助性的、战术性的角色**——**例如用于提高投资组合的运作效率、管理短期流动性或进行头寸微调以更好地拟合指数，而一般不能作为主要的复制工具来大规模替代现货股票的持仓**。

**衍生品引入的额外风险**：

> **基金在运用金融衍生品时，还必须充分认识并有效管理由此引入的额外风险**——**这些风险包括基差风险、合约展期成本或收益，以及潜在的杠杆风险和对手方风险等**；因此，**运用衍生品辅助指数复制，对基金管理人的衍生品交易能力、风险控制体系以及合规管理水平都提出了较高的要求**。

#### （七）复制方法的选择逻辑 P316–P317

> **指数复制方法的选择，实质上是一个在跟踪精度、成本效益、操作可行性以及基金自身特性之间进行审慎权衡和动态优化的过程**。

| 方法 | 首要目标 | 最适合的情形 |
|---|---|---|
| **完全复制法**|**追求最高的跟踪精度**|**成分证券数量相对较少、流动性充裕，且基金管理规模较大的情况**——**但其潜在的交易成本和在某些市场环境下的操作难度可能较高** |
| **抽样复制法（尤其是精细化分层抽样）**|**在跟踪精度与成本控制之间取得良好平衡**|**管理那些成分股数量众多、内部流动性差异较大的股票指数以及绝大多数债券指数时的主流选择**——**其成功的关键在于样本选取的代表性和对指数核心风险特征的准确把握** |
| **优化复制法**|**用更少的证券持仓实现对指数风险收益特征的更优匹配**|**理论上可以更精细地控制多种风险因子的暴露，但其效果高度依赖于模型的设定和历史数据的有效性，需要警惕模型风险和过拟合问题** |
| **衍生品辅助复制**|**提高运作效率、管理短期现金流或平滑组合调整的战术工具**|**其使用受到合规要求的严格限制，并伴随着特定的衍生品相关风险** |

> **无论采用何种方法或组合，基金管理人的核心任务都是持续监控组合与指数的偏离，分析来源，并及时有效地再平衡和优化，力求将跟踪误差控制在目标范围内**。

#### （八）四种复制方法速查表

| 方法 | 持有证券数 | 跟踪精度 | 成本 | 关键风险 |
|---|---|---|---|---|
| **完全复制**|**全部成分股**|**最高（跟踪误差最小）**|**高（尤其成分多、流动性差时）**|**操作不可行、最小交易单位限制** |
| **抽样复制**|**部分代表性证券**|**中高**|**中**|**样本代表性不足** |
| **优化复制**|**较少（模型选定）**|**理论上接近或优于抽样**|**中高（模型与数据成本）**|**过拟合、模型/历史数据失效** |
| **衍生品辅助**|**现货 + 期货**|**辅助性、战术性**|**较低（期货交易成本低）**|**基差风险、展期成本、杠杆与对手方风险** |

### 9.4.b 【掌握】跟踪偏离度和跟踪误差的概念和区别，以及跟踪误差的来源、事前与事后管理 P317–P322

**大纲原文**：掌握跟踪偏离度和跟踪误差的概念和区别，以及跟踪误差的来源、事前与事后管理

#### （一）跟踪误差的定义 P317

> **跟踪误差（Tracking Error，TE）是衡量被动投资组合表现与其业绩比较基准（通常是指数）之间一致性程度的关键指标**；它**定义为投资组合的收益率与其基准收益率之间差异（即跟踪偏离度）在一定观察期内的标准差**。

**被动与主动两类基金的不同理解（必背）**：

| 基金类型 | 跟踪误差的含义 |
|---|---|
| **被动投资**|**反映了投资组合复制或跟踪基准的紧密程度**；**投资者通常期望其尽可能小，因为较小的跟踪误差意味着基金的业绩表现更贴近其声称跟踪的指数** |
| **主动管理型基金**|**其目标是跑赢基准，因此它们必然会构建与基准不同的投资组合，这种主动偏离会导致较高的跟踪误差**；**在这种情况下，跟踪误差反映了基金经理主动承担的、相对于基准的风险水平，是其主动管理程度的一种度量** |

#### （二）跟踪偏离度（TD）的计算 P317

> **计算跟踪误差的第一步是计算每个观察期（如每日、每周、每月）的跟踪偏离度（Tracking Difference，TD）**。

> **跟踪偏离度是投资组合在当期的实际收益率与基准组合在同期收益率之间的简单差额**。

$$\boxed{TD_{t}=r_{p,t}-r_{b,t}}$$

**符号**：**TD_t**——**第 t 期的跟踪偏离度**；**r_p,t**——**投资组合在第 t 期的真实收益率**；**r_b,t**——**基准组合在第 t 期的收益率**。

#### （三）跟踪误差（TE）的计算 P317–P318

> **跟踪误差（TE）则是观察期内所有跟踪偏离度的样本标准差**。

$$TE=\sqrt{\frac{\sum_{t=1}^{n}(TD_{t}-\overline{TD})^{2}}{n-1}}$$

**符号**：**TE**——**跟踪误差**；**n**——**观察期数**（**例如，若使用过去 30 周的数据，则 n = 30**）；**TD̄**——**跟踪偏离度的均值**。

**均值公式**：

$$\overline{TD}=\frac{\sum_{t=1}^{n}TD_{t}}{n}$$

**简化公式（重要）**：

> **在某些情况下，如果可以合理假设长期的平均跟踪偏离度（TD̄）趋近于零（即投资组合长期来看没有系统性的向上或向下偏离基准），则上述跟踪误差的计算公式有时可以简化为**：

$$TE=\sqrt{\frac{\sum_{t=1}^{n}TD_{t}^{2}}{n-1}}\quad(\text{当 }\overline{TD}\approx 0\text{ 时})$$

#### （四）年化处理 P318

> **为了方便比较，通常将基于较短时间间隔（如日度或月度）计算的跟踪误差年化**。

$$TE_{\text{annualized}}=TE_{\text{periodic}}\times\sqrt{r}$$

**r 的取值（必背）**：

| 数据频率 | r 取值 |
|---|---|
| **日度数据**|**一年中的实际交易日数**——**在中国 A 股市场，股票交易日通常在 243 天上下** |
| **周度数据**|**52** |
| **月度数据**|**12** |

**提醒**：**不同国家和地区的交易所每年的实际交易日数量可能会有所不同，进行日度数据年化时应注意采用合适的 r 值**。

#### （五）计算跟踪误差的完整六步 P318

| 步骤 | 动作 |
|---|---|
| **1**|**选择合适的业绩比较基准** |
| **2**|**确定观察期和数据频率（如日度、周度、月度等）** |
| **3**|**收集投资组合和基准在每个观察期的收益率数据** |
| **4**|**计算每个观察期的跟踪偏离度（TD_t）** |
| **5**|**计算所有跟踪偏离度的样本标准差，得到该频率下的跟踪误差** |
| **6**|**将该跟踪误差进行年化处理，得到年化跟踪误差（TE_annualized），以便于比较和评估** |

#### （六）一个惊人的对比（高频考点） P319

> **值得注意的是，一个投资组合其总收益波动率可以很大，但是跟踪误差却很小**。

> **例如，一只跟踪标准普尔 500 指数的指数基金，总收益的波动率可能是 25%，而跟踪误差只有 0.5%**。

**启示**：**总波动率衡量"绝对风险"，跟踪误差衡量"相对基准的偏离"**——**两者完全不同，不可混淆**。

#### （七）跟踪误差与跟踪偏离度的区别与关系（核心考点） P319–P320

##### ① 本质区别

> **跟踪误差和跟踪偏离度是衡量投资组合，尤其是指数基金表现的重要指标，但它们反映的是不同层面的信息**。

| 指标 | 界定 | 性质 |
|---|---|---|
| **跟踪偏离度（TD）**|**指投资组合收益率与基准指数收益率之间的差值**|**可以是某一特定时点的值，也可以是一段时间内的累计值**——**是"点值/累计值"** |
| **跟踪误差（TE）**|**衡量投资组合跟踪其基准指数的稳定性**|**它是跟踪偏离度的标准差，反映了投资组合收益率偏离基准收益率的波动程度**——**是"波动性"** |

##### ② 总体正相关但非绝对 P320

> **一般而言，在实际投资中，跟踪误差和跟踪偏离度总体上呈现正相关关系**；**如果一个投资组合的跟踪偏离度较大，意味着它与基准的收益率差异较大，这种较大的差异通常不会很稳定，因此也会导致跟踪偏离度的波动性增加，从而使得跟踪误差也随之增大**。

**但这种正相关关系并非绝对**：

> **这种正相关关系并非绝对，其强度受到多种因素的影响**——例如，**投资组合偏离基准的方式和频率会影响正相关的强度**：**如果偏离是随机的、不稳定的，那么正相关性会更强；如果偏离是系统性的、稳定的，那么正相关性会减弱**。

- **其他影响因素**：**投资策略、市场环境和基金管理等因素也会影响两者的关系**；**主动管理型基金由于其策略的灵活性，跟踪误差和跟踪偏离度的关系可能更加复杂；而被动型指数基金通常更紧密地跟踪基准，两者正相关性更强**；**在市场波动较大的时期，即使是指数基金也可能出现较大的跟踪偏离度和跟踪误差**；**基金经理的能力、基金的规模、费用结构等也会影响跟踪效果**。

##### ③ 两种"看似矛盾"的情形（必考辨析） P320

| 情形 | 组合特征 | 出现原因 | 例子 |
|---|---|---|---|
| **情形一：高跟踪偏离度，但跟踪误差很低**|**相对基准有稳定且持续的偏离，但这种偏离的波动性很低**|**偏离方向稳定、幅度稳定**|**一只指数基金可能由于费用和现金拖累，每个月都以几乎相同的幅度落后于其跟踪的指数**；或者**某指数增强基金通过稳定均衡的策略，每个月稳定地超越基准** |
| **情形二：低跟踪偏离度均值或累计值，但跟踪误差很高**|**偏离方向在不同时间段内频繁变化，且幅度较大**|**这些偏离在累计上相互抵消** | — |

**记忆**：**TD 看"差多少"（累计方向），TE 看"稳不稳"（波动大小）**——**稳定落后→TD 大、TE 小；忽上忽下→TD 小、TE 大**。

#### （八）跟踪误差的五大来源 P320–P321

> **尽管指数基金的目标是精确复制标的指数，但在实际运作中，基金管理人会面临诸多挑战，这些挑战以及其他一些因素共同构成指数基金跟踪偏离和跟踪误差的来源**。

##### 来源一：成本因素 P320

> **成本因素是导致基金表现偏离指数的直接原因之一**——**指数的计算是理论上的，不涉及任何交易成本**；**然而，指数基金在复制指数的过程中，必然会产生各种费用和成本**。

| 成本类型 | 内容 | 影响特征 |
|---|---|---|
| **运营费用**|**基金日常运作产生的管理费、托管费等运营费用，这些会直接从基金资产中扣除，降低基金的净回报**|**由于这些费用通常每日从基金资产中按比例计提，它们会系统性地降低基金的净回报，从而构成基金表现与指数之间一个基础的、持续的负向跟踪偏离**；**虽然这种稳定的偏离主要影响的是跟踪偏离的平均水平，而非其波动性（即跟踪误差），但它是构成两者回报差异的根本来源之一** |
| **交易成本**|**显性成本**：**交易佣金、印花税（部分市场）、过户费等**；**隐性成本**：**买卖价差和因大额交易可能引发的市场冲击成本**|**这些成本都会侵蚀基金的收益，使其表现偏离指数** |

##### 来源二：指数复制策略的选择与执行 P320–P321

> **其次，指数复制策略的选择与执行本身也可能引入跟踪误差**。

| 具体情形 | 后果 |
|---|---|
| **流动性约束**——**某些指数成分股难以在合理价格或时间内足额交易时**|**基金管理人可能不得不采用抽样复制或优化复制**；**这些策略通过持有指数的部分成分股或调整权重来模拟指数，其本身就可能导致投资组合的结构与指数产生偏离，从而形成结构性跟踪误差** |
| **成分股数量过多、基金规模相对较小时** | 同上 |
| **资金规模与最小交易单位的限制**|**即使采用完全复制策略，资金规模与最小交易单位的限制也可能使得基金无法完全按照指数权重精确配置每一只证券，尤其对于小规模基金而言，这种"零股"问题或最低投资额限制可能导致持仓偏离** |

##### 来源三：现金管理与资金流动 P321

> **再次，基金的现金管理与资金流动也是重要的影响因素**。

> **指数基金通常会因应对投资者申购赎回、支付费用或等待投资机会而持有少量现金头寸**；**这部分未投资的现金在市场上涨时无法获得与指数同步的收益，产生所谓的"现金拖累"，导致基金表现落后于指数**；**反之，在市场下跌时，现金头寸可能起到一定的缓冲作用，但仍构成与指数表现的差异**。

- **额外影响**：**投资者的大规模申购或赎回会迫使基金经理进行买卖操作，这不仅会产生交易成本，还可能在短期内扰动组合的跟踪效果**。

##### 来源四：指数调整的应对和特殊公司事件的处理 P321

> **此外，指数调整的应对和特殊公司事件的处理同样对跟踪误差有显著影响**。

| 情形 | 影响机制 |
|---|---|
| **指数成分股调整或权重更新**|**基金经理需要相应调整投资组合**；**然而，基金可能无法完全在指数调整生效日的精确时点和价格完成所有交易，这种调整的滞后性或交易冲击会造成偏离** |
| **特殊公司事件**——**派发股息、配股、增发、长期停牌、触及涨跌停板等**|**例如，价格指数对股息的处理通常是让股价自然回落，全收益指数则假设其在除息日当天以特定价格（如收盘价）再投资，而基金实际收到股息并进行再投资可能存在时间差、交易成本或不同的再投资价格，这些差异均会导致跟踪误差** |
| **A 股特有制度**|**A 股市场特有的 T+1 交易制度和涨跌停板限制，也可能在特定情况下对基金应对指数调整或大额申赎时的操作效率和成本控制带来挑战，从而影响跟踪误差** |

##### 来源五：其他因素 P321

> **还有一些其他因素可能引致跟踪误差**——例如，**部分指数基金可能会进行证券借贷活动以获取额外收入，这部分收入可能有助于抵消费用、缩小跟踪偏离度，但也可能引入额外的风险**。

**总结**：

> **综上所述，指数基金的跟踪误差来源于多方面，既包括基金运作层面的成本和费用，也包括复制策略选择、市场流动性、资金管理、指数调整以及特殊事件处理等操作层面的挑战**；**被动型基金管理者的核心目标之一，就是在综合考量这些因素的基础上，通过精细化管理，尽可能地将跟踪误差控制在合理且预期的范围之内**。

#### （九）事前跟踪误差与事后跟踪误差 P321–P322

> **从时间维度看，跟踪误差可以区分为事前跟踪误差（Ex-ante Tracking Error）和事后跟踪误差（Ex-post Tracking Error）**。

| 类型 | 界定 |
|---|---|
| **事后跟踪误差（Ex-post TE）**|**通过历史数据计算得出的投资组合在过去实际发生的相对于基准的偏离波动程度** |
| **事前跟踪误差（Ex-ante TE）**|**在投资组合构建或调整之前，基于当前的持仓、市场数据和风险模型，对未来一定时期内投资组合表现可能偏离基准的程度进行的估计** |

##### 事前管理：设定目标 + 评估策略 P322

> **对于被动投资基金而言，虽然其核心目标是最小化实际发生的事后跟踪误差以紧密复制指数，但在基金设立、选择具体复制策略以及日常运作中，基金管理人会对潜在的跟踪误差水平进行事前考量与持续管理**。

> **这种事前考量主要体现在设定一个合理的预期跟踪误差目标，并评估不同复制方法（如完全复制、不同程度的抽样或优化）在特定指数和市场环境下可能产生的预期跟踪误差**。

**教材的决策示例**：

> 例如，**基金管理人在决定是采用完全复制还是抽样复制来跟踪一个成分股众多且部分流动性欠佳的指数时，会评估完全复制可能带来的高交易成本和操作难度，与抽样复制可能带来的结构性偏差进行权衡**；**他们可能会运用历史数据分析和风险模型来估计不同策略下的潜在跟踪误差范围，以确保所选策略能够在成本效益和跟踪精度之间达到可接受的平衡，并符合基金合同中对跟踪误差的规定**；**这种基于模型的对未来跟踪误差的预测，即为事前跟踪误差的运用**。

##### 日常管理：三种手段 P322

> **在日常管理中，基金管理人也会通过多种手段积极管理和控制跟踪误差**：

| # | 手段 | 目标 |
|---|---|---|
| **1**|**建立高效的交易执行机制**|**降低冲击成本** |
| **2**|**精细的现金管理**|**减少现金拖累** |
| **3**|**及时的组合调整**|**应对指数变动和公司事件** |

> **这些管理措施的目标都是围绕着尽可能缩小实际运作中产生的跟踪误差，使其贴近事前设定的目标**。

##### 事后监控的必要性 P322

> **需要注意的是，任何基于历史数据和模型的事前估计都存在局限性，实际的跟踪误差（事后跟踪误差）会受到未来市场环境和具体操作等多种不可预见因素的影响**；因此，**持续的事后监控、分析跟踪误差的来源，并根据实际情况调整管理策略，对于被动投资管理同样重要**。

#### （十）跟踪偏离度与跟踪误差对比表

| 维度 | **跟踪偏离度（TD）**|**跟踪误差（TE）** |
|---|---|---|
| **定义**|**组合收益率与基准收益率之差**|**跟踪偏离度的标准差** |
| **公式**|**TD_t = r_p,t − r_b,t**|**TE = √[Σ(TD_t − TD̄)²/(n−1)]** |
| **度量什么**|**差多少（点值/累计值）**|**差得稳不稳（波动程度）** |
| **有无符号**|**有正负（可正可负）**|**恒为非负** |
| **典型数值**|**可正可负，通常很小**|**标普 500 指数基金约 0.5%** |
| **年化处理**|**不年化（或累计）**|**× √r（日 243 / 周 52 / 月 12）** |
| **用途**|**判断是否系统性偏离**|**判断跟踪稳定性、考核被动管理能力** |

## 9.5 主动投资

### 9.5.a 【理解】主动投资的收益来源，主动收益和主动风险的概念，以及主动股票投资组合、主动债券投资组合管理的方式 P322–P326

**大纲原文**：理解主动投资的收益来源，主动收益和主动风险的概念，以及主动股票投资组合、主动债券投资组合管理的方式

#### （一）Alpha 的定义 P322

> **与被动投资旨在复制市场基准不同，主动投资的核心目标是通过积极的投资决策，力求获得超越特定业绩比较基准的超额收益，这种超额收益通常被称为"阿尔法"（Alpha）**。

> **在现代投资组合理论中，Alpha 通常指投资组合的实际收益率，在扣除其因承担系统性风险（由 Beta 衡量）而应获得的预期收益之后，所剩余的部分**；简而言之，**Alpha 是衡量投资经理在扣除市场整体波动因素后，通过其主动管理能力所创造的超额回报**。

#### （二）Alpha 的四个来源 P322–P323

| # | 来源 | 内涵 |
|---|---|---|
| **1**|**投资技能**|**投资管理人通过独到的证券选择、有效的市场择时或行业配置，展现出优异的投资技能** |
| **2**|**信息优势**|**投资者能够获取或准确解读那些尚未被市场充分反映的信息** |
| **3**|**利用市场无效性**|**主动投资者还可能通过识别和利用市场无效性，把握由其他投资者行为偏差引发的价格错位，从而实现超额收益** |
| **4**|**风险因子的暴露与择时**|**通过对不同风险因子（如价值、成长或动量等）进行有效的暴露与择时，并把握这些因子的周期表现，也有助于提升 Alpha 水平** |

**名义 Alpha ≠ 真实技能（重要辨析）** P323：

> **然而，需要强调的是，观察到的超额收益（亦称名义 Alpha）并不一定全部源自可持续的投资技能，其中可能包含了运气成分，或因承担传统风险模型未能捕捉到的隐性风险而获得的风险溢价（或风险补偿）**。

#### （三）业绩比较基准与"偏离"的中性含义 P323

> **所有的基金都需要选定一个业绩比较基准，它不仅是考核基金业绩的工具，也是投资经理进行组合构建的出发点和参照系**。

> **在主动管理中，基金经理有意识地对基准组合进行配置上的调整，以追求超额收益**；**这里的"偏离"是中性的专业术语，指的是有意识地与基准指数构成差异化配置，而非"错误"或"背离"，这种偏离必须在基金合同允许的范围内进行**。

**基准选择的两条依据**：

> **主动型基金在选定业绩比较基准时，需要充分考虑其投资目标和风格**——**投资目标决定了基金可投资产的类别（如股票与债券的比例），而投资风格则决定了证券选择的范围**；**在选择业绩比较基准时要尽可能地体现这些特征，否则业绩比较基准就失去了其参考价值**。

#### （四）主动收益与主动风险（核心考点） P323

##### ① 主动收益（Active Return） P323

> **通常将投资组合的实际收益与基准收益之差定义为主动收益（Active Return）**；**该指标反映了基金经理通过主动管理实现的超越或落后于基准的表现，因此主动收益既可能为正，也可能为负**。

$$\boxed{\text{主动收益}=r_{p}-r_{b}}$$

**注意**：**主动收益与 9.4 的"跟踪偏离度"在计算上完全相同**——**只是视角不同（主动 vs 被动）**。

##### ② 主动风险（Active Risk） P323

> **主动风险（Active Risk），实际上就是前述的跟踪误差，两者计算方法一致，均用于衡量主动收益的波动性**。

> **主动风险表明，基金经理在追求主动收益过程中，投资组合的业绩与基准之间可能出现多大程度的偏离**——**较高的主动风险意味着投资组合收益可能大幅超越或落后于基准，主动收益的波动性较大；而较低的主动风险则说明组合收益更紧密地跟随基准，主动收益的波动性较小**。

##### ③ 两者的分工（必背） P323

> **因此，主动收益衡量了"偏离"的结果，而主动风险则衡量了这种"偏离"的幅度和稳定性**。

##### ④ 信息比率（Information Ratio） P323

> **这两者的比值便构成了衡量主动管理能力的关键指标——信息比率（Information Ratio）**。

$$\boxed{IR=\frac{\text{主动收益}}{\text{主动风险}}}$$

> **越高的信息比率表明单位主动风险所能获得的超额收益越多，这通常被视为衡量投资经理在承担主动风险的前提下，获取超额收益能力的有效指标，即主动管理能力的体现**。

#### （五）主动投资业绩的两个决定因素：信息深度与信息广度 P323

> **主动投资的业绩主要取决于投资者使用信息的能力和掌握的投资机会的数量，即信息深度和信息广度**。

| # | 决定因素 | 逻辑 |
|---|---|---|
| **1**|**信息深度（投资技能）**|**在投资机会不变的情况下，投资技能的上升会提高信息比率**——**经验丰富的投资者通常能实现更高的风险调整后收益** |
| **2**|**信息广度（投资机会数量）**|**在同等的投资技能下，掌握更多投资机会的投资经理往往能提高投资组合的信息比率** |

> **因此，较高投资能力的投资经理如果掌握的投资机会较少，其业绩可能与投资能力一般但掌握机会较多的经理相当**。

**权衡关系**：

> **需要注意的是，投资机会的数量和使用这些机会的效率之间可能存在一种权衡关系**——例如，**过度寻求和扩展投资机会有时可能导致单一机会分析深度的不足或整体管理效率的下降**。

#### （六）主动股票投资组合管理 P324–P325

##### ① 股票分类与相关性 P324

> **研究表明，根据公司规模、所在地区、行业、业绩表现、股价表现等特征对股票进行分类，不同类别的股票在收益上存在显著差异**；**通常，同类股票之间具有较高的相关性，而不同类别的股票之间相关性较低**；因此，**投资者在实践中常从区域、行业、规模和风格等角度划分股票市场**——例如，**全球市场可以划分为发达市场、新兴市场和前沿市场**；**上市公司根据市值大小可以分为大盘股、中盘股和小盘股**。

##### ② 三种核心策略思想 P324

| 层次 | 策略 | 内涵 |
|---|---|---|
| **微观**|**证券选择**|**旨在通过识别并投资于价值被低估的证券，或卖出价值被高估的证券，以期获取超额回报** |
| **宏观**|**市场择时**|**试图通过预测市场的整体走向，在不同资产类别之间或同一资产类别内部的不同风格之间进行动态配置**——但**持续准确地预测市场极具挑战性** |
| **中观**|**行业或主题配置**|**介于宏观的市场择时和微观的证券选择之间**——**行业轮动**是根据**对经济周期或特定行业前景的判断，主动调整不同行业的配置权重**（例如**在经济复苏期超配周期性行业**）；**主题投资**则是**围绕具有长期增长潜力的特定投资主题（如人工智能、新能源等）来构建组合** |

##### ③ 三种投资风格 P324

> **投资风格的划分也十分重要，常见的风格包括价值型、成长型和平衡型**，**这些风格通常通过市盈率、市净率、盈利增长等指标来界定**。

| 风格 | 做法 |
|---|---|
| **成长风格**|**挑选预期未来盈利增长较快的股票，期望获得未来业绩实现后带来的价格上涨收益** |
| **价值风格**|**试图寻找相对便宜的股票，期望其估值恢复到合理水平** |
| **GARP（合理价格下的成长）**|**有的基金经理既追求价值风格，又追求成长效应，这种策略被称为"合理价格下的成长策略"（Growth At Reasonable Price，GARP）**，即**寻找盈利增长高于平均水平且价格合理的股票** |

- **风格切换**：**此外，投资者也可能试图通过风格切换来获取更高的收益**。

##### ④ 两种组合构建方式：自上而下 vs 自下而上（核心考点） P324–P325

**总体对比**：

> **在组合构建方面，常用的策略包括"自上而下"与"自下而上"两种**。

| 维度 | **自上而下（Top-down）**|**自下而上（Bottom-up）** |
|---|---|---|
| **出发点**|**从宏观经济形势及行业、板块特征入手**|**侧重个股表现** |
| **顺序**|**先确定大类资产、国家、行业的配置，然后再挑选相应的股票作为投资标的，实现配置目标**|**强调通过深入分析筛选优质股票，而不依赖于经济或市场的整体趋势** |
| **关注指标**|**消费者信心、商品价格、利率、通货膨胀率和国内生产总值等宏观经济指标**|**公司财务状况、管理团队、行业地位、增长前景、竞争优势、市场份额、公司治理** |
| **分析方法**|**宏观分析与预测**|**基本面分析、技术分析、量化分析综合运用** |
| **适用环境**|**适合通过大类资产与行业轮动获利**|**特别适用于市场存在广泛定价无效的情况** |

> **很多基金经理会结合两种策略，以兼顾宏观与微观因素**。

**自下而上的三种分析工具** P324–P325：

| 工具 | 作用 |
|---|---|
| **基本面分析**|**可以帮助投资者深入研究公司的财务状况、管理团队、行业地位和增长前景，从而评估其长期投资价值** |
| **技术分析**|**则通过研究股票价格走势和交易量等市场数据，帮助投资者把握交易时机** |
| **量化分析**|**利用数学模型和统计方法，系统地寻找被市场低估或高估的股票** |

**自上而下的两个额外用法** P325：

> **自上而下策略还可以通过积极的投资风格调整来追求额外收益**——例如，**根据市场环境的变化，投资者可以灵活调整价值股与成长股的投资比例**；此外，**这种策略还可以运用于板块轮换，通过在周期非敏感型行业和周期敏感型行业之间进行适时切换，捕捉不同经济周期下各行业板块的表现差异**。

##### ⑤ 组合构建的三层约束 P325

> **然而，需要注意的是，无论是采用自上而下还是自下而上的投资策略，基金的投资组合构建过程都受到多方面因素的制约**——**这些因素包括但不限于基金合同的规定、公司的投资政策、基金经理的个人能力和经验等**；**这些约束会在大类资产配置、行业选择、投资风格以及个股筛选等多个层面影响投资决策的制定和执行**。

##### ⑥ 我国公募基金的三项制度约束 P325

**（a）大类资产配置比例**：

> **当前我国公募基金投资的大类资产以股票与固定收益证券为主，基金类型基本上决定了大类资产配置的范围**。

| 基金类型 | 配置比例要求 |
|---|---|
| **股票型基金**|**通常要求在股票资产上的配置比例不低于基金资产的 80%** |
| **债券型基金**|**在债券资产上的配置比例一般不低于基金资产的 80%** |
| **混合型基金**|**选择的范围比较广，介于股票型和债券型之间** |

- **两种理念的差异**：**信奉自上而下理念的投资经理需要结合自己对宏观经济形势的预测来选择合适的股票投资比例，而信奉自下而上理念的投资经理在股票上的投资比例则主要取决于对其掌握的可投资股票的理解深度和广度**。

**（b）行业与风格限制**：

> **有的基金契约已经规定投资的具体行业或风格，如行业基金、大盘/小盘基金、价值/成长基金等**——**这些基金的投资范围受到较为严格的限制**；**有的基金没有明确的行业或风格限制，投资经理可通过对当前市场形势的研究和判断，自主决定行业和风格的配置**。

**（c）"双十限制"（必背）**：

> **此外，个股的选择与权重受到基金契约和法规中投资比例等方面的限制**——例如，**个股投资权重的"双十限制"**：

| 限制 | 内容 |
|---|---|
| **第一重**|**一只基金持有一家公司发行的证券，其市值不得超过基金资产净值的 10%** |
| **第二重**|**同一基金管理人管理的全部基金持有一家公司发行的证券，不得超过该证券的 10%** |

#### （七）主动债券投资组合管理 P325–P326

##### ① 债券与股票的差异 P325–P326

> **与股票相比，债券的收益特征，尤其是票息部分，具有较高的可预测性**，**但其价格同样受到宏观经济、市场利率、信用环境、供需关系等多种因素的影响而波动**。

> **债券分析方法也不同于股票**——**主要分析指标有到期收益率、利率期限结构、久期、凸性、信用利差等**。

##### ② 全球债券管理策略的演变 P326

| 时期 | 主流策略与背景 |
|---|---|
| **20 世纪 60 年代以前**|**大多数债券组合管理者采用买入并持有策略** |
| **70 年代初期**|**随着布雷顿森林体系的解体，利率和汇率波动加剧，投资者对积极债券组合管理策略的兴趣逐渐提高** |
| **70 年代末和 80 年代初**|**随着通货膨胀率和利率创历史新高，债券市场收益率波动剧烈，催生了许多新型金融工具和更为复杂的主动管理策略** |

##### ③ 两大类债券投资策略（核心分类） P326

> **从投资目标出发，债券投资组合的策略可大致划分为以满足负债为主要目的的投资策略和以追求投资收益为主要目的的投资策略**。

| 类型 | 目标 | 代表策略 |
|---|---|---|
| **① 以满足负债为主要目的**|**旨在确保资产未来的现金流收入能够覆盖未来偿付负债所需的现金流支出**；**该策略追求的目标是偿还负债，最小化无法满足负债支出的风险**|**所得免疫策略和价格免疫策略** |
| **② 以追求投资收益为主要目的**|**侧重于投资收益最大化**，**通常该类策略会选定业绩比较基准并追求超额收益** | 见下方三种主动手法 |

**主动型债券基金经理的三种超额收益手法** P326：

> **主动型债券基金经理通过对宏观、行业和个券研究，对利率和信用等要素进行预测，并调整组合的利率和信用风险水平以获取超额收益**。

| # | 手法 | 具体做法 |
|---|---|---|
| **1**|**久期错配（利率预测）**|**擅长利率预测的基金经理可以选择调整投资组合与基准在久期上的错配来获取超额收益**——**当基金经理认为当前市场的远期利率偏高而未来利率不太可能达到这个水平时，可以通过提高投资组合的久期，以从收益率曲线的下行中获利** |
| **2**|**品种错配（估值识别）**|**基金经理还可以通过识别被低估与被高估的债券，相对基准进行品种上的错配，低买高卖获取收益** |
| **3**|**曲线策略（相对价值）**|**基金经理还可以依据对收益率曲线上不同点的相对价值的判断，采用哑铃或者子弹型策略配置组合** |

##### ④ 债券基金的四层文件与自上而下三层次 P326

> **同股票型基金类似，债券型基金需要在招募说明书中说明基金的投资目标、投资理念、投资策略、投资范围、业绩比较基准、风险收益特征等关键要素**，**这些要素决定了基金投资组合的构建理念和流程**。

> **自上而下的债券配置从宏观层面开始，分析利率风险、流动性风险和信用风险，进而决定在不同的信用等级和行业类别上的配置比例**。

**三个决策层次（必背）**：

| 层次 | 内容 |
|---|---|
| **①**|**大类资产配置** |
| **②**|**类属资产配置** |
| **③**|**个券选择** |

> **通过这三个层次自上而下地决策，最终实现基金的投资目标**。

## 9.6 多元资产投资

### 9.6.a 【理解】多元资产投资的定义、特点、管理流程、挑战，以及战略资产配置、战术资产配置和资产配置再平衡的概念和作用 P327–P332

**大纲原文**：理解多元资产投资的定义、特点、管理流程、挑战，以及战略资产配置、战术资产配置和资产配置再平衡的概念和作用

#### （一）定义 P327

> **多元资产投资是一种通过在不同资产类别之间进行分散投资，以实现风险分散和收益优化的投资策略**；**根据现代投资组合理论，通过合理的分散化，投资者可以在不显著降低潜在收益的情况下有效降低整体风险**。

**理想组合的四大类资产**：

| 资产 | 在组合中的角色 |
|---|---|
| **股票**|**作为资本增值的主要来源，股票通常是投资组合中的增长引擎** |
| **债券**|**提供稳定的收益，尤其在市场波动时为投资组合提供保护** |
| **现金及现金等价物**|**确保投资组合的流动性，满足短期资金需求** |
| **另类投资**|**包括私募资本、房地产、大宗商品等，具有独特的风险收益特征，有助于进一步分散投资组合风险，提供额外的回报来源** |

**有效性的基础**：

> **不同资产类别之间的低相关性是多元资产配置有效性的基础**——**通过合理配置这些资产类别，投资者可以在优化收益的同时有效降低风险**。

- **衍生品的辅助**：**衍生品工具如期权、期货和互换等，可用于调整资产配置、管理风险敞口和实现特定投资策略，为多元资产投资提供了更大的灵活性和效率**。

#### （二）目标与业绩比较基准 P327

**主要目标**：

> **多元资产投资的主要目标是通过优化资产配置，实现长期稳健的投资回报，并穿越市场周期**。

| 投资者类型 | 做法 |
|---|---|
| **个人投资者**|**通常会将资金分散投资于房产、储蓄、理财产品、基金等，满足其多样化的理财需求** |
| **机构投资者**（**保险公司、银行、养老金计划、慈善基金等**） |**也会采用多元资产投资策略，以应对当期和未来的需求** |

> **这种策略不仅能够满足个人和机构的多样化投资目标，还能帮助他们在不同的市场环境中保持投资组合的稳定性**。

**复合基准（必背示例）** P327：

> **在多元资产投资中，投资者的业绩比较基准通常是多个指数的复合**。

**教材示例**：

> 一个典型的复合基准可能是 **"40% 沪深 300 指数 + 20% 标普 500 指数 + 10% 富时 100 指数 + 20% 彭博全球综合债券指数 + 10% 标普高盛大宗商品指数"** 这样的形式。

> **需要注意的是，这种基准的具体构成应根据投资者自身的投资目标、风险偏好和投资约束进行定制，而非一成不变**；**这种复合基准能够更准确地反映多元资产组合的表现，并为投资者提供一个衡量投资策略有效性的参考标准**；**业绩比较基准的选择应当与投资者的具体目标、风险偏好和投资约束相匹配**。

#### （三）管理流程（九个环节） P327–P328

> **多元资产投资的管理包括以下多个环节**：

| # | 环节 |
|---|---|
| **1**|**投资者需求分析** |
| **2**|**投资政策说明书制定或产品设计** |
| **3**|**资产配置** |
| **4**|**证券选择** |
| **5**|**组合构建** |
| **6**|**交易执行** |
| **7**|**风险管理** |
| **8**|**业绩评估** |
| **9**|**投资组合再平衡** |

**跨市场复杂度**：

> **与单一资产投资相比，多元资产投资的管理更为复杂，尤其是在跨国界和跨货币的投资中，需考虑汇率风险、各市场的交易时间差异，以及不同国家的监管环境和税务政策**；**这种复杂性要求多元资产投资通常需要依赖专业团队的合作，以有效管理投资组合并实现投资目标**。

**分工合作模式（重要）** P328：

> **多元资产投资经理的目标是通过投资于多个资产类别分散风险，增强组合的稳定性，并达成特定的投资目标**。

> **通常，多元资产投资经理负责资产配置，而具体的证券选择则交由单一资产类别的专业投资经理处理**；**这种分工合作的模式有助于充分利用各个领域的专业知识**；**在此过程中，投资经理需要深刻理解每一类资产的风险和收益特征，以及这些资产在投资组合中所扮演的不同角色**。

#### （四）六大独特挑战 P328

| # | 挑战 | 内涵 |
|---|---|---|
| **1**|**资产间相关性的动态变化**|**在市场极端波动或系统性风险事件（如全球金融危机、大规模经济衰退或地缘政治冲突）期间，资产间的相关性往往显著增加，可能导致传统的分散化策略失效**；**这种现象通常被称为"相关性趋同"（Correlation Convergence）或"尾部相关性"（Tail Correlation）** |
| **2**|**全球宏观经济因素的影响**|**多元资产投资需要持续监控和分析全球经济趋势，并根据经济周期、政策变化、地缘政治风险等因素及时调整投资策略**；**这种宏观因素的复杂性增加了投资决策的难度** |
| **3**|**流动性管理**|**不同资产类别的流动性差异可能会影响投资组合的整体流动性管理**；**特别是在市场不稳定时，流动性不足的资产可能难以迅速变现，从而影响资金的灵活运用** |
| **4**|**复杂的风险管理**|**多元资产投资需要综合考虑多个资产类别的市场风险、信用风险、操作风险等**；**这种多维度的风险管理要求使用先进的风险管理工具和技术，以识别、量化和控制各类风险** |
| **5**|**业绩归因分析的复杂性**|**在多元资产投资中，精确识别每个资产类别和投资决策对整体业绩的贡献是一个复杂的过程**；**复杂的组合结构使得业绩归因分析更加困难，尤其是在多重因素同时影响组合表现时** |
| **6**|**监管合规**|**不同资产类别往往面临不同的监管要求，特别是在跨国投资中**；**合规管理的复杂性增加了投资管理的难度，需要在多个司法管辖区内同时满足各自的法规要求** |

**应对之道**：

> **应对这些挑战需要强大的研究能力、先进的风险管理工具、高效的组织结构以及持续的专业发展**；**成功的多元资产投资管理不仅需要深入了解各个资产类别的专业知识，还需要具备从整体角度优化投资组合的能力，以实现投资者的长期目标**。

> **最终，成功的多元资产管理在于平衡收益与风险，确保投资组合在各种市场条件下都能稳健运行**。

#### （五）战略资产配置（SAA） P329

> **资产配置是根据投资者的需求将资金在不同资产类别和策略之间进行合理分配**；**资产配置是多元资产投资的核心步骤**——**通过资产配置，投资者可以在可接受的风险水平内，力求实现最高的预期收益**。

> **从一般意义上讲，战略资产配置（Strategic Asset Allocation，SAA）是为了满足投资者风险与收益目标所做的长期资产的配比**。

**四个关键定位**：

| # | 定位 |
|---|---|
| **1**|**战略资产配置根据投资者的风险承受能力，对资产作出事前的、整体性的、最能满足投资者需求的规划和安排** |
| **2**|**战略资产配置确定了各主要大类资产的投资比例，体现了适合投资者长期投资目标的最佳长期资产组合结构** |
| **3**|**战略资产配置是投资组合构建的起点，也是整个投资管理过程中的核心环节** |
| **4**|**无论是机构投资者还是个人投资者，通常都会将战略资产配置视为投资管理的基石**——**因为在这一过程中，投资者可以充分融入和体现自身的投资需求、偏好和长期目标** |

**三个特征（必背）**：

| 特征 | 内容 |
|---|---|
| **强调长期性**|**这种资产配置方式强调长期性，因此通常不考虑资产的短期波动** |
| **投资期限长**|**其投资期限往往较长，通常为 5 年以上** |
| **相对稳定**|**一旦战略资产配置确定下来，它在整个投资期限内通常会保持相对稳定** |

**构建方法**：

> **投资经理在确定可投资的资产类别后，基于长期投资目标制订战略资产配置计划**；**在这一过程中，投资经理需要对各类资产的长期预期收益率、风险水平以及资产间的相关性进行全面分析，并运用均值方差模型等优化方法来构建一个最优的资产组合**；**通过这些分析，投资经理可以确定各资产类别在投资组合中的权重，最终形成战略资产配置**。

**教材示例** P329：

> 例如，**某个投资组合的长期投资目标是战胜通货膨胀，并获得一定的相对收益**，其**投资范围仅限于债券和股票，且不可投资于投资级别以下的债券，如垃圾债券等**；**如果通货膨胀率是 2%，每年预计获取的真实收益率是 3%，则该投资组合每年的预期收益为真实收益率 3% 加上通货膨胀率 2%，为年化 5%**。

> **在战略资产配置层面，该组合将选择可以抵消或战胜通货膨胀率的资产，比如通胀保护债券，并配置部分在长期能够带来净值增长的资产类别，如股票**。

#### （六）战术资产配置（TAA） P329–P330

> **战略资产配置专注于长期目标的实现，但在此基础上，若能有效捕捉各资产类别的短期回报率波动，也可以显著增强投资组合的整体回报率**。

> **战术资产配置（Tactical Asset Allocation，TAA）便是在遵循战略资产配置所确定的大类资产比例基础上，根据短期内各特定资产类别的表现，对投资组合中这些资产类别的权重进行调整，从而实现这一目的**。

> **战术资产配置是一种基于对短期资本市场环境及经济条件的预测，主动对资产配置状态进行动态调整的投资策略**；**其核心在于通过对市场短期波动的敏锐把握，灵活调整各资产类别的配置比例，以期在短期内增加投资组合的价值**。

**与 SAA 的根本区别**：

> **与战略资产配置不同的是，战术资产配置更注重市场的短期表现，强调通过市场择时（Market Timing）等手段，利用金融工具在各大类资产之间灵活调配资金，从而在短期内优化投资收益和风险管理**。

**三个特征**：

| 特征 | 内容 |
|---|---|
| **周期短**|**战术资产配置的周期通常较短，一般在 1 年以内** |
| **高度灵活**|**这种策略的特点是高度灵活，要求投资管理人在市场变化时迅速作出反应，并根据市场状况的变化对资产类别的预期收益进行调整** |
| **不改变长期目标**|**然而，战术资产配置并不涉及对投资者长期目标或风险偏好的重新评估，更多的是基于当前市场机会的短期操作** |

**前提条件与工具**：

> **运用战术资产配置的前提条件是基金管理人具备较高的市场洞察力和预测能力，能够准确把握市场的短期波动并有效实施动态调整**；**为了支持这一策略的实施，投资管理人通常使用一系列工具和方法，例如分析政治经济状况、把握市场动态、观察估值水平的变化等**。

**争议与约束**：

> **然而，战术资产配置的有效性在投资界仍存在较大争议**——**虽然理论上，战术资产配置可以通过市场择时来获取超额收益，但实践证明，只有少数基金管理人能够持续性地通过这种策略战胜市场**；因此，**为了控制风险，战术资产配置对战略资产配置的偏离通常被限制在一定范围内，以避免由于过度的短期调整而导致投资组合偏离长期目标**。

#### （七）资产配置再平衡 P330–P331

##### ① 为什么需要再平衡 P330

> **在投资组合的运作过程中，随着时间的推移，各类资产的市场表现往往会出现差异**——**一些资产的价格上涨，导致其在投资组合中的占比上升；而另一些资产的价格下跌，其在投资组合中的占比则相应下降**；因此，**随着资产价格的不断变化，投资组合中各类资产的实际比例会逐渐偏离最初设定的战略资产配置基准**。

> **当这种偏离超过一定程度时，投资经理需要通过调整投资组合的资产权重，使投资组合的结构尽可能恢复到与战略资产配置设定一致的状态**——**这个过程被称为"资产配置再平衡"**。

##### ② 目的与性质（必背） P330

> **资产配置再平衡的主要目的是保持投资组合的风险收益特征与最初设定的一致性**。

> **再平衡并不涉及对市场状况的主动预测或分析，而是基于既定的目标进行被动操作**。

**与"重新配置"的区别**：

> **通常，再平衡特指由于资产价格变化导致的资产配置权重偏离战略资产配置基准，从而进行的资产权重调整**；**这与因投资者财务状况变化或因投资经理对市场预期调整而产生的重新配置需求不同，后者并不属于传统意义上的再平衡**。

##### ③ 三种实施方式 P330–P331

**方式一：定期再平衡**：

> **定期再平衡是一种最为简单直接的方式，即在预定的时间间隔内（如每月、每季度或每年），将投资组合中的资产权重调整回目标权重**。

- **示例**：**假设某投资组合的目标配置是 40% 股票和 60% 债券，投资经理可能会在每季度末检查组合的实际资产比例，并将其调整回 40% 股票和 60% 债券的初始配置**；
- **优点**：**这种方法的优点在于执行透明且易于管理，无须复杂的市场预测或分析**。

**方式二：基于偏离幅度的再平衡（阈值再平衡）**：

> **基于偏离幅度的再平衡则更为灵活，依赖于设定的偏离度阈值**——**当实际资产比例偏离初始配置超过预定的阈值时，才会触发再平衡**。

- **示例**：**基金经理可能设定了一个最大偏离度阈值为 10% 的再平衡策略**；**如果初始设定的资产配置为 40% 的股票和 60% 的债券，那么当债券的权重上升到 70% 或下降到 50% 时，就会触发再平衡**；**然而，如果偏离幅度在阈值内（如债券权重在 50%~70% 浮动），则不会进行再平衡**；
- **优点**：**这种方法的优点在于减少不必要的交易，降低交易成本，同时保持资产配置的灵活性**。

**方式三：两者结合**：

> **再平衡也可以采取"定期再平衡"与"基于偏离幅度再平衡"相结合的方式**；**这种方法允许投资组合在一定的时间周期内进行检查，并且只有在偏离超过一定阈值时才进行调整**；**这种结合方式可以在一定程度上优化再平衡的频率，既避免了过度交易导致的成本增加，又能够有效控制资产配置的偏离度**。

##### ④ 影响再平衡的七个因素 P331

| # | 因素 | 影响方向 |
|---|---|---|
| **1**|**资产的可交易性**|**某些资产的流动性较差，可能导致再平衡的执行难度增加，尤其是在市场波动剧烈时** |
| **2**|**交易成本**|**交易成本越高，投资经理可能会倾向于设定更大的偏离度阈值，以减少不必要的交易** |
| **3**|**单一资产的价格波动**|**如果投资组合中的某一资产价格波动剧烈，可能会导致该资产的权重迅速偏离初始配置，从而增加再平衡的频率** |
| **4**|**投资组合整体的波动性**|**投资组合中各类资产的波动性越大，组合的整体波动性就越大，偏离初始权重配置的可能性也就越高** |
| **5**|**相关性**|**如果某类资产与投资组合的相关性较高，那么该资产的变动趋势与组合相似，其偏离初始权重配置的速度会相对较慢** |
| **6**|**投资者的风险承受能力**|**投资者的风险容忍度越高，其资产配置权重允许的最大偏离度范围也会越大**——**这意味着再平衡的频率可能较低** |
| **7**|**管理人和托管人的运营资源**|**再平衡需要依赖基金管理人和托管人的操作能力和资源配置**；**资源越充足，再平衡的执行就越顺畅** |

**参数确定方法**：

> **投资者可以通过回测历史数据，比较不同时间频率和偏离阈值下的组合表现，确定最优的再平衡时间周期和偏离阈值**；**通过这些方式，投资者能够在维持投资组合长期目标一致性的同时，优化再平衡的成本和效果**。

##### ⑤ 总体评价 P332

> **总的来说，资产配置再平衡是一项至关重要的操作**——**它不仅帮助投资者维持投资组合的初始风险收益特征，还能在一定程度上通过纪律性操作，提升长期投资的稳定性**；**然而，再平衡的执行需要在成本、效益和风险控制之间找到平衡点，以确保投资组合能够在长期内保持健康的增长**。

#### （八）SAA / TAA / 再平衡三者对比（必背）

| 维度 | **战略资产配置（SAA）**|**战术资产配置（TAA）**|**资产配置再平衡** |
|---|---|---|---|
| **性质**|**事前的、整体性的长期规划**|**短期的主动动态调整**|**被动、纪律性的纠偏操作** |
| **时间跨度**|**通常 5 年以上**|**一般在 1 年以内**|**定期 / 触发式** |
| **依据**|**投资者的风险承受能力与长期目标**|**对短期市场环境与经济条件的预测**|**实际权重偏离目标权重的程度** |
| **目的**|**确定各主要大类资产的长期比例**|**捕捉短期波动、增强整体回报**|**保持风险收益特征与最初设定一致** |
| **是否预测市场**|**否（基于长期分析）**|**是（市场择时）**|**否（不涉及主动预测）** |
| **方法论**|**长期收益/风险/相关性分析 + 均值方差模型**|**政治经济分析、市场动态、估值水平**|**定期 / 阈值 / 两者结合** |
| **约束**|**投资范围、风险承受能力**|**偏离幅度通常被限制在一定范围内**|**交易成本、流动性、波动性** |

### 9.6.b 【了解】股票、债券和另类资产在投资组合中的主要作用 P332–P334

**大纲原文**：了解股票、债券和另类资产在投资组合中的主要作用

> **在构建投资组合时，各类资产的作用各有侧重，能够满足不同的投资需求**。

#### （一）股票资产的四项作用 P332

> **股票资产在投资组合中的主要作用包括实现资产增值、提供股息收入、分散组合风险以及在一定条件下对抗通货膨胀**。

| # | 作用 | 要点 |
|---|---|---|
| **1**|**资产增值**|**在经济高速增长期，股票往往表现优于其他资产类别；而在经济疲软时期，股票表现可能会逊色于债券或其他固定收益资产**；**竞争格局的改善、业绩成长性好等因素都可能带来股票资产增值** |
| **2**|**股息收入**|**股息收入是股票投资的重要收益来源之一**；**通常成熟型公司更倾向于将盈利以股息形式分配，而成长型公司则倾向于保留盈利进行再投资**——**这意味着，投资者可以通过持有成熟型公司的股票，获得相对稳定的现金流，从而增强投资组合的收益稳定性** |
| **3**|**分散组合风险**|**虽然单一股票的风险较高，但通过持有多只股票，投资者可以在一定程度上分散个股风险**；**然而，股票市场的系统性风险（即市场整体下跌的风险）无法通过个股的分散来消除**；因此，**将股票投资与其他低相关性的资产，如债券或房地产结合，可以进一步降低整个投资组合的风险** |
| **4**|**对抗通货膨胀**|**股票在长期内通常能够提供一定的通货膨胀保护，尤其是那些拥有较强定价能力、能够将成本上涨有效转嫁给消费者的企业的股票**；**然而短期内，特别是在通胀急剧上升或经济滞胀时，股票整体的表现可能并不理想**；因此，**股票并非在所有情境下都能有效对冲通胀，投资者需谨慎评估具体经济环境** |

#### （二）债券资产的三项作用 P332–P333

> **债券在投资组合中扮演着多重角色，包括分散风险、提供规律性现金流和对冲潜在的通货膨胀**。

##### ① 分散化优势 P333

> **在投资组合中加入债券能够显著提高分散化效果，尤其是在与股票或其他高风险资产组合时**；**通常，债券与股票的相关性较低，特别是在市场波动较大时，债券能够通过降低整体组合的波动性来分散风险**。

**相关性的动态变化（重要）**：

> **然而，资产类别之间的相关性并非恒定，可能随市场条件的变化而波动**——例如，**在熊市中，投资者倾向于从风险资产如股票和高收益债券，转向安全资产如政府债券**；**这些行为可能会降低政府债券与股票之间，以及政府债券与高收益债券之间的相关性；同时，股票和高收益债券等高风险资产之间的相关性可能会增加**。

##### ② 规律性现金流优势 P333

> **债券投资通常会产生有规律的现金流，投资者可以通过投资债券来为未来的支出提供资金，如学费、保险、赡养费等**。

> **此类负债驱动的投资组合所选取的债券现金流的时间和规模必须与预计未来负债的时间和规模相匹配**；**有的投资者会将组合中债券的到期日在投资期限内分散错开，构建阶梯式债券组合**——**这种方法有助于平衡债券价格波动风险和再投资风险**。

##### ③ 对冲潜在的通货膨胀 P333

> **某些债券有对冲通货膨胀的作用**。

| 债券类型 | 抗通胀机制 | 效果 |
|---|---|---|
| **通胀挂钩债券（Inflation-linked Bond）**|**本金与票息支付直接与消费者价格指数（CPI）等通胀指标挂钩**|**有效提供通胀保护** |
| **浮动利率债券（Floating Rate Bonds）**|**票息与市场基准利率挂钩**；**当通货膨胀导致市场利率上升时，其票息随之调高，从而提供一定的通胀保护**|**但其抗通胀作用机制与直接挂钩通胀指数的债券不同，效果通常也较通胀挂钩债券弱** |

#### （三）另类资产的三类作用 P333–P334

> **在多元资产投资中，另类资产日益成为关键组成部分**；**它们不仅能够提升投资组合的潜在收益，还能通过其独特的风险特征，实现有效的风险分散**。

| 类别 | 正向作用 | 需权衡的挑战 |
|---|---|---|
| **① 私募资本**|**主要通过非公开市场的独特机会和长期投资策略，提升整体收益**；**其独特的风险—收益特性使其在不同市场环境下能够提供一定的稳定性**；**此外，私募资本通常与传统资产的相关性较低，有助于降低组合的整体波动性**|**投资者需权衡其流动性较低和估值复杂等挑战** |
| **② 实物资产**|**涵盖不动产和大宗商品等多种类别，作为多元化工具在投资组合中发挥关键作用**——**不动产通过稳定的租金收入和资产增值，提供稳健的现金流和长期资本增值，且其价值通常随通货膨胀上升，具有良好的通胀对冲能力**；**大宗商品则因其与通货膨胀高度相关，在通胀上升时期表现较好，同时其价格走势与传统金融市场不同，进一步分散投资风险** | — |
| **③ 对冲基金**|**通过多样化的投资策略，如多空股票策略、套利和事件驱动策略等，追求在不同市场环境下的超额收益**；**其策略的多样性和较低相关性能够提升组合整体的风险分散效果**|**对冲基金的策略差异显著，投资者需谨慎评估具体策略的风险特征，以及其对组合整体风险贡献的影响** |

#### （四）三类资产作用速查表

| 资产 | 收益来源 | 风险分散作用 | 抗通胀 | 主要局限 |
|---|---|---|---|---|
| **股票**|**资本增值 + 股息**|**分散个股风险，但无法消除系统性风险**|**长期有效（须有定价能力），短期不理想**|**系统性风险、滞胀期表现差** |
| **债券**|**票息 + 规律现金流**|**与股票低相关，降低组合波动**|**通胀挂钩债券有效；浮息债较弱**|**价格波动风险、再投资风险、相关性会漂移** |
| **另类资产**|**私募资本（独特机会）、不动产（租金+增值）、大宗商品（通胀）、对冲基金（超额收益）**|**与传统资产低相关，进一步分散**|**不动产与大宗商品较强**|**流动性低、估值复杂、策略差异大** |

### 9.6.c 【理解】常见的多元资产投资策略和产品类型 P334–P338

**大纲原文**：理解常见的多元资产投资策略和产品类型

> **进行多元资产投资策略时，投资者根据不同的目标，可以采用多种策略或策略组合**；这里介绍几种常见的多元资产投资策略，**包括核心—卫星策略、风险平价策略和全天候策略，以及几种典型的多元资产基金**。

#### （一）核心—卫星策略 P334

> **核心—卫星策略是一种广受认可的资产配置方法，其核心思想是将投资组合分为两个主要部分：一个较大的核心部分和一个较小的卫星部分**。

**两部分的分工（必背）**：

| 部分 | 占比 | 管理方式 | 工具 | 目标 |
|---|---|---|---|---|
| **核心部分**|**通常占比 60%~80%**|**一般采用被动管理方式**|**通过低成本的指数基金或 ETF 来实现**|**旨在提供稳定的市场回报** |
| **卫星部分**|**占比 20%~40%**|**主要采用主动管理方式**|**通过投资于特定机会或另类资产**|**力求获取超额收益** |

**实施步骤**：

> **实施核心—卫星策略时，投资者首先需要根据自身风险承受能力、投资目标和市场观点确定核心与卫星的配置比例，然后选择匹配的投资工具**；**在运作过程中需要定期再平衡，以保持预定的配置比例**。

**优缺点**：

| 优点 | 缺点 |
|---|---|
| **平衡风险与收益——核心部分提供稳定性和市场敞口，卫星部分则增加获取超额收益的机会，同时保持低成本**|**该策略管理上较为复杂，需具备一定的专业知识和管理能力**；**频繁的再平衡可能增加交易成本，并影响整体收益** |

**适用对象**：

> **核心—卫星策略适合那些希望在控制风险的同时追求一定程度超额收益的投资者**；**这些投资者通常具有一定的投资知识和经验，能够理解和管理相对复杂的投资策略**；同时，**由于有效实施分散化投资需要一定的资金规模，这种策略也更适合资金较为充裕的投资者**。

#### （二）风险平价策略 P334–P335

> **风险平价策略是一种根据不同资产类别的风险贡献度来确定其在投资组合中的权重的策略，以实现风险均衡配置**。

**与传统配置的根本区别（核心）**：

> **与传统的资产配置方法不同，风险平价策略关注的是每种资产对整体投资组合风险的贡献，而不是单纯依据预期收益或市值比例来分配资产**。

**对高波动资产的处理**：

> **一般情况下，高波动性的资产（如股票）在传统的投资组合中占比较大**；**但在风险平价策略中，这些资产的配置比例会被适当降低，以确保其对整体组合的风险贡献与其他资产类别相当**。

**两个特点与核心理念**：

> **风险平价策略通常涉及多种资产类别，通过分散投资，能够在不同市场环境下保持相对稳定的表现**；**由于每种资产的风险贡献相对均衡，该策略在市场波动时更能保护投资组合，同时捕捉不同资产类别的上涨机会**。

> **风险平价策略的核心理念是通过均衡配置风险实现长期稳健的投资回报，而非单纯追求高回报**；**这种策略适合希望通过分散投资来减少投资组合波动性的投资者**。

#### （三）全天候策略 P335

> **全天候策略（All-Weather Strategy）是由桥水基金（Bridgewater Associates）创始人雷·达利欧（Ray Dalio）在 1996 年提出并发展的投资方法**。

**设计目标与核心理念**：

> **这一策略的设计目标是在不同市场环境下都能获得稳定收益并有效控制风险**；**其核心理念是通过广泛分散投资，降低投资组合对单一经济环境的依赖，从而在任何市场条件下都能获得合理回报**。

**四种经济环境的应对（必背）**：

> **全天候策略考虑了经济增长、通货膨胀、通货紧缩和经济衰退等不同经济环境，通过配置适应不同经济环境的资产类别（如股票、债券、大宗商品、通胀保护证券等），确保投资组合能够在不同经济条件下表现良好**。

| 经济环境 | 表现较好的资产 |
|---|---|
| **经济增长 + 通胀上升**|**股票和大宗商品** |
| **经济衰退 + 通货紧缩**|**债券和现金（更好的防御性资产）** |

**分散化逻辑**：

> **全天候策略通过在多种资产类别之间广泛分散投资来降低组合的波动性**；**这种策略强调资产之间的低相关性，这样在某些资产下跌时，其他资产能够提供支撑，从而平滑整体投资组合的表现**。

**三点局限（必背）**：

| # | 局限 |
|---|---|
| **1**|**全天候策略在强劲牛市中可能表现落后于更激进的策略** |
| **2**|**且其有效性依赖于历史资产相关性的持续性** |
| **3**|**此外，频繁的再平衡可能带来额外的交易成本** |

**适用对象**：

> **该策略适合那些希望长期稳健投资的投资者**；**自达利欧提出以来，全天候策略因其在不同市场环境下的稳定表现而受到广泛关注，并被许多投资者和机构采用和改进**。

#### （四）多元资产基金 P335–P336

**为什么需要多元资产基金**：

> **资产规模较大的投资者可以单独购买不同的资产类别进行多元资产投资**；**对于资产规模较小的投资者，考虑到多元资产投资的复杂性和某些资产较高的投资门槛，投资于专门的多元资产基金更为可行**。

**投资范围**：

> **多元资产基金将多种资产类别组合在一个投资组合中，既包括传统的股票和债券、指数基金、金融衍生品，也包括另类投资，如不动产投资信托（REITs）和商品**；**基金经理通过对各类型资产、因子、风格和管理人的广泛和深入的研究，精心设计风险敞口，进行动态管理**。

> **养老目标基金就是多元资产基金的一种**。

**与传统基金的区别（重要）**：

> **多元资产投资基金通常以实现特定的投资结果为目标，而不是根据基准指数来衡量业绩**。

**三类常见多元资产基金**：

| # | 类型 | 目标与特征 |
|---|---|---|
| **1**|**收入基金（Income Fund）**|**侧重于为投资者提供经常性收入，通常持有债券、优先股、货币市场工具和支付股息的股票**；**有的收入基金定期分配收益，有的则是按照投资者的负债端需求设计** |
| **2**|**目标风险基金（Target Risk Fund）**|**寻求在特定的预期收益波动范围内获得收益**；**基金经理使用多种资产类别对风险与收益进行平衡，将风险控制在投资者可容忍的水平**；**风险容忍度低的投资者可以选择保守型基金，而风险容忍度较高的投资者可以选择温和型、进取型或成长型目标风险基金** |
| **3**|**目标日期基金（Target Date Fund）**|**是一种根据投资者的年龄和退休目标，动态调整资产配置比例的投资产品，通常用于教育或退休规划**；**目标日期基金会在产品名称中设立一个"目标日期"（通常代表预计的退休年份）** |

**目标日期基金的"下滑轨道"（glide path）逻辑（必背）**：

> **目标日期基金的设计理念是随着投资者接近退休年龄，逐渐降低投资组合的风险水平**。

| 阶段 | 资产配置 |
|---|---|
| **投资初期**|**基金的资产配置会偏向于高风险、高回报的资产类别（如股票），以追求资本增值** |
| **随着目标日期的临近**|**基金会逐步降低股票的配置比例，增加债券和现金等低风险资产的配置，以保护已有的投资收益，降低市场波动对退休资金的影响** |

#### 案例 9-6：挪威政府养老金全球基金（GPFG） P336–P338

## 9.7 可持续投资

### 9.7.a 【理解】可持续投资的概念和关键因素，ESG 因素在股票和债券分析中的应用，以及常见的可持续投资策略 P338–P346

**大纲原文**：理解可持续投资的概念和关键因素，ESG 因素在股票和债券分析中的应用，以及常见的可持续投资策略

#### （一）背景 P338

> **近年来，可持续发展成为全球共同关注的焦点**；在此背景下，**追求长期价值增长、兼顾经济和社会效益的可持续投资理念也日益受到重视**；**其核心是将企业的可持续发展因素纳入投资决策过程，以实现财务回报与社会、环境效益的平衡**。

> **在可持续投资体系中，ESG（Environmental、Social、Governance）投资凭借其系统化的评估框架和较高的数据可得性，已发展成为关键的评估体系和操作工具**；**通过对企业在这三大维度表现的量化评估，投资者能够筛选高质量标的并优化资产配置，使 ESG 投资成为实践可持续投资理念的主流途径**。

- **其他策略**：**另外，可持续投资还包括影响力投资、主题投资等其他重要策略和方法**。

#### （二）三个关键因素（ESG 详解） P338–P339

> **可持续投资关注环境、社会和公司治理这三个关键的非财务因素，这些因素在评估企业的可持续性和长期价值创造能力中起着重要作用**。

| 维度 | 涵盖范围 | 为什么重要 |
|---|---|---|
| **环境（E）**|**气候变化、资源管理、污染控制、生物多样性保护**等 |**企业在环境方面的表现可能会对其运营的可持续性产生多方面影响，具体程度取决于行业特性、企业规模和经营地区等因素**；**能源、制造等高环境敏感度行业的企业，其环境表现直接关系到运营成本、监管合规性和品牌声誉** |
| **社会（S）**|**员工权益、产品安全、供应链管理、社区关系**等 |**企业通过良好的社会责任实践，妥善平衡与各利益相关方的关系，树立起负责任的社会形象，增强社会声誉** |
| **公司治理（G）**|**公司董事会结构、商业道德、透明度、股东权利、反腐败**等 |**健全的公司治理结构是企业长期稳定发展的基石**——**良好的公司治理结构能够有效避免代理冲突，确保企业决策的科学性和透明度，从而维护公司各方面的利益，保障企业长期稳定的健康发展** |

**两个重要认识**：

> **可持续投资通过从环境、社会和治理等维度，对企业进行定量或定性的研究分析，以将抽象的可持续发展理念转化为具体、可操作的投资决策依据**。

> **值得注意的是，环境、社会和公司治理这三个因素并非完全独立，而是常常相互交织、互为影响**——例如，**薄弱的公司治理可能导致企业在环境保护和社会责任方面的投入不足和管理缺失**。

**记忆**：**E = 环境（外部自然）· S = 社会（利益相关方）· G = 治理（内部机制）**——**三者交织，G 是根基**。

#### （三）可持续投资的概念 P339

> **可持续投资是一种将环境、社会和治理（ESG）因素融入投资决策过程的投资理念和策略，旨在实现长期可持续的财务回报**。

**支持逻辑**：

> **可持续投资者通常认为，在环境、社会和公司治理等方面表现良好的企业往往具有更强的韧性和发展潜力，它们能够更好地规避风险、把握机遇，并为社会创造积极影响**。

**必须承认的反面证据（重要）**：

> **同时，也有研究指出，可持续投资在某些市场和特定时期，投资表现可能并不优于传统投资策略**；因此，**投资者在采用可持续投资策略时应权衡其潜在的投资回报与创造社会及环境价值之间的关系**。

#### （四）五种常见的可持续投资策略（核心考点） P339

> **可持续投资策略的形式多种多样，包括 ESG 整合、负面筛选、正面筛选、主题投资和影响力投资等**。

| # | 策略 | 具体做法 |
|---|---|---|
| **1**|**ESG 整合**|**将环境、社会和公司治理因素系统性地纳入传统的财务分析中** |
| **2**|**负面筛选**|**排除不符合特定可持续发展标准或可持续发展水平较差的公司或行业** |
| **3**|**正面筛选**|**优先选择可持续发展水平优异的公司** |
| **4**|**主题投资**|**聚焦在有助于环境、社会等可持续发展的主题或资产，如清洁能源或社会责任相关的投资** |
| **5**|**影响力投资**|**旨在获得财务回报的同时，创造可衡量的社会或环境影响** |

> **这些策略形式在实际投资中有不同的应用，帮助投资者在追求财务回报的同时，也关注企业的社会责任和环境影响**。

#### （五）五种策略的"主动性"递增逻辑

| 层次 | 策略 | 与基准的偏离程度 |
|---|---|---|
| **最温和**|**ESG 整合**|**不排除任何行业，只把 ESG 纳入财务分析** |
| **较温和**|**负面筛选**|**剔除少数不达标行业/公司** |
| **较主动**|**正面筛选**|**主动优选 ESG 表现优异者** |
| **更主动**|**主题投资**|**集中投向特定可持续主题** |
| **最主动**|**影响力投资**|**以可衡量的社会/环境影响为明确目标** |

### 9.7.b 【了解】可持续投资的发展历程与现状，ESG 评级体系方法，ESG 评级结果差异原因和中国 ESG 评级体系特点 P339–P352

#### （一）可持续投资的源起 P339

> **可持续投资的理念可以追溯到 20 世纪 60 年代末 70 年代初**；当时**西方国家的人权运动、环保运动和反种族隔离运动推动了社会责任投资的兴起**。

| 时间 | 事件 |
|---|---|
| **1971 年**|**美国帕斯全球基金（Pax World Funds）拒绝投资从越战中获利的公司** |
| **1988 年**|**英国梅林生态基金（Merlin Ecology Fund）则专注于投资注重环境保护的企业** |
| **20 世纪 90 年代**|**社会责任投资开始从单纯的道德考量转向更系统的投资策略** |

#### （二）ESG 概念与 PRI 的诞生 P340

> **进入 21 世纪，ESG 投资概念逐渐形成，并逐渐发展成为主流的可持续投资策略之一**。

| 时间 | 事件 |
|---|---|
| **2004 年**|**联合国首次提出了 ESG 概念，并将其作为评估企业可持续性和长期价值的重要框架** |
| **2006 年**|**在联合国的支持下，"负责任投资原则"（Principles for Responsible Investment，PRI）正式成立** |

> **PRI 旨在为全球投资者提供一个具体的投资原则框架，帮助投资者将 ESG 因素系统地纳入投资决策和所有权实践**；**PRI 提出的六项原则进一步细化了 ESG 因素融入投资实践的具体措施，标志着可持续投资理念进入了更加成熟和实际的发展阶段**。

#### （三）全球发展情况 P340–P341

##### ① 全球可持续投资框架体系（三大部分）

> **全球可持续投资框架体系的建立是推动可持续投资发展的关键因素之一**；**这个体系主要包括报告框架和标准、投资原则和倡议以及环境信息披露和气候变化相关组织**。

| 部分 | 代表机构/标准 |
|---|---|
| **报告框架和标准**|**全球报告倡议组织（GRI）的可持续发展报告指引**、**国际标准化组织（ISO）的 ISO 26000 社会责任指引**、**可持续发展会计准则委员会（SASB）的行业准则**——**为企业提供了重要的报告指导** |
| **投资原则和倡议**|**PRI 和联合国环境规划署金融倡议（UNEP FI）**——**为投资者提供了明确的投资原则和行动指南** |
| **环境信息披露与气候变化**|**CDP 全球环境信息研究中心、气候信息披露标准委员会（CDSB）、金融稳定理事会气候相关财务信息披露工作组（TCFD）** 等——**推动了企业在这些领域的信息透明度** |

##### ② ISSB：全球披露标准化的里程碑 P340

> **2021 年，国际可持续发展准则理事会（ISSB）的成立是全球可持续信息披露标准化进程的重要里程碑**——**作为国际财务报告准则基金会（IFRS Foundation）的一部分，ISSB 旨在制定全球统一的可持续信息披露标准，有助于提高相关信息的可比性和一致性**。

> **2023 年，ISSB 发布的首批两项可持续信息披露标准进一步推动了全球可持续信息披露标准基线的形成**；**ISSB 标准的出台促进了全球范围内可持续信息披露标准朝着一致性、可比性和可验证性的方向发展，尤其加强了气候披露要求**；**这也促进了 2023 年下半年全球各国在可持续信息披露指引建立方面进展的加速**。

#### （五）ESG 评级体系 P344

##### ① 评级的作用与主体 P344

> **ESG 评级是可持续投资策略实践的核心工具**；**评级通过系统地整合企业的可持续发展信息，以对比打分和评级的方式，将传统财报难以捕捉的长期风险与价值创造潜力转化为可量化指标，帮助可持续投资者穿透"信息迷雾"**。

**五类评级主体**：

> **常见的 ESG 评级主体主要包括专业评级机构、指数公司、资管机构、证券公司以及高校或研究机构等**。

| 类型 | 界定 |
|---|---|
| **第三方评级**|**由与被评公司无直接利益关系的独立机构进行的评级** |
| **内部评级**|**通常由资管机构为了支持其投资决策而进行的内部评估** |

##### ② 评级的三个环节 P344

> **ESG 评级过程包含多个环节，包括评级方法论的制定、数据采集、评分评级等步骤**。

| 环节 | 内容 |
|---|---|
| **① 评级方法论的制定**|**评级机构通常根据自身的框架，结合国际组织、交易所等机构公布的标准和指引，制定适用的评级方法论** |
| **② 数据采集**|**评级机构通过多种渠道采集数据，包括公开信息、第三方数据供应商的报告以及新闻报道和监管文件等** |
| **③ 评分评级**|**评级机构基于采集的数据，按照既定方法论进行综合分析，对公司的可持续绩效进行评分，并给出最终的评级结果** |

##### ③ ESG 指标体系的三层结构（必背） P344

> **ESG 指标体系通常包含多个层级**。

| 层级 | 内容 |
|---|---|
| **一级指标**|**环境、社会和公司治理三个核心维度** |
| **二级指标**|**以上三个维度下的细分关键议题** |
| **三级及以下层级指标**|**针对关键议题的具体指标及数据点** |

> **各家评级公司在设计 ESG 指标体系时，通常基于三大核心维度确定关键议题，并通过子指标或数据点支持各项议题的评价**。

**三个关键议题示例（教材原文）**：

| 议题 | 关注什么 |
|---|---|
| **环境政策**|**重点在于要关注企业在生产过程中是否明确了对环境可能产生的影响，承担起了保护环境的责任，并据此制定相应的企业层面的保护政策** |
| **员工权益**|**企业在雇佣和管理员工过程中，需要确保员工的基本权利得到保障**——**包括提供安全、健康的工作环境，公平的薪酬和福利，禁止歧视和剥削行为，保障平等就业机会，尊重员工的工会权利以及其他相关的劳动保护措施**；**良好的员工权益实践不仅能够提升员工的工作积极性，还能促进企业的长期可持续发展** |
| **反不正当竞争**|**企业处理不同的机构或个人商业关系时，应注意是否有违反道德或公平原则的潜在风险**；**企业作为社区的一部分，应制定公平适宜的政策，并在改善社区的情况下获取相应的收益** |

##### ④ 实质性原则与"风险暴露 + 管理能力"两维度 P344

> **评级架构通常会引入对行业议题或行业权重的考量，基于实质性原则（Materiality Principle）调整具体行业评价模型，以确保评级能够准确反映各行业面临的独特风险和机遇**。

> **实质性原则的核心是关注对特定行业和企业财务表现及长期价值创造具有重大影响的 ESG 议题**。

> **在公司层面的评估上，有的评级机构会引入"风险暴露"和"管理能力"两个维度的评价，分别衡量公司面临的 ESG 风险以及其应对这些风险的能力**；**通过这种区分，评级能够有效反映不同公司在同一行业中的差异，避免因相似风险导致评价结果缺乏区分度**。

##### ⑤ 数据来源五类 P345

> **可持续相关数据采集来源多种多样，主要包括以下几类**：

| # | 来源 |
|---|---|
| **1**|**上市公司通过官网、公告及可持续发展报告等形式主动披露的信息**，如**公司年度报告、社会责任报告、ESG 报告、可持续发展报告** 等 |
| **2**|**监管部门披露的关于公司的信息**，如**排污数据、行政处罚决定** 等 |
| **3**|**新闻媒体披露的舆情信息** |
| **4**|**非政府组织（NGO）及行业协会整理的关于公司的数据** |
| **5**|**通过对公司调研得到的信息** |

##### ⑥ 数据处理的四个环节 P345

> **数据处理过程主要包含数据预审查、初步加工、深度加工、逻辑校验等环节**；**在数据源相似情况下，数据处理能力是评价数据供应商能力的重要指标**。

> **在信息收集的基础上，评级机构的分析师使用相应标准，确定定量指标和定性指标的具体评分或评级，最终汇总形成公司整体的 ESG 评级结果**；**随着底层数据的不断扩充和可持续发展理念的升级，关键议题的范围及重要性将不断演进变化**——**这要求评级机构和数据供应商保持敏锐性并不断更新其方法论**。

#### （六）ESG 评级结果差异的原因（核心考点） P345

> **研究表明，各家机构的评级结果存在显著差异，这些差异主要来源于底层数据、关键议题的选择及指标赋权的差异**。

**两项经典研究**：

| 研究 | 发现 |
|---|---|
| **Chatterjee et al.（2016）**|**对比了来自 6 家国际知名评级机构的评级，发现这 6 家机构对社会议题缺乏共识，建议评级的使用者在根据以上评级得出有关公司的结论时保持谨慎** |
| **Berg、Koelbel 和 Rigobon（2019）**|**研究了 6 家国际评级机构在 ESG 评级之间的差异，发现 6 家机构的 ESG 评级之间的平均相关性约为 0.46**，其中**治理的平均相关性最低，而环境方面的平均相关性最高**；**他们将整体差异分解为三个来源：范围差异、度量差异和权重差异，其中度量差异解释了整体差异的 50% 以上** |

**三个差异来源（必背）**：

| 来源 | 含义 |
|---|---|
| **范围差异**|**评级机构覆盖的议题范围不同** |
| **度量差异**|**同一议题的测量方法不同**——**解释了整体差异的 50% 以上** |
| **权重差异**|**各议题的赋权不同** |

#### （七）中国 ESG 评级体系特点 P345

> **近年来，随着可持续投资理念的传播，我国也出现了一批第三方 ESG 评级机构，海外机构对 A 股部分公司也有 ESG 评级覆盖**；**国内外可持续发展的含义和侧重点有所不同，既体现在指标的选择上，也体现在权重的设置上**。

> **从 ESG 评级体系特点来看，我国 ESG 评级体系更加注重国际标准与中国特色的有机结合**。

| 维度 | 中国特色指标 |
|---|---|
| **环境（E）**|**引入了"碳达峰、碳中和"等指标** |
| **社会（S）**|**体现"共同富裕"、乡村振兴等中国特色的社会发展理念**——**乡村振兴是具有中国特色的企业社会责任，诸多中国企业尤其是国企都积极响应乡村振兴号召，开展多元化的相关行动** |
| **新兴关注点**|**近年来，社会各界对隐私和数据安全、反垄断、新质生产力、科技创新的关注度逐渐提升，各方也正合力推动安全有序、竞争有序的市场体系的形成** |

#### （八）可持续投资实践：ESG 在股票与债券分析中的应用 P345–P346

##### ① 总原则 P345–P346

> **可持续投资是将可持续发展理念具象化并融入投资决策过程的实践，其核心是将可持续发展要素与传统的财务分析相结合，形成一个更全面的投资分析框架**；**这种方法将公司内部治理和外部影响（环境与社会因素）纳入考量，从而更全面地评估公司可持续发展能力、长期竞争力和潜在风险**。

> **可持续投资分析方法与财务分析方法并非对立，而是互为补充**——**ESG 因素可能直接或间接影响公司的财务表现，同时，公司的财务状况也可能影响其在可持续发展方面的表现和投入**；**这种综合分析方法不仅关注风险管理，还致力于识别可持续发展带来的长期机遇，旨在实现财务回报与社会环境效益的协同**。

> **可持续投资强调长期视角，因为许多 ESG 因素的影响可能需要较长时间才能充分体现在财务结果中**。

##### ② 在股票分析中的应用 P346

> **在股票分析中，ESG 因素常被用于识别潜在的机会或风险，帮助投资者优选投资标的并减少下行风险**。

> **分析师可以通过调整财务模型变量、进行敏感性分析和情景分析，来评估 ESG 因素对公司财务数据的影响**——例如，**分析师可能会根据可持续信息数据、未来预测和同业比较，对财务报表中的收入、成本、资本支出等项目进行调整**。

**教材示例（员工离职率）**：

> 例如，**对于某服务行业公司，如果其员工离职率过高，分析师可能会更紧密地跟踪该公司的运营效率和顾客满意度**；**若发现导致离职率更高的原因是公司自身治理问题而非运营优化或数字化代替，便会调低收入预期，最终影响公司的利润预期**。

##### ③ 在债券分析中的应用 P346

> **在债券投资分析中，ESG 因素主要被用来评估信用风险**。

> 例如，**在债券估值中，ESG 因素可能会影响信用价差或者信用违约互换的定价**；**在内部信用评估中，ESG 因素可以用于预测财务比率和信用评级**；**如果某公司面临法律诉讼，投资者可能会认为其债券的信用价差会扩大，从而会影响信用违约互换的定价**。

**绿色债券的三个特点**：

> **绿色债券是可持续投资理念的标的之一，它将所募集的资金专门用于支持绿色项目**——**发行人需要向投资人和社会披露募集资金的使用途径及产生的绿色效益**。

| # | 特点 |
|---|---|
| **1**|**用途特定：募集资金专门支持绿色项目** |
| **2**|**额外成本：由于监管机构对绿色债券通常有更高的要求，发行人往往面临额外的监管和报告成本** |
| **3**|**流动性风险：由于绿色债券相较一般债券而言交易量相对较少，投资者需额外考虑其流动性风险** |

#### （九）两类筛选策略详解 P346–P347

##### ① 负面筛选（Negative/Exclusionary Screening） P346

> **负面筛选是指在构建投资组合时剔除那些不符合可持续理念的行业或在可持续发展实践上表现不佳的公司**。

**三类常见标准**：

| 类型 | 举例 |
|---|---|
| **产品类别**|**烟草、武器、化石燃料** |
| **公司行为**|**高碳足迹、腐败、环境污染** |
| **ESG 得分最低标准**|**如排除同行业 ESG 排名最低的 20% 公司** |

> **负面筛选策略实施相对简单，发展时间较长，尤其适用于可持续投资披露和评价标准体系尚未健全的市场环境**。

#### 案例 9-7：多层次负面筛选 P346–P347

> **某欧洲资产管理公司采用多层次的负面筛选策略，并根据产品类型和资产类别进行区分**——例如，**其"目标排除政策"适用于所有主动管理策略，并尽可能适用于被动管理的可持续投资基金**。

**该政策排除的六类公司**：

| # | 排除对象 |
|---|---|
| **1**|**涉及杀伤性武器（如地雷、集束炸弹）、化学武器、生物武器或贫铀武器生产、销售、储存或服务的公司** |
| **2**|**严重、多次违反联合国全球契约十项原则，且未采取可信措施进行整改的公司** |
| **3**|**从事核武器生产、销售或储存的公司，特别是那些位于非核扩散条约缔约国的公司** |
| **4**|**生产完整烟草产品的公司（收入占比超过 5%）** |
| **5**|**正在开发或计划开发新的动力煤项目的公司，以及在热煤采矿和热煤发电中收入占比超过 50% 的公司** |
| **6**|**业务活动中超过 30% 与非常规油气（包括页岩油气和油砂）勘探和生产相关的公司** |

> **该公司的负面筛选策略体现了其对可持续发展和责任投资的承诺，并通过明确的排除标准和阈值，有效降低了投资组合的 ESG 风险**。

##### ② 正面筛选或最优选择（Positive/Best-in-class Screening） P347

> **正面筛选策略是指选择在可持续发展实践中表现优异的行业或公司作为投资对象**。

> **通常，投资者会选择 ESG 得分较高的公司，或设置 ESG 指标的门槛值**；**正向筛选出来的公司通常具有良好的可持续发展价值观和实践表现**；**主动型基金可以通过量化方法选择这些公司，被动型基金则可以投资于采用正向筛选法编制的 ESG 指数**。

**正面筛选的集中风险（重要）**：

> **然而，正面筛选策略可能会带来较为集中的风险敞口**——**有研究表明，信息技术公司、大市值公司和欧洲公司往往具有更高的 ESG 评分，这可能导致采用正面筛选策略的全球资产配置组合超配这些板块，进而带来行业、风格和区域风险的被动集中**。

#### 案例 9-8："同类最佳"的正面筛选流程 P347

> **某欧洲资产管理公司在其"同类最佳"系列基金中采用了正面筛选策略**，其**投资流程** 如下：

| 步骤 | 内容 |
|---|---|
| **① ESG 评级**|**该公司采用内部开发的 ESG 评级体系，对全球超过 6 000 家公司进行 ESG 评级，评级结果分为 A~G 七个等级，得分越高代表可持续发展表现越好** |
| **② 排除筛选**|**排除 ESG 评级为 E、F、G 级的公司**——**这些公司在可持续发展方面存在较高风险或表现不佳** |
| **③ 同业比较**|**将剩余公司的 ESG 评分与其所在行业的平均水平进行比较，筛选出 ESG 表现优于同行的公司** |
| **④ 投资组合构建**|**将筛选出的公司纳入投资组合，并根据其 ESG 评分和财务指标进行权重配置** |

#### （十）负面筛选与正面筛选对比表

| 维度 | **负面筛选**|**正面筛选（最优选择）** |
|---|---|---|
| **做法**|**剔除不符合可持续理念的行业或表现不佳的公司**|**选择可持续发展表现优异的行业或公司** |
| **标准**|**产品类别、公司行为、ESG 得分最低标准**|**ESG 得分较高或设置门槛值** |
| **优势**|**实施相对简单，发展时间较长**|**标的质量较高，价值观导向明确** |
| **风险**|**可能遗漏"转型中"的公司**|**风险敞口集中（超配信息技术、大市值、欧洲公司）** |
| **适用环境**|**尤其适用于披露和评价标准体系尚未健全的市场**|**ESG 数据较丰富、评级体系较成熟的市场** |
| **主动/被动适用**|**两者均可**|**主动型用量化方法；被动型可投 ESG 指数** |

#### 四、易错点清单

1. **相关性只影响组合风险，不影响组合预期收益率**；
2. **ρ = +1 无分散效果；ρ = −1 可构造零风险组合**；
3. **有效前沿只有最小方差前沿的上半部分**（**下半部分同风险下收益更低**）；
4. **有效组合"收益高必然风险大"**；
5. **最优组合 = 无差异曲线与有效前沿的切点**（**不是可行集内部的点**）；
6. **CAL 有无数条，CML 唯一**（**最优 CAL 是相切那条**）；
7. **SML 管定价、适用一切组合；CML 管配置、仅适用有效组合**；
8. **SML 线下方 = 价格高估 + 收益率低估 → 卖出**（**方向易错**）；
9. **比较 α 而非直接比较预期收益率**（**案例 9-3：A 的 13.2% < B 的 15%，但 A 的 α 更大**）；
10. **弱有效 ⇒ 技术分析无效；半强有效 ⇒ 基本面分析无效；强有效 ⇒ 内幕信息也无效**；
11. **跟踪误差是标准差，恒非负；跟踪偏离度可正可负**；
